Docs, skill, AGENTS.md, README, MCP `list_surfaces` and component JSDoc present the library as theme-driven with `style` as one knob (default `solid`) and glass as an opt-in style. Glass-only rules (`backdrop-filter`, `data-ca-blur`, `will-change`) are scoped to a "Glass and frosted styles" section with their wording unchanged. Examples, templates and demo specs no longer pin `material="glass"`. The `liquid-glass` npm keyword is replaced by `theming` and `design-tokens`. No API changes.
