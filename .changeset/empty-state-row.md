`EmptyState size="row"`: one line with a 16 px icon, the text and the optional actions, about one control high, for an empty slot inside a list, a card or a grid of sibling cards (class `ca-empty--row`, inset `--ca-empty-row-padding`). The row's title is text, not a heading, so a column of empty rows adds nothing to the page outline; it stays a `role="status"` named by its title. The EmptyState docs add the rule for collections: repeated empties are grouped into one row, and an empty never takes a whole card in a grid of siblings.
