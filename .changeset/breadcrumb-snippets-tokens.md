Breadcrumb: `separator` also takes a snippet (an icon, drawn `aria-hidden`), `link` renders the anchor of every non-current item so a client router link can be used, and `--ca-breadcrumb-size`, `--ca-breadcrumb-line-height`, `--ca-breadcrumb-tracking` and `--ca-breadcrumb-link-radius` set the type and the link radius. Unset, nothing changes.
