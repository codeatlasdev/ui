Migration tooling for teams moving an existing app onto the library (#383). New commands of `codeatlas-ui`: `tokens import <css|json>` turns the custom properties of an existing design system (hex, `rgb()`, `hsl()` or `oklch()`, with or without alpha, one rule per theme) into a typed `theme.ts` with a preset per theme, composites every translucent token over its background and prints each token it flattened and each text or outline pair under 4.5:1 or 3:1 (`--strict` exits 1); `doctor` checks peer versions, optional peers, theme wiring, viewport meta, a root `font-size`, `TODO(lib#n)` markers and `.ca-*` selectors, one line per finding with a fix hint, and `--fix` renames the markers `workarounds` reads; `lint` is a UI guard that reads `.svelte`, `.astro` and `.css` (no hex, raw px, inline style, `:global(.ca-*)` outside `ui-guard.config.json`, literal text in templates); `compare <urlA> <urlB>` opens two pages in Chromium and prints the elements whose box, computed styles or pixels differ, sorted by deviation. `init --with lint,e2e` writes the guard scripts and a Playwright config with a 390/768/1280 matrix and an axe spec. `migrate` renames the pre-1.0 `NavModule` keys `path`/`sections` to `basePath`/`items` (registry entry `v1-navmodule-basepath-items`). `@codeatlasdev/ui/testing` gains `withTheme({ scheme, preset, style })`, `coarsePointer()` and `measure(el, props)`.
