Element: #104 Closable (display/alert)
What it shows: Two dismissible alerts, an info one with a title and a warning one, that are replaced by a short dismissed note once closed.
When to use: Inline notices the user can dismiss, such as beta-feature banners or storage warnings.
Spec:
- `<Alert severity="info" title="Heads up" closable onclose={() => (closedInfo = true)}>` with beta-feature text
- `<Alert severity="warning" closable onclose={() => (closedWarn = true)}>` with a storage 85% full message, no title
- `let closedInfo = $state(false)` and `let closedWarn = $state(false)` track each alert
- `{#if !closedInfo}` and `{#if !closedWarn}` render the alert, `{:else}` renders a `<p class="dismissed">` note
- Wrapper `.col` has `max-width: 560px`
Tags: alert, closable, dismiss, onclose, notice, severity
Needs: @codeatlasdev/ui@4.1.0
Components: Alert
Live demo: https://ui.codeatlas.com.br/docs/display/alert#closable

<script lang="ts">
  import { Alert } from '@codeatlasdev/ui';

  let closedInfo = $state(false);
  let closedWarn = $state(false);
</script>

<div class="col">
  {#if !closedInfo}
    <Alert severity="info" title="Heads up" closable onclose={() => (closedInfo = true)}>
      This feature is in beta. Some behavior may change.
    </Alert>
  {:else}
    <p class="dismissed">Info alert dismissed.</p>
  {/if}
  {#if !closedWarn}
    <Alert severity="warning" closable onclose={() => (closedWarn = true)}>
      Storage is 85% full. Consider cleaning up old files.
    </Alert>
  {:else}
    <p class="dismissed">Warning alert dismissed.</p>
  {/if}
</div>

<style>
  .col { display: flex; flex-direction: column; gap: var(--ca-space-3); width: 100%; max-width: 560px; }
  .dismissed { margin: 0; font-size: var(--ca-font-size-caption); color: var(--ca-text-hint); font-style: italic; }
</style>
