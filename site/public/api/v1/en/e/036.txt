Element: #036 Horizontal (inputs/radio)
What it shows: Radio group laid out in a row with Small, Medium and Large options.
When to use: Short choice lists of 2 to 4 options, such as a size picker, where a row fits the layout.
Spec:
- `<RadioGroup items={sizes}` with `orientation="horizontal"`
- `sizes` has 3 items: `value: 'sm'`, `value: 'md'`, `value: 'lg'` labelled Small, Medium, Large
- `bind:value={size}` with initial `$state('md')`
Tags: radio-group, radio, horizontal, orientation, size
Needs: @codeatlasdev/ui@4.1.0
Components: RadioGroup
Live demo: https://ui.codeatlas.com.br/docs/inputs/radio#horizontal

<script lang="ts">
  import { RadioGroup } from '@codeatlasdev/ui';

  let size = $state('md');

  const sizes = [
    { value: 'sm', label: 'Small' },
    { value: 'md', label: 'Medium' },
    { value: 'lg', label: 'Large' },
  ];
</script>

<RadioGroup items={sizes} bind:value={size} orientation="horizontal" />
