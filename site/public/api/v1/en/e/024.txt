Element: #024 use:mask action (inputs/masked-field)
What it shows: A native input masked with the mask action, showing the bound value below.
When to use: Adding input masking to a custom or third-party input that is not a MaskedField.
Spec:
- `use:mask={maskCPF}` on a plain `<input` with `bind:value`
- `placeholder="000.000.000-00"` and `inputmode="numeric"`
- `<label class="lbl" for="mask-action-input">` is linked to `id="mask-action-input"`
- Output line prints `value = {value || '–'}`
Tags: mask, action, input-mask, cpf, native-input, forms
Needs: @codeatlasdev/ui@4.1.0
Components: none
Live demo: https://ui.codeatlas.com.br/docs/inputs/masked-field#use-mask-action

<script lang="ts">
  import { mask, maskCPF } from '@codeatlasdev/ui/forms';

  let value = $state('');
</script>

<div class="col">
  <label class="lbl" for="mask-action-input">Plain input with <code>use:mask</code></label>
  <input id="mask-action-input" class="native" use:mask={maskCPF} bind:value placeholder="000.000.000-00" inputmode="numeric" />
  <p class="out">value = {value || '–'}</p>
</div>
