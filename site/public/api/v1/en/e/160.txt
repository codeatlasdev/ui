Element: #160 Basic (navigation/popover)
What it shows: A popover opened from a button, containing a sentence of text and a Confirm button.
When to use: Short contextual help or a quick confirmation anchored to the element that triggered it.
Spec:
- `<Popover>` with `{#snippet triggerChild(props)}<Button {...props}>Open popover</Button>{/snippet}`
- Content is `<Stack gap="3">` with a paragraph and `<Button size="sm" variant="filled">Confirm</Button>`
- Paragraph text: This is a basic popover with some content inside.
Tags: popover, trigger, overlay, confirm, stack, contextual
Needs: @codeatlasdev/ui@4.1.0
Components: Popover, Button, Stack
Live demo: https://ui.codeatlas.com.br/docs/navigation/popover#basic

<script lang="ts">
  import { Popover, Button, Stack } from '@codeatlasdev/ui';
</script>

<Popover>
  {#snippet triggerChild(props)}<Button {...props}>Open popover</Button>{/snippet}
  <Stack gap="3">
    <p class="text">This is a basic popover with some content inside.</p>
    <Button size="sm" variant="filled">Confirm</Button>
  </Stack>
</Popover>

<style>
  .text { margin: 0; font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); }
</style>
