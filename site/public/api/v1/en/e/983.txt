Element: #983 Button addons (inputs/text-field)
What it shows: Two TextFields with a button inside the border: a read-only share link with a copy IconButton and a coupon code with an Apply button.
When to use: A field with its own action: copy a value, apply a code, submit a search, with the button keeping its own name and Tab stop.
Spec:
- `label="Share link" readonly` with `suffix={copyBtn}`: a text-variant small IconButton named "Copy link" ("Link copied" after a click)
- `label="Coupon code"` with `suffix={applyBtn}`: a ghost small Button "Apply", disabled while the field is empty
- The fields are stacked in a column, `max-width: 24rem`, `gap: var(--ca-space-4)`
Tags: input-group, text-field, suffix, addon, button, icon-button, copy, coupon
Needs: @codeatlasdev/ui@4.5.0
Components: Button, IconButton, TextField
Live demo: https://ui.codeatlas.com.br/docs/inputs/text-field#button-addons

<script lang="ts">
  import { Button, IconButton, TextField } from '@codeatlasdev/ui';
  import { Check, Copy } from '@lucide/svelte';

  let copied = $state(false);
  let code = $state('');
</script>

{#snippet copyBtn()}
  <IconButton
    variant="text"
    size="sm"
    aria-label={copied ? 'Link copied' : 'Copy link'}
    onclick={() => { copied = true; }}
  >
    {#if copied}<Check size={14} />{:else}<Copy size={14} />{/if}
  </IconButton>
{/snippet}
{#snippet applyBtn()}
  <Button variant="ghost" size="sm" disabled={!code}>Apply</Button>
{/snippet}

<div class="col">
  <TextField label="Share link" readonly value="https://ca.dev/s/x7Qk" suffix={copyBtn} />
  <TextField label="Coupon code" placeholder="SPRING25" bind:value={code} suffix={applyBtn} />
</div>

<style>
  .col { display: grid; gap: var(--ca-space-4); width: 100%; max-width: 24rem; }
</style>
