Element: #164 Default (navigation/tabs)
What it shows: An uncontrolled tab set of Overview, Props and Examples, each with a short paragraph of documentation text.
When to use: Splitting a detail view into a few peer sections of content without managing state.
Spec:
- `<Tabs value="overview">` sets the initial tab without binding
- `<TabsList>` holds 3 `TabsTrigger` items: `value="overview"`, `value="props"`, `value="examples"`
- Each value has a `TabsContent` with a `<div class="panel">` and one paragraph
- Wrapper is `.wrap` with `max-width: 560px`
Tags: tabs, uncontrolled, tabs-list, tabs-content, sections, default
Needs: @codeatlasdev/ui@4.1.0
Components: Tabs, TabsList, TabsTrigger, TabsContent
Live demo: https://ui.codeatlas.com.br/docs/navigation/tabs#default

<script lang="ts">
  import { Tabs, TabsList, TabsTrigger, TabsContent } from '@codeatlasdev/ui';
</script>

<div class="wrap">
  <Tabs value="overview">
    <TabsList>
      <TabsTrigger value="overview">Overview</TabsTrigger>
      <TabsTrigger value="props">Props</TabsTrigger>
      <TabsTrigger value="examples">Examples</TabsTrigger>
    </TabsList>
    <TabsContent value="overview">
      <div class="panel">
        <p>The <strong>Tabs</strong> component implements the WAI-ARIA tabs pattern. Arrow keys cycle through tabs, Home and End jump to the first and last.</p>
      </div>
    </TabsContent>
    <TabsContent value="props">
      <div class="panel">
        <p>Tabs accepts a <code>value</code> prop for controlled mode and <code>onchange</code> for change notifications. Uncontrolled mode works too.</p>
      </div>
    </TabsContent>
    <TabsContent value="examples">
      <div class="panel">
        <p>Common uses: settings pages, detail views with several data categories, code and preview panes, and stepped forms.</p>
      </div>
    </TabsContent>
  </Tabs>
</div>
