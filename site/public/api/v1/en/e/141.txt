Element: #141 With variants (display/timeline)
What it shows: A Timeline of an order's five tracking events, coloured by variant, with descriptions and timestamps.
When to use: Order, shipment or ticket status trails where completed, in progress and pending steps need different emphasis.
Spec:
- `<Timeline items={events} />`
- 5 events with `label`, `description`, `date` and `variant`; the last, Delivered, has no `description`
- `variant: 'success' as const` on Order created and Payment confirmed
- `variant: 'info' as const` on Picking
- `variant: 'default' as const` on Awaiting shipment and Delivered
- Wrapped in `.wrap` with `max-width: 440px`
Tags: timeline, variant, success, info, order-tracking, status
Needs: @codeatlasdev/ui@4.1.0
Components: Timeline
Live demo: https://ui.codeatlas.com.br/docs/display/timeline#with-variants

<script lang="ts">
  import { Timeline } from '@codeatlasdev/ui';

  const events = [
    { label: 'Order created', description: 'Order #1234 received.', date: 'Today, 14:32', variant: 'success' as const },
    { label: 'Payment confirmed', description: 'Card ending 4242 approved.', date: 'Today, 14:35', variant: 'success' as const },
    { label: 'Picking', description: 'Items are being collected from stock.', date: 'Today, 15:10', variant: 'info' as const },
    { label: 'Awaiting shipment', description: 'Package ready for pickup.', date: 'Today, 16:00', variant: 'default' as const },
    { label: 'Delivered', date: 'Expected tomorrow', variant: 'default' as const },
  ];
</script>

<div class="wrap"><Timeline items={events} /></div>

<style>
  .wrap { max-width: 440px; width: 100%; }
</style>
