Element: #077 Interactive (surfaces/surface)
What it shows: A Surface rendered as a button that counts how many times it was pressed.
When to use: Custom clickable tiles or cards that need hover and press feedback while staying a native button.
Spec:
- `<Surface` with `as="button"`, `type="button"` and `interactive`
- Styling props: `elevation={2}`, `material="solid"`, `radius="md"`, `p="4"`
- Handler: `onclick={() => count++}`
- State: `let count = $state(0)`
- Label: `Pressed {count} times`
Tags: surface, interactive, button, as, onclick, counter
Needs: @codeatlasdev/ui@4.1.0
Components: Surface
Live demo: https://ui.codeatlas.com.br/docs/surfaces/surface#interactive

<script lang="ts">
  import { Surface } from '@codeatlasdev/ui';

  let count = $state(0);
</script>

<Surface
  as="button"
  type="button"
  interactive
  elevation={2}
  material="solid"
  radius="md"
  p="4"
  onclick={() => count++}
>
  Pressed {count} times
</Surface>
