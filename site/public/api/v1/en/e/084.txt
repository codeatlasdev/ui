Element: #084 Confirmation (feedback/dialog)
What it shows: A small dialog asking to delete an item, with Cancel and Delete buttons in the actions snippet.
When to use: Confirming a destructive action when you need custom footer buttons instead of the AlertDialog defaults.
Spec:
- `<Dialog` with `bind:open`, `title="Delete this item?"` and `size="sm"`
- `description=` text says the action cannot be undone
- `{#snippet actions()}` holds `<Button variant="ghost"` Cancel and `<Button variant="destructive"` Delete
- Delete runs `confirmed = true; open = false;` and shows `Item deleted.` with `aria-live="polite"`
- Trigger is `<Button variant="destructive"` with a `<Trash2 size={14} />` icon in `{#snippet leading()}`
Tags: dialog, confirmation, destructive, delete, actions
Needs: @codeatlasdev/ui@4.1.0
Components: Dialog, Button
Live demo: https://ui.codeatlas.com.br/docs/feedback/dialog#confirmation

<script lang="ts">
  import { Dialog, Button } from '@codeatlasdev/ui';
  import { Trash2 } from '@lucide/svelte';

  let open = $state(false);
  let confirmed = $state(false);
</script>

<Button variant="destructive" onclick={() => ((confirmed = false), (open = true))}>
  {#snippet leading()}<Trash2 size={14} />{/snippet}
  Delete item
</Button>

<Dialog
  bind:open
  title="Delete this item?"
  description="This action cannot be undone. The item will be permanently removed from your workspace."
  size="sm"
>
  {#snippet actions()}
    <Button variant="ghost" onclick={() => (open = false)}>Cancel</Button>
    <Button variant="destructive" onclick={() => { confirmed = true; open = false; }}>Delete</Button>
  {/snippet}
</Dialog>

{#if confirmed}<p class="feedback" aria-live="polite">Item deleted.</p>{/if}

<style>
  .feedback { margin: 0; font-size: 13px; color: var(--ca-semantic-error); font-style: italic; }
</style>
