Element: #131 Controlled (display/notification-bell)
What it shows: A NotificationBell whose notifications live in state and are updated by its read, read-all and clear callbacks.
When to use: An app header bell where the app owns the notification list and persists read and cleared state itself.
Spec:
- `let items = $state([` holds 3 notifications with `id`, `title`, `body`, `time` and `read`
- Two items set `variant: 'success' as const` and `variant: 'warning' as const`, the New comment item sets none
- `notifications={items}` passes the list to `NotificationBell`
- `onRead={(id) =>` marks the matching item `read: true`
- `onReadAll={() =>` marks every item as read
- `onClear={() => (items = [])}` empties the list
Tags: notification-bell, notifications, controlled, unread, header, state
Needs: @codeatlasdev/ui@4.1.0
Components: NotificationBell
Live demo: https://ui.codeatlas.com.br/docs/display/notification-bell#controlled

<script lang="ts">
  import { NotificationBell } from '@codeatlasdev/ui';

  let items = $state([
    { id: '1', title: 'Deploy succeeded', body: 'prod-api-v2.4 is live', time: '2m ago', read: false, variant: 'success' as const },
    { id: '2', title: 'New comment', body: 'Ana replied on PR #142', time: '18m ago', read: false },
    { id: '3', title: 'Budget alert', body: '80% of monthly quota used', time: '1h ago', read: true, variant: 'warning' as const },
  ]);
</script>

<NotificationBell
  notifications={items}
  onRead={(id) => (items = items.map((n) => (n.id === id ? { ...n, read: true } : n)))}
  onReadAll={() => (items = items.map((n) => ({ ...n, read: true })))}
  onClear={() => (items = [])}
/>
