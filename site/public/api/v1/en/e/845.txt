Element: #845 Decorative (display/avatar)
What it shows: Avatars next to a visible name, marked decorative so a screen reader says the name once.
When to use: Lists, headers and comment rows where the avatar repeats the name written beside it.
Spec:
- `<Avatar alt={name} size="sm" decorative />` followed by `<span>{name}</span>` in each `<li>`
- People are `Ada Lovelace` and `Grace Hopper` in a `ul` with `list-style: none`
Tags: avatar, decorative, aria-hidden, name, list, a11y
Needs: @codeatlasdev/ui@4.6.0
Components: Avatar
Live demo: https://ui.codeatlas.com.br/docs/display/avatar#decorative

<script lang="ts">
  import { Avatar } from '@codeatlasdev/ui';
</script>

<ul class="people">
  {#each ['Ada Lovelace', 'Grace Hopper'] as name}
    <li>
      <Avatar alt={name} size="sm" decorative />
      <span>{name}</span>
    </li>
  {/each}
</ul>

<style>
  .people { display: grid; gap: var(--ca-space-2); margin: 0; padding: 0; list-style: none; }
  li { display: flex; align-items: center; gap: var(--ca-space-2); }
</style>
