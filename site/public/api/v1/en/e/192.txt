Element: #192 Grouped and stacked (charts/bar)
What it shows: A bar chart with Grouped and Stacked buttons that switch the same two-year quarterly data between layouts.
When to use: Letting users flip between comparing values side by side and seeing the combined total.
Spec:
- `let mode = $state<'grouped' | 'stacked'>('grouped')` drives the layout
- Two `<Button` elements with `size="sm"`, labelled Grouped and Stacked, using `variant={mode === 'grouped' ? 'filled' : 'glass'}` and `variant={mode === 'stacked' ? 'filled' : 'glass'}`
- `onclick={() => (mode = 'grouped')}` and `onclick={() => (mode = 'stacked')}` set the mode
- `<BarChart` with 2 series `'2025'` and `'2026'`, 4 values each
- `categories={['Q1', 'Q2', 'Q3', 'Q4']}`
- `stacked={mode === 'stacked'}` and `height="300px"`
Tags: bar-chart, stacked, grouped, toggle, button, state, flex
Needs: @codeatlasdev/ui@4.1.0 + echarts
Components: Card, Flex, Button, BarChart
Live demo: https://ui.codeatlas.com.br/docs/charts/bar#grouped-and-stacked

<script lang="ts">
  import { Card, Flex, Button } from '@codeatlasdev/ui';
  import { BarChart } from '@codeatlasdev/ui/charts';

  const fmt = (v: number) => `$${(v / 1000).toFixed(0)}k`;
  let mode = $state<'grouped' | 'stacked'>('grouped');
</script>

<div class="wrap">
  <Flex gap="2">
    <Button variant={mode === 'grouped' ? 'filled' : 'glass'} size="sm" onclick={() => (mode = 'grouped')}>Grouped</Button>
    <Button variant={mode === 'stacked' ? 'filled' : 'glass'} size="sm" onclick={() => (mode = 'stacked')}>Stacked</Button>
  </Flex>
  <Card material="glass" full>
    <BarChart
      series={[
        { name: '2025', data: [44200, 58600, 67400, 81200] },
        { name: '2026', data: [52800, 71400, 84600, 98800] },
      ]}
      categories={['Q1', 'Q2', 'Q3', 'Q4']}
      valueFormatter={fmt}
      stacked={mode === 'stacked'}
      height="300px"
    />
  </Card>
</div>

<style>
  .wrap { width: 100%; display: flex; flex-direction: column; gap: var(--ca-space-3); }
</style>
