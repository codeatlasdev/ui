Element: #5031 Soft limit and threshold (inputs/text-area)
What it shows: Two text areas with a character counter: a post with a soft 280-character limit and a report whose count appears only from 400 characters.
When to use: Composers and long-form fields where a length limit matters only near the end.
Spec:
- Post has `counter={{ max: 280 }}` and no `maxlength`: typing may go past 280 and the count turns to the error tone
- Report details has `maxlength={500}` and `counter={{ from: 400 }}`: no count below 400 characters
- Both have `rows={3}` and a description beside the count
- Column wrapper has `max-width: 480px`
Tags: text-area, textarea, counter, maxlength, character count, limit
Needs: @codeatlasdev/ui@4.6.0
Components: TextArea
Live demo: https://ui.codeatlas.com.br/docs/inputs/text-area#soft-limit-and-threshold

<script lang="ts">
  import { TextArea } from '@codeatlasdev/ui';

  let post = $state('Shipping the new release notes today.');
  let report = $state('');
</script>

<div class="col">
  <TextArea
    label="Post"
    description="Posts over 280 characters cannot be sent."
    bind:value={post}
    counter={{ max: 280 }}
    rows={3}
  />
  <TextArea
    label="Report details"
    description="The count appears from 400 characters."
    bind:value={report}
    maxlength={500}
    counter={{ from: 400 }}
    rows={3}
  />
</div>

<style>
  .col {
    display: flex;
    flex-direction: column;
    gap: var(--ca-space-4);
    width: 100%;
    max-width: 480px;
  }
</style>
