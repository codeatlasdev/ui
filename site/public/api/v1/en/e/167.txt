Element: #167 Basic (layout/empty-state)
What it shows: An empty inbox state with an icon, a title, a description and a Compose message button.
When to use: First-run or cleared lists where the user needs a clear next action.
Spec:
- `<EmptyState icon={Inbox} title="No messages yet" description="Your inbox is empty. New messages will appear here.">`
- `{#snippet actions()}` holds `<Button variant="filled" size="sm">Compose message</Button>`
Tags: empty-state, inbox, icon, actions, placeholder
Needs: @codeatlasdev/ui@4.1.0
Components: EmptyState, Button
Live demo: https://ui.codeatlas.com.br/docs/layout/empty-state#basic

<script lang="ts">
  import { EmptyState, Button } from '@codeatlasdev/ui';
  import { Inbox } from '@lucide/svelte';
</script>

<EmptyState icon={Inbox} title="No messages yet" description="Your inbox is empty. New messages will appear here.">
  {#snippet actions()}
    <Button variant="filled" size="sm">Compose message</Button>
  {/snippet}
</EmptyState>
