Element: #5030 Counter and warning tone (inputs/text-field)
What it shows: Two text fields with a character counter: a headline already in the warning tone and a promo code that warns earlier.
When to use: Single-line fields with a length limit where the writer needs to see how much room is left.
Spec:
- Headline has `maxlength={40}`, `counter` and a 37-character value, so the count reads 37/40 in the warning tone
- Promo code has `maxlength={12}` and `counter={{ warnAt: 0.75 }}`: the warning tone starts at 9 characters
- The count sits beside the description and is the field's accessible description; crossing the threshold is announced once
- Column wrapper has `max-width: 400px`
Tags: text-field, counter, maxlength, character count, limit
Needs: @codeatlasdev/ui@4.6.0
Components: TextField
Live demo: https://ui.codeatlas.com.br/docs/inputs/text-field#counter-and-warning-tone

<script lang="ts">
  import { TextField } from '@codeatlasdev/ui';

  let headline = $state('Quarterly report is ready for review');
  let code = $state('');
</script>

<div class="col">
  <TextField
    label="Headline"
    description="Shown on the card."
    bind:value={headline}
    maxlength={40}
    counter
  />
  <TextField label="Promo code" bind:value={code} maxlength={12} counter={{ warnAt: 0.75 }} />
</div>

<style>
  .col {
    display: flex;
    flex-direction: column;
    gap: var(--ca-space-4);
    width: 100%;
    max-width: 400px;
  }
</style>
