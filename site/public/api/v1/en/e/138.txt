Element: #138 Cards on narrow containers (display/table)
What it shows: A SimpleTable that turns each row into a stacked card on narrow screens, listing three users in a flush glass card.
When to use: Data tables that must stay readable on phones without horizontal scrolling.
Spec:
- `<Card material="glass" flush full>` wraps the table
- `<SimpleTable responsive="cards">` with plain `thead` and `tbody`
- Header columns: Name, Email, Role, Status
- 3 rows from `rows` with `name`, `email`, `role`, `status`
- Each cell carries a label such as `data-label="Name"` for the card layout
- The first cell uses `class="primary"`
Tags: table, simple-table, responsive, cards, mobile, data-label
Needs: @codeatlasdev/ui@4.1.0
Components: SimpleTable, Card
Live demo: https://ui.codeatlas.com.br/docs/display/table#cards-on-narrow-containers

<script lang="ts">
  import { SimpleTable, Card } from '@codeatlasdev/ui';

  const rows = [
    { name: 'Ana Souza', email: 'ana@example.com', role: 'Admin', status: 'Active' },
    { name: 'Bruno Lima', email: 'bruno@example.com', role: 'Editor', status: 'Invited' },
    { name: 'Carla Dias', email: 'carla@example.com', role: 'Viewer', status: 'Active' },
  ];
</script>

<Card material="glass" flush full>
  <SimpleTable responsive="cards">
    <thead>
      <tr><th>Name</th><th>Email</th><th>Role</th><th>Status</th></tr>
    </thead>
    <tbody>
      {#each rows as r}
        <tr>
          <td class="primary" data-label="Name">{r.name}</td>
          <td data-label="Email">{r.email}</td>
          <td data-label="Role">{r.role}</td>
          <td data-label="Status">{r.status}</td>
        </tr>
      {/each}
    </tbody>
  </SimpleTable>
</Card>
