Element: #462 Type to confirm (feedback/alert-dialog)
What it shows: A destructive alert dialog with a rich description and a TextField body; Confirm stays disabled until the key is typed.
When to use: Irreversible deletes that need a deliberate confirmation, such as typing the item key.
Spec:
- Trigger `<Button variant="destructive"` labelled `Delete {key}` with a `<Trash2 size={14} />` leading icon; it resets `typed = ''` and opens the dialog
- `<AlertDialog` with `bind:open`, `title="Delete {key}?"`, `confirmLabel="Delete"`, `cancelVariant="outlined"` and `destructive`
- `confirmDisabled={typed !== key}` where `const key = 'PRJ-42'`, and `confirmProps={{ 'data-testid': 'confirm-delete' }}`
- `{#snippet description()}` renders `This removes <strong>3 linked records</strong> too and cannot be undone.`
- Body is `<TextField label="Type {key} to confirm" bind:value={typed} />`
- `onconfirm` sets `deleted = true`, which shows `{key} deleted.` in a `<span class="out" aria-live="polite">`
Tags: alert-dialog, type-to-confirm, confirm-disabled, destructive, children, confirm-props
Needs: @codeatlasdev/ui@4.3.0
Components: AlertDialog, Button, TextField
Live demo: https://ui.codeatlas.com.br/docs/feedback/alert-dialog#type-to-confirm

<script lang="ts">
  import { AlertDialog, Button, TextField } from '@codeatlasdev/ui';
  import { Trash2 } from '@lucide/svelte';

  const key = 'PRJ-42';
  let open = $state(false);
  let typed = $state('');
  let deleted = $state(false);
</script>

<Button variant="destructive" onclick={() => { typed = ''; open = true; }}>
  {#snippet leading()}<Trash2 size={14} />{/snippet}
  Delete {key}
</Button>
{#if deleted}<span class="out" aria-live="polite">{key} deleted.</span>{/if}

<AlertDialog
  bind:open
  title="Delete {key}?"
  confirmLabel="Delete"
  cancelVariant="outlined"
  destructive
  confirmDisabled={typed !== key}
  confirmProps={{ 'data-testid': 'confirm-delete' }}
  onconfirm={() => (deleted = true)}
>
  {#snippet description()}This removes <strong>3 linked records</strong> too and cannot be undone.{/snippet}
  <TextField label="Type {key} to confirm" bind:value={typed} />
</AlertDialog>

<style>
  .out { font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); }
</style>
