Element: #006 Variants (inputs/button)
What it shows: All five button variants in a row: filled, glass, outlined, ghost and destructive.
When to use: Picking the emphasis of an action: filled for primary, outlined or ghost for secondary, destructive for irreversible.
Spec:
- `variant="filled"` labelled Filled
- `variant="glass"` labelled Glass
- `variant="outlined"` labelled Outlined
- `variant="ghost"` labelled Ghost
- `variant="destructive"` labelled Destructive
Tags: button, variant, filled, glass, outlined, ghost, destructive
Needs: @codeatlasdev/ui@4.1.0
Components: Button
Live demo: https://ui.codeatlas.com.br/docs/inputs/button#variants

<script lang="ts">
  import { Button } from '@codeatlasdev/ui';
</script>

<Button variant="glass">Glass</Button>

<Button variant="ghost">Ghost</Button>
<Button variant="destructive">Destructive</Button>
