Element: #073 Default (closed) (surfaces/collapsible)
What it shows: Three independent Collapsible FAQ panels stacked with a small gap, all closed initially.
When to use: Short FAQ or help blocks where each answer expands on its own.
Spec:
- `<Stack gap="2" class="collapsible-faq">` with `max-width: 560px`
- 3 `<Collapsible` items with a `title`: What is a glass surface?, How do presets work?, Is dark mode automatic?
- Each body is a `<p>` child, two of them include a `<code>` token
- Nothing is bound to the open state, each panel manages its own
Tags: collapsible, faq, stack, disclosure, expand, title
Needs: @codeatlasdev/ui@4.1.0
Components: Collapsible, Stack
Live demo: https://ui.codeatlas.com.br/docs/surfaces/collapsible#default-closed

<script lang="ts">
  import { Collapsible, Stack } from '@codeatlasdev/ui';
</script>

<Stack gap="2" class="collapsible-faq">
  <Collapsible title="What is a glass surface?">
    <p>A glass surface uses backdrop-filter blur and a translucent tint to create a layered depth effect that reacts to the content behind it.</p>
  </Collapsible>
  <Collapsible title="How do presets work?">
    <p>Presets remap the brand hue token. Switching preset updates every component that reads from <code>--ca-brand-*</code> without any JS.</p>
  </Collapsible>
  <Collapsible title="Is dark mode automatic?">
    <p>Yes. The <code>colorScheme</code> store writes a <code>.dark</code> class to the root element, which flips all dark-mode tokens.</p>
  </Collapsible>
</Stack>
