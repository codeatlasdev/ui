Element: #169 No icon (layout/empty-state)
What it shows: An empty state without an icon, showing a title, a description and a Create item button with a Plus icon.
When to use: Simple empty lists where an icon adds no meaning and a single create action is enough.
Spec:
- `<EmptyState title="Nothing here yet" description="Create your first item to get started.">` is passed no icon
- `{#snippet actions()}` holds `<Button variant="filled" size="sm">`
- Button has `{#snippet leading()}<Plus size={14} />{/snippet}` and the label Create item
Tags: empty-state, no-icon, create, leading-icon, actions
Needs: @codeatlasdev/ui@4.1.0
Components: EmptyState, Button
Live demo: https://ui.codeatlas.com.br/docs/layout/empty-state#no-icon

<script lang="ts">
  import { EmptyState, Button } from '@codeatlasdev/ui';
  import { Plus } from '@lucide/svelte';
</script>

<EmptyState title="Nothing here yet" description="Create your first item to get started.">
  {#snippet actions()}
    <Button variant="filled" size="sm">
      {#snippet leading()}<Plus size={14} />{/snippet}
      Create item
    </Button>
  {/snippet}
</EmptyState>
