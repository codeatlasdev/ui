Element: #150 longpress (navigation/actions)
What it shows: A native button that fires a long-press handler after an 800ms hold and shows Long press! for 1.5 seconds.
When to use: Touch and desktop shortcuts for secondary actions, such as selecting a row or opening a context menu.
Spec:
- `use:longpress={800}` imported from `@codeatlasdev/ui/actions` on a native `<button`
- `onlongpress={done}` sets `fired = true` and resets it with `setTimeout(() => (fired = false), 1500)`
- Label switches with state: `{fired ? 'Long press!' : 'Press and hold (800ms)'}`
- `let fired = $state(false)`
Tags: longpress, action, touch, gesture, button, hold
Needs: @codeatlasdev/ui@4.1.0
Components: none
Live demo: https://ui.codeatlas.com.br/docs/navigation/actions#longpress

<script lang="ts">
  import { longpress } from '@codeatlasdev/ui/actions';

  let fired = $state(false);
  function done() {
    fired = true;
    setTimeout(() => (fired = false), 1500);
  }
</script>

<button use:longpress={800} onlongpress={done} class="btn">
  {fired ? 'Long press!' : 'Press and hold (800ms)'}
</button>
