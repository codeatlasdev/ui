Element: #048 Custom colors (inputs/swatch-group)
What it shows: Swatch group with four custom colors where one swatch is disabled.
When to use: Letting users pick a label or tag color from a fixed palette.
Spec:
- `<SwatchGroup` with `size="sm"` and `aria-label="Label color"` and `bind:value={color}`
- Items set `value`, `label` and `color`: Blue `#2563eb`, Green `#16a34a`, Red `#dc2626`, Purple `#9333ea`
- Purple has `disabled: true`
- Initial value is `$state('#2563eb')`
- Current value is shown as `value: {color}`
Tags: swatch-group, color-picker, custom, palette, disabled
Needs: @codeatlasdev/ui@4.1.0
Components: SwatchGroup
Live demo: https://ui.codeatlas.com.br/docs/inputs/swatch-group#custom-colors

<script lang="ts">
  import { SwatchGroup } from '@codeatlasdev/ui';

  let color = $state('#2563eb');
</script>

<div class="col">
  <SwatchGroup
    size="sm"
    aria-label="Label color"
    bind:value={color}
    items={[
      { value: '#2563eb', label: 'Blue', color: '#2563eb' },
      { value: '#16a34a', label: 'Green', color: '#16a34a' },
      { value: '#dc2626', label: 'Red', color: '#dc2626' },
      { value: '#9333ea', label: 'Purple', color: '#9333ea', disabled: true },
    ]}
  />
  <p class="out">value: {color}</p>
</div>

<style>

    display: flex;
    flex-direction: column;
    gap: var(--ca-space-3);
  }

  .out {
    margin: 0;
    font-size: var(--ca-font-size-caption);
    color: var(--ca-text-secondary);
  }
</style>
