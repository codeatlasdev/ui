Element: #128 srcset and sizes (display/image)
What it shows: An Image with a two-rendition `srcset` (400w and 800w) and a `sizes` hint, in a 420px wrapper.
When to use: Responsive content images where the browser should pick the smaller file on narrow screens.
Spec:
- `srcset={`${small} 400w, ${large} 800w`}` lists two renditions
- `sizes="(min-width: 768px) 420px, 100vw"`
- `src={large}` with `width={800}` and `height={450}`
- `alt="Two renditions of the same 16 by 9 picture"`
- Wrapper is `<div style="max-width: 420px">`
Tags: image, srcset, sizes, responsive, alt, width
Needs: @codeatlasdev/ui@4.1.0
Components: Image
Live demo: https://ui.codeatlas.com.br/docs/display/image#srcset-and-sizes

<script lang="ts">
  import { Image } from '@codeatlasdev/ui';

  const svg = (w: number, h: number, c: string) =>
    "data:image/svg+xml;utf8," +
    encodeURIComponent(`<svg xmlns='http://www.w3.org/2000/svg' width='${w}' height='${h}'><rect width='${w}' height='${h}' fill='${c}'/></svg>`);
  const small = svg(400, 225, '#2b5fd9');
  const large = svg(800, 450, '#1a7a50');
</script>

<div style="max-width: 420px">
  <Image
    src={large}
    srcset={`${small} 400w, ${large} 800w`}
    sizes="(min-width: 768px) 420px, 100vw"
    alt="Two renditions of the same 16 by 9 picture"
    width={800}
    height={450}
  />
</div>
