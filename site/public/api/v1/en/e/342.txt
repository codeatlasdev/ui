Element: #342 Morphing toggle (motion/micro)
What it shows: A sun icon that morphs into a moon: a mask circle slides over the disc to bite it into a crescent while the rays rotate and shrink away.
When to use: Theme switch, mute toggle or any two-state icon button where the icon itself should show the state change.
Spec:
- `MotionStage` from `@codeatlasdev/ui` with `loop={2400}`
- `role="switch"` with `aria-checked={dark}` and `aria-label="Dark mode"`
- `<mask id="{uid}-bite">` holds a black `circle` that `.tg__bite` moves from `translate(10px, -10px)` to `translate(0, 0)`
- `.tg__btn--dark .tg__rays` goes to `transform: rotate(45deg) scale(0.4)` and `opacity: 0`
- `.tg__btn--dark .tg__icon` rotates to `transform: rotate(-35deg)`
- `.tg__btn--still` sets `transition: none` under reduced motion
Motion:
- transform (bite mask, icon rotation, rays), opacity (rays): 420ms cubic-bezier(0.2, 0, 0, 1)
- opacity (rays): 280ms cubic-bezier(0.2, 0, 0, 1)
Names: Morphing toggle | Icon morph | Toggle com morph | Bascule animée
Tags: motion, toggle, morph, icon, theme, switch
Needs: @codeatlasdev/ui@4.3.0
Components: MotionStage
Live demo: https://ui.codeatlas.com.br/docs/motion/micro#morphing-toggle

<script lang="ts">
  import { MotionStage } from '@codeatlasdev/ui';

  const uid = $props.id();
  let dark = $state(false);

  // Autoplay flips the switch once per cycle.
  const flip = (node: HTMLElement) => {
    const t = setTimeout(() => (dark = !dark), 700);
    return () => clearTimeout(t);
  };
</script>

<MotionStage label="Morphing toggle: a sun morphs into a moon" loop={2400}>
  {#snippet children(m)}
    {#key m.cycle}
      <div class="tg" {@attach (node) => (m.playing && !m.reduced ? flip(node) : undefined)}>
        <button
          type="button"
          role="switch"
          aria-checked={dark}
          aria-label="Dark mode"
          class="tg__btn"
          class:tg__btn--dark={dark}
          class:tg__btn--still={m.reduced}
          onclick={() => (dark = !dark)}
        >
          <svg viewBox="0 0 24 24" class="tg__icon" aria-hidden="true">
            <!-- The sun's disc: a mask circle slides in and bites it into a crescent. -->
            <mask id="{uid}-bite">
              <rect width="24" height="24" fill="white" />
              <circle class="tg__bite" cx="17" cy="7" r="7" fill="black" />
            </mask>
            <circle class="tg__disc" cx="12" cy="12" r="6" mask={`url(#${uid}-bite)`} />
            <g class="tg__rays">
              {#each [0, 45, 90, 135, 180, 225, 270, 315] as a}
                <line x1="12" y1="2" x2="12" y2="4.5" transform="rotate({a} 12 12)" />
              {/each}
            </g>
          </svg>
        </button>
        <p class="tg__label">{dark ? 'Dark' : 'Light'} appearance</p>
      </div>
    {/key}
  {/snippet}
</MotionStage>
