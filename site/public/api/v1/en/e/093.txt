Element: #093 Determinate (feedback/progress)
What it shows: Four determinate progress bars at 25, 50, 75 and 100 percent, each with a percent label.
When to use: Showing known completion, such as quota used or onboarding steps done.
Spec:
- `{#each [25, 50, 75, 100] as v}` renders one row per value
- `<Progress value={v} label="{v} percent" />` gives each bar an accessible label
- Text `{v}%` shown beside each bar
- Column has `max-width: 480px`
Tags: progress, determinate, value, percent, label
Needs: @codeatlasdev/ui@4.1.0
Components: Progress
Live demo: https://ui.codeatlas.com.br/docs/feedback/progress#determinate

<script lang="ts">
  import { Progress } from '@codeatlasdev/ui';
</script>

<div class="col">
  {#each [25, 50, 75, 100] as v}
    <div class="row">
      <span class="label">{v}%</span>
      <Progress value={v} label="{v} percent" />
    </div>
  {/each}
</div>
