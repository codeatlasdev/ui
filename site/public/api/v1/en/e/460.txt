Element: #460 Line (navigation/tabs)
What it shows: Tabs with variant="line": bare text tabs with an underline on the active one, used as a view switcher with no panels.
When to use: Page headers and view switchers where the tabs change what the page shows, not a panel under the list.
Spec:
- `<Tabs bind:value={view} variant="line">` with `<TabsList aria-label="View">`
- 3 triggers: `board`, `list`, `timeline`, each with a `data-testid` forwarded to the button
- No `TabsContent`: triggers carry no `aria-controls`
- A line below the tabs reads `Showing the {view} view.`
- Wrapper is `.wrap` with `max-width: 420px`
Tags: tabs, line, variant, view-switcher, aria-label, tabs-list
Needs: @codeatlasdev/ui@4.3.0
Components: Tabs, TabsList, TabsTrigger
Live demo: https://ui.codeatlas.com.br/docs/navigation/tabs#line

<script lang="ts">
  import { Tabs, TabsList, TabsTrigger } from '@codeatlasdev/ui';

  let view = $state('board');
</script>

<div class="wrap">
  <!-- View switcher: no TabsContent, so no aria-controls points at a missing panel. -->
  <Tabs bind:value={view} variant="line">
    <TabsList aria-label="View">
      <TabsTrigger value="board" data-testid="view-board">Board</TabsTrigger>
      <TabsTrigger value="list" data-testid="view-list">List</TabsTrigger>
      <TabsTrigger value="timeline" data-testid="view-timeline">Timeline</TabsTrigger>
    </TabsList>
  </Tabs>
  <p class="out">Showing the {view} view.</p>
</div>

<style>
  .wrap { width: 100%; max-width: 420px; }
  .out { margin: 16px 0 0; font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); }
</style>
