Element: #233 CodeTabs (docs-kit/docs)
What it shows: Two CodeTabs groups, each with cURL and Node.js tabs, that share the selected language through the same sync key.
When to use: API docs that show the same request in several languages and keep the choice in sync across the page.
Spec:
- Two `<CodeTabs sync="demo-lang">` blocks use the same sync key
- Each group has `<CodeTab label="cURL">` and `<CodeTab label="Node.js">`
- Tab content is `<div class="ca-code"><pre><code>` rendering a string constant such as `{curl}` or `{node}`
- First group sends a POST to messages/text, second group lists sessions with `{curlList}` and `{nodeList}`
- Wrapped in `<div class="ca-prose wrap">`
Tags: code-tabs, code-tab, docs-kit, sync, curl, api-docs
Needs: @codeatlasdev/ui@4.1.0
Components: CodeTab, CodeTabs
Live demo: https://ui.codeatlas.com.br/docs/docs-kit/docs#codetabs

<script lang="ts">
  import { CodeTab, CodeTabs } from '@codeatlasdev/ui';

  const curl = `curl -X POST https://api.example.com/messages/text \\
  -H "x-api-key: YOUR_API_KEY" \\
  -H "x-instance: my-session" \\
  -d '{"to":"5511999990000","text":"Hello"}'`;
  const node = `await fetch("https://api.example.com/messages/text", {
  method: "POST",
  headers: { "x-api-key": process.env.API_KEY, "x-instance": "my-session" },
  body: JSON.stringify({ to: "5511999990000", text: "Hello" }),
});`;
  const curlList = `curl https://api.example.com/sessions -H "x-api-key: YOUR_API_KEY"`;
  const nodeList = `await fetch("https://api.example.com/sessions", { headers: { "x-api-key": KEY } });`;
</script>

<div class="ca-prose wrap">
  <CodeTabs sync="demo-lang">
    <CodeTab label="cURL">
      <div class="ca-code"><pre><code>{curl}</code></pre></div>
    </CodeTab>
    <CodeTab label="Node.js">
      <div class="ca-code"><pre><code>{node}</code></pre></div>
    </CodeTab>
  </CodeTabs>
  <CodeTabs sync="demo-lang">
    <CodeTab label="cURL">
      <div class="ca-code"><pre><code>{curlList}</code></pre></div>
    </CodeTab>
    <CodeTab label="Node.js">
      <div class="ca-code"><pre><code>{nodeList}</code></pre></div>
    </CodeTab>
  </CodeTabs>
</div>
