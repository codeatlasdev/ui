Element: #170 No results (layout/empty-state)
What it shows: A no-results state for search with a magnifier icon and a Clear filters button.
When to use: Search and filter screens where the query matched nothing and the user should reset it.
Spec:
- `<EmptyState icon={Search} title="No results found" description="Try adjusting your search terms or filters.">`
- `{#snippet actions()}` holds `<Button variant="outlined" size="sm">Clear filters</Button>`
Tags: empty-state, no-results, search, filters, actions
Needs: @codeatlasdev/ui@4.1.0
Components: EmptyState, Button
Live demo: https://ui.codeatlas.com.br/docs/layout/empty-state#no-results

<script lang="ts">
  import { EmptyState, Button } from '@codeatlasdev/ui';
  import { Search } from '@lucide/svelte';
</script>

<EmptyState icon={Search} title="No results found" description="Try adjusting your search terms or filters.">
  {#snippet actions()}
    <Button variant="outlined" size="sm">Clear filters</Button>
  {/snippet}
</EmptyState>
