Element: #096 Swipe to dismiss (feedback/sheet)
What it shows: A sheet titled Switch session with a description and a list of eight accounts that close it on click.
When to use: Mobile account or option pickers that slide up and can be dragged down to dismiss.
Spec:
- `<Sheet bind:open title="Switch session" description="Choose the active account">`
- `const accounts` has 8 entries, Account A to Account H, rendered by `{#each accounts as acc}`
- Each item is `<button class="item" onclick={() => (open = false)}>` inside `<Stack gap="1">`
- Trigger is `<Button variant="outlined"` labelled Open sheet
Tags: sheet, swipe, bottom-sheet, account-switcher, list, mobile
Needs: @codeatlasdev/ui@4.1.0
Components: Sheet, Button, Stack
Live demo: https://ui.codeatlas.com.br/docs/feedback/sheet#swipe-to-dismiss

<script lang="ts">
  import { Sheet, Button, Stack } from '@codeatlasdev/ui';

  let open = $state(false);
  const accounts = ['Account A', 'Account B', 'Account C', 'Account D', 'Account E', 'Account F', 'Account G', 'Account H'];
</script>

<Button variant="outlined" onclick={() => (open = true)}>Open sheet</Button>

<Sheet bind:open title="Switch session" description="Choose the active account">
  <Stack gap="1">
    {#each accounts as acc}
      <button class="item" onclick={() => (open = false)}>{acc}</button>
    {/each}
  </Stack>
</Sheet>

  }
  .item:hover { background: var(--ca-action-hover); }
</style>
