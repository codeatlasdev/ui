Element: #097 Card layout (feedback/skeleton)
What it shows: A glass card skeleton with a circular avatar placeholder beside three text lines of different widths.
When to use: Loading placeholder for a profile or list card so layout does not jump when data arrives.
Spec:
- `<Card material="glass" p="5" full>`
- `<Skeleton variant="circular" width="48px" height="48px" />` inside `<Flex gap="4" align="start">`
- Three lines in `<Stack gap="2">`: `height="16px" width="40%"`, `height="13px" width="70%"`, `height="13px" width="55%"`
Tags: skeleton, card, loading, avatar, placeholder
Needs: @codeatlasdev/ui@4.1.0
Components: Skeleton, Card, Stack, Flex
Live demo: https://ui.codeatlas.com.br/docs/feedback/skeleton#card-layout

<script lang="ts">
  import { Skeleton, Card, Stack, Flex } from '@codeatlasdev/ui';
</script>

<Card material="glass" p="5" full>
  <Flex gap="4" align="start">
    <Skeleton variant="circular" width="48px" height="48px" />
    <Stack gap="2">
      <Skeleton height="16px" width="40%" />
      <Skeleton height="13px" width="70%" />
      <Skeleton height="13px" width="55%" />
    </Stack>
  </Flex>
</Card>
