Element: #112 Colors (display/badge)
What it shows: A notification bell icon button wrapped in a count badge, shown in the four badge colors.
When to use: Telling apart badge meaning on a counter: brand, success, warning and error.
Spec:
- `<Flex gap="4" align="center" wrap>` wraps four badges
- Each is a `<Badge count={5}` around `<IconButton aria-label="Notifications">` with a `<Bell size={20} />`
- `color="brand"`, `color="success"`, `color="warning"` and `color="error"` are the four variants
Tags: badge, color, count, icon-button, notification, flex
Needs: @codeatlasdev/ui@4.1.0
Components: Badge, IconButton, Flex
Live demo: https://ui.codeatlas.com.br/docs/display/badge#colors

<script lang="ts">
  import { Badge, IconButton, Flex } from '@codeatlasdev/ui';
  import { Bell } from '@lucide/svelte';
</script>

<Flex gap="4" align="center" wrap>
  <Badge count={5} color="brand"><IconButton aria-label="Notifications"><Bell size={20} /></IconButton></Badge>
  <Badge count={5} color="success"><IconButton aria-label="Notifications"><Bell size={20} /></IconButton></Badge>
  <Badge count={5} color="warning"><IconButton aria-label="Notifications"><Bell size={20} /></IconButton></Badge>
  <Badge count={5} color="error"><IconButton aria-label="Notifications"><Bell size={20} /></IconButton></Badge>
</Flex>
