Element: #965 Several per view (display/carousel)
What it shows: Five plan cards shown three at a time in a looping carousel.
When to use: Card rows that overflow: pricing tiers, related products, team members.
Spec:
- `<Carousel label="Plans" perView={3} loop>` over five names
- Each card is `<CarouselItem><div class="card">{name}</div></CarouselItem>`
- `cards` is `['Starter', 'Team', 'Business', 'Enterprise', 'Partner']`
Tags: carousel, per-view, loop, cards, scroll-snap
Needs: @codeatlasdev/ui@4.6.0
Components: Carousel, CarouselItem
Live demo: https://ui.codeatlas.com.br/docs/display/carousel#several-per-view

<script lang="ts">
  import { Carousel, CarouselItem } from '@codeatlasdev/ui';

  const cards = ['Starter', 'Team', 'Business', 'Enterprise', 'Partner'];
</script>

<div class="frame">
  <Carousel label="Plans" perView={3} loop>
    {#each cards as name (name)}
      <CarouselItem><div class="card">{name}</div></CarouselItem>
    {/each}
  </Carousel>
</div>
