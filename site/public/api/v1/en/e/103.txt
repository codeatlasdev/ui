Element: #103 Variants and duration (feedback/toast)
What it shows: Eight buttons that trigger toasts: five variants and three duration cases, with one Toaster mounted.
When to use: Non-blocking feedback after an action, such as saved, failed or an available update.
Spec:
- `<Toaster />` mounted once, toasts fired with `toast` from `@codeatlasdev/ui`
- Variants: `toast.show(`, `toast.success(`, `toast.error(`, `toast.warning(` and `toast.info(` with a message string
- Persistent: `{ variant: 'info', duration: 0 }` passed as second argument of `toast.show(`
- Timed: `toast.success('Gone in 1 second.', 1000)` and `toast.info('Stays for 8 seconds.', 8000)`
- All triggers are `<Button variant="outlined"` in two labelled groups, Variants and Duration
Tags: toast, toaster, notification, success, error, duration
Needs: @codeatlasdev/ui@4.1.0
Components: Button, Toaster
Live demo: https://ui.codeatlas.com.br/docs/feedback/toast#variants-and-duration

<script lang="ts">
  import { Button, Toaster, toast } from '@codeatlasdev/ui';
</script>

<Toaster />

<div class="group">
  <p class="label">Variants</p>
  <div class="row">
    <Button variant="outlined" onclick={() => toast.show('This is a default notification.')}>Default</Button>
    <Button variant="outlined" onclick={() => toast.success('Changes saved successfully.')}>Success</Button>
    <Button variant="outlined" onclick={() => toast.error('Something went wrong. Please try again.')}>Error</Button>
    <Button variant="outlined" onclick={() => toast.warning('Your session expires in 5 minutes.')}>Warning</Button>
    <Button variant="outlined" onclick={() => toast.info('A new version is available.')}>Info</Button>
  </div>
</div>

<div class="group">
  <p class="label">Duration</p>
  <div class="row">
    <Button variant="outlined" onclick={() => toast.show('This will not auto-dismiss.', { variant: 'info', duration: 0 })}>
      Persistent (duration 0)
    </Button>
    <Button variant="outlined" onclick={() => toast.success('Gone in 1 second.', 1000)}>1 s</Button>
    <Button variant="outlined" onclick={() => toast.info('Stays for 8 seconds.', 8000)}>8 s</Button>
  </div>
</div>
