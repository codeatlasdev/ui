Element: #058 States (inputs/text-field)
What it shows: Six text fields showing description, error, required, read-only, disabled and small size.
When to use: Reference for validation and availability states of a single-line input.
Spec:
- Username has `description="3–20 characters, letters and underscores only."`
- Email has `error="Please enter a valid email address."` and `bind:value={wrong}`
- Company has `required`
- Read-only field uses `readonly` and Disabled field uses `disabled`, both `value="Cannot edit this"`
- Small field uses `size="sm"`
Tags: text-field, error, required, readonly, disabled, size, description
Needs: @codeatlasdev/ui@4.1.0
Components: TextField
Live demo: https://ui.codeatlas.com.br/docs/inputs/text-field#states

<script lang="ts">
  import { TextField } from '@codeatlasdev/ui';

  let wrong = $state('wrong@');
</script>

<div class="col">
  <TextField label="Username" placeholder="john_doe" description="3–20 characters, letters and underscores only." />
  <TextField label="Email" bind:value={wrong} error="Please enter a valid email address." />
  <TextField label="Company" required />
  <TextField label="Read-only field" value="Cannot edit this" readonly />
  <TextField label="Disabled field" value="Cannot edit this" disabled />
  <TextField label="Small" size="sm" placeholder="Compact height" />
</div>
