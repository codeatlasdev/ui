Element: #942 File menu (navigation/context-menu)
What it shows: A dashed file area that opens a Rename, Pinned, Move to and Delete menu at the pointer on right-click, at the finger on a long touch press, or from the keyboard with Shift+F10.
When to use: Context menus on rows, files or canvases that reuse the DropdownMenu items, including checkbox items and submenus, without wiring any event handler.
Spec:
- `<ContextMenu class="cm-area" role="group" aria-label="Project file">` wraps the region content and takes the items in a `{#snippet menu()}`
- The menu holds `DropdownMenuItem`, a `<DropdownMenuCheckboxItem bind:checked={pinned}>`, a `DropdownMenuSub` with `DropdownMenuSubTrigger`, a `DropdownMenuSeparator` and a destructive Delete
- Each action item calls `function pick(action: string)`, which sets `last` and calls `announce`
- Pinned (yes or no) and the last action are shown below the area
Tags: context-menu, right-click, long-press, keyboard, dropdown-menu, submenu
Needs: @codeatlasdev/ui@4.6.0
Components: ContextMenu, DropdownMenuCheckboxItem, DropdownMenuItem, DropdownMenuSeparator, DropdownMenuSub, DropdownMenuSubTrigger
Live demo: https://ui.codeatlas.com.br/docs/navigation/context-menu#file-menu

<script lang="ts">
  import {
    announce,
    ContextMenu,
    DropdownMenuCheckboxItem,
    DropdownMenuItem,
    DropdownMenuSeparator,
    DropdownMenuSub,
    DropdownMenuSubTrigger,
  } from '@codeatlasdev/ui';

  let last = $state('');
  let pinned = $state(false);

  function pick(action: string) {
    last = action;
    announce(`Last action: ${action}`);
  }
</script>

<div class="cm-file">
<ContextMenu class="cm-area" role="group" aria-label="Project file">
  <span>quarterly-report.pdf. Right-click, long-press, or focus it and press Shift+F10.</span>
  {#snippet menu()}
    <DropdownMenuItem onclick={() => pick('Rename')}>Rename</DropdownMenuItem>
    <DropdownMenuCheckboxItem bind:checked={pinned}>Pinned</DropdownMenuCheckboxItem>
    <DropdownMenuSub>
      {#snippet trigger()}<DropdownMenuSubTrigger>Move to</DropdownMenuSubTrigger>{/snippet}
      <DropdownMenuItem onclick={() => pick('Move to Archive')}>Archive</DropdownMenuItem>
      <DropdownMenuItem onclick={() => pick('Move to Shared')}>Shared</DropdownMenuItem>
    </DropdownMenuSub>
    <DropdownMenuSeparator />
    <DropdownMenuItem variant="destructive" onclick={() => pick('Delete')}>Delete</DropdownMenuItem>
  {/snippet}
</ContextMenu>
</div>

<span class="note">Pinned: {pinned ? 'yes' : 'no'}{last ? `. Last action: ${last}` : ''}</span>
