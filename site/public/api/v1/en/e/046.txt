Element: #046 Single value (inputs/slider)
What it shows: Two single-value sliders, Volume and Brightness, each with a live readout.
When to use: Adjusting a continuous setting such as volume or brightness.
Spec:
- Volume: `<Slider bind:value={volume} min={0} max={100} />` with initial `$state(60)`
- Brightness: `<Slider bind:value={brightness} min={0} max={100} />` with initial `$state(40)`
- Readouts are `{volume}` and `{brightness}%`
- Wrapper `.col` uses `max-width: 480px`
Tags: slider, single, volume, brightness, bind-value
Needs: @codeatlasdev/ui@4.1.0
Components: Slider
Live demo: https://ui.codeatlas.com.br/docs/inputs/slider#single-value

<script lang="ts">
  import { Slider } from '@codeatlasdev/ui';

  let volume = $state(60);
  let brightness = $state(40);
</script>

<div class="col">
  <div class="row">
    <span class="label">Volume</span>
    <Slider bind:value={volume} min={0} max={100} />
    <span class="val">{volume}</span>
  </div>
  <div class="row">
    <span class="label">Brightness</span>
    <Slider bind:value={brightness} min={0} max={100} />
    <span class="val">{brightness}%</span>
  </div>
</div>
