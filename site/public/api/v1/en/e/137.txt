Element: #137 Vertical scroll (display/scroll-area)
What it shows: A vertical ScrollArea capped at 220px tall containing 20 Lorem ipsum rows inside a glass card.
When to use: Bounded panels such as activity logs or long option lists that scroll inside a fixed height.
Spec:
- `<Card material="glass" full>` wraps the area
- `<ScrollArea maxHeight="220px">`
- `Array.from({ length: 20 }, (_, i) =>` builds items labelled Item 1 to Item 20: Lorem ipsum dolor sit amet
- Each row is a `<div class="item">` rendered with `{#each items as item}`
Tags: scroll-area, vertical, max-height, scrollbar, card, list
Needs: @codeatlasdev/ui@4.1.0
Components: ScrollArea, Card
Live demo: https://ui.codeatlas.com.br/docs/display/scroll-area#vertical-scroll

<script lang="ts">
  import { ScrollArea, Card } from '@codeatlasdev/ui';

  const items = Array.from({ length: 20 }, (_, i) => `Item ${i + 1}: Lorem ipsum dolor sit amet`);
</script>

<Card material="glass" full>
  <ScrollArea maxHeight="220px">
    {#each items as item}
      <div class="item">{item}</div>
    {/each}
  </ScrollArea>
</Card>

<style>
  .item {
    padding: 10px 16px;
    font-size: var(--ca-font-size-body2);
    color: var(--ca-text-secondary);
    border-bottom: 1px solid var(--ca-outline-subtle);
  }
  .item:last-child { border-bottom: none; }
</style>
