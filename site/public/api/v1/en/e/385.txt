Element: #385 Hero intro sequence (motion/hero-ambient)
What it shows: A hero block whose eyebrow, headline, copy and buttons enter one after another, each rising 14px and fading in, 90ms apart.
When to use: The first screen of a landing page or the header of a feature page. The static first frame is already complete, so no content is hidden for crawlers or slow scripts.
Spec:
- `MotionStage` with `loop={4200}`; `{#key m.cycle}` remounts the block so the sequence replays
- Each child gets `--i` (0 to 3) and `animation: intro-in 520ms cubic-bezier(0.2, 0, 0, 1) calc(var(--i) * 90ms) both`
- Keyframes: `from { opacity: 0; transform: translateY(14px); }` to `to { opacity: 1; transform: translateY(0); }`
- `class:intro--run={m.playing && m.cycle > 0}`: server HTML, reduced motion and a taken-over demo render the finished layout with no animation
Motion:
- opacity, transform: translateY: 520ms cubic-bezier(0.2, 0, 0, 1) stagger 90ms
Names: Hero intro sequence | Staggered hero entrance | Headline and CTA intro | Intro escalonada do hero | Entrada em sequência do hero | Séquence d'entrée du hero

<script lang="ts">
  import { Button, MotionStage } from '@codeatlasdev/ui';
</script>

<MotionStage label="Hero intro: eyebrow, headline, copy and buttons enter one after another" loop={4200}>
  {#snippet children(m)}
    <!-- Keyed on the cycle: a new cycle mounts fresh nodes, so every delay restarts. The static
         first frame (server HTML, reduced motion) is the finished layout: nothing starts hidden. -->
    {#key m.cycle}
      <section class="intro" class:intro--run={m.playing && m.cycle > 0}>
        <p class="intro__eyebrow" style="--i:0">New in 4.2</p>
        <h3 class="intro__title" style="--i:1">Ship the dashboard your team asked for</h3>
        <p class="intro__lead" style="--i:2">Pick a page, hand the number to your AI, review the pull request.</p>
        <div class="intro__cta" style="--i:3">
          <Button>Open the gallery</Button>
          <Button variant="outlined">Read the docs</Button>
        </div>
      </section>
    {/key}
  {/snippet}
</MotionStage>
