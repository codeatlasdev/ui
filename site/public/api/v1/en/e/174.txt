Element: #174 Without header (layout/form-page)
What it shows: A compact form page with no title or description, one section and a Cancel and Save footer.
When to use: Quick edit forms embedded in a larger page that already provides its own heading.
Spec:
- `<AppForm>` is used with no title or description
- `<FormSection title="Quick update">` holds `<TextField label="Name" placeholder="Enter name…" />` and `<TextField label="Email" type="email" placeholder="email@example.com" />`
- `{#snippet footer()}` holds `<Button variant="ghost">Cancel</Button>` and `<Button variant="filled">Save</Button>`
Tags: app-form, form-section, form, no-header, text-field, footer
Needs: @codeatlasdev/ui@4.1.0
Components: AppForm, FormSection, TextField, Button
Live demo: https://ui.codeatlas.com.br/docs/layout/form-page#without-header

<script lang="ts">
  import { AppForm, FormSection, TextField, Button } from '@codeatlasdev/ui';
</script>

<div class="frame">
  <AppForm>
    <FormSection title="Quick update">
      <TextField label="Name" placeholder="Enter name…" />
      <TextField label="Email" type="email" placeholder="email@example.com" />
    </FormSection>
    {#snippet footer()}
      <Button variant="ghost">Cancel</Button>
      <Button variant="filled">Save</Button>
    {/snippet}
  </AppForm>
</div>
