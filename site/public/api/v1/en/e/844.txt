Element: #844 Boot (feedback/splash-screen)
What it shows: A button that boots a fake app: the splash shows at least 800ms, waits for ready, then leaves and reports ondone.
When to use: App shells that load a session or data before the first screen and must not flash the splash.
Spec:
- `<SplashScreen {ready} minDuration={800} ondone={() => seen++}>` with a `logo` snippet holding `<strong class="mark">Acme</strong>`
- `start()` sets `ready = false`, bumps `boot` and sets `ready = true` after `1200` ms
- Wrapped in `{#key boot}` and rendered only once `boot > 0`
- A caption shows `Splash screens shown: {seen}`
Tags: splash-screen, boot, loading, min-duration, reduced-motion, status
Needs: @codeatlasdev/ui@4.6.0
Components: Button, SplashScreen
Live demo: https://ui.codeatlas.com.br/docs/feedback/splash-screen#boot

<script lang="ts">
  import { Button, SplashScreen } from '@codeatlasdev/ui';

  let boot = $state(0);
  let ready = $state(false);
  let seen = $state(0);

  function start() {
    ready = false;
    boot++;
    setTimeout(() => (ready = true), 1200);
  }
</script>

<Button variant="outlined" size="sm" onclick={start}>Boot the app</Button>
<p class="note">Splash screens shown: {seen}</p>

{#key boot}
  {#if boot > 0}
    <SplashScreen {ready} minDuration={800} ondone={() => seen++}>
      {#snippet logo()}<strong class="mark">Acme</strong>{/snippet}
    </SplashScreen>
  {/if}
{/key}

<style>

</style>
