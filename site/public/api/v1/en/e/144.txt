Element: #144 On icon buttons (display/tooltip)
What it shows: Four icon-only buttons (Info, Heart, Zap, Star) that each reveal a Tooltip describing the action.
When to use: Icon-only toolbar actions that need a visible text label on hover or focus.
Spec:
- Each `Tooltip` uses `{#snippet triggerChild(props)}` with `<IconButton aria-label="Info" {...props}>`
- Icons from `@lucide/svelte`: `<Info size={20} />`, `<Heart size={20} />`, `<Zap size={20} />`, `<Star size={20} />`
- Tooltip content: Info, Add to favourites, Boost performance, Rate this component
- Other `aria-label` values: `aria-label="Favourite"`, `aria-label="Boost"`, `aria-label="Rate"`
Tags: tooltip, icon-button, icons, aria-label, toolbar, lucide
Needs: @codeatlasdev/ui@4.1.0
Components: Tooltip, IconButton
Live demo: https://ui.codeatlas.com.br/docs/display/tooltip#on-icon-buttons

<script lang="ts">
  import { Tooltip, IconButton } from '@codeatlasdev/ui';
  import { Info, Star, Heart, Zap } from '@lucide/svelte';
</script>

<Tooltip content="Info">
  {#snippet triggerChild(props)}<IconButton aria-label="Info" {...props}><Info size={20} /></IconButton>{/snippet}
</Tooltip>
<Tooltip content="Add to favourites">
  {#snippet triggerChild(props)}<IconButton aria-label="Favourite" {...props}><Heart size={20} /></IconButton>{/snippet}
</Tooltip>
<Tooltip content="Boost performance">
  {#snippet triggerChild(props)}<IconButton aria-label="Boost" {...props}><Zap size={20} /></IconButton>{/snippet}
</Tooltip>
<Tooltip content="Rate this component">
  {#snippet triggerChild(props)}<IconButton aria-label="Rate" {...props}><Star size={20} /></IconButton>{/snippet}
</Tooltip>
