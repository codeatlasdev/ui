Element: #307 Blur in (motion/text)
What it shows: A two-line headline that sharpens from a 12px blur while rising 8px, each line 160ms after the previous. The sentence keeps one accessible name; a button replays it.
When to use: Hero titles, product-reveal moments and section intros that want a soft, cinematic entrance instead of a hard slide.
Spec:
- `MotionStage` from `@codeatlasdev/ui` with `label="Blur in: a headline sharpens from a blur, line by line"` and `loop={3400}`
- `aria-label={lines.join(' ')}` on the heading is the one accessible name; each `.bi__line` is `aria-hidden="true"`
- `animation: blur-in 900ms cubic-bezier(0.2, 0, 0, 1) calc(var(--i) * 160ms) both` with `style="--i:{i}"` per line
- Keyframes: `from { opacity: 0; filter: blur(12px); transform: translateY(8px); }` to `to { opacity: 1; filter: blur(0); transform: translateY(0); }`
- The `Button` `onclick` runs `manual++`, which remounts the lines through `{#key`: pressing Sharpen again is the takeover
- Under reduced motion `class:bi__line--run={!m.reduced}` drops the animation: the lines render sharp
Motion:
- opacity, filter: blur, transform: translateY (per line): 900ms cubic-bezier(0.2, 0, 0, 1) stagger calc(var(--i) * 160ms)
Names: Blur in | Blur reveal | Focus pull text | Texto com desfoque | Entrada com blur | Apparition floue
Tags: motion, text, blur, headline, entrance, stagger
Needs: @codeatlasdev/ui@4.3.0
Components: Button, MotionStage
Live demo: https://ui.codeatlas.com.br/docs/motion/text#blur-in

<script lang="ts">
  import { Button, MotionStage } from '@codeatlasdev/ui';

  const lines = ['Meet your new', 'finance co-pilot'];
  let manual = $state(0);
</script>

<MotionStage label="Blur in: a headline sharpens from a blur, line by line" loop={3400}>
  {#snippet children(m)}
    <div class="bi">
      {#key `${m.cycle}:${manual}`}
        <h3 class="bi__title" aria-label={lines.join(' ')}>
          {#each lines as line, i (i)}
            <span class="bi__line" class:bi__line--run={!m.reduced} style="--i:{i}" aria-hidden="true">{line}</span>
          {/each}
        </h3>
      {/key}
      <Button size="sm" variant="outlined" onclick={() => manual++}>Sharpen again</Button>
    </div>
  {/snippet}
</MotionStage>

<style>
  .bi { display: grid; gap: var(--ca-space-3); justify-items: start; }
  .bi__title {
    display: grid;
    margin: 0;
    font-family: var(--ca-font-display);
    font-size: var(--ca-font-size-h2);
    font-weight: var(--ca-font-weight-heading);
    line-height: 1.1;
    color: var(--ca-text-primary);
  }
  .bi__line { display: block; }
  .bi__line--run { animation: blur-in 900ms cubic-bezier(0.2, 0, 0, 1) calc(var(--i) * 160ms) both; }
  @keyframes blur-in {
    from { opacity: 0; filter: blur(12px); transform: translateY(8px); }
    to { opacity: 1; filter: blur(0); transform: translateY(0); }
  }
</style>
