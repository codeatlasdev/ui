Element: #011 States (inputs/combobox)
What it shows: Three Combobox states: with description and custom search and empty texts, with error and required, and disabled.
When to use: Documenting validation, helper text and unavailable states of a searchable select in a form.
Spec:
- `frameworks` has 4 options, the last is `{ value: 'astro', label: 'Astro', disabled: true }`
- First field: `bind:value`, `description="Astro is disabled."`, `searchPlaceholder="Filter frameworks…"`, `emptyText="No framework matches."`
- Second field: `error="Pick a framework."` and `required`
- Third field: `disabled` with `placeholder="Unavailable"`
- Wrapper `.col` has `max-width: 320px`
Tags: combobox, error, disabled, required, description, empty-state
Needs: @codeatlasdev/ui@4.1.0
Components: Combobox
Live demo: https://ui.codeatlas.com.br/docs/inputs/combobox#states

<script lang="ts">
  import { Combobox } from '@codeatlasdev/ui';

  const frameworks = [
    { value: 'svelte', label: 'Svelte' },
    { value: 'react', label: 'React' },
    { value: 'vue', label: 'Vue' },
    { value: 'astro', label: 'Astro', disabled: true },
  ];

  let value = $state('');
</script>

<div class="col">
  <Combobox
    label="Framework"
    options={frameworks}
    bind:value
    description="Astro is disabled."
    searchPlaceholder="Filter frameworks…"
    emptyText="No framework matches."
  />
  <Combobox label="Framework" options={frameworks} error="Pick a framework." required />
  <Combobox label="Framework" options={frameworks} disabled placeholder="Unavailable" />
</div>

<style>
  .col {
    display: flex;
    flex-direction: column;
    gap: var(--ca-space-4);
    width: 100%;
    max-width: 320px;
  }
</style>
