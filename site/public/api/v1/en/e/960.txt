Element: #960 ratio and fit (display/image)
What it shows: One 4:3 gradient file rendered in three boxes: ratio 16/9 (cropped), ratio 1 (cropped) and ratio 1 with fit contain (letterboxed).
When to use: Card covers, thumbnails and avatar grids where every picture must share one box whatever its own proportions.
Spec:
- `<Image {src} alt="Wide cover" width={800} height={600} ratio={16 / 9} />`
- `<Image {src} alt="Square cover" width={800} height={600} ratio={1} />`
- `<Image {src} alt="Contained" width={800} height={600} ratio={1} fit="contain" />`
- `src` is an inlined 4:3 `data:image/svg+xml;utf8,` gradient with a circle
- Each image sits in a `<figure>` with a `<figcaption>` naming its ratio
Tags: image, ratio, aspect-ratio, crop, object-fit, cover, contain
Needs: @codeatlasdev/ui@4.5.0
Components: Image
Live demo: https://ui.codeatlas.com.br/docs/display/image#ratio-and-fit

<script lang="ts">
  import { Image } from '@codeatlasdev/ui';

  // A 4:3 file cropped into three boxes; inlined so the demo needs no asset.
  const src =
    "data:image/svg+xml;utf8," +
    encodeURIComponent(
      `<svg xmlns='http://www.w3.org/2000/svg' width='800' height='600'><defs><linearGradient id='g' x1='0' y1='0' x2='1' y2='1'><stop offset='0' stop-color='#c47a15'/><stop offset='1' stop-color='#2b5fd9'/></linearGradient></defs><rect width='800' height='600' fill='url(#g)'/><circle cx='400' cy='300' r='140' fill='#fff' fill-opacity='.35'/></svg>`
    );
</script>

<div class="row">
  <figure><Image {src} alt="Wide cover" width={800} height={600} ratio={16 / 9} /><figcaption>16 / 9</figcaption></figure>
  <figure><Image {src} alt="Square cover" width={800} height={600} ratio={1} /><figcaption>1</figcaption></figure>
  <figure><Image {src} alt="Contained" width={800} height={600} ratio={1} fit="contain" /><figcaption>1, contain</figcaption></figure>
</div>

<style>

  figure { margin: 0; }

</style>
