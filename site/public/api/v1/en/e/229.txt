Element: #229 Body and UI scale (foundation/typography)
What it shows: Seven body text size tokens from Body 1 to Nano, each rendered as a sample line.
When to use: Choosing a font size token for body copy, captions, labels and buttons.
Spec:
- Renders `<TypeRows {rows} />` with 7 rows
- Row tokens: `--ca-font-size-body1`, `--ca-font-size-body2`, `--ca-font-size-caption`, `--ca-font-size-label`
- Then `--ca-font-size-button`, `--ca-font-size-micro`, `--ca-font-size-nano`
- Row labels: Body 1, Body 2, Caption, Label, Button, Micro, Nano
