Element: #209 Rose chart (charts/pie)
What it shows: A Nightingale rose chart of six product areas, using the rose prop on PieChart.
When to use: Comparing category sizes in a rose layout instead of a plain pie.
Spec:
- `<PieChart data={roseData} rose height="340px" />`
- `roseData` has 6 items with `value` and `name`: Analytics `72`, Automation `58`, Security `45`, Integrations `38`, Storage `30`, Support `22`
- Wrapped in `<Card material="glass" full>`
Tags: pie-chart, rose, nightingale, categories, card
Needs: @codeatlasdev/ui@4.1.0 + echarts
Components: Card, PieChart
Live demo: https://ui.codeatlas.com.br/docs/charts/pie#rose-chart

<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { PieChart } from '@codeatlasdev/ui/charts';

  const roseData = [
    { value: 72, name: 'Analytics' },
    { value: 58, name: 'Automation' },
    { value: 45, name: 'Security' },
    { value: 38, name: 'Integrations' },
    { value: 30, name: 'Storage' },
    { value: 22, name: 'Support' },
  ];
</script>

<Card material="glass" full><PieChart data={roseData} rose height="340px" /></Card>
