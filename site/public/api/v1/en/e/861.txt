Element: #861 Type roles (foundation/typography)
What it shows: The six type roles (title, heading, body, label, caption, num) rendered with Text, one row each.
When to use: Picking the text role of a line of UI: use the role instead of loose font-size, line-height and letter-spacing, so a theme `type` override restyles it.
Spec:
- `import { Text } from '@codeatlasdev/ui'`
- One `<Text role={r.role}>` per role: `title`, `heading`, `body`, `label`, `caption` and `num`
- The `num` sample is `1,284 leads, 18:42`, drawn with tabular digits
- Rows are a `grid-template-columns: var(--ca-space-20) 1fr` with `gap: var(--ca-space-3)`
Tags: typography, text, type-scale, role, tabular-nums
Needs: @codeatlasdev/ui@4.6.0
Components: Text
Live demo: https://ui.codeatlas.com.br/docs/foundation/typography#type-roles

<script lang="ts">
  import { Text } from '@codeatlasdev/ui';

  const roles = [
    { role: 'title', sample: 'Quarterly pipeline' },
    { role: 'heading', sample: 'Leads by channel' },
    { role: 'body', sample: 'Follow up with every lead within a day.' },
    { role: 'label', sample: 'Company name' },
    { role: 'caption', sample: 'Updated 3 minutes ago' },
    { role: 'num', sample: '1,284 leads, 18:42' },
  ] as const;
</script>

<dl class="roles">
  {#each roles as r (r.role)}
    <div class="roles__row">
      <dt><code>{r.role}</code></dt>
      <dd><Text role={r.role}>{r.sample}</Text></dd>
    </div>
  {/each}
</dl>

<style>
  .roles {
    display: grid;
    gap: var(--ca-space-3);
    margin: 0;
  }
  .roles__row {
    display: grid;
    grid-template-columns: var(--ca-space-20) 1fr;
    align-items: baseline;
    gap: var(--ca-space-3);
  }
  dt,
  dd {
    margin: 0;
  }
</style>
