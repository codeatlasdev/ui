Element: #111 Avatar stack (display/avatar)
What it shows: An overlapping avatar stack of three photo avatars and a fourth `+4` overflow avatar.
When to use: Showing collaborators on a card, project or document with an overflow count.
Spec:
- `const people` has 4 entries: Alice, Bob and Clara with `src`, and `{ alt: '+4' }` without one
- `{#each people as p, i}` renders `<Avatar src={p.src} alt={p.alt} size="md" />`
- Each avatar is wrapped in `<div class="item" style="--z:{people.length - i}">`
- Overlap uses `.item { margin-left: -10px; position: relative; z-index: var(--z, 0); }`
Tags: avatar, stack, avatar-group, overlap, overflow, collaborators
Needs: @codeatlasdev/ui@4.1.0
Components: Avatar
Live demo: https://ui.codeatlas.com.br/docs/display/avatar#avatar-stack

<script lang="ts">
  import { Avatar } from '@codeatlasdev/ui';

  const people = [
    { src: 'https://i.pravatar.cc/150?img=1', alt: 'Alice' },
    { src: 'https://i.pravatar.cc/150?img=12', alt: 'Bob' },
    { src: 'https://i.pravatar.cc/150?img=32', alt: 'Clara' },
    { alt: '+4' },
  ];
</script>

<div class="stack">
  {#each people as p, i}
    <div class="item" style="--z:{people.length - i}">
      <Avatar src={p.src} alt={p.alt} size="md" />
    </div>
  {/each}
</div>

<style>
  .stack { display: flex; align-items: center; }
  .item { margin-left: -10px; position: relative; z-index: var(--z, 0); }
  .item:first-child { margin-left: 0; }
</style>
