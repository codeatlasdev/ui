Element: #560 Reading width with an aside (layout/page-shell)
What it shows: A PageShell with width="reading" (form column capped at 46rem) and an aside snippet holding a section index, inside a fixed-height frame.
When to use: Settings and form pages on wide screens that need a readable column plus a companion column (in-page index, summary, help, preview).
Spec:
- Frame is a 420px tall flex column with an inset outline
- `<PageShell title="Workspace settings" description="Reading width keeps the form at a comfortable line length." width="reading" asideLabel="Sections">`
- `{#snippet aside()}` renders a glass `Card` with a nav (aria-label On this page) of three links: General, Billing, Danger zone
- Body is a `Card material="glass" full title="General"` with a `Stack gap="4"` of two `TextField`s: Name (Acme Inc.) and Slug (acme)
Tags: page-shell, aside, width, reading, settings, form, sticky, layout
Needs: @codeatlasdev/ui@4.5.0
Components: PageShell, Card, TextField, Stack
Live demo: https://ui.codeatlas.com.br/docs/layout/page-shell#reading-width-with-an-aside

<script lang="ts">
  import { PageShell, Card, TextField, Stack } from '@codeatlasdev/ui';

  let name = $state('Acme Inc.');
  let slug = $state('acme');
</script>

<div class="stage">
  <PageShell title="Workspace settings" description="Reading width keeps the form at a comfortable line length." width="reading" asideLabel="Sections">
    {#snippet aside()}
      <Card material="glass" full>
        <nav class="index" aria-label="On this page">
          <a href="#general">General</a>
          <a href="#billing">Billing</a>
          <a href="#danger">Danger zone</a>
        </nav>
      </Card>
    {/snippet}

    <Card material="glass" full title="General">
      <Stack gap="4">
        <TextField label="Name" bind:value={name} />
        <TextField label="Slug" bind:value={slug} />
      </Stack>
    </Card>
  </PageShell>
</div>
