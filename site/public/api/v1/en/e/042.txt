Element: #042 Placeholder (inputs/select)
What it shows: Select with no initial value that shows placeholder text until a country is chosen.
When to use: Required choice in a form where no default should be preselected.
Spec:
- `<Select label="Country" placeholder="Choose a country…"` with `options={countries}`
- `countries` has 5 options: Brazil, United States, Germany, Japan, Australia
- `bind:value={country}` with initial `$state('')`
Tags: select, placeholder, country, form, options
Needs: @codeatlasdev/ui@4.1.0
Components: Select
Live demo: https://ui.codeatlas.com.br/docs/inputs/select#placeholder

<script lang="ts">
  import { Select } from '@codeatlasdev/ui';

  let country = $state('');

  const countries = [
    { value: 'br', label: 'Brazil' },
    { value: 'us', label: 'United States' },
    { value: 'de', label: 'Germany' },
    { value: 'jp', label: 'Japan' },
    { value: 'au', label: 'Australia' },
  ];
</script>

<div class="col">
  <Select label="Country" placeholder="Choose a country…" options={countries} bind:value={country} />
</div>

<style>
  .col {
    width: 100%;
    max-width: 320px;
  }
</style>
