Element: #220 Brand (foundation/colors)
What it shows: Six swatches for the brand color tokens, each showing its name and CSS variable.
When to use: Picking a brand color token for a fill, a text color or an accent.
Spec:
- Renders `<Swatches {tokens} />` with 6 tokens
- Tokens in order: `--ca-brand-main`, `--ca-brand-light`, `--ca-brand-dark`
- Then `--ca-brand-contrast`, `--ca-brand-fill`, `--ca-brand-text`
- No bordered prop is passed
Tags: colors, brand, tokens, swatches, theme
Needs: @codeatlasdev/ui@4.1.0
Components: none
Live demo: https://ui.codeatlas.com.br/docs/foundation/colors#brand

<script lang="ts">
	import Swatches from "./Swatches.svelte";
	const tokens = [
		"--ca-brand-main",
		"--ca-brand-light",
		"--ca-brand-dark",
		"--ca-brand-contrast",
		"--ca-brand-fill",
		"--ca-brand-text",
	];
</script>

<Swatches {tokens} />
