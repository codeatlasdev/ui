Element: #082 Controlled pending (feedback/alert-dialog)
What it shows: An alert dialog driven by parent state: the pending prop is set for 1.5 seconds before the dialog closes itself.
When to use: Publishing or saving flows where the confirm button must show progress and the parent decides when to close.
Spec:
- `<AlertDialog bind:open title="Publish changes?" confirmLabel="Publish"` with no description
- `{pending}` shorthand passes `let pending = $state(false)` to the dialog
- `onconfirm={publish}` sets `pending = true`, awaits 1500 ms, then sets `pending = false` and `open = false`
- Trigger is `<Button variant="outlined"` labelled Open controlled
Tags: alert-dialog, controlled, pending, async, publish
Needs: @codeatlasdev/ui@4.1.0
Components: AlertDialog, Button
Live demo: https://ui.codeatlas.com.br/docs/feedback/alert-dialog#controlled-pending

<script lang="ts">
  import { AlertDialog, Button } from '@codeatlasdev/ui';

  let open = $state(false);
  let pending = $state(false);

  async function publish() {
    pending = true;
    await new Promise<void>((r) => setTimeout(r, 1500));
    pending = false;
    open = false;
  }
</script>

<Button variant="outlined" onclick={() => (open = true)}>Open controlled</Button>

<AlertDialog bind:open title="Publish changes?" confirmLabel="Publish" {pending} onconfirm={publish} />
