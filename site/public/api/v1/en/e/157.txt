Element: #157 Left and right (navigation/drawer)
What it shows: Two buttons that open a left navigation drawer and a right settings drawer.
When to use: Slide-in panels for site navigation on mobile or for quick settings without leaving the page.
Spec:
- `<Drawer bind:open={leftOpen} side="left" title="Navigation">` holds a `<nav class="nav" aria-label="Demo navigation">` with 4 links: Home, Components, Foundation, About
- Left links close it with `onclick={() => (leftOpen = false)}`
- `<Drawer bind:open={rightOpen} side="right" title="Settings">` lists 3 label and value rows: Theme Amber, Language English, Notifications Enabled
- Triggers are `Button` with `variant="outlined"`, the second with `{#snippet leading()}<Settings size={16} stroke-width={2} />{/snippet}`
Tags: drawer, side-panel, navigation, settings, overlay, left, right
Needs: @codeatlasdev/ui@4.1.0
Components: Drawer, Button
Live demo: https://ui.codeatlas.com.br/docs/navigation/drawer#left-and-right

<script lang="ts">
  import { Drawer, Button } from '@codeatlasdev/ui';
  import { Settings } from '@lucide/svelte';

  let leftOpen = $state(false);
  let rightOpen = $state(false);
</script>

<Button variant="outlined" onclick={() => (leftOpen = true)}>Open left drawer</Button>
<Button variant="outlined" onclick={() => (rightOpen = true)}>
  {#snippet leading()}<Settings size={16} stroke-width={2} />{/snippet}
  Open settings
</Button>

<Drawer bind:open={leftOpen} side="left" title="Navigation">
  <nav class="nav" aria-label="Demo navigation">
    {#each ['Home', 'Components', 'Foundation', 'About'] as item}
      <a href="#top" class="nav__item" onclick={() => (leftOpen = false)}>{item}</a>
    {/each}
  </nav>
</Drawer>

<Drawer bind:open={rightOpen} side="right" title="Settings">
  <div class="settings">
    {#each [['Theme', 'Amber'], ['Language', 'English'], ['Notifications', 'Enabled']] as [label, value]}
      <div class="row">
        <p class="label">{label}</p>
        <p class="value">{value}</p>
      </div>
    {/each}
  </div>
</Drawer>
