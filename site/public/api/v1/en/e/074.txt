Element: #074 Open by default (surfaces/collapsible)
What it shows: A Collapsible that starts expanded with its open state bound and printed below it.
When to use: Panels that should be visible on first load, or whose open state the app tracks.
Spec:
- `<Collapsible title="Expanded on mount" bind:open>`
- State: `let open = $state(true)` starts the panel open
- `<p class="state">open = {open}</p>` prints the bound value
- Wrapped in `.wrap` with `max-width: 560px`
Tags: collapsible, open, bind, expanded, controlled
Needs: @codeatlasdev/ui@4.1.0
Components: Collapsible
Live demo: https://ui.codeatlas.com.br/docs/surfaces/collapsible#open-by-default

<script lang="ts">
  import { Collapsible } from '@codeatlasdev/ui';

  let open = $state(true);
</script>

<div class="wrap">
  <Collapsible title="Expanded on mount" bind:open>
    <p>This panel starts open. The user can collapse it.</p>
  </Collapsible>
  <p class="state">open = {open}</p>
</div>

<style>
  .wrap { width: 100%; max-width: 560px; display: flex; flex-direction: column; gap: var(--ca-space-2); }
  p { margin: 0; font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); line-height: 1.6; }
  .state { font-family: var(--ca-font-mono); font-size: var(--ca-font-size-caption); }
</style>
