Element: #171 Error or offline (layout/empty-state)
What it shows: A load-failure state with a wifi-off icon and Retry plus Contact support buttons.
When to use: Network or fetch errors on a data panel where the user can retry or escalate.
Spec:
- `<EmptyState icon={WifiOff} title="Couldn't load data" description="Check your connection and try again.">`
- `{#snippet actions()}` holds `<Button variant="outlined" size="sm">Retry</Button>` and `<Button variant="ghost" size="sm">Contact support</Button>`
Tags: empty-state, offline, error, retry, network, actions
Needs: @codeatlasdev/ui@4.1.0
Components: EmptyState, Button
Live demo: https://ui.codeatlas.com.br/docs/layout/empty-state#error-or-offline

<script lang="ts">
  import { EmptyState, Button } from '@codeatlasdev/ui';
  import { WifiOff } from '@lucide/svelte';
</script>

<EmptyState icon={WifiOff} title="Couldn't load data" description="Check your connection and try again.">
  {#snippet actions()}
    <Button variant="outlined" size="sm">Retry</Button>
    <Button variant="ghost" size="sm">Contact support</Button>
  {/snippet}
</EmptyState>
