Element: #132 Default (display/notification-bell)
What it shows: Two NotificationBell triggers side by side: one given three notifications and one given an empty list.
When to use: Comparing the populated and empty bell states for an app header or toolbar.
Spec:
- `<Flex gap="6" align="center">` wraps both bells
- `<NotificationBell notifications={items} />` with 3 const items (`id`, `title`, `body`, `time`, `read`), two with `read: false` and one with `read: true`
- `<NotificationBell notifications={[]} />` passes an empty list
- No callback props are passed to either bell
Tags: notification-bell, notifications, empty-state, unread, badge, header
Needs: @codeatlasdev/ui@4.1.0
Components: NotificationBell, Flex
Live demo: https://ui.codeatlas.com.br/docs/display/notification-bell#default

<script lang="ts">
  import { NotificationBell, Flex } from '@codeatlasdev/ui';

  const items = [
    { id: '1', title: 'Deploy succeeded', body: 'prod-api-v2.4 is live', time: '2m ago', read: false },
    { id: '2', title: 'New comment', body: 'Ana replied on PR #142', time: '18m ago', read: false },
    { id: '3', title: 'Budget alert', body: '80% of monthly quota used', time: '1h ago', read: true },
  ];
</script>

<Flex gap="6" align="center">
  <NotificationBell notifications={items} />
  <NotificationBell notifications={[]} />
</Flex>
