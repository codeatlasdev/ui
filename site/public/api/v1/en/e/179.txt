Element: #179 Three cards (layout/kpi-grid)
What it shows: A KpiGrid holding three KPI cards to show how the grid lays out an odd number of items.
When to use: Dashboards with three headline metrics, where the grid should still look balanced.
Spec:
- `<KpiGrid>` with 3 `KpiCard` items
- `<KpiCard title="Revenue" value="$112k" trend={18.4} icon={DollarSign} />`
- `<KpiCard title="Users" value="24.8k" trend={12.1} icon={Users} />`
- `<KpiCard title="Growth" value="34" unit="%" trend={5.6} icon={TrendingUp} />`
Tags: kpi-grid, kpi-card, odd, three-columns, dashboard, grid
Needs: @codeatlasdev/ui@4.1.0
Components: KpiCard, KpiGrid
Live demo: https://ui.codeatlas.com.br/docs/layout/kpi-grid#three-cards

<script lang="ts">
  import { KpiCard, KpiGrid } from '@codeatlasdev/ui';
  import { Users, DollarSign, TrendingUp } from '@lucide/svelte';
</script>

<KpiGrid>
  <KpiCard title="Revenue" value="$112k" trend={18.4} icon={DollarSign} />
  <KpiCard title="Users" value="24.8k" trend={12.1} icon={Users} />
  <KpiCard title="Growth" value="34" unit="%" trend={5.6} icon={TrendingUp} />
</KpiGrid>
