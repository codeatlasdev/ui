Element: #990 Brand color (inputs/color-field)
What it shows: Color field with a swatch, a native picker, a text input and a live WCAG contrast readout against white.
When to use: Picking a brand or accent color where contrast matters.
Spec:
- `<ColorField` with `label="Brand color"` and `bind:value={brand}`
- `against="#ffffff"`, `role="fill"` and `minRatio={3}` so the readout measures white on the color as a UI part
- Has a `description`: Type #hex, rgb() or oklch(), or pick.
- Initial value is `$state('#2b5fd9')`
- Current value is shown as `value: {brand}`
Tags: color-field, color-picker, oklch, contrast, brand
Needs: @codeatlasdev/ui@4.6.0
Components: ColorField
Live demo: https://ui.codeatlas.com.br/docs/inputs/color-field#brand-color

<script lang="ts">
  import { ColorField } from '@codeatlasdev/ui';

  let brand = $state('#2b5fd9');
</script>

<div class="col">
  <ColorField label="Brand color" bind:value={brand} against="#ffffff" role="fill" minRatio={3} description="Type #hex, rgb() or oklch(), or pick." />
  <p class="out">value: {brand}</p>
</div>
