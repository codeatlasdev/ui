Element: #124 Horizontal (display/divider)
What it shows: Three stacked text sections inside a glass card separated by horizontal dividers.
When to use: Separating sections of content inside a card or panel.
Spec:
- `<Card material="glass" p="6" full>` wraps the content
- `<Stack gap="4">` stacks Section A, B and C paragraphs
- `<Divider />` is placed between them with no props
Tags: divider, horizontal, separator, card, stack
Needs: @codeatlasdev/ui@4.1.0
Components: Divider, Card, Stack
Live demo: https://ui.codeatlas.com.br/docs/display/divider#horizontal

<script lang="ts">
  import { Divider, Card, Stack } from '@codeatlasdev/ui';
</script>

<Card material="glass" p="6" full>
  <Stack gap="4">
    <p>Section A content</p>
    <Divider />
    <p>Section B content</p>
    <Divider />
    <p>Section C content</p>
  </Stack>
</Card>
