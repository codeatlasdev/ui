Element: #113 Dot and counts (display/badge)
What it shows: Four badges on icon buttons: a dot, a count of 3, a count of 99 and a count of 100.
When to use: Unread counters on notification, message and cart icons.
Spec:
- `<Badge dot>` around a Bell `<IconButton aria-label="Notifications">`
- `<Badge count={3}>` around a Mail `<IconButton aria-label="Messages">`
- `<Badge count={99}>` around a ShoppingCart `<IconButton aria-label="Cart">`
- `<Badge count={100}>` around a Bell `<IconButton aria-label="Notifications">`
- `<Flex gap="4" align="center" wrap>` lays them out
Tags: badge, count, dot, overflow, icon-button, unread
Needs: @codeatlasdev/ui@4.1.0
Components: Badge, IconButton, Flex
Live demo: https://ui.codeatlas.com.br/docs/display/badge#dot-and-counts

<script lang="ts">
  import { Badge, IconButton, Flex } from '@codeatlasdev/ui';
  import { Bell, Mail, ShoppingCart } from '@lucide/svelte';
</script>

<Flex gap="4" align="center" wrap>
  <Badge dot><IconButton aria-label="Notifications"><Bell size={20} /></IconButton></Badge>
  <Badge count={3}><IconButton aria-label="Messages"><Mail size={20} /></IconButton></Badge>
  <Badge count={99}><IconButton aria-label="Cart"><ShoppingCart size={20} /></IconButton></Badge>
  <Badge count={100}><IconButton aria-label="Notifications"><Bell size={20} /></IconButton></Badge>
</Flex>
