Element: #085 Form (feedback/dialog)
What it shows: A medium dialog containing an invite form with name, email and role fields and a Send invite button disabled until name and email are filled.
When to use: Short create or invite flows that collect a few fields without leaving the page.
Spec:
- `<Dialog bind:open title="Invite team member" size="md">`
- Fields stacked in `<Stack gap="3.5">`: two `<TextField` (Full name, Email with `type="email"`) using `bind:value={name}` and `bind:value={email}`
- `<Select label="Role" bind:value={role} options={roleOpts}` with three options: Admin, Editor, Viewer
- `let role = $state('viewer')` is the default role
- `{#snippet actions()}`: ghost Cancel and filled Send invite with `disabled={!name || !email}`
Tags: dialog, form, text-field, select, invite, modal
Needs: @codeatlasdev/ui@4.1.0
Components: Dialog, Button, TextField, Select, Stack
Live demo: https://ui.codeatlas.com.br/docs/feedback/dialog#form

<script lang="ts">
  import { Dialog, Button, TextField, Select, Stack } from '@codeatlasdev/ui';

  let open = $state(false);
  let name = $state('');
  let email = $state('');
  let role = $state('viewer');
  const roleOpts = [
    { value: 'admin', label: 'Admin' },
    { value: 'editor', label: 'Editor' },
    { value: 'viewer', label: 'Viewer' },
  ];
</script>

<Button variant="filled" onclick={() => (open = true)}>Invite member</Button>

<Dialog bind:open title="Invite team member" size="md">
  <Stack gap="3.5">
    <TextField label="Full name" bind:value={name} placeholder="Ada Lovelace" />
    <TextField label="Email" type="email" bind:value={email} placeholder="ada@company.com" />
    <Select label="Role" bind:value={role} options={roleOpts} />
  </Stack>
  {#snippet actions()}
    <Button variant="ghost" onclick={() => (open = false)}>Cancel</Button>
    <Button variant="filled" disabled={!name || !email} onclick={() => (open = false)}>Send invite</Button>
  {/snippet}
</Dialog>
