Element: #105 Severities (display/alert)
What it shows: The four alert severities stacked: success, warning, error and info, each with a one-line message.
When to use: Choosing the alert severity for save confirmations, trial warnings, connection errors and update notices.
Spec:
- `severity="success"` with the saved-changes message
- `severity="warning"` with the trial-expires-in-3-days message
- `severity="error"` with the failed-to-connect message
- `severity="info"` with the new-version message
- Wrapper `.col` has `max-width: 560px`
Tags: alert, severity, success, warning, error, info
Needs: @codeatlasdev/ui@4.1.0
Components: Alert
Live demo: https://ui.codeatlas.com.br/docs/display/alert#severities

<script lang="ts">
  import { Alert } from '@codeatlasdev/ui';
</script>

<div class="col">
  <Alert severity="success">Your changes have been saved successfully.</Alert>
  <Alert severity="warning">Your trial expires in 3 days. Upgrade to keep access.</Alert>
  <Alert severity="error">Failed to connect. Check your network and try again.</Alert>
  <Alert severity="info">A new version of CodeAtlas UI is available.</Alert>
</div>
