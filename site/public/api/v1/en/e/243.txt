Element: #243 iOS instructions (feedback/install-prompt)
What it shows: The install prompt in iOS mode, showing add to home screen instructions inside a reserved stage box.
When to use: Prompting Safari on iPhone users, who have no native install event, to install the app to their home screen.
Spec:
- `<InstallPrompt mode="ios" storageKey="demo-install-ios" />`
- Wrapped in `<div class="stage">` with `min-height: calc(var(--ca-space-8) * 3)` so the page does not shift when it appears
- No handlers or state in the demo, the prompt renders only after mounting in the browser
Tags: install-prompt, pwa, ios, banner, install
Needs: @codeatlasdev/ui@4.1.0
Components: InstallPrompt
Live demo: https://ui.codeatlas.com.br/docs/feedback/install-prompt#ios-instructions

<script lang="ts">
  import { InstallPrompt } from '@codeatlasdev/ui';
</script>

<!-- The prompt renders nothing until it is mounted in the browser; the box gives the island
     something to intersect (client:visible) and keeps the page from shifting when it appears. -->
<div class="stage">
  <InstallPrompt mode="ios" storageKey="demo-install-ios" />
</div>

<style>
  .stage { min-height: calc(var(--ca-space-8) * 3); }
</style>
