Element: #080 Async onconfirm (feedback/alert-dialog)
What it shows: A destructive alert dialog whose async confirm handler waits 1.5 seconds before an Item removed note appears.
When to use: Confirming a delete that calls the server, where the dialog waits for the request before closing.
Spec:
- `<AlertDialog` with `bind:open`, `title="Remove item?"` and `confirmLabel="Remove"`
- `destructive` flag set on the dialog
- `onconfirm={removeItem}` is an async function that awaits `wait(1500)` then sets `done = true`
- Trigger is `<Button variant="destructive"` labelled Remove item (1.5s)
- Result note uses `aria-live="polite"` and shows when `{#if done}`
Tags: alert-dialog, destructive, async, confirm, delete, dialog
Needs: @codeatlasdev/ui@4.1.0
Components: AlertDialog, Button
Live demo: https://ui.codeatlas.com.br/docs/feedback/alert-dialog#async-onconfirm

<script lang="ts">
  import { AlertDialog, Button } from '@codeatlasdev/ui';

  let open = $state(false);
  let done = $state(false);
  const wait = (ms: number) => new Promise<void>((r) => setTimeout(r, ms));

  async function removeItem() {
    await wait(1500);
    done = true;
  }
</script>

<Button variant="destructive" onclick={() => ((done = false), (open = true))}>Remove item (1.5s)</Button>

<AlertDialog
  bind:open
  title="Remove item?"
  description="The request takes 1.5 seconds."
  confirmLabel="Remove"
  destructive
  onconfirm={removeItem}
/>

{#if done}<span class="note" aria-live="polite">Item removed (async onconfirm resolved).</span>{/if}

<style>
  .note { font-size: 13px; color: var(--ca-text-secondary); }
</style>
