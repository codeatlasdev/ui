Element: #248 A grouped conversation (display/message-bubble)
What it shows: A grouped chat thread: two incoming bubbles from one sender with a name and avatar, then an outgoing read bubble.
When to use: Chat threads and support inboxes where consecutive messages from one person are grouped and your own replies show delivery status.
Spec:
- `<MessageBubble direction="in" grouped="first" sender="Maria Souza" time="14:30">` opens the run and shows the sender
- `<MessageBubble direction="in" grouped="last" time="14:30">` closes it
- `{#snippet avatar()}<Avatar alt="Maria Souza" size="sm" />{/snippet}` in each incoming bubble
- `<MessageBubble direction="out" time="14:32" status="read">`
Tags: message-bubble, chat, avatar, grouped, delivery-status
Needs: @codeatlasdev/ui@4.1.0
Components: Avatar, MessageBubble
Live demo: https://ui.codeatlas.com.br/docs/display/message-bubble#a-grouped-conversation

<script lang="ts">
  import { Avatar, MessageBubble } from '@codeatlasdev/ui';
</script>

<div class="thread">
  <MessageBubble direction="in" grouped="first" sender="Maria Souza" time="14:30">
    {#snippet avatar()}<Avatar alt="Maria Souza" size="sm" />{/snippet}
    Can you send the invoice for March?
  </MessageBubble>
  <MessageBubble direction="in" grouped="last" time="14:30">
    {#snippet avatar()}<Avatar alt="Maria Souza" size="sm" />{/snippet}
    I need it before the review.
  </MessageBubble>
  <MessageBubble direction="out" time="14:32" status="read">Sent it by email just now.</MessageBubble>
</div>
