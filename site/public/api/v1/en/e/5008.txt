Element: #5008 Group sizes (display/avatar)
What it shows: Five avatar groups at sizes `xs` to `xl` and a rounded one, each capped at three with a `+2` chip.
When to use: Choosing the group size that matches the Avatar size used elsewhere on the page; the overlap scales with it.
Spec:
- `const team` has 5 entries without photos
- `{#each ['xs', 'sm', 'md', 'lg', 'xl'] as const as size (size)}` renders `<AvatarGroup items={team} max={3} {size} label="Team, size {size}" />`
- A last group uses `shape="rounded"`
Tags: avatar, avatar-group, sizes, rounded, overflow
Needs: @codeatlasdev/ui@4.6.0
Components: AvatarGroup
Live demo: https://ui.codeatlas.com.br/docs/display/avatar#group-sizes

<script lang="ts">
  import { AvatarGroup } from '@codeatlasdev/ui';

  const team = [
    { name: 'Alice Moreira' },
    { name: 'Bob Tavares' },
    { name: 'Clara Nunes' },
    { name: 'Davi Prado' },
    { name: 'Eva Ramos' },
  ];
</script>

<div class="rows">
  {#each ['xs', 'sm', 'md', 'lg', 'xl'] as const as size (size)}
    <AvatarGroup items={team} max={3} {size} label="Team, size {size}" />
  {/each}
  <AvatarGroup items={team} max={3} size="md" shape="rounded" label="Team, rounded" />
</div>
