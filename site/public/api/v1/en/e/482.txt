Element: #482 Stacked controls (surfaces/card)
What it shows: A glass Card titled Trending topics that stacks three Checkbox controls in a column with gap="sm", the title aligned with the controls.
When to use: Settings and filter cards whose content is several inline controls (Checkbox, Switch, TextField) that need vertical spacing.
Spec:
- `<Card material="glass" title="Trending topics" headingLevel={3} gap="sm" class="stacked">` with `max-width: 320px`
- Three `<Checkbox label="Hacker News" />` children: Hacker News, Product Hunt, Lobsters
- `gap="sm"` stacks the children in a column with 8px between them; the title shares the checkboxes' left edge
Tags: card, gap, stack, checkbox, title, glass, settings
Needs: @codeatlasdev/ui@4.5.0
Components: Card, Checkbox
Live demo: https://ui.codeatlas.com.br/docs/surfaces/card#stacked-controls

<script lang="ts">
  import { Card, Checkbox } from '@codeatlasdev/ui';
</script>

<Card material="glass" title="Trending topics" headingLevel={3} gap="sm" class="stacked">
  <Checkbox label="Hacker News" />
  <Checkbox label="Product Hunt" />
  <Checkbox label="Lobsters" />
</Card>

<style>
  :global(.stacked) { max-width: 320px; width: 100%; }
</style>
