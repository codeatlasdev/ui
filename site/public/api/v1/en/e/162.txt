Element: #162 Horizontal stepper (navigation/stepper)
What it shows: A four-step horizontal stepper inside a glass card with Back and Next buttons that advance the step.
When to use: Multi-step flows such as onboarding or checkout where the user moves through ordered stages.
Spec:
- `<Stepper {steps} bind:current={step} />` with `let step = $state(0)`
- `const steps` has 4 entries with a `label` field: Account, Profile, Billing, Review
- Wrapper is `<Card material="glass" p="6" full>` with `<Stack gap="6">`
- Body shows `Step {step + 1}: {steps[step].label}`
- Back is `<Button variant="ghost" disabled={step <= 0} onclick={() => step--}>`
- Next is `<Button variant="filled" disabled={step >= steps.length - 1} onclick={() => step++}>` and reads Finish on the last step
Tags: stepper, wizard, steps, progress, onboarding, back-next, card
Needs: @codeatlasdev/ui@4.1.0
Components: Stepper, Button, Card, Stack, Flex
Live demo: https://ui.codeatlas.com.br/docs/navigation/stepper#horizontal-stepper

<script lang="ts">
  import { Stepper, Button, Card, Stack, Flex } from '@codeatlasdev/ui';

  let step = $state(0);
  const steps = [{ label: 'Account' }, { label: 'Profile' }, { label: 'Billing' }, { label: 'Review' }];
</script>

<Card material="glass" p="6" full>
  <Stack gap="6">
    <Stepper {steps} bind:current={step} />
    <div class="body">
      <p>Step {step + 1}: {steps[step].label}</p>
    </div>
    <Flex gap="2" justify="end">
      <Button variant="ghost" disabled={step <= 0} onclick={() => step--}>Back</Button>
      <Button variant="filled" disabled={step >= steps.length - 1} onclick={() => step++}>
        {step < steps.length - 1 ? 'Next' : 'Finish'}
      </Button>
    </Flex>
  </Stack>
</Card>

<style>
  .body { min-height: 80px; display: flex; align-items: center; padding: 0 4px; }
  .body p { margin: 0; font-size: var(--ca-font-size-body1); color: var(--ca-text-secondary); }
</style>
