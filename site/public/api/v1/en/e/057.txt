Element: #057 With icons (inputs/text-field)
What it shows: Search field with a leading icon and a revealable password field.
When to use: Search boxes and password inputs that need an inline icon or action.
Spec:
- Search field uses `{#snippet leading()}` with `<Search size={16} stroke-width={2} />`
- Password field is `type="password"` with `revealable`: the component renders the show/hide eye button
- No local reveal state in the demo
Tags: text-field, icon, leading, trailing, password, search, snippet
Needs: @codeatlasdev/ui@4.5.0
Components: TextField
Live demo: https://ui.codeatlas.com.br/docs/inputs/text-field#with-icons

<script lang="ts">
  import { TextField } from '@codeatlasdev/ui';
  import { Search } from '@lucide/svelte';

  let password = $state('');
</script>

<div class="col">
  <TextField label="Search" placeholder="Type to search…">
    {#snippet leading()}<Search size={16} stroke-width={2} />{/snippet}
  </TextField>
  <TextField label="Password" type="password" revealable placeholder="••••••••" bind:value={password} />
</div>
