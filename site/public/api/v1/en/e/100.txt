Element: #100 In a button (feedback/spinner)
What it shows: A Button that shows its loading spinner for two seconds after click and changes its label to Saving.
When to use: Save or submit buttons that wait on a request.
Spec:
- `<Button onclick={simulate} {loading}>` with `let loading = $state(false)`
- `simulate` sets `loading = true` and resets it with `setTimeout(() => (loading = false), 2000)`
- Label is `{loading ? 'Saving…' : 'Save changes'}`
Tags: spinner, button, loading, save, async
Needs: @codeatlasdev/ui@4.1.0
Components: Button
Live demo: https://ui.codeatlas.com.br/docs/feedback/spinner#in-a-button

<script lang="ts">
  import { Button } from '@codeatlasdev/ui';

  let loading = $state(false);
  function simulate() {
    loading = true;
    setTimeout(() => (loading = false), 2000);
  }
</script>

<Button onclick={simulate} {loading}>{loading ? 'Saving…' : 'Save changes'}</Button>
