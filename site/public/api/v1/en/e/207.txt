Element: #207 Donut with center KPI (charts/pie)
What it shows: A donut chart with a total value and caption shown in the centre.
When to use: Summarising a total inside the donut, like total revenue split by category.
Spec:
- `<PieChart data={marketData} donut`
- `centerLabel={{ value: '$2.4M', label: 'Total Revenue' }}`
- `marketData` has 5 items: Cloud Services `38`, Enterprise SW `24`, SaaS Tools `18`, Infrastructure `12`, Other `8`
- `height="300px"` inside `<Card material="glass" full>`
Tags: pie-chart, donut, center-label, total, market-share, card
Needs: @codeatlasdev/ui@4.1.0 + echarts
Components: Card, PieChart
Live demo: https://ui.codeatlas.com.br/docs/charts/pie#donut-with-center-kpi

<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { PieChart } from '@codeatlasdev/ui/charts';

  const marketData = [
    { value: 38, name: 'Cloud Services' },
    { value: 24, name: 'Enterprise SW' },
    { value: 18, name: 'SaaS Tools' },
    { value: 12, name: 'Infrastructure' },
    { value: 8, name: 'Other' },
  ];
</script>

<Card material="glass" full>
  <PieChart data={marketData} donut centerLabel={{ value: '$2.4M', label: 'Total Revenue' }} height="300px" />
</Card>
