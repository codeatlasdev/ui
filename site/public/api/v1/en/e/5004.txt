Element: #5004 Icon-only, ghost, small and disabled (inputs/toggle)
What it shows: Standalone Toggle buttons: icon-only, ghost with a label, small and disabled.
When to use: A single on/off control such as bold, pin or mute that is not part of a group.
Spec:
- Two outlined icon-only toggles with `aria-label="Bold"` and `aria-label="Italic"`, Bold starts pressed
- A ghost toggle with an icon and the label `Pin`
- A `size="sm"` toggle and a `disabled` toggle
Tags: toggle, pressed, aria-pressed, button, icon-only, ghost
Needs: @codeatlasdev/ui@4.6.0
Components: Toggle
Live demo: https://ui.codeatlas.com.br/docs/inputs/toggle#icon-only-ghost-small-and-disabled

<script lang="ts">
  import { Bold, Italic, Pin } from '@lucide/svelte';
  import { Toggle } from '@codeatlasdev/ui';

  let bold = $state(true);
  let italic = $state(false);
  let pinned = $state(false);
</script>

<div style="display:flex;flex-wrap:wrap;align-items:center;gap:var(--ca-space-3)">
  <Toggle icon={Bold} aria-label="Bold" bind:pressed={bold} />
  <Toggle icon={Italic} aria-label="Italic" bind:pressed={italic} />
  <Toggle icon={Pin} label="Pin" variant="ghost" bind:pressed={pinned} />
  <Toggle label="Small" size="sm" />
  <Toggle label="Disabled" disabled />
</div>
