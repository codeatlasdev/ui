Element: #490 Dedupe and replace by id (feedback/toast)
What it shows: Two buttons: one fires the same error ten times and shows a single toast with a ×10 badge, the other replaces an uploading toast by id.
When to use: Polling or parallel requests that fail with the same message, and progress toasts that turn into a result.
Spec:
- `<Toaster />` mounted once, `toast` imported from `@codeatlasdev/ui`
- Dedupe: `toast.error('Too many requests, retry later.')` called in a loop of 10 keeps one toast, bumps its count badge and restarts its timer
- Replace: `toast.info('Uploading report.pdf…', { id: 'upload', duration: 0 })` then `toast.success('report.pdf uploaded.', { id: 'upload' })` swaps the same toast in place
- Both triggers are `<Button variant="outlined"`
Tags: toast, toaster, dedupe, id, replace, notification, count
Needs: @codeatlasdev/ui@4.5.0
Components: Button, Toaster
Live demo: https://ui.codeatlas.com.br/docs/feedback/toast#dedupe-and-replace-by-id

<script lang="ts">
  import { Button, Toaster, toast } from '@codeatlasdev/ui';

  function flood() {
    for (let i = 0; i < 10; i++) toast.error('Too many requests, retry later.');
  }

  function upload() {
    toast.info('Uploading report.pdf…', { id: 'upload', duration: 0 });
    setTimeout(() => toast.success('report.pdf uploaded.', { id: 'upload' }), 1500);
  }
</script>

<Toaster />

<Button variant="outlined" onclick={flood}>Fail 10 times</Button>
<Button variant="outlined" onclick={upload}>Upload with id</Button>
