Element: #163 Controlled (navigation/tabs)
What it shows: Tabs bound to a state variable with a line below showing the active tab value.
When to use: Tabbed views whose active tab must also drive other UI or be read and set from code.
Spec:
- `<Tabs bind:value={active}>` with `let active = $state('overview')`
- `<TabsList>` holds 3 `TabsTrigger` items: `value="overview"`, `value="props"`, `value="examples"`
- A matching `TabsContent` per value, each with a one-line `<div class="panel">`
- State is echoed as `Active tab: <code>{active}</code>`
- Wrapper is `.wrap` with `max-width: 480px`
Tags: tabs, controlled, bind-value, state, tabs-list, tabs-content
Needs: @codeatlasdev/ui@4.1.0
Components: Tabs, TabsList, TabsTrigger, TabsContent
Live demo: https://ui.codeatlas.com.br/docs/navigation/tabs#controlled

<script lang="ts">
  import { Tabs, TabsList, TabsTrigger, TabsContent } from '@codeatlasdev/ui';

  let active = $state('overview');
</script>

<div class="wrap">
  <Tabs bind:value={active}>
    <TabsList>
      <TabsTrigger value="overview">Overview</TabsTrigger>
      <TabsTrigger value="props">Props</TabsTrigger>
      <TabsTrigger value="examples">Examples</TabsTrigger>
    </TabsList>
    <TabsContent value="overview"><div class="panel">Overview panel.</div></TabsContent>
    <TabsContent value="props"><div class="panel">Props panel.</div></TabsContent>
    <TabsContent value="examples"><div class="panel">Examples panel.</div></TabsContent>
  </Tabs>
  <p class="state">Active tab: <code>{active}</code></p>
</div>

<style>
  .wrap { width: 100%; max-width: 480px; }
  .panel { padding: 20px 0 8px; font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); }
  .state { font-size: var(--ca-font-size-caption); color: var(--ca-text-secondary); margin: 12px 0 0; }
  .state code { font-family: var(--ca-font-mono); color: var(--ca-brand-text); }
</style>
