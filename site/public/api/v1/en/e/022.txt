Element: #022 Role filter (inputs/filter-group)
What it shows: A FilterGroup of three role options bound to a value that is printed below.
When to use: Filtering a list or table by one category, such as user role, with a short set of choices.
Spec:
- `<FilterGroup label="Role" options={roles} bind:value={role} />`
- `const roles` has 3 options with `value` and `label`: `admin`, `editor`, `viewer`
- `let role = $state('all')` starts at `all`, which is not one of the options
- `<p>Selected: {role}</p>` prints the current value
Tags: filter-group, filter, options, role, bind, category
Needs: @codeatlasdev/ui@4.1.0
Components: FilterGroup
Live demo: https://ui.codeatlas.com.br/docs/inputs/filter-group#role-filter

<script lang="ts">
  import { FilterGroup } from '@codeatlasdev/ui';

  const roles = [
    { value: 'admin', label: 'Admin' },
    { value: 'editor', label: 'Editor' },
    { value: 'viewer', label: 'Viewer' },
  ];
  let role = $state('all');
</script>

<FilterGroup label="Role" options={roles} bind:value={role} />
<p>Selected: {role}</p>
