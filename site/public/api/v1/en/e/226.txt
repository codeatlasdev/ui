Element: #226 Glass tiers (foundation/materials)
What it shows: Five glass surfaces at elevations 1 to 5, from Ultra thin to Chrome, over a three color gradient.
When to use: Choosing the glass tier by how much blur and fill a panel needs over its background.
Spec:
- `{#each tiers as tier (tier.elevation)}` renders 5 `<Surface material="glass" elevation={tier.elevation} class="tier">`
- Tiers: Ultra thin (`elevation: 1`), Thin (`elevation: 2`), Regular (`elevation: 3`), Thick (`elevation: 4`), Chrome (`elevation: 5`)
- Each tier shows a `label` and a `desc`, for example Subtle background hint and Heaviest blur and fill
- Backdrop gradient uses `var(--ca-brand-main) 0%`, `var(--ca-semantic-info) 50%` and `var(--ca-semantic-success) 100%`
Tags: materials, glass, surface, elevation, blur, tiers
Needs: @codeatlasdev/ui@4.1.0
Components: Surface
Live demo: https://ui.codeatlas.com.br/docs/foundation/materials#glass-tiers

<script lang="ts">
	import { Surface } from "@codeatlasdev/ui";

	const tiers: { elevation: 1 | 2 | 3 | 4 | 5; label: string; desc: string }[] = [
		{ elevation: 1, label: "Ultra thin", desc: "Subtle background hint" },
		{ elevation: 2, label: "Thin", desc: "Light translucency" },
		{ elevation: 3, label: "Regular", desc: "Default blur" },
		{ elevation: 4, label: "Thick", desc: "Strong blur" },
		{ elevation: 5, label: "Chrome", desc: "Heaviest blur and fill" },
	];
</script>

<div class="backdrop">
	{#each tiers as tier (tier.elevation)}
		<Surface material="glass" elevation={tier.elevation} class="tier">
			<p class="label">{tier.label}</p>
			<p class="desc">{tier.desc}</p>
		</Surface>
	{/each}
</div>
