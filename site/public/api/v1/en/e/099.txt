Element: #099 Text lines (feedback/skeleton)
What it shows: A glass card skeleton with a 60% wide heading line above a block of three text lines.
When to use: Loading placeholder for an article or description block.
Spec:
- `<Card material="glass" p="5" full>` with `<Stack gap="3">`
- Heading line `<Skeleton height="20px" width="60%" />`
- Body lines `<Skeleton rows={3} height="14px" />` render three rows from one element
Tags: skeleton, text, rows, card, loading
Needs: @codeatlasdev/ui@4.1.0
Components: Skeleton, Card, Stack
Live demo: https://ui.codeatlas.com.br/docs/feedback/skeleton#text-lines

<script lang="ts">
  import { Skeleton, Card, Stack } from '@codeatlasdev/ui';
</script>

<Card material="glass" p="5" full>
  <Stack gap="3">
    <Skeleton height="20px" width="60%" />
    <Skeleton rows={3} height="14px" />
  </Stack>
</Card>
