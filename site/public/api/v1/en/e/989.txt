Element: #989 Components (feedback/sound)
What it shows: Button, Switch, Tabs, Slider, Toast and Dialog with their sound prop on, behind one sound toggle.
When to use: Show which components speak when the sound prop is set, and that they stay silent until the toggle is on.
Spec:
- `<SoundToggle />` on top, off until the user presses it
- `<Button sound>`, `<Switch sound`, `<Tabs sound bind:value={tab}>`, `<Slider sound`
- `toast.success('Saved', { sound: true })` from a Toast button
- `<Dialog sound bind:open title="Sound on open and close">`
Tags: sound, button, switch, tabs, slider, toast, dialog
Needs: @codeatlasdev/ui@4.6.0
Components: Button, Dialog, Slider, Switch, Tabs, TabsList, TabsTrigger, SoundToggle
Live demo: https://ui.codeatlas.com.br/docs/feedback/sound#components

<script lang="ts">
  import { Button, Dialog, Slider, Switch, Tabs, TabsList, TabsTrigger, toast } from '@codeatlasdev/ui';
  import { SoundToggle } from '@codeatlasdev/ui/sound';

  let on = $state(false);
  let level = $state(40);
  let tab = $state('a');
  let open = $state(false);
</script>

<div class="comp">
  <SoundToggle />
  <Button sound>Save</Button>
  <Switch sound bind:checked={on} label="Notifications" />
  <Tabs sound bind:value={tab}>
    <TabsList>
      <TabsTrigger value="a">Overview</TabsTrigger>
      <TabsTrigger value="b">Activity</TabsTrigger>
    </TabsList>
  </Tabs>
  <Slider sound bind:value={level} />
  <Button variant="outlined" onclick={() => toast.success('Saved', { sound: true })}>Toast</Button>
  <Button variant="outlined" onclick={() => (open = true)}>Dialog</Button>
  <Dialog sound bind:open title="Sound on open and close">Every cue also has a visible change.</Dialog>
</div>

<style>
  .comp { display: grid; justify-items: start; gap: var(--ca-space-4); }
</style>
