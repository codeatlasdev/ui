Element: #303 Infinite marquee (motion/text)
What it shows: A row of partner names sliding left forever at a constant speed, with a seamless loop. Hovering or focusing any name pauses it; Back and Forward buttons nudge it once you take over.
When to use: Logo walls, customer and press strips, announcement tickers and feature tags that should stay visible without taking space or a carousel.
Spec:
- `MotionStage` from `@codeatlasdev/ui` with `label="Marquee: partner names scroll endlessly and pause on hover or focus"` and `loop={4000}`
- `animation: mq-slide 18s linear infinite` on the track while `m.playing && !m.reduced`
- Keyframes: `from { transform: translateX(var(--nudge)); }` to `to { transform: translateX(calc(var(--nudge) - 50%)); }`
- The list is rendered twice; the second copy is `aria-hidden="true"` with `tabindex="-1"` so the loop is seamless and read once
- `.mq__viewport:hover .mq__track` and `.mq__viewport:focus-within .mq__track` set `animation-play-state: paused`
- The `Button` `onclick` handlers change `nudge` by 56px, the manual takeover
- Under reduced motion `m.playing` is false, so the strip stays static and every name is readable
Motion:
- transform: translateX (the track moves -50% of its own width): 18s linear
- transform: translateX (manual nudge after takeover): 240ms cubic-bezier(0.2, 0, 0, 1)

<script lang="ts">
  import { Button, MotionStage } from '@codeatlasdev/ui';

  const logos = [
    { name: 'Northwind', href: '#northwind' },
    { name: 'Lumen Health', href: '#lumen' },
    { name: 'Kestrel Freight', href: '#kestrel' },
    { name: 'Orbit Pay', href: '#orbit' },
    { name: 'Fjord Energy', href: '#fjord' },
    { name: 'Atlas Bank', href: '#atlas' }
  ];

  // Takeover: the Back and Forward buttons nudge the strip by hand, 56px per press, once autoplay has stopped.
  let nudge = $state(0);
</script>

<MotionStage label="Marquee: partner names scroll endlessly and pause on hover or focus" loop={4000}>
  {#snippet children(m)}
    <div class="mq">
      <p class="mq__eyebrow" id="mq-eyebrow">Trusted by 1,200 finance teams</p>
      <div class="mq__viewport" role="group" aria-labelledby="mq-eyebrow">
        <ul class="mq__track" class:mq__track--run={m.playing && !m.reduced} style="--nudge:{nudge}px">
          {#each logos as l (l.name)}
            <li><a class="mq__item" href={l.href}>{l.name}</a></li>
          {/each}
          <!-- Second copy closes the loop: the track moves -50% and lands on an identical frame. -->
          {#each logos as l (l.name)}
            <li aria-hidden="true"><a class="mq__item" href={l.href} tabindex="-1">{l.name}</a></li>
          {/each}
        </ul>
      </div>
      <div class="mq__bar">
        <p class="mq__hint">Hover or focus a name to pause.</p>
        <Button size="sm" variant="ghost" onclick={() => (nudge += 56)}>Back</Button>
        <Button size="sm" variant="ghost" onclick={() => (nudge -= 56)}>Forward</Button>
      </div>
    </div>
  {/snippet}
</MotionStage>
