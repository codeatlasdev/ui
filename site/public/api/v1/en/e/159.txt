Element: #159 Icon trigger (navigation/menu)
What it shows: A dropdown menu opened by a three-dot icon button, with Share and Copy link items aligned to the end.
When to use: Compact overflow menus on cards and table rows where a full button would take too much space.
Spec:
- `<DropdownMenu align="end">`
- `{#snippet triggerChild(props)}` renders `<IconButton aria-label="More options" {...props}>` with `<MoreHorizontal size={18} />`
- `<DropdownMenuLabel>Actions</DropdownMenuLabel>` then 2 items: Share and Copy link
- Item content is passed with `{#snippet children()}` using `<Share2 size={14} />` and `<Copy size={14} />`
Tags: dropdown-menu, menu, icon-button, overflow, more-options, align, a11y
Needs: @codeatlasdev/ui@4.1.0
Components: DropdownMenu, DropdownMenuItem, DropdownMenuLabel, IconButton
Live demo: https://ui.codeatlas.com.br/docs/navigation/menu#icon-trigger

<script lang="ts">
  import { DropdownMenu, DropdownMenuItem, DropdownMenuLabel, IconButton } from '@codeatlasdev/ui';
  import { MoreHorizontal, Copy, Share2 } from '@lucide/svelte';
</script>

<DropdownMenu align="end">
  {#snippet triggerChild(props)}
    <IconButton aria-label="More options" {...props}><MoreHorizontal size={18} /></IconButton>
  {/snippet}
  <DropdownMenuLabel>Actions</DropdownMenuLabel>
  <DropdownMenuItem>
    {#snippet children()}<Share2 size={14} /> Share{/snippet}
  </DropdownMenuItem>
  <DropdownMenuItem>
    {#snippet children()}<Copy size={14} /> Copy link{/snippet}
  </DropdownMenuItem>
</DropdownMenu>
