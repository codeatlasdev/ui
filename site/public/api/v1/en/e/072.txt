Element: #072 Stat cards (surfaces/card)
What it shows: Three glass stat Cards in a flex row, each with a label, a large value and a delta line.
When to use: Dashboard KPI strips showing a metric, its value and a short qualifier.
Spec:
- `{#each stats as s}` renders `<Card material="glass" class="stat">` once per stat
- 3 stats with `label`, `value`, `delta`: Components 70+, Presets 8, Tokens 80+
- Each card has three paragraphs: `{s.label}`, `{s.value}` and `{s.delta}`
- `.stat` uses `min-width: 140px` inside a wrapping flex `.grid`
Tags: card, stats, kpi, dashboard, glass, metrics
Needs: @codeatlasdev/ui@4.1.0
Components: Card
Live demo: https://ui.codeatlas.com.br/docs/surfaces/card#stat-cards

<script lang="ts">
  import { Card } from '@codeatlasdev/ui';

  const stats = [
    { label: 'Components', value: '70+', delta: 'Svelte 5' },
    { label: 'Presets', value: '8', delta: 'Amber, Ocean, Crimson and more' },
    { label: 'Tokens', value: '80+', delta: 'CSS custom properties' },
  ];
</script>

<div class="grid">
  {#each stats as s}
    <Card material="glass" class="stat">
      <p class="label">{s.label}</p>
      <p class="value">{s.value}</p>
      <p class="delta">{s.delta}</p>
    </Card>
  {/each}
</div>

<style>
  .grid { display: flex; flex-wrap: wrap; gap: var(--ca-space-3); width: 100%; }
  :global(.stat) { flex: 1; min-width: 140px; }
  .label {
    margin: 0 0 4px;
    font-size: var(--ca-font-size-caption);
    font-weight: 500;
    text-transform: uppercase;
    letter-spacing: 0.05em;
    color: var(--ca-text-secondary);
  }
  .value { margin: 0 0 4px; font-size: var(--ca-font-size-h3); font-weight: 700; line-height: 1.1; color: var(--ca-text-primary); }
  .delta { margin: 0; font-size: var(--ca-font-size-caption); color: var(--ca-brand-text); }
</style>
