Element: #018 DatePicker and DateRangePicker (inputs/date-picker)
What it shows: A DatePicker and a DateRangePicker with popover calendars, each printing its selected value.
When to use: Choosing a delivery date or a reporting period where the user can type or pick from a calendar popover.
Spec:
- `<DatePicker` with `label="Delivery date"` and `description="Type a date or pick one from the calendar."`
- `bind:value={picked}` with `let picked = $state<DateValue | undefined>()`
- `<DateRangePicker label="Period" locale="en-US" weekStartsOn={0} bind:value={range} />`
- `let range = $state<DateRange>({ start: undefined, end: undefined })`
- Wrappers: `.col` has `max-width: 400px`, `.col--wide` has `max-width: 460px`
Tags: date-picker, date-range-picker, popover, date, date-range, calendar
Needs: @codeatlasdev/ui@4.1.0
Components: DatePicker, DateRangePicker
Live demo: https://ui.codeatlas.com.br/docs/inputs/date-picker#datepicker-and-daterangepicker

<script lang="ts">
  import { DatePicker, DateRangePicker, type DateRange, type DateValue } from '@codeatlasdev/ui';

  let picked = $state<DateValue | undefined>();
  let range = $state<DateRange>({ start: undefined, end: undefined });

  const fmt = (d: DateValue | undefined) => (d ? d.toString() : '–');
</script>

<div class="col">
  <DatePicker
    label="Delivery date"
    description="Type a date or pick one from the calendar."
    locale="en-US"
    weekStartsOn={0}
    bind:value={picked}
  />
  <p class="out">value: <code>{fmt(picked)}</code></p>
</div>

<div class="col col--wide">
  <DateRangePicker label="Period" locale="en-US" weekStartsOn={0} bind:value={range} />
  <p class="out">start: <code>{fmt(range.start)}</code> · end: <code>{fmt(range.end)}</code></p>
</div>

<style>
