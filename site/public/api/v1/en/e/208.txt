Element: #208 Basic donut (charts/pie)
What it shows: A donut chart of market share split across five categories.
When to use: Showing the proportional split of a total, such as revenue by product line.
Spec:
- `<PieChart data={marketData} donut height="300px" />`
- `marketData` has 5 items with `value` and `name`: Cloud Services `38`, Enterprise SW `24`, SaaS Tools `18`, Infrastructure `12`, Other `8`
- Wrapped in `<Card material="glass" full>`
Tags: pie-chart, donut, market-share, proportions, card
Needs: @codeatlasdev/ui@4.1.0 + echarts
Components: Card, PieChart
Live demo: https://ui.codeatlas.com.br/docs/charts/pie#basic-donut

<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { PieChart } from '@codeatlasdev/ui/charts';

  const marketData = [
    { value: 38, name: 'Cloud Services' },
    { value: 24, name: 'Enterprise SW' },
    { value: 18, name: 'SaaS Tools' },
    { value: 12, name: 'Infrastructure' },
    { value: 8, name: 'Other' },
  ];
</script>

<Card material="glass" full><PieChart data={marketData} donut height="300px" /></Card>
