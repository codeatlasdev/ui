Element: #147 clickOutside (navigation/actions)
What it shows: A box that counts how many clicks land outside it using the clickOutside action.
When to use: Closing popovers, dropdowns and inline editors when the user clicks elsewhere on the page.
Spec:
- `use:clickOutside={() => count++}` imported from `@codeatlasdev/ui/actions` on a `div` with `class="box"`
- `let count = $state(0)` is incremented by the callback
- Box text: Click inside this area, then click outside.
- Counter shown as `Outside clicks: {count}`
Tags: click-outside, action, dismiss, popover, dropdown, event
Needs: @codeatlasdev/ui@4.1.0
Components: none
Live demo: https://ui.codeatlas.com.br/docs/navigation/actions#clickoutside

<script lang="ts">
  import { clickOutside } from '@codeatlasdev/ui/actions';

  let count = $state(0);
</script>

<div use:clickOutside={() => count++} class="box">
  <p>Click inside this area, then click outside.</p>
</div>
<p class="hint">Outside clicks: {count}</p>
