Element: #188 End aligned (layout/sticky-actions)
What it shows: A scrolling form whose sticky Cancel and Save bar only appears once the Name field has text.
When to use: Edit forms that reveal a save bar only after the user changes something.
Spec:
- `let name = $state('')` and `const dirty = $derived(name.length > 0)`
- `<StickyActions show={dirty}>` holds `<Button variant="ghost" onclick={() => (name = '')}>Cancel</Button>` and `<Button variant="filled">Save</Button>`
- `<TextField label="Name" bind:value={name} placeholder="Type to reveal the bar" />` above a `Long content…` filler
- Scroller uses `max-height: 280px` and `overflow-y: auto`
Tags: sticky-actions, dirty, form, save-bar, scroll, text-field
Needs: @codeatlasdev/ui@4.1.0
Components: StickyActions, Button, TextField, Stack
Live demo: https://ui.codeatlas.com.br/docs/layout/sticky-actions#end-aligned

<script lang="ts">
  import { StickyActions, Button, TextField, Stack } from '@codeatlasdev/ui';

  let name = $state('');
  const dirty = $derived(name.length > 0);
</script>

<div class="scroller">
  <Stack gap="4">
    <TextField label="Name" bind:value={name} placeholder="Type to reveal the bar" />
    <div class="filler">Long content…</div>
  </Stack>
  <StickyActions show={dirty}>
    <Button variant="ghost" onclick={() => (name = '')}>Cancel</Button>
    <Button variant="filled">Save</Button>
  </StickyActions>
</div>

<style>
  .scroller { width: 100%; max-height: 280px; overflow-y: auto; padding: 0 var(--ca-space-4); }
  .filler { height: 320px; color: var(--ca-text-secondary); }
</style>
