Use @codeatlasdev/ui demo #104 "Closable" (display/alert).
What it shows: Two dismissible alerts, an info one with a title and a warning one, that are replaced by a short dismissed note once closed. When to use: Inline notices the user can dismiss, such as beta-feature banners or storage warnings.
Spec:
- `<Alert severity="info" title="Heads up" closable onclose={() => (closedInfo = true)}>` with beta-feature text
- `<Alert severity="warning" closable onclose={() => (closedWarn = true)}>` with a storage 85% full message, no title
- `let closedInfo = $state(false)` and `let closedWarn = $state(false)` track each alert
- `{#if !closedInfo}` and `{#if !closedWarn}` render the alert, `{:else}` renders a `<p class="dismissed">` note
- Wrapper `.col` has `max-width: 560px`
