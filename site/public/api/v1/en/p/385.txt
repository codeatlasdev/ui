Use @codeatlasdev/ui demo #385 "Hero intro sequence" (motion/hero-ambient).
What it shows: A hero block whose eyebrow, headline, copy and buttons enter one after another, each rising 14px and fading in, 90ms apart. When to use: The first screen of a landing page or the header of a feature page. The static first frame is already complete, so no content is hidden for crawlers or slow scripts.
Spec:
- `MotionStage` with `loop={4200}`; `{#key m.cycle}` remounts the block so the sequence replays
- Each child gets `--i` (0 to 3) and `animation: intro-in 520ms cubic-bezier(0.2, 0, 0, 1) calc(var(--i) * 90ms) both`
- Keyframes: `from { opacity: 0; transform: translateY(14px); }` to `to { opacity: 1; transform: translateY(0); }`
- `class:intro--run={m.playing && m.cycle > 0}`: server HTML, reduced motion and a taken-over demo render the finished layout with no animation
Motion:
- opacity, transform: translateY: 520ms cubic-bezier(0.2, 0, 0, 1) stagger 90ms
