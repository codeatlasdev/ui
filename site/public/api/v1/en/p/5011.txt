Use @codeatlasdev/ui demo #5011 "Settings page" (layout/sortable-list).
What it shows: A complete settings page: AppSettings tabs with a reorderable list of pipeline stages (grip, menu, Edit on a phone) and a notifications tab of switches. When to use: The configuration screen of a CRM: editable lists such as stages, tags or loss reasons next to plain toggles, with one Save action.
Spec:
- `<AppSettings title={m.title} description={m.description} {tabs}>`
- `<SortableList items={stages} getId={(s) => s.id} getLabel={(s) => s.name} onreorder={reorder} label={m.stages.list}>`
- `<EditableRow label={stage.name}>`
- `<FormSection title={m.email.title} layout="list">`
- `<SettingItem label={m.email.newDeal} description={m.email.newDealHint}>`
