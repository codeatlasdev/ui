Use @codeatlasdev/ui demo #5019 "Multiple, small" (inputs/chip-group).
What it shows: Multi-select shortcut chips: compact 28px pills that wrap, each toggling on or off with a check icon. When to use: Combinable one-tap shortcuts in a search form (niches, tags, categories) where the user picks several and unpicks any of them.
Spec:
- `<ChipGroup multiple size="sm" label="Most searched" items={niches} bind:value={picked} />`
- `niches` has 7 items: dentists, lawyers, doctors, architects, accountants, vets and a disabled `gyms`
- `bind:value={picked}` is a `string[]` with initial `['dentists', 'lawyers']`; selected chips show a check icon
