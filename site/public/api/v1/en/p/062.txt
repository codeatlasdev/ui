Use @codeatlasdev/ui demo #062 "No schema" (inputs/use-form).
What it shows: Form built with useForm and a hand-written validate function, with Validate and Reset buttons. When to use: Small forms where validation runs on demand without a schema.
Spec:
- `const form = useForm({ name: '', email: '' })`
- TextFields use `value={form.fields.name.value}`, `error={form.fields.name.error}`, `oninput={(v) => form.set('name', v)}`, `onblur={() => form.touch('name')}`
- Same wiring for `email` with `type="email"`
- `validate()` sets `form.fields[k].touched` and `form.fields[k].error` manually
- Buttons: Validate with `onclick={validate}`, Reset with `variant="outlined"` calling `form.reset()`
- `{#if form.dirty}` shows the hint `dirty: values changed from initial`
