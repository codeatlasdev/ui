Use @codeatlasdev/ui demo #5031 "Soft limit and threshold" (inputs/text-area).
What it shows: Two text areas with a character counter: a post with a soft 280-character limit and a report whose count appears only from 400 characters. When to use: Composers and long-form fields where a length limit matters only near the end.
Spec:
- Post has `counter={{ max: 280 }}` and no `maxlength`: typing may go past 280 and the count turns to the error tone
- Report details has `maxlength={500}` and `counter={{ from: 400 }}`: no count below 400 characters
- Both have `rows={3}` and a description beside the count
- Column wrapper has `max-width: 480px`
