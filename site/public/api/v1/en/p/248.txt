Use @codeatlasdev/ui demo #248 "A grouped conversation" (display/message-bubble).
What it shows: A grouped chat thread: two incoming bubbles from one sender with a name and avatar, then an outgoing read bubble. When to use: Chat threads and support inboxes where consecutive messages from one person are grouped and your own replies show delivery status.
Spec:
- `<MessageBubble direction="in" grouped="first" sender="Maria Souza" time="14:30">` opens the run and shows the sender
- `<MessageBubble direction="in" grouped="last" time="14:30">` closes it
- `{#snippet avatar()}<Avatar alt="Maria Souza" size="sm" />{/snippet}` in each incoming bubble
- `<MessageBubble direction="out" time="14:32" status="read">`
