Use @codeatlasdev/ui demo #389 "Hidden label" (inputs/text-field).
What it shows: Two inline TextFields whose label is kept for screen readers only with hideLabel, plus native maxlength and a bound ref. When to use: Inline editing in lists and toolbars where the label is implied visually but each input still needs an accessible name.
Spec:
- `label="Task name"` with `hideLabel`: the label stays for screen readers and is not shown
- `maxlength={40}` and `autocomplete="off"` reach the native input
- `bind:ref` gives the `HTMLInputElement`; a text `Button` calls `first?.focus()`
- Column wrapper has `max-width: 400px`
