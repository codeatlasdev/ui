Use @codeatlasdev/ui demo #360 "Shared element" (motion/transitions).
What it shows: A plan cover that morphs from a list tile into the detail card through the View Transitions API, with a plain crossfade when the API is missing. When to use: Opening a product, plan, photo or message from a list into its detail view without a jump cut.
Spec:
- `MotionStage` with `label="Shared element: a plan cover grows into the detail view"` and `loop={2800}`
- The cover in the tile and the cover in the detail both carry `view-transition-name: se-cover`
- `doc.startViewTransition(() => flushSync(() => (open = next)))` swaps the view; without the API the new view runs `animation: se-fade 240ms`
- `::view-transition-group(se-cover)` uses `animation-duration: 420ms` and `animation-timing-function: cubic-bezier(0.2, 0, 0, 1)`
- Under reduced motion the detail is shown and no transition runs
Motion:
- position and size of the shared cover (view-transition-name: se-cover): 420ms cubic-bezier(0.2, 0, 0, 1)
- opacity (crossfade fallback): 240ms cubic-bezier(0.2, 0, 0, 1)
