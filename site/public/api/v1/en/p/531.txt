Use @codeatlasdev/ui demo #531 "Stage" (layout/app-shell).
What it shows: An app shell with a persistent stage behind the pages: mounted once, click-through content, hide and pause. When to use: Map, canvas, video or 3D products where the pages float over one live layer that must keep its state across routes.
Spec:
- `<AppShellLayout {modules} {pathname} onNavigate={(path) => (pathname = path)} {stage} {stageVisible} persistPanel={false} mainId={null} skipLink={false}>` with `stage` a snippet that draws the map
- The map is a draggable grid whose camera lives in `$state`; an attachment counts each mount in `mounts` with `untrack` (a tracked `+=` would loop), shown in the page
- One module `id: 'field'` with 3 items: Leads, Routes, Report
- The page is `<PageShell title="Floating over the stage" description={pathname}>` with a `ca-stage-panel` wrapper around a glass `Card` that holds the mount count hint and an outlined `Button` toggling `stageVisible`
- Stage frame height is `height: 440px`
Check first: Svelte 5 + @codeatlasdev/ui installed? theme in src/lib/theme.ts? Kit 2 or 3?
