Use @codeatlasdev/ui demo #5005 "Icon tile" (layout/kpi-card).
What it shows: Four KPI cards with the icon in a tinted tile above the label: brand, success, warning and error tones, large numbers and trends. When to use: Dashboard headline numbers where each metric gets a coloured icon tile instead of a bare corner icon.
Spec:
- `<KpiGrid>` with 4 `KpiCard` items, each with `iconStyle="tile"`
- `<KpiCard title="Revenue" value="$48,200" trend={12.4} icon={DollarSign} iconStyle="tile" />` (brand tone by default)
- Active users uses `tone="success"`; Open incidents `tone="warning"` with `trendTone="positive-down"`; Error rate `tone="error"` with `trendTone="positive-down"`
