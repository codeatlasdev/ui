Use @codeatlasdev/ui demo #5020 "Composer bar, overflow menu" (inputs/toolbar).
What it shows: A message action bar that stays on one line: icon buttons move into a More menu when the row is narrow, and Send never leaves. When to use: A composer, reply box or list header whose controls must not wrap and push the primary action out of view on a phone.
Spec:
- `<Toolbar aria-label="Message actions" overflow="menu">`
- Five text `IconButton`s (Attach, Templates, Emoji, Bold, Italic), each with an `aria-label`
- `<span class="ca-toolbar-spacer">` then a filled `Send` button carrying `data-priority="primary"`, which never moves into the menu
