Use @codeatlasdev/ui demo #306 "Count up" (motion/text).
What it shows: A KPI that counts from 0 to 12,480 in 1400ms with an ease-out-expo curve, so the last digits settle slowly. A Count again button replays it on demand. When to use: Stat blocks and metrics sections that scroll into view, totals after a report loads, and any headline number worth a moment of attention.

- The `Button` `onclick` calls `run()`: pressing Count again is the takeover and re-runs the count on demand
- Under reduced motion the attachment sets `n = target` and no frame loop starts
