Use @codeatlasdev/ui demo #244 "Native prompt" (feedback/install-prompt).
What it shows: The install prompt in native mode, triggered by a stand-in beforeinstallprompt event fired on mount. When to use: Offering an install banner on browsers that expose the beforeinstallprompt event, such as Chrome and Edge.
Spec:
- `<InstallPrompt mode="native" storageKey="demo-install-native" />`
- `onMount` dispatches `new Event('beforeinstallprompt', { cancelable: true })` on the window
- The fake event gets `prompt: () => Promise.resolve()` and `userChoice: Promise.resolve({ outcome: 'dismissed' })`
- Wrapped in `<div class="stage">` with `min-height: calc(var(--ca-space-8) * 3)`
