Use @codeatlasdev/ui demo #255 "Fast and slow loads" (navigation/loading-boundary).
What it shows: A LoadingBoundary around a suspending report with a fast (100 ms) and a slow (1.5 s) load button. When to use: Showing a skeleton for slow data without flashing it on fast responses, in any page that awaits a loader.
Spec:
- `<LoadingBoundary label="Loading invoices">` wraps `<Report load={load(ms)} />`
- `{#key run}` restarts the load for each button
- `ms = 100; run++;` is the fast case and `ms = 1500; run++;` the slow one
