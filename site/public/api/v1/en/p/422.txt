Use @codeatlasdev/ui demo #422 "Async results" (navigation/command-palette).
What it shows: A CommandPalette whose async `search` returns grouped invoice and customer records after a simulated 600 ms server delay. When to use: Command palettes that search server data (records, documents, users) next to local navigation items.
Spec:
- `<CommandPalette {modules} {search} shortcut={false} onNavigate={(path) => (picked = path)} bind:open />`: the page's other palette owns Mod+K
- `function search(query: string, signal: AbortSignal)` resolves after 600 ms with `records` filtered by label and rejects with `AbortError` when the signal aborts
- `records` has 4 results in the `Invoices` and `Customers` groups
- Local `modules` items (Dashboard, Settings) filter instantly and stay above server results
- Button `Search records` opens the palette, `Selected:` shows the picked path
