Use @codeatlasdev/ui demo #147 "clickOutside" (navigation/actions).
What it shows: A box that counts how many clicks land outside it using the clickOutside action. When to use: Closing popovers, dropdowns and inline editors when the user clicks elsewhere on the page.
Spec:
- `use:clickOutside={() => count++}` imported from `@codeatlasdev/ui/actions` on a `div` with `class="box"`
- `let count = $state(0)` is incremented by the callback
- Box text: Click inside this area, then click outside.
- Counter shown as `Outside clicks: {count}`
