Use @codeatlasdev/ui demo #082 "Controlled pending" (feedback/alert-dialog).
What it shows: An alert dialog driven by parent state: the pending prop is set for 1.5 seconds before the dialog closes itself. When to use: Publishing or saving flows where the confirm button must show progress and the parent decides when to close.
Spec:
- `<AlertDialog bind:open title="Publish changes?" confirmLabel="Publish"` with no description
- `{pending}` shorthand passes `let pending = $state(false)` to the dialog
- `onconfirm={publish}` sets `pending = true`, awaits 1500 ms, then sets `pending = false` and `open = false`
- Trigger is `<Button variant="outlined"` labelled Open controlled
