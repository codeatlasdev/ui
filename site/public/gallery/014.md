# #014 Variants and sizes

CopyButton in three variants and two extra sizes, side by side.

When to use: Choosing the emphasis and size of a copy action to match the surrounding UI.

## Facets

- Kind: component / input
- Industry: devtools
- Style: default, glassmorphism
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: CopyButton
- Also searched as: clipboard

## Spec

- `variant="filled"` with `value="filled"`
- `variant="glass"` with `value="glass"`
- `variant="outlined"` with `value="outlined"`
- `size="sm"` with `value="small"`
- `size="lg"` with `value="large"`
