# #5033 Posts in a feed

Two posts in Cards: a long one cut to 3 lines by ClampedText with a Show more button, and a short one that fits and shows no button.

When to use: A feed, comment list or description where long text is cut to a few lines and opened on demand, with no button on text that already fits.

## Facets

- Kind: component / display
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Card, ClampedText
- Also searched as: read more, show more, line clamp, truncated text, expandable text

## Spec

- `const posts` has 2 entries with `id`, `author` and `body`: a long paragraph and one short sentence
- Each post is a `<Card>` around an `<article class="post">` with a `<strong class="author">` and `<ClampedText lines={3}>{p.body}</ClampedText>`
- `.feed` is a grid with `gap: var(--ca-space-4)` and `max-width: 560px`
- Only the long post shows the Show more button; it reveals the rest and turns into Show less

## Source

```svelte
<script lang="ts">
  import { Card, ClampedText } from '@codeatlasdev/ui';

  const posts = [
    {
      id: 'p1',
      author: 'Product team',
      body: 'Shipped the new onboarding flow today. The first screen now asks for a workspace name only; invites, billing and the theme moved to later steps that can be skipped. People in the pilot group got to their first project with fewer steps and fewer questions in the chat. Two things are still open: the spreadsheet import times out on very large files, and the welcome email still links to the old help page. Both are on the board for next week. Thanks to everyone who sat through the early prototypes and sent notes, especially on the empty states, which read much better now.',
    },
    {
      id: 'p2',
      author: 'Office',
      body: 'The office is closed on Friday for the holiday. See you on Monday.',
    },
  ];
</script>

<div class="feed">
  {#each posts as p (p.id)}
    <Card>
      <article class="post">
        <strong class="author">{p.author}</strong>
        <ClampedText lines={3}>{p.body}</ClampedText>
      </article>
    </Card>
  {/each}
</div>

<style>
  .feed {
    display: grid;
    gap: var(--ca-space-4);
    max-width: 560px;
  }

  .post {
    display: grid;
    gap: var(--ca-space-2);
    line-height: var(--ca-line-height-body);
  }

  .author {
    font-weight: var(--ca-font-weight-medium);
  }
</style>
```
