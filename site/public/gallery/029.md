# #029 Helpers

Two money helper functions evaluated inline: centsToDisplay and parseInputToCents.

When to use: Formatting stored cents for display or parsing user-typed currency strings outside a MoneyInput.

## Facets

- Kind: component / input
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: none
- Also searched as: format, parse, utility

## Spec

- `centsToDisplay(123456)` is printed with its result
- `parseInputToCents('R$ 1.234,56')` is printed with its result
- Both helpers are imported from `@codeatlasdev/ui/forms`
- No input component is rendered

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/money-input#helpers
Reference: https://ui.codeatlas.com.br/api/v1/en/e/029.txt
