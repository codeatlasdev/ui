# #021 Images only and disabled

Two FileUpload dropzones: one restricted to images with custom label and hint, and one disabled.

When to use: Image-only upload fields and upload areas that are unavailable to the current user.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, drag, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: FileUpload
- Also searched as: image upload, drop area

## Spec

- `accept="image/*"` with `label="Drop images here"` and `hint="PNG, JPG, GIF, WebP"`
- `disabled` with `label="Upload unavailable"`
- Wrapper `.wrap` stacks both with `max-width: 480px`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/file-upload#images-only-and-disabled
Reference: https://ui.codeatlas.com.br/api/v1/en/e/021.txt
