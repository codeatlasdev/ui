# #231 Heading scale

Six heading size tokens, Heading 1 to Heading 6, each rendered as a bold sample line.

When to use: Choosing a heading size token for a page title hierarchy.

## Facets

- Kind: component / foundation
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: none
- Also searched as: heading sizes, title scale, h1 h6

## Spec

- `[1, 2, 3, 4, 5, 6].map((n) =>` builds 6 rows
- Each row has label `Heading ${n}` and token `--ca-font-size-h${n}`
- Renders `<TypeRows {rows} heading />` with the `heading` flag for bold samples

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/foundation/typography#heading-scale
Reference: https://ui.codeatlas.com.br/api/v1/en/e/231.txt

## Source

```svelte
<script lang="ts">
	import TypeRows from "./TypeRows.svelte";
	const rows = [1, 2, 3, 4, 5, 6].map((n) => ({ label: `Heading ${n}`, token: `--ca-font-size-h${n}` }));
</script>

<TypeRows {rows} heading />
```
