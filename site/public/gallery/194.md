# #194 Animated counter

A ring gauge that counts up from 0 to 94 on mount, with a text label that changes with the value.

When to use: Animating a score or health metric on load and pairing it with a verdict label.

## Facets

- Kind: component / chart
- Industry: devtools, saas
- Style: default
- Motion: expressive
- Interaction: hover
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, Stack, GaugeChart
- Also searched as: animated score, count up gauge, progress ring

## Spec

- `let value = $state(0)` incremented in `onMount` by `Math.min(value + 2, 94)` every 40 ms via `setInterval`
- `<GaugeChart {value} variant="ring"` with `height="260px"`
- `formatter={(v) => String(Math.round(v))}` rounds the displayed number
- `const label = $derived(value < 40 ? 'Needs work' : value <= 70 ? 'Good' : 'Excellent')`
- `<Stack gap="3">` stacks the gauge above `<p class="label">{label}</p>`
- Interval is cleared when `value >= 94` and on unmount

## Source

```svelte
<script lang="ts">
  import { Card, Stack } from '@codeatlasdev/ui';
  import { GaugeChart } from '@codeatlasdev/ui/charts';
  import { onMount } from 'svelte';

  let value = $state(0);
  const label = $derived(value < 40 ? 'Needs work' : value <= 70 ? 'Good' : 'Excellent');

  onMount(() => {
    const id = setInterval(() => {
      value = Math.min(value + 2, 94);
      if (value >= 94) clearInterval(id);
    }, 40);
    return () => clearInterval(id);
  });
</script>

<Card full>
  <Stack gap="3">
    <GaugeChart {value} variant="ring" formatter={(v) => String(Math.round(v))} height="260px" />
    <p class="label">{label}</p>
  </Stack>
</Card>

<style>
  .label { text-align: center; font-size: var(--ca-font-size-h6); font-weight: 700; color: var(--ca-semantic-success); margin: 0; }
</style>
```
