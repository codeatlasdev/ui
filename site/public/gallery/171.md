# #171 Error or offline

A load-failure state with a wifi-off icon and Retry plus Contact support buttons.

When to use: Network or fetch errors on a data panel where the user can retry or escalate.

## Facets

- Kind: component / layout
- Style: default
- Motion: none
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: EmptyState, Button
- Also searched as: network error, connection lost, retry state

## Spec

- `<EmptyState icon={WifiOff} title="Couldn't load data" description="Check your connection and try again.">`
- `{#snippet actions()}` holds `<Button variant="outlined" size="sm">Retry</Button>` and `<Button variant="ghost" size="sm">Contact support</Button>`
