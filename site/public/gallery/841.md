# #841 Sign-up field

A password field with a 3-step strength meter and a polite text label under it.

When to use: Sign-up and reset-password forms that need strength feedback that does not rely on colour alone.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: PasswordStrength, TextField
- Also searched as: password meter, signup, strength indicator

## Spec

- `let password = $state('')` bound with `<TextField label="Password" type="password" bind:value={password} />`
- `<PasswordStrength value={password} />` directly under the field
- Column is `max-width: 20rem` with `gap: var(--ca-space-2)`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/password-strength#sign-up-field
