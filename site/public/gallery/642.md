# #642 Stats in a card

A Card titled This week holding three card-less Stat blocks in a responsive grid: leads with a hint, reply rate with a unit, trend and hint, and booked calls with a positive trend.

When to use: Plain statistics inside an existing card or panel, with no nested box, instead of several KpiCards.

## Facets

- Kind: component / layout
- Style: default
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, Stat
- Also searched as: card-less stats, inline metrics, stat group

## Spec

- `<Card title="This week" headingLevel={3} class="stats-card">` with `max-width: 640px`
- `<Stat label="Leads this week" value="128" hint="12 more than last week" />`
- `<Stat label="Reply rate" value="18" unit="%" trend={-2.4} hint="Goal: 25%" />`
- `<Stat label="Booked calls" value="9" trend={12.5} />`
- The Stats sit in an auto-fit grid, `minmax(150px, 1fr)`, `gap: var(--ca-space-5)`

Needs: @codeatlasdev/ui@4.5.0
