# #035 Disabled

Two radio groups: one with a single disabled item and one fully disabled group.

When to use: Showing unavailable choices in a form: one option locked, or a whole question locked.

## Facets

- Kind: component / input
- Style: default
- Motion: none
- Interaction: keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: RadioGroup
- Also searched as: inactive options

## Spec

- First group `items={yesNo}` with `orientation="horizontal"` and `bind:value={answer}`
- `yesNo` has Yes, No, Maybe, and Maybe carries `disabled: true`
- Second group `items={fruits}` with `value="banana"` and `disabled` on the whole group
- `fruits` has 3 items: Apple, Banana, Cherry

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/radio#disabled
Reference: https://ui.codeatlas.com.br/api/v1/en/e/035.txt

## Source

```svelte
<script lang="ts">
  import { RadioGroup } from '@codeatlasdev/ui';

  let answer = $state('yes');

  const yesNo = [
    { value: 'yes', label: 'Yes' },
    { value: 'no', label: 'No' },
    { value: 'maybe', label: 'Maybe', disabled: true },
  ];

  const fruits = [
    { value: 'apple', label: 'Apple' },
    { value: 'banana', label: 'Banana' },
    { value: 'cherry', label: 'Cherry' },
  ];
</script>

<RadioGroup items={yesNo} bind:value={answer} orientation="horizontal" />
<RadioGroup items={fruits} value="banana" disabled />
```
