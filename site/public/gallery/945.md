# #945 Bar open state

A two-menu bar (Share, Insert) with a line reporting whether any menu is open through onOpenChange.

When to use: Reacting to the bar as a whole, for example dimming a canvas while a menu is open, without tracking each menu.

## Facets

- Kind: component / navigation
- Industry: general
- Style: glassmorphism
- Motion: subtle
- Interaction: keyboard, press, hover
- Layout: stack
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: DropdownMenuItem, Menubar, MenubarMenu
- Also searched as: menu bar, toolbar menu

## Spec

- `<Menubar aria-label="Document" onOpenChange={(o) => (open = o)}>` with two `MenubarMenu`s, Share and Insert
- `onOpenChange` fires when the bar goes from none open to one open and back, not when the pointer or arrows switch between menus
- A line reads "A menu is" followed by open or closed

## Source

```svelte
<script lang="ts">
  import { DropdownMenuItem, Menubar, MenubarMenu } from '@codeatlasdev/ui';

  let open = $state(false);
</script>

<Menubar aria-label="Document" onOpenChange={(o) => (open = o)}>
  <MenubarMenu label="Share">
    <DropdownMenuItem>Copy link</DropdownMenuItem>
    <DropdownMenuItem>Invite people</DropdownMenuItem>
  </MenubarMenu>
  <MenubarMenu label="Insert">
    <DropdownMenuItem>Table</DropdownMenuItem>
    <DropdownMenuItem>Image</DropdownMenuItem>
  </MenubarMenu>
</Menubar>
<span class="note">A menu is {open ? 'open' : 'closed'}.</span>

<style>
  .note { display: block; margin-block-start: var(--ca-space-3); font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); }
</style>
```
