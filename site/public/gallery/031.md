# #031 States

Four NumberField states in a Stack: with description, with error and required, disabled, and small.

When to use: Documenting helper text, validation, locked and compact variants of numeric fields such as seat counts.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: NumberField, Stack
- Also searched as: stepper, validation, seats

## Spec

- `<NumberField label="Seats" value={3} min={1} max={50} description="Max 50 seats per plan." />`
- `bind:value={seats}` with `let seats = $state(60)`, `error="Plans support up to 50 seats."` and `required`
- `<NumberField label="Fixed amount" bind:value={fixed} disabled />`
- `<NumberField label="Small" size="sm" value={2} />`
- `<Stack gap="4">` wraps the four fields

## Source

```svelte
<script lang="ts">
  import { NumberField, Stack } from '@codeatlasdev/ui';

  let fixed = $state(5);
  let seats = $state(60);
</script>

<Stack gap="4">
  <NumberField label="Seats" value={3} min={1} max={50} description="Max 50 seats per plan." />
  <NumberField label="Seats" bind:value={seats} min={1} max={50} error="Plans support up to 50 seats." required />
  <NumberField label="Fixed amount" bind:value={fixed} disabled />
  <NumberField label="Small" size="sm" value={2} />
</Stack>
```
