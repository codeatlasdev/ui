# #946 Marketing header

A marketing header nav with Products and Resources disclosure buttons that open panels of links (Products links carry a description), followed by Pricing (the current page) and Contact links.

When to use: The primary navigation of a marketing site: a few top-level links and a couple of grouped panels, reachable by hover, click and keyboard.

## Facets

- Kind: component / navigation
- Industry: saas
- Style: glassmorphism
- Motion: subtle
- Interaction: hover, keyboard, press
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: NavigationMenu, NavigationMenuItem, NavigationMenuLink
- Also searched as: mega menu, site header, top nav

## Spec

- `<NavigationMenu aria-label="Main">` renders a navigation landmark with a list
- `<NavigationMenuItem label="Products">` and `<NavigationMenuItem label="Resources">` are disclosure buttons whose children are `NavigationMenuLink`s
- Products links pass `description` for a second line that is part of the link name
- `<NavigationMenuLink href="#pricing" current>` marks the current page; Contact is a plain link

</NavigationMenu>
