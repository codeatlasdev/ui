# #055 States

Six text areas showing description, error, required, read-only, disabled and fixed-size states.

When to use: Reference for every validation and availability state of a multi-line field.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: TextArea
- Also searched as: validation, readonly, resize

## Spec

- Feedback has `description="Max 500 characters."`
- Bio has `error="Bio must be at least 20 characters."` and `description="Tell us about yourself."`
- Summary has `required`
- Read-only content uses `readonly`; Disabled content uses `disabled`, both `value="Cannot be edited."`
- Fixed uses `resize="none"` and `rows={3}`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/text-area#states

## Source

```svelte
<script lang="ts">
  import { TextArea } from '@codeatlasdev/ui';

  let bio = $state('');
  let summary = $state('');
  let feedback = $state('');
  let fixed = $state('This textarea cannot resize.');
</script>

<div class="col">
  <TextArea label="Feedback" description="Max 500 characters." bind:value={feedback} />
  <TextArea
    label="Bio"
    bind:value={bio}
    error="Bio must be at least 20 characters."
    description="Tell us about yourself."
  />
  <TextArea label="Summary" required bind:value={summary} />
  <TextArea label="Read-only content" value="Cannot be edited." readonly />
  <TextArea label="Disabled content" value="Cannot be edited." disabled />
  <TextArea label="Fixed" bind:value={fixed} resize="none" rows={3} />
</div>

<style>

    display: flex;

    gap: var(--ca-space-4);

  }
```
