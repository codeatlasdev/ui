# #250 Quote and reactions

An incoming bubble with a reply quote at the top and two reaction chips under it.

When to use: Chat messages that reply to an earlier message or carry emoji reactions.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: MessageBubble
- Also searched as: reply quote, emoji reaction, quoted reply

## Spec

- `<MessageBubble` with `direction="in"` and `sender="Carlos"`
- `reactions={[{ emoji: '👍', count: 2, mine: true }, { emoji: '🎉' }]}`
- `{#snippet quote()}` holds a `<strong>You</strong>` label and the quoted text

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/display/message-bubble#quote-and-reactions
Reference: https://ui.codeatlas.com.br/api/v1/en/e/250.txt

## Source

```svelte
<script lang="ts">
  import { MessageBubble } from '@codeatlasdev/ui';
</script>

<div class="thread">
  <MessageBubble
    direction="in"
    sender="Carlos"
    time="18:02"
    reactions={[{ emoji: '👍', count: 2, mine: true }, { emoji: '🎉' }]}
  >
    {#snippet quote()}
      <strong>You</strong>
      <span>Meeting moved to 3 pm</span>
    {/snippet}
    Perfect, see you there.
  </MessageBubble>
</div>
```
