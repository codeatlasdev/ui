# #964 Highlights

A four-slide carousel (Plan, Build, Ship, Learn) with arrows and dots, bound to an index shown in a caption.

When to use: Feature highlights, onboarding steps or testimonials where one item shows at a time.

## Facets

- Kind: component / display
- Style: default
- Motion: subtle
- Interaction: drag, press, keyboard
- Layout: carousel
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Carousel, CarouselItem
- Also searched as: slider, slideshow, swipe, product tour

## Spec

- `<Carousel label="Product highlights" bind:index>` over `{#each slides as title (title)}`
- Each slide is `<CarouselItem><div class="slide">{title}</div></CarouselItem>`
- `slides` is `['Plan', 'Build', 'Ship', 'Learn']`
- Caption `Slide {index + 1} of {slides.length}`

## Source

```svelte
<script lang="ts">
  import { Carousel, CarouselItem } from '@codeatlasdev/ui';

  const slides = ['Plan', 'Build', 'Ship', 'Learn'];
  let index = $state(0);
</script>

<div class="frame">
  <Carousel label="Product highlights" bind:index>
    {#each slides as title (title)}
      <CarouselItem><div class="slide">{title}</div></CarouselItem>
    {/each}
  </Carousel>
</div>
<p class="note">Slide {index + 1} of {slides.length}. Swipe, use the buttons, or focus the carousel and press the arrow keys.</p>

<style>

  .slide {
```
