# #961 Embed

An AspectRatio of 16/9 inside a 28rem frame holding a centred caption, standing in for a video or iframe.

When to use: Embeds, maps and video players that have no intrinsic size but must hold a ratio while loading.

## Facets

- Kind: component / display
- Industry: media
- Style: minimal
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: AspectRatio
- Also searched as: 16 9 box, video frame, responsive embed, ratio box

## Spec

- `<AspectRatio ratio={16 / 9}>` with one `<div class="slot">16 / 9: any child, one box</div>` child
- Wrapper `.frame` is `max-width: 28rem` with `--ca-radius-md` and `overflow: hidden`
- `.slot` is `height: 100%` on `--ca-surface-sunken` and centres its text

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/display/aspect-ratio#embed
Reference: https://ui.codeatlas.com.br/api/v1/en/e/961.txt

## Source

```svelte
<script lang="ts">
  import { AspectRatio } from '@codeatlasdev/ui';
</script>

<div class="frame">
  <AspectRatio ratio={16 / 9}>
    <div class="slot">16 / 9: any child, one box</div>
  </AspectRatio>
</div>

<style>
  .frame { max-width: 28rem; border-radius: var(--ca-radius-md); overflow: hidden; }
  .slot {
    display: grid;
    place-items: center;
    height: 100%;
    background: var(--ca-surface-sunken);
    color: var(--ca-text-secondary);
    font-size: var(--ca-font-size-caption);
  }
</style>
```
