# #075 Refraction layer

A LiquidGlass refraction layer using the regular optics preset behind a line of text in a padded frame.

When to use: Adding a real refraction effect to a hero or overlay frame, using a preset from GLASS_OPTICS.

## Facets

- Kind: component / surface
- Style: liquid, glassmorphism
- Motion: none
- Interaction: none
- Layout: overlay
- Color mode: both
- Density: airy
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: LiquidGlass
- Also searched as: refraction, lens, frosted lens

## Spec

- `<LiquidGlass optics={GLASS_OPTICS.regular} />`
- Imports `LiquidGlass` and `GLASS_OPTICS` from `@codeatlasdev/ui`
- Sits in `<div class="frame">` with `position: relative` and `overflow: hidden`
- Foreground text: Refraction layer behind this text.

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/surfaces/liquid-glass#refraction-layer
Reference: https://ui.codeatlas.com.br/api/v1/en/e/075.txt

<script lang="ts">
