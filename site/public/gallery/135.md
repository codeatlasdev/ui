# #135 More siblings

Pagination for 200 items at 10 per page with two sibling pages shown on each side of the current page.

When to use: Long result sets where users need to jump a few pages around the current one.

## Facets

- Kind: component / display
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Pagination
- Also searched as: ellipsis pager, sibling pages, long pager

## Spec

- `<Pagination count={200} perPage={10} siblingCount={2} />`
- `siblingCount={2}` sets how many pages show on each side of the current page
- Only `count`, `perPage` and `siblingCount` are set, nothing is bound
