# #175 Basic metrics

Three KPI cards with title, value, an optional unit, a positive or negative trend and an icon, inside a KpiGrid.

When to use: Dashboard headline numbers such as revenue, users and conversion with their period-over-period change.

## Facets

- Kind: component / layout
- Industry: saas, fintech
- Style: default, bento
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: KpiCard, KpiGrid
- Also searched as: metric card, dashboard stat, trend indicator

## Spec

- `<KpiGrid>` with 3 `KpiCard` items
- `<KpiCard title="Monthly Revenue" value="$48,200" trend={12.4} icon={DollarSign} />`
- `<KpiCard title="Active Users" value="3,847" trend={-2.1} icon={Users} />`
- `<KpiCard title="Conversion" value="4.8" unit="%" trend={0.6} icon={TrendingUp} />`
