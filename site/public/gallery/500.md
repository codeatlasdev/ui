# #500 Password

A sign-in pair of TextFields: a required email and a revealable password with a Forgot password link under it, neither showing an asterisk.

When to use: Login and reset forms: the show/hide password eye, a link or strength meter under the field, and required fields without the asterisk when nothing is optional.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard, press
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: TextField
- Also searched as: login, sign in, show password

## Spec

- Email field `type="email"` with `required` and `requiredIndicator={false}`: the input is required, the label shows no asterisk
- Password field `type="password"` with `revealable`: the component renders the eye button inside the field; the demo has no local reveal state
- `{#snippet below()}` renders `<a href="/forgot-password">Forgot password?</a>` under the field, after any error or description
- Column wrapper has `max-width: 400px`

<script lang="ts">
  import { TextField } from '@codeatlasdev/ui';

  let email = $state('');
  let password = $state('');

<div class="col">
  <TextField label="Email" type="email" autocomplete="email" required requiredIndicator={false} bind:value={email} />
  <TextField
    label="Password"
    type="password"
    revealable
    required
    requiredIndicator={false}
    autocomplete="current-password"
    bind:value={password}
  >
    {#snippet below()}
      <a href="/forgot-password">Forgot password?</a>
    {/snippet}
  </TextField>
</div>
