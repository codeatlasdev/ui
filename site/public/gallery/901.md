# #901 Responsive keyboard hint

Two outlined neutral Buttons (Next lead, Snooze) with a Kbd keyboard hint in the trailing slot, marked trailingHint so the hint disappears below md and on touch screens without leaving a gap.

When to use: Queue and inbox actions that show a keyboard shortcut on desktop only.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, Kbd
- Also searched as: shortcut hint, keycap

## Spec

- `<Button variant="outlined" tone="neutral" trailingHint>` labelled Next lead with a `trailing` snippet holding `<Kbd>K</Kbd>`
- A second one labelled Snooze with `<Kbd>S</Kbd>`
- Wrapping flex `.row` with `gap: var(--ca-space-3)`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/button#responsive-keyboard-hint
