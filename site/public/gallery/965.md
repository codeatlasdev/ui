# #965 Several per view

Five plan cards shown three at a time in a looping carousel.

When to use: Card rows that overflow: pricing tiers, related products, team members.

## Facets

- Kind: component / display
- Style: default
- Motion: subtle
- Interaction: drag, press, keyboard
- Layout: carousel
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Carousel, CarouselItem
- Also searched as: multi item slider, plan cards, card row, pricing slider

## Spec

- `<Carousel label="Plans" perView={3} loop>` over five names
- Each card is `<CarouselItem><div class="card">{name}</div></CarouselItem>`
- `cards` is `['Starter', 'Team', 'Business', 'Enterprise', 'Partner']`

Needs: @codeatlasdev/ui@4.5.0

## Source

```svelte
<script lang="ts">
  import { Carousel, CarouselItem } from '@codeatlasdev/ui';

  const cards = ['Starter', 'Team', 'Business', 'Enterprise', 'Partner'];
</script>

<div class="frame">
  <Carousel label="Plans" perView={3} loop>
    {#each cards as name (name)}
      <CarouselItem><div class="card">{name}</div></CarouselItem>
    {/each}
  </Carousel>
</div>

<style>
  .frame { max-width: 36rem; }
  .card {
    display: grid;
    place-items: center;
    height: 6rem;
    margin-inline: var(--ca-space-1);
    border: var(--ca-border-width) solid var(--ca-outline-default);
    border-radius: var(--ca-radius-md);
    color: var(--ca-text-primary);
  }
</style>
```
