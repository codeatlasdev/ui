# #017 DateField and TimeField

Segmented DateField and TimeField inputs with bound values, minute granularity and 24h and 12h hour cycles.

When to use: Typing a date or time directly in a form, such as a birthday or an appointment start time.

## Facets

- Kind: component / input
- Industry: general
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: DateField, TimeField
- Also searched as: segmented date, time input, 12 hour 24 hour

## Spec

- `<DateField label="Birthday" locale="en-US" bind:value={birthday} />` initialised with `new CalendarDate(2026, 10, 10)`
- `<DateField label="Starts at" locale="en-US" granularity="minute" />`
- `<TimeField label="Time (24h)" locale="en-US" hourCycle={24} bind:value={time} />` initialised with `new Time(14, 30)`
- `<TimeField label="Time (12h)" locale="en-US" hourCycle={12} />`
- Two `value:` output lines print `birthday.toString()` and `time.toString()`

## Source

```svelte
<script lang="ts">
  import { CalendarDate, DateField, Time, TimeField, type DateValue } from '@codeatlasdev/ui';

  let birthday = $state<DateValue | undefined>(new CalendarDate(2026, 10, 10));
  let time = $state<Time | undefined>(new Time(14, 30));
</script>

<div class="col">
  <DateField label="Birthday" locale="en-US" bind:value={birthday} />
  <DateField label="Starts at" locale="en-US" granularity="minute" />
  <p class="out">value: <code>{birthday ? birthday.toString() : '–'}</code></p>
  <TimeField label="Time (24h)" locale="en-US" hourCycle={24} bind:value={time} />
  <TimeField label="Time (12h)" locale="en-US" hourCycle={12} />
  <p class="out">value: <code>{time ? time.toString() : '–'}</code></p>
</div>

<style>
  .col {

    flex-direction: column;

  }

    margin: 0;
    font-size: var(--ca-font-size-caption);
    color: var(--ca-text-secondary);
  }
</style>
```
