# #214 Bubble chart

A bubble chart where each of 50 accounts carries a third value that sets the bubble size.

When to use: Adding a third dimension, such as account size, to a two-axis comparison.

## Facets

- Kind: component / chart
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, ScatterChart
- Also searched as: weighted scatter, size encoding, three variables

## Spec

- `data` is 50 `[number, number, number]` triples from `Array.from({ length: 50 }`
- The third value of each point is the bubble size
- `<ScatterChart series={[{ name: 'Accounts', data }]}`
- `yName="Conversion %"` and `yFormatter={(v) => `${v.toFixed(1)}%`}`
- `height="340px"` inside `<Card full>`

Needs: @codeatlasdev/ui@4.5.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/scatter#bubble-chart

## Source

```svelte
<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { ScatterChart } from '@codeatlasdev/ui/charts';

  // The third value of each point is the bubble size.
  const data = Array.from({ length: 50 }, (_, i): [number, number, number] => [
    Math.round(1000 + 13000 * (0.5 + 0.5 * Math.sin(i * 0.43 + 0.6)) * (0.65 + 0.35 * Math.cos(i * 0.19))),
    parseFloat((1 + 12 * (0.5 + 0.5 * Math.cos(i * 0.37 + 1.1)) * (0.7 + 0.3 * Math.sin(i * 0.53))).toFixed(2)),
    Math.round(1000 + 49000 * Math.abs(Math.sin(i * 0.29 + 0.4)) * Math.abs(Math.cos(i * 0.11))),
  ]);
</script>

<Card full>
  <ScatterChart series={[{ name: 'Accounts', data }]} yName="Conversion %" yFormatter={(v) => `${v.toFixed(1)}%`} height="340px" />
</Card>
```
