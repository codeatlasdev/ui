# #099 Text lines

A card skeleton with a 60% wide heading line above a block of three text lines.

When to use: Loading placeholder for an article or description block.

## Facets

- Kind: component / feedback
- Style: default
- Motion: expressive
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Skeleton, Card, Stack
- Also searched as: placeholder, text loading, shimmer

## Spec

- `<Card p="5" full>` with `<Stack gap="3">`
- Heading line `<Skeleton height="20px" width="60%" />`
- Body lines `<Skeleton rows={3} height="14px" />` render three rows from one element
