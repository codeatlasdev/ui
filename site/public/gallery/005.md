# #005 States

Disabled buttons, a destructive action with an icon, and a link rendered as a button.

When to use: Showing non-interactive and dangerous actions, or navigating with button styling via `href`.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button
- Also searched as: inactive, danger, link

## Spec

- `disabled` on `variant="filled"`, `variant="outlined"` and `variant="glass"`
- `variant="destructive"` with a `Trash2` icon in `{#snippet leading()}` (`size={15}`)
- `href="https://github.com/codeatlasdev/ui"` with `target="_blank"` renders an anchor

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/button#states
Reference: https://ui.codeatlas.com.br/api/v1/en/e/005.txt

## Source

```svelte
<script lang="ts">
  import { Button } from '@codeatlasdev/ui';
  import { Trash2 } from '@lucide/svelte';
</script>

<Button variant="filled" disabled>Filled</Button>
<Button variant="outlined" disabled>Outlined</Button>
<Button variant="glass" disabled>Glass</Button>
<Button variant="destructive">
  {#snippet leading()}<Trash2 size={15} stroke-width={2} />{/snippet}
  Delete account
</Button>
<Button variant="outlined" href="https://github.com/codeatlasdev/ui" target="_blank">Link button</Button>
```
