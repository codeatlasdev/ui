# #986 Inline content

A button pair inside a PreviewStage at 390 px, with a toolbar button that flips the content between light and dark.

When to use: Showcasing a component at phone, tablet and desktop width inside a docs page or a design review.

## Facets

- Kind: component / layout
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, PreviewStage
- Also searched as: device frame, responsive preview, theme toggle preview

## Spec

- `<PreviewStage label="Button pair" bind:width {scheme} height={220}>`
- `{#snippet toolbar()}` adds a Dark / Light toggle next to the width control
- The content is themed in its own island: the page around the stage keeps its scheme

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/layout/preview-stage#inline-content

## Source

```svelte
<script lang="ts">
  import { Button, PreviewStage } from '@codeatlasdev/ui';

  let width = $state<number | 'fill'>(390);
  let scheme = $state<'light' | 'dark'>('light');
</script>

<PreviewStage label="Button pair" bind:width {scheme} height={220}>
  <Button>Continue</Button>
  <Button variant="outlined">Cancel</Button>
  {#snippet toolbar()}
    <Button size="sm" variant="ghost" onclick={() => (scheme = scheme === 'light' ? 'dark' : 'light')}>
      {scheme === 'light' ? 'Dark' : 'Light'}
    </Button>
  {/snippet}
</PreviewStage>
```
