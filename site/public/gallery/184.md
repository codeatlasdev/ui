# #184 AppSettings

A settings page with General and Security tabs, a Save action and form sections with text fields and switches.

When to use: Workspace or account settings split into tabs, each with its own grouped form.

## Facets

- Kind: component / layout
- Industry: saas
- Style: default
- Motion: subtle
- Interaction: keyboard, press
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: AppSettings, Button, FormSection, Switch, TextField
- Also searched as: preferences, tabbed settings, workspace settings

## Spec

- `<AppSettings title="Settings" tabs={TABS}>` with `const TABS` of 2 entries: General (`value: 'general'`) and Security (`value: 'security'`), each with an `icon`
- `{#snippet actions()}` holds `<Button variant="filled" size="sm">Save</Button>`
- `{#snippet children(tab)}` switches on `{#if tab === 'general'}` and `{:else if tab === 'security'}`
- General has `<FormSection title="Workspace">` with `<TextField label="Name" bind:value={wsName} />` and `<TextField label="Slug" value="my-workspace" />`
- Security has `<FormSection title="Authentication" layout="list">` with `<Switch label="Two-factor authentication" />` and `<Switch label="Single sign-on (SSO)" />`
- Frame size is `height: 380px`

## Source

```svelte
<script lang="ts">
  import { AppSettings, Button, FormSection, Switch, TextField } from '@codeatlasdev/ui';
  import { Settings, Shield } from '@lucide/svelte';

  const TABS = [
    { value: 'general', label: 'General', icon: Settings },
    { value: 'security', label: 'Security', icon: Shield },
  ];
  let wsName = $state('My Workspace');
</script>

<div class="frame">
  <AppSettings title="Settings" tabs={TABS}>
    {#snippet actions()}
      <Button variant="filled" size="sm">Save</Button>
    {/snippet}
    {#snippet children(tab)}
      {#if tab === 'general'}
        <FormSection title="Workspace">
          <TextField label="Name" bind:value={wsName} />
          <TextField label="Slug" value="my-workspace" />
        </FormSection>
      {:else if tab === 'security'}
        <FormSection title="Authentication" layout="list">
          <Switch label="Two-factor authentication" />
          <Switch label="Single sign-on (SSO)" />
        </FormSection>
      {/if}
    {/snippet}
  </AppSettings>
</div>

<style>
  .frame {
    width: 100%;
    height: 380px;
    border-radius: var(--ca-radius-lg);
    box-shadow: inset 0 0 0 1px var(--ca-outline-subtle);
    overflow: hidden;
    display: flex;
    flex-direction: column;
  }
</style>
```
