# #202 Multi-line comparison

A line chart with three series, Revenue, Expenses and Profit, across nine months.

When to use: Comparing related metrics over time, such as income against cost and the resulting margin.

## Facets

- Kind: component / chart
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, LineChart
- Also searched as: multi series, profit and loss, compare lines

## Spec

- `<LineChart` with 3 series: `{ name: 'Revenue', data: revenue }`, `{ name: 'Expenses', data: expenses }`, `{ name: 'Profit', data: profit }`
- `const profit = revenue.map((r, i) => r - expenses[i])` derives the third series
- `categories={months}` with `'Jan'` to `'Sep'`
- `valueFormatter={fmt}` renders `$${(v / 1000).toFixed(0)}k`
- `height="300px"` inside `<Card full>`

Needs: @codeatlasdev/ui@4.6.0 + echarts

## Source

```svelte
<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { LineChart } from '@codeatlasdev/ui/charts';

  const months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep'];
  const revenue = [42000, 51000, 58000, 63000, 72000, 80000, 88000, 95000, 112000];
  const expenses = [38000, 41000, 44000, 47000, 52000, 55000, 58000, 61000, 67000];
  const profit = revenue.map((r, i) => r - expenses[i]);
  const fmt = (v: number) => `$${(v / 1000).toFixed(0)}k`;
</script>

<Card full>
  <LineChart
    series={[
      { name: 'Revenue', data: revenue },
      { name: 'Expenses', data: expenses },
      { name: 'Profit', data: profit },
    ]}
    categories={months}
    valueFormatter={fmt}
    height="300px"
  />
</Card>
```
