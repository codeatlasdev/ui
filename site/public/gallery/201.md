# #201 Area with gradient fill

A single Revenue line with a filled area under it across nine months.

When to use: Emphasizing volume or cumulative growth of one metric over time.

## Facets

- Kind: component / chart
- Industry: fintech, saas
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, LineChart
- Also searched as: filled line, trend, growth curve

## Spec

- `<LineChart` with one series `{ name: 'Revenue', data: revenue }`
- `revenue` has 9 values from `42000` to `112000`
- `categories={months}` with `'Jan'` to `'Sep'`
- `area` prop
- `valueFormatter={fmt}` renders `$${(v / 1000).toFixed(0)}k`
- `height="360px"` inside `<Card full>`

Needs: @codeatlasdev/ui@4.5.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/line#area-with-gradient-fill
Reference: https://ui.codeatlas.com.br/api/v1/en/e/201.txt

## Source

```svelte
<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { LineChart } from '@codeatlasdev/ui/charts';

  const months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep'];
  const revenue = [42000, 51000, 58000, 63000, 72000, 80000, 88000, 95000, 112000];
  const fmt = (v: number) => `$${(v / 1000).toFixed(0)}k`;
</script>

<Card full>
  <LineChart series={[{ name: 'Revenue', data: revenue }]} categories={months} valueFormatter={fmt} area height="360px" />
</Card>
```
