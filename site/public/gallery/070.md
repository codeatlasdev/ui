# #070 Header and actions

A Card with a built-in Team members header and an Invite button supplied through a headerActions snippet.

When to use: Panels whose header needs a title and an action, such as team, billing or settings sections.

## Facets

- Kind: component / surface
- Industry: saas
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Card, Button
- Also searched as: panel header, card toolbar, titled panel

## Spec

- `<Card title="Team members" class="titled">` with `max-width: 420px`
- `{#snippet headerActions()}` renders `<Button size="sm" variant="outlined">Invite</Button>`
- Body is one paragraph explaining `title` and `headerActions`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/surfaces/card#header-and-actions

```svelte
<script lang="ts">

  <p>Use <code>title</code> and <code>headerActions</code> for a built-in card header.</p>
```
