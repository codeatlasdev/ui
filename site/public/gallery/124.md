# #124 Horizontal

Three stacked text sections inside a card separated by horizontal dividers.

When to use: Separating sections of content inside a card or panel.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Divider, Card, Stack
- Also searched as: separator, horizontal rule, hr

## Spec

- `<Card p="6" full>` wraps the content
- `<Stack gap="4">` stacks Section A, B and C paragraphs
- `<Divider />` is placed between them with no props

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/display/divider#horizontal
Reference: https://ui.codeatlas.com.br/api/v1/en/e/124.txt

## Source

```svelte
<script lang="ts">
  import { Divider, Card, Stack } from '@codeatlasdev/ui';
</script>

<Card p="6" full>
  <Stack gap="4">
    <p>Section A content</p>
    <Divider />
    <p>Section B content</p>
    <Divider />
    <p>Section C content</p>
  </Stack>
</Card>

<style>
  p { margin: 0; font-size: var(--ca-font-size-body1); color: var(--ca-text-secondary); }
</style>
```
