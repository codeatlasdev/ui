# #009 Without label

Three checkboxes with no visible label, named only through aria-label: bound, checked and indeterminate.

When to use: Row selection checkboxes in tables or lists where the label is implied by the row and only an accessible name is needed.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Checkbox
- Also searched as: unlabelled, aria label only

## Spec

- `bind:checked={value}` with `aria-label="Unlabelled checkbox"`
- `checked` with `aria-label="Unlabelled checked checkbox"`
- `indeterminate` with `aria-label="Unlabelled indeterminate checkbox"`
- No `label` prop on any of the three

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/checkbox#without-label
