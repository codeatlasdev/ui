# #246 Without a menu

A three column record list of webhooks with no actions slot, so there is no trailing menu track.

When to use: Read-only lists such as webhook endpoints or logs where rows have facts but no per-row actions.

## Facets

- Kind: component / layout
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: RecordCell, RecordList, RecordRow
- Also searched as: webhook list, endpoint rows, read only rows

## Spec

- `<RecordList` with `columns="minmax(0,2fr) minmax(0,1.4fr) 5rem"`
- `labels={['Endpoint', 'Events', 'Delivered']}` and `aria-label="Webhooks"`
- 2 rows from `hooks`, each a `<RecordRow>` keyed by `hook.id`
- `{#snippet identity()}` renders the endpoint as `<code>{hook.url}</code>`
- `<RecordCell label="Events">` and `<RecordCell label="Delivered">` follow; the row has no actions snippet and `columns` has no trailing action track

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/layout/record-list#without-a-menu
Reference: https://ui.codeatlas.com.br/api/v1/en/e/246.txt

## Source

```svelte
<script lang="ts">
  import { RecordCell, RecordList, RecordRow } from '@codeatlasdev/ui';

  const hooks = [
    { id: 1, url: 'https://example.com/hooks/orders', events: 'order.created', ok: '99.8%' },
    { id: 2, url: 'https://example.com/hooks/refunds', events: 'refund.created refund.failed', ok: '100%' },
  ];
</script>

<RecordList
  columns="minmax(0,2fr) minmax(0,1.4fr) 5rem"
  labels={['Endpoint', 'Events', 'Delivered']}
  aria-label="Webhooks"
>
  {#each hooks as hook (hook.id)}
    <RecordRow>
      {#snippet identity()}<code>{hook.url}</code>{/snippet}
      <RecordCell label="Events">{hook.events}</RecordCell>
      <RecordCell label="Delivered">{hook.ok}</RecordCell>
    </RecordRow>
  {/each}
</RecordList>

<style>
  code { font-size: var(--ca-font-size-caption); overflow-wrap: anywhere; }
</style>
```
