# #059 Basic

Theme toggle button rendered inside a rail container.

When to use: Letting users switch between light and dark appearance from a sidebar or header.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard, hover
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: ThemeToggle
- Also searched as: dark mode, light mode, color scheme

## Spec

- `<ThemeToggle />` with no props
- Wrapped in `<div class="rail">`
