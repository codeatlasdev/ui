# #067 Single

A single-open Accordion with three FAQ questions about theming, where opening one closes the others.

When to use: FAQ sections where only one answer should be visible at a time.

## Facets

- Kind: component / surface
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Accordion, AccordionItem
- Also searched as: faq, one at a time, collapse panel

## Spec

- `<Accordion type="single">`
- 3 items: `<AccordionItem value="a1" title="What is a surface style?">`, `value="a2"` and `value="a3"`
- Item titles: What is a surface style?, Do I need to change components to restyle the app?, Can I nest a Surface inside a Card?
- The accordion is uncontrolled, nothing is bound
- Wrapped in `.wrap` with `max-width: 560px`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/surfaces/accordion#single
Reference: https://ui.codeatlas.com.br/api/v1/en/e/067.txt

## Source

```svelte
<script lang="ts">
  import { Accordion, AccordionItem } from '@codeatlasdev/ui';
</script>

<div class="wrap">
  <Accordion type="single">
    <AccordionItem value="a1" title="What is a surface style?">
      A surface style is one knob of the theme: solid (the default), flat, outlined, tonal, frosted,
      glass and more. Every component follows it.
    </AccordionItem>
    <AccordionItem value="a2" title="Do I need to change components to restyle the app?">
      No. Change the theme object and every component follows, in light and dark.
    </AccordionItem>
    <AccordionItem value="a3" title="Can I nest a Surface inside a Card?">
      Yes. A Card is a Surface, so any Surface can sit inside it.
    </AccordionItem>
  </Accordion>
</div>

<style>
  .wrap { width: 100%; max-width: 560px; }
</style>
```
