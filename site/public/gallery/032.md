# #032 Default

A verification-code PinInput that reports its value and completion, plus a masked four-digit PIN.

When to use: One-time code entry for sign-in verification, or a short secret PIN that must be hidden.

## Facets

- Kind: component / input
- Industry: saas
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: PinInput
- Also searched as: otp, verification code, one time code, passcode

## Spec

- `<PinInput label="Verification code" bind:value={code} oncomplete={(v) => (done = v)} />`
- Output line prints `value: {code || '–'} · completed: {done || '–'}`
- `<PinInput label="PIN" length={4} mask bind:value={pin} />`
