# #780 Scoped block

ThemeIsland as a scoped block: a light ocean island inside a dark page.

When to use: A section or card that must use another preset or scheme than the rest of the app, without touching <html>.

## Facets

- Kind: component / layout
- Style: default
- Motion: none
- Interaction: press, keyboard
- Layout: single-column
- Color mode: light
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, ThemeIsland
- Also searched as: scoped theme, light block, forced scheme, theme boundary

## Spec

- `<ThemeIsland preset="ocean" scheme="light"`
- A light block inside the page, nothing mirrored to the document

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/layout/theme-island#scoped-block
Reference: https://ui.codeatlas.com.br/api/v1/en/e/780.txt

## Source

```svelte
<script lang="ts">
  import { Button, ThemeIsland } from '@codeatlasdev/ui';
</script>

<!-- A light island inside whatever scheme the page uses. -->
<ThemeIsland preset="ocean" scheme="light" class="island">
  <div class="island-body">
    <h3>Ink on cream</h3>
    <p>This block is light even when the app is dark.</p>
    <Button variant="filled" size="sm">Get started</Button>
  </div>
</ThemeIsland>

<style>
  :global(.island) {
    min-height: 0;
    border-radius: var(--ca-radius-lg);
    overflow: hidden;
  }
  .island-body {
    display: grid;
    gap: var(--ca-space-3);
    padding: var(--ca-space-6);
    justify-items: start;
  }
</style>
```
