# #077 Interactive

A Surface rendered as a button that counts how many times it was pressed.

When to use: Custom clickable tiles or cards that need hover and press feedback while staying a native button.

## Facets

- Kind: component / surface
- Style: default
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Surface
- Also searched as: clickable tile, press feedback, button surface

## Spec

- `<Surface` with `as="button"`, `type="button"` and `interactive`
- Styling props: `elevation={2}`, `material="solid"`, `radius="md"`, `p="4"`
- Handler: `onclick={() => count++}`
- State: `let count = $state(0)`
- Label: `Pressed {count} times`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/surfaces/surface#interactive
Reference: https://ui.codeatlas.com.br/api/v1/en/e/077.txt

## Source

```svelte
<script lang="ts">
  import { Surface } from '@codeatlasdev/ui';

  let count = $state(0);
</script>

<Surface
  as="button"
  type="button"
  interactive
  elevation={2}
  material="solid"
  radius="md"
  p="4"
  onclick={() => count++}
>
  Pressed {count} times
</Surface>
```
