# #109 Shape and status

Large avatars showing the rounded shape and the four status indicators: online, busy, away and offline.

When to use: Presence in chat, team lists or support queues, plus a rounded avatar shape.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Avatar
- Also searched as: presence, online indicator, availability dot

## Spec

- `shape="rounded"` on `alt="Ana Lima"`
- `status="online"` on `alt="Online"`
- `status="busy"` on `alt="Busy"`
- `status="away"` on `alt="Away"`
- `status="offline"` on `alt="Offline"`
- All five use `size="lg"`
