# #5016 Filter strip, overflow scroll

A row of small outlined filter buttons that stays on one line and scrolls sideways, with no scrollbar drawn.

When to use: A quick-filter strip above a list where every option must stay reachable and none should be hidden in a menu.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, Toolbar
- Also searched as: filter strip, scrolling toolbar, chip row

## Spec

- `<Toolbar aria-label="Deal filters" overflow="scroll">`
- Eight small outlined neutral `Button`s generated from a list
- `overflow="scroll"` keeps the row on one line and scrolls it sideways with no scrollbar drawn; the buttons keep their size

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/toolbar#filter-strip-overflow-scroll

## Source

```svelte
<script lang="ts">
  import { Button, Toolbar } from '@codeatlasdev/ui';

  const filters = ['All', 'Open', 'Won', 'Lost', 'Stalled', 'Archived', 'Mine', 'Unassigned'];
</script>

<Toolbar aria-label="Deal filters" overflow="scroll">
  {#each filters as label}
    <Button variant="outlined" tone="neutral" size="sm">{label}</Button>
  {/each}
</Toolbar>
```
