# #5007 Avatar group

A labelled group of six overlapping avatars: three photos and three initials, capped at four with an overflow chip counting the other two.

When to use: Showing who is on a review, task or document when only the first few fit: the chip says how many more, in the page language.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: AvatarGroup
- Also searched as: avatar group, overlapping avatars, facepile, team members, plus n overflow

## Spec

- `const reviewers` has 6 entries: Alice, Bob and Clara with `src`, Davi, Eva and Fabio without
- `<AvatarGroup items={reviewers} max={4} label="Reviewers" />` renders four avatars and a chip for the rest
