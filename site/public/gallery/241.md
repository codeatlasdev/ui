# #241 The skeleton prop

Avatar, KpiCard, TextField and Card all switched to their skeleton state by one shared loading flag.

When to use: Loading states where real components keep their exact size and show a placeholder until data arrives.

## Facets

- Kind: component / feedback
- Style: default
- Motion: expressive
- Interaction: press
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Avatar, Button, Card, Flex, KpiCard, Stack, TextField
- Also searched as: loading state, placeholder, layout shift

## Spec

- `let loading = $state(true)` passed as `skeleton={loading}` to four components
- `<Avatar alt="Ana Lima" size="xl" skeleton={loading} />` and `<KpiCard title="Revenue" value="R$ 12.400" trend={3.2} skeleton={loading} />`
- `<TextField label="Email" description="We never share it" skeleton={loading} />`
- `<Card title="Overview" skeleton={loading}>` with one paragraph of content
- Toggle `<Button variant="outlined" size="sm"` runs `onclick={() => (loading = !loading)}`

## Source

```svelte
<script lang="ts">
  import { Avatar, Button, Card, Flex, KpiCard, Stack, TextField } from '@codeatlasdev/ui';

  let loading = $state(true);
</script>

<Stack gap="4">
  <Button variant="outlined" size="sm" onclick={() => (loading = !loading)}>
    {loading ? 'Show loaded' : 'Show loading'}
  </Button>
  <Flex gap="4" align="start" wrap>
    <Avatar alt="Ana Lima" size="xl" skeleton={loading} />
    <KpiCard title="Revenue" value="R$ 12.400" trend={3.2} skeleton={loading} />
  </Flex>
  <TextField label="Email" description="We never share it" skeleton={loading} />
  <Card title="Overview" skeleton={loading}>
    <p>The card keeps the exact size it has once loaded, so nothing shifts when the data arrives.</p>
  </Card>
</Stack>
```
