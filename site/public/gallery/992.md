# #992 Label and number

Two labelled sliders with an editable number and a unit: radius and type scale.

When to use: Tuning a numeric setting where both scrubbing and typing an exact value matter.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: drag, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: SliderField
- Also searched as: labelled slider, slider with number, settings slider, editable value

## Spec

- Two `<SliderField` stacked in a column
- First: `label="Radius"`, `bind:value={radius}`, `min={0}`, `max={2}`, `step={0.05}`, `unit="x"`, initial `0.8`
- Second: `label="Type scale"`, `bind:value={scale}`, `min={0.8}`, `max={1.3}`, `step={0.01}`, `unit="x"`, initial `1`, with a `description` Multiplies every font size.

  <SliderField label="Type scale" bind:value={scale} min={0.8} max={1.3} step={0.01} unit="x" description="Multiplies every font size." />
</div>
