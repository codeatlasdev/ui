# #249 Delivery status

Four outgoing bubbles, one per delivery state: pending, sent, delivered and read.

When to use: Showing message delivery ticks in a chat, with a visually hidden status text for screen readers.

## Facets

- Kind: component / display
- Industry: saas
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: MessageBubble
- Also searched as: delivery receipt, read receipt, sent delivered read, message state

## Spec

- `const states = ['pending', 'sent', 'delivered', 'read'] as const;`
- `{#each states as status}` renders `<MessageBubble direction="out" time="09:41" {status}>`

```svelte
<script lang="ts">
  import { MessageBubble } from '@codeatlasdev/ui';

  const states = ['pending', 'sent', 'delivered', 'read'] as const;

  {#each states as status}
    <MessageBubble direction="out" time="09:41" {status}>{status}</MessageBubble>
  {/each}
</div>
```
