# #193 Vertical bars

A vertical bar chart of one Revenue series across four quarters.

When to use: Comparing a single metric across a few time periods, such as quarterly revenue.

## Facets

- Kind: component / chart
- Industry: fintech, saas
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, BarChart
- Also searched as: column chart, quarterly revenue, histogram

## Spec

- `<BarChart` inside `<Card full>`
- One series `{ name: 'Revenue', data: [38400, 54200, 71600, 89800] }`
- `categories={['Q1', 'Q2', 'Q3', 'Q4']}`
- `valueFormatter={fmt}` renders `$${(v / 1000).toFixed(0)}k`
- `height="300px"`

Needs: @codeatlasdev/ui@4.5.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/bar#vertical-bars
Reference: https://ui.codeatlas.com.br/api/v1/en/e/193.txt

## Source

```svelte
<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { BarChart } from '@codeatlasdev/ui/charts';

  const fmt = (v: number) => `$${(v / 1000).toFixed(0)}k`;
</script>

<Card full>
  <BarChart series={[{ name: 'Revenue', data: [38400, 54200, 71600, 89800] }]} categories={['Q1', 'Q2', 'Q3', 'Q4']} valueFormatter={fmt} height="300px" />
</Card>
```
