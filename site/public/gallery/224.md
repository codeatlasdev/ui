# #224 Text

Four swatches for the text color tokens: primary, secondary, hint and disabled.

When to use: Choosing a text color by importance, from main content to hints and disabled labels.

## Facets

- Kind: component / foundation
- Style: default
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: none
- Also searched as: foreground colors, font colors, text contrast

## Spec

- Renders `<Swatches {tokens} bordered={true} />` with 4 tokens
- Tokens in order: `--ca-text-primary`, `--ca-text-secondary`, `--ca-text-hint`, `--ca-text-disabled`
