# #720 Wrapping chips

Single-choice chips for a sales team size: five short options that wrap to two rows on a phone.

When to use: Choosing one of a few short options (team size, plan length, frequency) where RadioGroup is too tall and SegmentedControl would overflow a 390px screen.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: ChipGroup
- Also searched as: choice chips, pills, team size

## Spec

- `<ChipGroup label="Sales team size" items={sizes} bind:value={size} />`
- `sizes` has 5 items: `1` Just me, `2-5` 2 to 5, `6-20` 6 to 20, `21-50` 21 to 50, `50+` 50+
- `bind:value={size}` with initial `$state('2-5')`; the selected chip shows a check icon

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/chip-group#wrapping-chips
Reference: https://ui.codeatlas.com.br/api/v1/en/e/720.txt

## Source

```svelte
<script lang="ts">
  import { ChipGroup } from '@codeatlasdev/ui';

  let size = $state('2-5');

  const sizes = [
    { value: '1', label: 'Just me' },
    { value: '2-5', label: '2 to 5' },
    { value: '6-20', label: '6 to 20' },
    { value: '21-50', label: '21 to 50' },
    { value: '50+', label: '50+' },
  ];
</script>

<ChipGroup label="Sales team size" items={sizes} bind:value={size} />
```
