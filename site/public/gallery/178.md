# #178 Four cards

A KpiGrid holding four KPI cards: Revenue, Users, Growth and Uptime, each with a trend and icon.

When to use: A full-width row of headline metrics at the top of a dashboard.

## Facets

- Kind: component / layout
- Style: bento, default
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: KpiCard, KpiGrid
- Also searched as: four metrics, dashboard row, stat grid

## Spec

- `<KpiGrid>` with 4 `KpiCard` items
- `<KpiCard title="Revenue" value="$112k" trend={18.4} icon={DollarSign} />`
- `<KpiCard title="Users" value="24.8k" trend={12.1} icon={Users} />`
- `<KpiCard title="Growth" value="34" unit="%" trend={5.6} icon={TrendingUp} />`
- `<KpiCard title="Uptime" value="99.9" unit="%" trend={0.1} icon={Activity} />`
