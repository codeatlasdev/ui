# #243 iOS instructions

The install prompt in iOS mode, showing add to home screen instructions inside a reserved stage box.

When to use: Prompting Safari on iPhone users, who have no native install event, to install the app to their home screen.

## Facets

- Kind: component / feedback
- Industry: general
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: InstallPrompt
- Also searched as: add to home screen, pwa, install banner

## Spec

- `<InstallPrompt mode="ios" storageKey="demo-install-ios" />`
- Wrapped in `<div class="stage">` with `min-height: calc(var(--ca-space-8) * 3)` so the page does not shift when it appears
- No handlers or state in the demo, the prompt renders only after mounting in the browser

Needs: @codeatlasdev/ui@4.5.0
