# #190 Horizontal bars

A horizontal bar chart ranking eight products by a single Sales series, with values formatted as thousands.

When to use: Ranking items by one metric, such as top products or top accounts, when category labels are long.

## Facets

- Kind: component / chart
- Industry: saas, e-commerce
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, BarChart
- Also searched as: ranking, leaderboard, top products

## Spec

- `<BarChart` inside `<Card full>`
- One series `{ name: 'Sales', data: [9840, 8720, 7650, 6430, 5980, 4810, 3920, 3140] }`
- `categories={products}` with 8 product names
- `horizontal` prop
- `valueFormatter` renders `${(v / 1000).toFixed(1)}k`
- `height="300px"`

Needs: @codeatlasdev/ui@4.5.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/bar#horizontal-bars
Reference: https://ui.codeatlas.com.br/api/v1/en/e/190.txt

## Source

```svelte
<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { BarChart } from '@codeatlasdev/ui/charts';

  const products = ['Atlas Pro', 'Nova Suite', 'Relay SDK', 'Mesh API', 'Drift UI', 'Pulse DB', 'Forge CI', 'Orbit ML'];
</script>

<Card full>
  <BarChart
    series={[{ name: 'Sales', data: [9840, 8720, 7650, 6430, 5980, 4810, 3920, 3140] }]}
    categories={products}
    valueFormatter={(v) => `${(v / 1000).toFixed(1)}k`}
    horizontal
    height="300px"
  />
</Card>
```
