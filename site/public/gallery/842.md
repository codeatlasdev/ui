# #842 Your own rule

A strength meter driven by your own length rule, with custom label text.

When to use: Apps whose password policy is length-based or comes from a server rule.

## Facets

- Kind: component / input
- Industry: saas
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: PasswordStrength, TextField
- Also searched as: custom rule, passphrase, password meter

## Spec

- `const byLength = (v: string) => (v.length === 0 ? 0 : v.length >= 12 ? 3 : v.length >= 8 ? 2 : 1)`
- `value={password}` and `score={byLength}` on `<PasswordStrength`
- `labels={{ empty: 'Type a passphrase', weak: 'Too short', fair: 'Almost there', strong: 'Good length' }}`
- Field is `<TextField label="Passphrase" type="password" bind:value={password} />`

## Source

```svelte
<script lang="ts">
  import { PasswordStrength, TextField } from '@codeatlasdev/ui';

  let password = $state('');
  // Your own rule: 12+ characters is strong, 8+ fair. Return 0 (empty) to 3 (strong).
  const byLength = (v: string) => (v.length === 0 ? 0 : v.length >= 12 ? 3 : v.length >= 8 ? 2 : 1);
</script>

<div class="col">
  <TextField label="Passphrase" type="password" bind:value={password} />
  <PasswordStrength
    value={password}
    score={byLength}
    labels={{ empty: 'Type a passphrase', weak: 'Too short', fair: 'Almost there', strong: 'Good length' }}
  />
</div>

<style>
  .col { display: grid; gap: var(--ca-space-2); width: 100%; max-width: 20rem; }
</style>
```
