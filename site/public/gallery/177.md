# #177 Without trend

Three KPI cards without a trend value, one with an icon and two plain.

When to use: Snapshot counters, such as orders today or error rate, that have no comparison period.

## Facets

- Kind: component / layout
- Style: default, bento
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: KpiCard, KpiGrid
- Also searched as: plain metric, value only, stat without delta

## Spec

- `<KpiGrid>` with 3 `KpiCard` items and no trend value
- `<KpiCard title="Orders Today" value="124" icon={ShoppingCart} />`
- `<KpiCard title="Avg. Session" value="3m 42s" />`
- `<KpiCard title="Error Rate" value="0.03" unit="%" />`
