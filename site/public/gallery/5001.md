# #5001 Filter bar

A filter Toolbar: a search TextField, a Select, a compact NumberField without steppers, a spacer and an Export button, all in one wrapping row.

When to use: A filter bar above a list or table where the fields have their own widths instead of stretching to the row.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, NumberField, Select, TextField, Toolbar
- Also searched as: filter bar, action bar, search bar

## Spec

- `<Toolbar aria-label="Filter deals">` holding every control, no wrapper div per field
- `TextField` with `hideLabel` and `width="14rem"`, then a `Select` with `hideLabel` and `width="10rem"` whose third option is long enough to be truncated
- `NumberField` with `hideLabel`, `steppers={false}`, `width="6rem"`, min 0 and max 90
- `<span class="ca-toolbar-spacer">` pushes an outlined neutral `Export` button to the end

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/toolbar#filter-bar
Reference: https://ui.codeatlas.com.br/api/v1/en/e/5001.txt

## Source

```svelte
<script lang="ts">
  import { Button, NumberField, Select, TextField, Toolbar } from '@codeatlasdev/ui';

  let status = $state('open');
</script>

<Toolbar aria-label="Filter deals">
  <TextField label="Search" hideLabel placeholder="Search deals" width="14rem" />
  <Select
    label="Status"
    hideLabel
    width="10rem"
    bind:value={status}
    options={[
      { value: 'open', label: 'Open' },
      { value: 'won', label: 'Won' },
      { value: 'lost', label: 'Lost, waiting for the customer to answer' },
    ]}
  />
  <NumberField label="Day" hideLabel steppers={false} width="6rem" min={0} max={90} value={7} />
  <span class="ca-toolbar-spacer"></span>
  <Button variant="outlined" tone="neutral">Export</Button>
</Toolbar>
```
