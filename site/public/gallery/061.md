# #061 Variants and orientation

Three toggle groups sharing one value: outlined, ghost and vertical.

When to use: Choosing a view such as list, grid or board with a button-style group.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: ToggleGroup
- Also searched as: vertical, outlined, ghost

## Spec

- Outlined group: `variant="outlined"`, `size="md"`, `aria-label="Outlined"`
- Outlined items: List, Grid, Board, and Board has `disabled: true`
- Ghost group: `variant="ghost"`, `size="sm"`, `aria-label="Ghost"`
- Vertical group: `orientation="vertical"`, `aria-label="Vertical"`
- All 3 use `bind:value={view}` with initial `$state('list')`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/toggle-group#variants-and-orientation
Reference: https://ui.codeatlas.com.br/api/v1/en/e/061.txt

## Source

```svelte
<script lang="ts">
  import { ToggleGroup } from '@codeatlasdev/ui';

  let view = $state('list');
</script>

<ToggleGroup
  variant="outlined"
  size="md"
  aria-label="Outlined"
  bind:value={view}
  items={[
    { value: 'list', label: 'List' },
    { value: 'grid', label: 'Grid' },
    { value: 'board', label: 'Board', disabled: true },
  ]}
/>
<ToggleGroup
  variant="ghost"
  size="sm"
  aria-label="Ghost"
  bind:value={view}
  items={[
    { value: 'list', label: 'List' },
    { value: 'grid', label: 'Grid' },
  ]}
/>
<ToggleGroup
  orientation="vertical"
  aria-label="Vertical"
  bind:value={view}
  items={[
    { value: 'list', label: 'List' },
    { value: 'grid', label: 'Grid' },
  ]}
/>
```
