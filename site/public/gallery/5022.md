# #5022 Flush in a panel

Two flush Collapsibles inside a padded side panel: no box, title and body aligned to the panel gutter, a hairline between sections.

When to use: Sections inside a surface that already has its own background, border and padding, such as a context side panel.

## Facets

- Kind: component / surface
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Collapsible
- Also searched as: flat collapsible, borderless section, panel section

## Spec

- `<Collapsible title="Contact" variant="flush" open>`
- `<Collapsible title="Deal" variant="flush" divided open>` draws a top border
- Wrapped in `<aside class="panel">` with `padding: 0 var(--ca-space-4)` and `max-width: 360px`
