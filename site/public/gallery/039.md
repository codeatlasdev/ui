# #039 Small, full width, disabled item

Small full-width segmented control with four items, one disabled.

When to use: Compact filter bar that should stretch to its container, such as a table toolbar.

## Facets

- Kind: component / input
- Industry: general
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: SegmentedControl
- Also searched as: full width switch, disabled segment

## Spec

- `<SegmentedControl` with `size="sm"`, `fullWidth` and `aria-label="Size"`
- `bind:value={size}` with initial `$state('b')`
- 4 items: Alpha, Beta, Gamma, Delta
- Gamma has `disabled: true`
- Wrapper `.wide` uses `max-width: 420px`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/segmented-control#small-full-width-disabled-item
Reference: https://ui.codeatlas.com.br/api/v1/en/e/039.txt

## Source

```svelte
<script lang="ts">
  import { SegmentedControl } from '@codeatlasdev/ui';

  let size = $state('b');
</script>

<div class="wide">
  <SegmentedControl
    size="sm"
    fullWidth
    aria-label="Size"
    bind:value={size}
    items={[
      { value: 'a', label: 'Alpha' },
      { value: 'b', label: 'Beta' },
      { value: 'c', label: 'Gamma', disabled: true },
      { value: 'd', label: 'Delta' },
    ]}
  />
</div>

<style>
  .wide {
    width: 100%;
    max-width: 420px;
  }
</style>
```
