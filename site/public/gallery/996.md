# #996 Scrolling filter row

A row of eight filter chips that scrolls sideways inside a narrow frame, with a fade where more chips are hidden.

When to use: A filter or message-type row on a phone that must scroll without clipping the 44px touch area of its chips.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: press, keyboard, scroll
- Layout: single-column
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Chip, ChipRow
- Also searched as: filter row, scrolling chips, chip scroller

## Spec

- `<ChipRow label="Filter chats" fade>` wraps the chips in one scrolling group
- `const filters = ['All', 'Unread', 'Groups', 'Archived', 'Starred', 'Muted', 'Mentions', 'Drafts']` lists the eight filters
- `<Chip label={f} selected={active === f} onclick={() => (active = f)} />` makes each one a toggle

## Source

```svelte
<script lang="ts">
  import { Chip, ChipRow } from '@codeatlasdev/ui';

  const filters = ['All', 'Unread', 'Groups', 'Archived', 'Starred', 'Muted', 'Mentions', 'Drafts'];
  let active = $state('All');
</script>

<div class="frame">
  <ChipRow label="Filter chats" fade>
    {#each filters as f (f)}
      <Chip label={f} selected={active === f} onclick={() => (active = f)} />
    {/each}
  </ChipRow>
</div>

<style>
  .frame { width: min(100%, 22rem); }
</style>
```
