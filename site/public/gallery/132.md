# #132 Default

Two NotificationBell triggers side by side: one given three notifications and one given an empty list.

When to use: Comparing the populated and empty bell states for an app header or toolbar.

## Facets

- Kind: component / display
- Industry: devtools, saas
- Style: default
- Motion: subtle
- Interaction: press, keyboard, hover
- Layout: overlay
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: NotificationBell, Flex
- Also searched as: alerts popover, bell icon, empty notifications

## Spec

- `<Flex gap="6" align="center">` wraps both bells
- `<NotificationBell notifications={items} />` with 3 const items (`id`, `title`, `body`, `time`, `read`), two with `read: false` and one with `read: true`
- `<NotificationBell notifications={[]} />` passes an empty list
- No callback props are passed to either bell
