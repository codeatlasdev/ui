# #981 Split button and vertical

A split button (Publish plus a chevron DropdownMenu trigger) and a vertical ButtonGroup of two icon buttons.

When to use: A primary action with its alternatives behind a menu, or a stacked pair of icon controls.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, ButtonGroup, DropdownMenu, DropdownMenuItem, IconButton
- Also searched as: split button, dropdown button

## Spec

- `<ButtonGroup aria-label="Publish">` with a `filled` Publish Button followed by a `DropdownMenu` whose `triggerChild` is a filled `IconButton` named "More publish options"
- The menu has Schedule and Save as draft, aligned to the end
- `<ButtonGroup aria-label="Pages" orientation="vertical">` with two outlined neutral IconButtons (Previous page, Next page)
- Both groups sit in a wrapping row with `gap: var(--ca-space-6)`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/button-group#split-button-and-vertical

## Source

```svelte
<script lang="ts">
  import {
    Button,
    ButtonGroup,
    DropdownMenu,
    DropdownMenuItem,
    IconButton,
  } from '@codeatlasdev/ui';
  import { ChevronDown, ChevronLeft, ChevronRight } from '@lucide/svelte';
</script>

<div class="row">
  <ButtonGroup aria-label="Publish">
    <Button variant="filled">Publish</Button>
    <DropdownMenu align="end">
      {#snippet triggerChild(props)}
        <IconButton variant="filled" aria-label="More publish options" {...props}><ChevronDown size={16} /></IconButton>
      {/snippet}
      <DropdownMenuItem>Schedule</DropdownMenuItem>
      <DropdownMenuItem>Save as draft</DropdownMenuItem>
    </DropdownMenu>
  </ButtonGroup>

  <ButtonGroup aria-label="Pages" orientation="vertical">
    <IconButton variant="outlined" tone="neutral" aria-label="Previous page"><ChevronLeft size={16} /></IconButton>
    <IconButton variant="outlined" tone="neutral" aria-label="Next page"><ChevronRight size={16} /></IconButton>
  </ButtonGroup>
</div>

<style>
  .row { display: flex; flex-wrap: wrap; align-items: flex-start; gap: var(--ca-space-6); }
</style>
```
