# #129 Shortcuts in text

Keyboard key caps inline in a sentence describing the Ctrl+K shortcut to open the command palette and Esc to close it.

When to use: Documenting keyboard shortcuts inside help text, tooltips or onboarding hints.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Kbd
- Also searched as: keyboard shortcut, key cap, hotkey hint

## Spec

- `<Kbd>Ctrl</Kbd>` and `<Kbd>K</Kbd>` joined by a plus sign inside a paragraph
- `<Kbd>Esc</Kbd>` as the second shortcut in the same sentence
- Each key is plain text children of `Kbd`, no props

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/display/kbd#shortcuts-in-text
Reference: https://ui.codeatlas.com.br/api/v1/en/e/129.txt
