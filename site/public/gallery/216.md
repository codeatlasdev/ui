# #216 Bar sparklines

Three labelled bar sparklines with up, down and neutral trends in a wrapping row.

When to use: Showing compact weekly metrics inline where a full chart would be too heavy.

## Facets

- Kind: component / chart
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: stack
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Flex, Stack, Sparkline
- Also searched as: mini bars, inline chart, tiny columns

## Spec

- `items` has 3 entries: Weekly sessions, Bounce rate, Avg pages, each with 7 `data` values
- `<Sparkline data={s.data} variant="bar" trend={s.trend} height="40px" />`
- `trend` values are `'up' as const`, `'down' as const` and `'neutral' as const`
- `<Flex gap="6" wrap align="center">` lays out the items, each in a `<Stack gap="1.5">` with a label

Needs: @codeatlasdev/ui@4.5.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/sparklines#bar-sparklines
Reference: https://ui.codeatlas.com.br/api/v1/en/e/216.txt

## Source

```svelte
<script lang="ts">
  import { Flex, Stack } from '@codeatlasdev/ui';
  import { Sparkline } from '@codeatlasdev/ui/charts';

  const items = [
    { label: 'Weekly sessions', data: [42, 38, 55, 61, 48, 72, 65], trend: 'up' as const },
    { label: 'Bounce rate', data: [38, 41, 37, 43, 36, 39, 35], trend: 'down' as const },
    { label: 'Avg pages', data: [3.2, 3.4, 3.1, 3.5, 3.3, 3.4, 3.6], trend: 'neutral' as const },
  ];
</script>

<Flex gap="6" wrap align="center">
  {#each items as s}
    <div class="item">
      <Stack gap="1.5">
        <span class="label">{s.label}</span>
        <Sparkline data={s.data} variant="bar" trend={s.trend} height="40px" />
      </Stack>
    </div>
  {/each}
</Flex>

<style>
  .item { width: 160px; }
  .label { font-size: var(--ca-font-size-caption); color: var(--ca-text-secondary); }
</style>
```
