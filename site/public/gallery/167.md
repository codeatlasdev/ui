# #167 Basic

An empty inbox state with an icon, a title, a description and a Compose message button.

When to use: First-run or cleared lists where the user needs a clear next action.

## Facets

- Kind: component / layout
- Style: default
- Motion: none
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: airy
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: EmptyState, Button
- Also searched as: blank slate, no data, inbox zero

## Spec

- `<EmptyState icon={Inbox} title="No messages yet" description="Your inbox is empty. New messages will appear here.">`
- `{#snippet actions()}` holds `<Button variant="filled" size="sm">Compose message</Button>`

Needs: @codeatlasdev/ui@4.5.0
