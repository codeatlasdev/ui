# #169 No icon

An empty state without an icon, showing a title, a description and a Create item button with a Plus icon.

When to use: Simple empty lists where an icon adds no meaning and a single create action is enough.

## Facets

- Kind: component / layout
- Industry: saas
- Style: default, minimal
- Motion: none
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: EmptyState, Button
- Also searched as: text only empty, nothing yet, create first item

## Spec

- `<EmptyState title="Nothing here yet" description="Create your first item to get started.">` is passed no icon
- `{#snippet actions()}` holds `<Button variant="filled" size="sm">`
- Button has `{#snippet leading()}<Plus size={14} />{/snippet}` and the label Create item
