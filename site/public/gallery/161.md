# #161 Form

A popover anchored below-start of a button that holds a text field with Cancel and Save buttons.

When to use: Inline editing of a single value, such as renaming a label, without opening a modal.

## Facets

- Kind: component / navigation
- Style: default
- Motion: subtle
- Interaction: keyboard, press
- Layout: overlay
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Popover, Button, TextField, Stack, Flex
- Also searched as: inline form, floating form

## Spec

- `<Popover side="bottom" align="start">`
- `{#snippet triggerChild(props)}` renders `<Button variant="filled" {...props}>Edit label</Button>`
- `<TextField label="Label name" placeholder="e.g. Priority" />` inside `<Stack gap="3">`
- `<Flex gap="2" justify="end">` holds `<Button size="sm" variant="ghost">Cancel</Button>` and `<Button size="sm" variant="filled">Save</Button>`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/navigation/popover#form

## Source

```svelte
<script lang="ts">
  import { Popover, Button, TextField, Stack, Flex } from '@codeatlasdev/ui';
</script>

<Popover side="bottom" align="start">
  {#snippet triggerChild(props)}<Button variant="filled" {...props}>Edit label</Button>{/snippet}
  <Stack gap="3">
    <TextField label="Label name" placeholder="e.g. Priority" />
    <Flex gap="2" justify="end">
      <Button size="sm" variant="ghost">Cancel</Button>
      <Button size="sm" variant="filled">Save</Button>
    </Flex>
  </Stack>
</Popover>
```
