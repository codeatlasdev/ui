# #049 Theme presets

Swatch group of five theme presets: ocean, violet, emerald, rose, amber.

When to use: Choosing an accent theme preset in appearance settings.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: SwatchGroup
- Also searched as: accent color, theme picker, color chooser

## Spec

- `<SwatchGroup` with `aria-label="Accent"` and `bind:value={preset}`
- 5 items with only `value`: `{ value: 'ocean' }`, `{ value: 'violet' }`, `{ value: 'emerald' }`, `{ value: 'rose' }`, `{ value: 'amber' }`
- Initial value is `$state('ocean')`
- Current value is shown as `value: {preset}`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/swatch-group#theme-presets
Reference: https://ui.codeatlas.com.br/api/v1/en/e/049.txt

## Source

```svelte
<script lang="ts">
  import { SwatchGroup } from '@codeatlasdev/ui';

  let preset = $state('ocean');
</script>

<div class="col">
  <SwatchGroup
    aria-label="Accent"
    bind:value={preset}
    items={[
      { value: 'ocean' },
      { value: 'violet' },
      { value: 'emerald' },
      { value: 'rose' },
      { value: 'amber' },
    ]}
  />
  <p class="out">value: {preset}</p>
</div>

<style>
  .col {
    display: flex;
    flex-direction: column;
    gap: var(--ca-space-3);
  }

  .out {
    margin: 0;
    font-size: var(--ca-font-size-caption);
    color: var(--ca-text-secondary);
  }
</style>
```
