# #120 Variants and size

Chip color variants (default, brand, success, warning, error, info) plus a small size chip.

When to use: Picking the chip tone for categories and semantic labels.

## Facets

- Kind: component / display
- Industry: general
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Chip
- Also searched as: color tags, semantic pills, tag sizes

## Spec

- `<Chip label="Default" />` has no variant
- `variant="brand"`, `variant="success"`, `variant="warning"`, `variant="error"` and `variant="info"` each with a matching label
- `<Chip label="Small" size="sm" />` shows the small size

Needs: @codeatlasdev/ui@4.5.0
