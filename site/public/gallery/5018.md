# #5018 Rating

Star ratings: an editable whole-star rating, a half-step rating and a small read-only average.

When to use: Collecting or showing a score out of five, such as service or product reviews.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Rating
- Also searched as: star rating, review stars, score input

## Spec

- A `Rating` labelled `Service` bound to 4
- A `Rating` labelled `Food` with `step={0.5}` bound to 3.5
- A `readonly` `size="sm"` `Rating` labelled `Average` showing 4.5

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/rating#rating
Reference: https://ui.codeatlas.com.br/api/v1/en/e/5018.txt
