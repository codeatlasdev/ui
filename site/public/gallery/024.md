# #024 use:mask action

A native input masked with the mask action, showing the bound value below.

When to use: Adding input masking to a custom or third-party input that is not a MaskedField.

## Facets

- Kind: component / input
- Style: default
- Motion: none
- Interaction: keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: none
- Also searched as: input mask, action, format as you type

## Spec

- `use:mask={maskCPF}` on a plain `<input` with `bind:value`
- `placeholder="000.000.000-00"` and `inputmode="numeric"`
- `<label class="lbl" for="mask-action-input">` is linked to `id="mask-action-input"`
- Output line prints `value = {value || '–'}`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/masked-field#use-mask-action
Reference: https://ui.codeatlas.com.br/api/v1/en/e/024.txt
