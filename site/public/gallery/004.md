# #004 Sizes

The three button sizes side by side: small, medium and large.

When to use: Choosing button density: `sm` in toolbars and tables, `md` by default, `lg` for hero or touch-first actions.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button
- Also searched as: small medium large

## Spec

- `size="sm"` labelled Small
- `size="md"` labelled Medium
- `size="lg"` labelled Large
