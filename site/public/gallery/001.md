# #001 Full width

Two buttons that stretch to the width of their container: a filled primary and an outlined cancel.

When to use: Stacked action pairs in forms, dialogs and bottom sheets where the buttons should span the column.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button
- Also searched as: block button, stretch

## Spec

- `fullWidth` on `Button` makes it fill its parent
- Primary action keeps the default variant, secondary uses `variant="outlined"`
- Wrapper column is `max-width: 320px` with `gap: var(--ca-space-2)`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/button#full-width
Reference: https://ui.codeatlas.com.br/api/v1/en/e/001.txt

## Source

```svelte
<script lang="ts">
  import { Button } from '@codeatlasdev/ui';
</script>

<div class="col">
  <Button fullWidth>Continue</Button>
  <Button fullWidth variant="outlined">Cancel</Button>
</div>

<style>
  .col {
    display: flex;
    flex-direction: column;
    gap: var(--ca-space-2);
    width: 100%;
    max-width: 320px;
  }
</style>
```
