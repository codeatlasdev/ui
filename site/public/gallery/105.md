# #105 Severities

The four alert severities stacked: success, warning, error and info, each with a one-line message.

When to use: Choosing the alert severity for save confirmations, trial warnings, connection errors and update notices.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Alert
- Also searched as: status banner, callout, feedback message

## Spec

- `severity="success"` with the saved-changes message
- `severity="warning"` with the trial-expires-in-3-days message
- `severity="error"` with the failed-to-connect message
- `severity="info"` with the new-version message
- Wrapper `.col` has `max-width: 560px`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/display/alert#severities
