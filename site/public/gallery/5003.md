# #5003 Invite and consent

A full-page CenteredPage with a brand mark above one narrow card, switchable between an organisation invite and an OAuth consent screen.

When to use: Transactional pages outside the app shell: accepting an invite, granting consent, a magic-link landing or a notice.

## Facets

- Kind: component / layout
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: airy
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: AuthCard, Button, CenteredPage, SegmentedControl, Stack
- Also searched as: standalone page, invite page, consent screen, interstitial, centred card page

## Spec

- `<CenteredPage maxWidth="sm" mainId={null}>` with a `brand` snippet holding `<strong>Acme</strong>`
- `AuthCard` titled `Join Acme` (subtitle `Ana invited you to the Design workspace.`) or `Allow Notes to sign in?` with an Accept/Allow filled full-width Button and an outlined Close/Deny Button, chosen by `kind`
- A `SegmentedControl` (Invite, Consent) bound to `kind` under the card
- Opened by an outlined small Button inside an overlay with `position: fixed;` and `inset: 0;`

## Source

```svelte
<script lang="ts">
  import { AuthCard, Button, CenteredPage, SegmentedControl, Stack } from '@codeatlasdev/ui';

  let open = $state(false);
  let kind = $state<'invite' | 'consent'>('invite');
</script>

<Button variant="outlined" size="sm" onclick={() => (open = true)}>Open invite page</Button>

{#if open}
  <div class="overlay">
    <CenteredPage maxWidth="sm" mainId={null}>
      {#snippet brand()}<strong>Acme</strong>{/snippet}

      {#if kind === 'invite'}
        <AuthCard title="Join Acme" subtitle="Ana invited you to the Design workspace.">
          <Stack gap="3">
            <Button fullWidth>Accept invite</Button>
            <Button variant="outlined" fullWidth onclick={() => (open = false)}>Close</Button>
          </Stack>
        </AuthCard>
      {:else}
        <AuthCard title="Allow Notes to sign in?" subtitle="Notes will read your name and email. It cannot change your account.">
          <Stack gap="3">
            <Button fullWidth>Allow</Button>
            <Button variant="outlined" fullWidth onclick={() => (open = false)}>Deny</Button>
          </Stack>
        </AuthCard>
      {/if}

      <SegmentedControl
        aria-label="Page"
        bind:value={kind}
        items={[
          { value: 'invite', label: 'Invite' },
          { value: 'consent', label: 'Consent' },
        ]}
      />
    </CenteredPage>
  </div>
{/if}

<style>
  .overlay {
    position: fixed;
    inset: 0;
    z-index: var(--ca-z-modal);
    overflow: auto;
    background: var(--ca-surface-base);
  }
</style>
```
