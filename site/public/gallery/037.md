# #037 Vertical

Default vertical radio group of three fruits with the selected value printed below.

When to use: Single choice from a short list in a form or settings panel.

## Facets

- Kind: component / input
- Industry: general
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: RadioGroup
- Also searched as: option list, single choice

## Spec

- `<RadioGroup items={fruits}` with `bind:value={fruit}` and no orientation prop
- `fruits` has 3 items: Apple, Banana, Cherry
- Initial value is `$state('apple')`
- Selected value is shown in `<code>{fruit}</code>` under the group

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/radio#vertical
Reference: https://ui.codeatlas.com.br/api/v1/en/e/037.txt

## Source

```svelte
<script lang="ts">
  import { RadioGroup } from '@codeatlasdev/ui';

  let fruit = $state('apple');

  const fruits = [
    { value: 'apple', label: 'Apple' },
    { value: 'banana', label: 'Banana' },
    { value: 'cherry', label: 'Cherry' },
  ];
</script>

<RadioGroup items={fruits} bind:value={fruit} />
<p class="out">Selected: <code>{fruit}</code></p>

<style>
  .out {
    flex-basis: 100%;
    margin: 0;
    font-size: var(--ca-font-size-caption);
    color: var(--ca-text-secondary);
  }
</style>
```
