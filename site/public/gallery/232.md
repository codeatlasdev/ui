# #232 LinkCard, CardGrid and MethodBadge

A CardGrid with two LinkCards, followed by a row of five MethodBadges for the HTTP verbs.

When to use: Docs landing pages linking to guides, and API references that tag endpoints with their HTTP method.

## Facets

- Kind: component / display
- Style: default
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: CardGrid, LinkCard, MethodBadge
- Also searched as: link cards, http method badge, api verbs, docs landing

## Spec

- `<CardGrid>` contains 2 `LinkCard` entries: Quick start and Webhooks
- Each `LinkCard` sets `title`, `description` and `href="#top"`
- `<MethodBadge method="GET" />`
- Other badges: `method="POST"`, `method="PUT"`, `method="PATCH"`, `method="DELETE"`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/docs-kit/docs#linkcard-cardgrid-and-methodbadge
