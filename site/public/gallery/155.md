# #155 Keyboard

A static list of four keyboard hints for the command palette, each pairing a Kbd key with a description.

When to use: Documenting the shortcuts of a search or command palette next to the feature it belongs to.

## Facets

- Kind: component / navigation
- Style: default
- Motion: none
- Interaction: keyboard
- Layout: stack
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Kbd
- Also searched as: shortcuts, hotkeys, cheat sheet

## Spec

- `const keys` has four entries with fields `key` and `desc`
- Rendered with `{#each keys as k}` as `<Kbd>{k.key}</Kbd><span>{k.desc}</span>` inside a `<ul class="list">`
- Key labels: `Type`, `↑ ↓`, `↵`, `ESC`
- Descriptions: `Filter by label or module name`, `Move through the results`, `Navigate to the selected item`, `Close the palette`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/navigation/command-palette#keyboard
Reference: https://ui.codeatlas.com.br/api/v1/en/e/155.txt

## Source

```svelte
<script lang="ts">
  import { Kbd } from '@codeatlasdev/ui';

  const keys = [
    { key: 'Type', desc: 'Filter by label or module name' },
    { key: '↑ ↓', desc: 'Move through the results' },
    { key: '↵', desc: 'Navigate to the selected item' },
    { key: 'ESC', desc: 'Close the palette' },
  ];
</script>

<ul class="list">
  {#each keys as k}
    <li><Kbd>{k.key}</Kbd><span>{k.desc}</span></li>
  {/each}
</ul>

<style>
  .list { list-style: none; margin: 0; padding: 0; display: grid; gap: 4px; width: 100%; max-width: 480px; }
  li { display: flex; align-items: center; gap: 16px; padding: 8px 4px; }
  span { font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); }
</style>
```
