# #097 Card layout

A card skeleton with a circular avatar placeholder beside three text lines of different widths.

When to use: Loading placeholder for a profile or list card so layout does not jump when data arrives.

## Facets

- Kind: component / feedback
- Industry: saas
- Style: default
- Motion: expressive
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Skeleton, Card, Stack, Flex
- Also searched as: placeholder, shimmer, profile card loading

## Spec

- `<Card p="5" full>`
- `<Skeleton variant="circular" width="48px" height="48px" />` inside `<Flex gap="4" align="start">`
- Three lines in `<Stack gap="2">`: `height="16px" width="40%"`, `height="13px" width="70%"`, `height="13px" width="55%"`
