# #223 Surfaces

Four swatches for the surface tokens from sunken to overlay, drawn with a border.

When to use: Choosing the background layer for a page, card, raised panel or popover.

- Kind: component / foundation

- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: none
- Also searched as: background colors, elevation colors, layers

## Spec

- Renders `<Swatches {tokens} bordered={true} />` with 4 tokens
- Tokens in order: `--ca-surface-sunken`, `--ca-surface-base`, `--ca-surface-raised`, `--ca-surface-overlay`
