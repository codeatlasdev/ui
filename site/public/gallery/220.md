# #220 Brand

Six swatches for the brand color tokens, each showing its name and CSS variable.

When to use: Picking a brand color token for a fill, a text color or an accent.

## Facets

- Kind: component / foundation
- Industry: general
- Style: default
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: none
- Also searched as: palette, brand colors, color tokens

## Spec

- Renders `<Swatches {tokens} />` with 6 tokens
- Tokens in order: `--ca-brand-main`, `--ca-brand-light`, `--ca-brand-dark`
- Then `--ca-brand-contrast`, `--ca-brand-fill`, `--ca-brand-text`
- No bordered prop is passed
