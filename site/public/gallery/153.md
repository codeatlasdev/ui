# #153 Levels

Four stacked breadcrumbs with 2, 3, 5 and 1 levels, where the last item is the current page without a link.

When to use: Showing where a page sits in the hierarchy, from a single root page to a deep settings path.

## Facets

- Kind: component / navigation
- Style: default
- Motion: none
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Breadcrumb
- Also searched as: trail, path, hierarchy

## Spec

- Four `Breadcrumb` components in a `<div class="stack">`, each with an `items` array of `label` and optional `href`
- Two levels: `{ label: 'Home', href: '/' }, { label: 'Components' }`
- Three levels end with `{ label: 'Breadcrumb' }` after `href: '/docs/navigation/'`
- Five levels run from Home to `{ label: 'Two-Factor Auth' }` via `href: '/settings/account/security'`
- Single level: `items={[{ label: 'Home' }]}` with no `href`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/navigation/breadcrumb#levels
Reference: https://ui.codeatlas.com.br/api/v1/en/e/153.txt

## Source

```svelte
<script lang="ts">
  import { Breadcrumb } from '@codeatlasdev/ui';
</script>

<div class="stack">
  <Breadcrumb items={[{ label: 'Home', href: '/' }, { label: 'Components' }]} />
  <Breadcrumb items={[{ label: 'Home', href: '/' }, { label: 'Navigation', href: '/docs/navigation/' }, { label: 'Breadcrumb' }]} />
  <Breadcrumb
    items={[
      { label: 'Home', href: '/' },
      { label: 'Settings', href: '/settings' },
      { label: 'Account', href: '/settings/account' },
      { label: 'Security', href: '/settings/account/security' },
      { label: 'Two-Factor Auth' },
    ]}
  />
  <Breadcrumb items={[{ label: 'Home' }]} />
</div>

<style>
  .stack { display: grid; gap: 18px; }
</style>
```
