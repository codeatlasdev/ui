# #118 Selectable

Two toggle chips, Filter A starting off and Filter B starting on, that flip on click.

When to use: Filter chips that toggle a facet on or off in a list or search view.

## Facets

- Kind: component / display
- Industry: general
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Chip
- Also searched as: filter chip, toggle tag, choice pill

## Spec

- `let a = $state(false)` and `let b = $state(true)` hold the state
- `<Chip label="Filter A" selected={a} onclick={() => (a = !a)} />`
- `<Chip label="Filter B" selected={b} onclick={() => (b = !b)} />`
