# #145 All sides

Four outlined buttons whose tooltips open on the top, right, bottom and left side.

When to use: Choosing the tooltip side so it does not cover neighbouring controls or run off the screen.

## Facets

- Kind: component / display
- Style: default
- Motion: subtle
- Interaction: hover, keyboard
- Layout: overlay
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Tooltip, Button
- Also searched as: placement, tooltip position, popover side

## Spec

- `side="top"` with `content="Tooltip on top"`
- `side="right"` with `content="Tooltip on right"`
- `side="bottom"` with `content="Tooltip on bottom"`
- `side="left"` with `content="Tooltip on left"`
- Each trigger uses `{#snippet triggerChild(props)}` with `<Button variant="outlined" {...props}>`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/display/tooltip#all-sides

```svelte
<script lang="ts">
  import { Tooltip, Button } from '@codeatlasdev/ui';
</script>

<div class="grid">
  <Tooltip content="Tooltip on top" side="top">
    {#snippet triggerChild(props)}<Button variant="outlined" {...props}>Top</Button>{/snippet}
  </Tooltip>
  <Tooltip content="Tooltip on right" side="right">
    {#snippet triggerChild(props)}<Button variant="outlined" {...props}>Right</Button>{/snippet}
  </Tooltip>
  <Tooltip content="Tooltip on bottom" side="bottom">
    {#snippet triggerChild(props)}<Button variant="outlined" {...props}>Bottom</Button>{/snippet}
  </Tooltip>
  <Tooltip content="Tooltip on left" side="left">
    {#snippet triggerChild(props)}<Button variant="outlined" {...props}>Left</Button>{/snippet}
  </Tooltip>
</div>

<style>
  .grid { display: flex; flex-wrap: wrap; gap: var(--ca-space-3); padding: var(--ca-space-6); align-items: center; justify-content: center; width: 100%; }
```
