# #5008 Group sizes

Five avatar groups at sizes `xs` to `xl` and a rounded one, each capped at three with a `+2` chip.

When to use: Choosing the group size that matches the Avatar size used elsewhere on the page; the overlap scales with it.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: AvatarGroup
- Also searched as: avatar group sizes, facepile sizes

## Spec

- `const team` has 5 entries without photos
- `{#each ['xs', 'sm', 'md', 'lg', 'xl'] as const as size (size)}` renders `<AvatarGroup items={team} max={3} {size} label="Team, size {size}" />`
- A last group uses `shape="rounded"`
