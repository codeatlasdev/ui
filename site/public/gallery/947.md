# #947 Delays and alignment

A two-item docs nav (Guides, Reference) that opens on hover at once and stays open 400 ms after the pointer leaves.

When to use: Tuning how eager the hover behaviour is for dense navigation, and aligning each panel to its button's start or end.

## Facets

- Kind: component / navigation
- Industry: devtools
- Style: glassmorphism
- Motion: subtle
- Interaction: hover, keyboard, press
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: NavigationMenu, NavigationMenuItem, NavigationMenuLink
- Also searched as: hover delay, top nav, site header

## Spec

- `<NavigationMenu aria-label="Docs sections" openDelay={0} closeDelay={400}>`
- `<NavigationMenuItem label="Guides" align="start">` and `<NavigationMenuItem label="Reference" align="end">` align their panels to the button
- Each panel holds two `NavigationMenuLink`s
