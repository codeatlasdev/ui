# #078 Materials

Five Surface tiles, one per material, over a brand to info to success gradient so the translucency is visible.

When to use: Comparing auto, solid, frosted, glass and liquid materials before picking one for a card or panel.

## Facets

- Kind: component / surface
- Industry: general
- Style: glassmorphism, aurora
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Surface
- Also searched as: translucency, blur, glass vs solid

## Spec

- `const materials = ['auto', 'solid', 'frosted', 'glass', 'liquid'] as const`
- `<Surface {material} elevation={3} p="4" class="tile">` rendered with `{#each materials as material (material)}`
- Each tile prints its material name in a `.name` paragraph
- `.backdrop` paints `linear-gradient(135deg` behind the tiles

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/surfaces/surface#materials

## Source

```svelte
<script lang="ts">
  import { Surface } from '@codeatlasdev/ui';

  const materials = ['auto', 'solid', 'frosted', 'glass', 'liquid'] as const;
</script>

<div class="backdrop">
  {#each materials as material (material)}
    <Surface {material} elevation={3} p="4" class="tile">
      <p class="name">{material}</p>
    </Surface>
  {/each}
</div>

<style>
  .backdrop {
    display: flex;
    flex-wrap: wrap;
    gap: var(--ca-space-3);
    width: 100%;
    padding: var(--ca-space-6);
    border-radius: var(--ca-radius-lg);
    background: linear-gradient(135deg, var(--ca-brand-main) 0%, var(--ca-semantic-info) 50%, var(--ca-semantic-success) 100%);
  }
  .backdrop :global(.tile) { flex: 1; min-width: 7rem; text-align: center; }
  .name { margin: 0; font-family: var(--ca-font-mono); font-size: var(--ca-font-size-caption); font-weight: 600; }
</style>
```
