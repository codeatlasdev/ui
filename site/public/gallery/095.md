# #095 Footer and swipeToDismiss

A bottom sheet titled Sessions with a footer button, opened with swipe to dismiss on or off.

When to use: Mobile sheets with a pinned primary action that sometimes must not be dismissed by dragging.

## Facets

- Kind: component / feedback
- Style: default
- Motion: subtle
- Interaction: drag, press, keyboard
- Layout: overlay
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Sheet, Button, Stack
- Also searched as: bottom sheet, action sheet

## Spec

- `<Sheet bind:open title="Sessions" swipeToDismiss={swipe} onclose={() => (open = false)}>`
- Two triggers set `swipe = true` and `swipe = false` before `open = true`: Sheet with footer and Swipe disabled
- Body is `<Stack gap="2">` with a paragraph whose text depends on `swipe`
- `{#snippet footer()}` holds `<Button variant="filled"` New session with a `<Plus size={15} />` icon

## Source

```svelte
<script lang="ts">
  import { Sheet, Button, Stack } from '@codeatlasdev/ui';
  import { Plus } from '@lucide/svelte';

  let open = $state(false);
  let swipe = $state(true);
</script>

<Button variant="outlined" onclick={() => ((swipe = true), (open = true))}>Sheet with footer</Button>
<Button variant="outlined" onclick={() => ((swipe = false), (open = true))}>Swipe disabled</Button>

<Sheet bind:open title="Sessions" swipeToDismiss={swipe} onclose={() => (open = false)}>
  <Stack gap="2">
    <p class="text">
      {swipe
        ? 'Drag the handle or the header down to dismiss.'
        : 'swipeToDismiss is false: use the close button, Escape or the overlay.'}
    </p>
  </Stack>
  {#snippet footer()}
    <Button variant="filled" onclick={() => (open = false)}>
      {#snippet leading()}<Plus size={15} />{/snippet}
      New session
    </Button>
  {/snippet}
</Sheet>

<style>
  .text { margin: 0; font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); }
</style>
```
