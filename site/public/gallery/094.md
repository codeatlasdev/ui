# #094 Indeterminate

Two indeterminate progress bars labelled Loading and Syncing for work of unknown length.

When to use: Background loading or syncing where no percentage is available.

## Facets

- Kind: component / feedback
- Style: default
- Motion: expressive
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Progress
- Also searched as: loading bar, busy

## Spec

- `<Progress indeterminate label="Loading content" />`
- `<Progress indeterminate label="Syncing data" />`
- Each bar sits in a row next to a text label, Loading and Syncing
- Column has `max-width: 480px`

Needs: @codeatlasdev/ui@4.5.0
