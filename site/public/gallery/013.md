# #013 Icon only and toast

An icon-only CopyButton and a labelled one that shows a toast after copying, with a Toaster mounted.

When to use: Copying links or snippets where a compact icon is enough or where a visible confirmation toast is wanted.

## Facets

- Kind: component / input
- Industry: devtools
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: CopyButton, Toaster
- Also searched as: share link, copied toast

## Spec

- `<Toaster />` is rendered alongside the buttons
- `<CopyButton value="icon-only" label="" />` is icon-only via an empty `label`
- `<CopyButton value="https://ui.codeatlas.com.br" label="Copy link" toast="Link copied" />`
