# #030 Basic

Two NumberField inputs in a Stack: an integer quantity with bounds and a decimal price with a step.

When to use: Quantity and price steppers in order or cart forms.

## Facets

- Kind: component / input
- Industry: e-commerce
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: NumberField, Stack
- Also searched as: stepper, quantity, spinbutton

## Spec

- `<Stack gap="4">` wraps both fields
- `<NumberField label="Quantity" bind:value={qty} min={0} max={99} />` with `let qty = $state(1)`
- `<NumberField label="Price" bind:value={price} min={0} step={0.01} />` with `let price = $state(9.99)`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/number-field#basic

## Source

```svelte
<script lang="ts">
  import { NumberField, Stack } from '@codeatlasdev/ui';

  let qty = $state(1);
  let price = $state(9.99);
</script>

<Stack gap="4">
  <NumberField label="Quantity" bind:value={qty} min={0} max={99} />
  <NumberField label="Price" bind:value={price} min={0} step={0.01} />
</Stack>
```
