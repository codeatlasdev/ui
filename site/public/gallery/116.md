# #116 Deletable

Removable chips: deleting one drops it from the list, and a reset link appears when all are gone.

When to use: Tag inputs and filter pills the user can remove, with a way to restore them.

## Facets

- Kind: component / display
- Industry: general
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Chip
- Also searched as: removable tag, dismissible tag, remove token

## Spec

- `const initial = ['Design', 'Svelte', 'Glass']` seeds `let tags = $state([...initial])`
- `{#each tags as tag (tag)}` renders `<Chip label={tag} deletable ondelete={() => (tags = tags.filter((t) => t !== tag))} />`
- `{#if tags.length === 0}` shows a `<button class="reset" type="button"` labelled Reset tags
- The reset button runs `onclick={() => (tags = [...initial])}`

## Source

```svelte
<script lang="ts">
  import { Chip } from '@codeatlasdev/ui';

  const initial = ['Design', 'Svelte', 'Glass'];
  let tags = $state([...initial]);
</script>

{#each tags as tag (tag)}
  <Chip label={tag} deletable ondelete={() => (tags = tags.filter((t) => t !== tag))} />
{/each}
{#if tags.length === 0}
  <button class="reset" type="button" onclick={() => (tags = [...initial])}>Reset tags</button>
{/if}

<style>
  .reset {
    font: inherit;
    font-size: var(--ca-font-size-caption);
    color: var(--ca-brand-text);
    background: none;
    border: none;
    cursor: pointer;
    text-decoration: underline;
  }
</style>
```
