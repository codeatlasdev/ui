# #910 Configured split

A split dialog sized 66vw by 88svh with a 2fr/3fr column ratio that goes full screen under 600px: a map column beside a details column with a Close button.

When to use: Wide detail dialogs (map + details, media + form) that need their own box and column ratio and must fill the screen on phones.

## Facets

- Kind: component / feedback
- Industry: saas, general
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: overlay
- Color mode: both
- Density: airy
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Dialog, Button, Stack
- Also searched as: fullscreen mobile, two pane modal

## Spec

- `<Dialog` with `size="split"`, `chromeless` and `title="Lead details"`
- `splitColumns="2fr 3fr"` and `fullscreenBelow="sm"`
- `splitSize={{ width: 'min(66vw, 80rem)', height: 'min(88svh, 56rem)' }}`
- Two direct children: `<div class="map">` labelled Map and `<div class="details">` with a name and a filled Close `<Button variant="filled" onclick={() => (open = false)}>`

## Source

```svelte
<script lang="ts">
  import { Dialog, Button, Stack } from '@codeatlasdev/ui';

  let open = $state(false);
</script>

<Button variant="filled" onclick={() => (open = true)}>Open lead</Button>

<Dialog
  bind:open
  title="Lead details"
  size="split"
  chromeless
  splitColumns="2fr 3fr"
  splitSize={{ width: 'min(66vw, 80rem)', height: 'min(88svh, 56rem)' }}
  fullscreenBelow="sm"
>
  <div class="map">Map</div>
  <div class="details">
    <Stack gap="3">
      <p class="name">Atlas Logistics</p>
      <Button variant="filled" onclick={() => (open = false)}>Close</Button>
    </Stack>
  </div>
</Dialog>

<style>
  .map {
    display: grid;
    place-items: center;
    min-height: 160px;
    background: color-mix(in oklab, var(--ca-brand-main) 12%, var(--ca-surface-overlay));
    color: var(--ca-text-secondary);
  }
  .details { padding: 24px; overflow-y: auto; }
  .name { margin: 0; color: var(--ca-text-primary); }
</style>
```
