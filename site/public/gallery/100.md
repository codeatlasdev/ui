# #100 In a button

A Button that shows its loading spinner for two seconds after click and changes its label to Saving.

When to use: Save or submit buttons that wait on a request.

## Facets

- Kind: component / feedback
- Style: default
- Motion: expressive
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button
- Also searched as: loading button, busy button, pending

## Spec

- `<Button onclick={simulate} {loading}>` with `let loading = $state(false)`
- `simulate` sets `loading = true` and resets it with `setTimeout(() => (loading = false), 2000)`
- Label is `{loading ? 'Saving…' : 'Save changes'}`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/feedback/spinner#in-a-button
Reference: https://ui.codeatlas.com.br/api/v1/en/e/100.txt

## Source

```svelte
<script lang="ts">
  import { Button } from '@codeatlasdev/ui';

  let loading = $state(false);
  function simulate() {
    loading = true;
    setTimeout(() => (loading = false), 2000);
  }
</script>

<Button onclick={simulate} {loading}>{loading ? 'Saving…' : 'Save changes'}</Button>
```
