# #146 autofocus

An input that receives focus on mount, with a button that remounts it through a keyed block.

When to use: Dialogs, inline editors and search fields where the first field should take focus as soon as it appears.

## Facets

- Kind: component / navigation
- Industry: devtools
- Style: default
- Motion: none
- Interaction: keyboard, press
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button
- Also searched as: focus on mount, auto focus

## Spec

- `use:autofocus` imported from `@codeatlasdev/ui/actions` on a native `<input`
- Input has `placeholder="Focused on mount"` and `aria-label="Autofocused input"`
- `let key = $state(0)` drives `{#key key}` around the input
- `<Button onclick={() => key++}>Remount input</Button>` remounts the input so focus is applied again

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/navigation/actions#autofocus
Reference: https://ui.codeatlas.com.br/api/v1/en/e/146.txt

## Source

```svelte
<script lang="ts">
  import { Button } from '@codeatlasdev/ui';
  import { autofocus } from '@codeatlasdev/ui/actions';

  let key = $state(0);
</script>

<Button onclick={() => key++}>Remount input</Button>
{#key key}
  <input use:autofocus placeholder="Focused on mount" class="input" aria-label="Autofocused input" />
{/key}

<style>
  .input {
    min-height: var(--ca-control-height);
    flex-basis: 100%;

    background: transparent;
    color: var(--ca-text-primary);
    font: inherit;
    font-size: var(--ca-font-size-body2);
  }
</style>
```
