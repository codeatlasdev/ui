# #006 Variants

All five button variants in a row: filled, glass, outlined, ghost and destructive.

When to use: Picking the emphasis of an action: filled for primary, outlined or ghost for secondary, destructive for irreversible.

## Facets

- Kind: component / input
- Industry: general
- Style: default, glassmorphism
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button
- Also searched as: button styles, primary secondary

## Spec

- `variant="filled"` labelled Filled
- `variant="glass"` labelled Glass
- `variant="outlined"` labelled Outlined
- `variant="ghost"` labelled Ghost
- `variant="destructive"` labelled Destructive
