# #147 clickOutside

A box that counts how many clicks land outside it using the clickOutside action.

When to use: Closing popovers, dropdowns and inline editors when the user clicks elsewhere on the page.

## Facets

- Kind: component / navigation
- Style: default
- Motion: none
- Interaction: press, cursor
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: none
- Also searched as: outside click, dismiss

## Spec

- `use:clickOutside={() => count++}` imported from `@codeatlasdev/ui/actions` on a `div` with `class="box"`
- `let count = $state(0)` is incremented by the callback
- Box text: Click inside this area, then click outside.
- Counter shown as `Outside clicks: {count}`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/navigation/actions#clickoutside
Reference: https://ui.codeatlas.com.br/api/v1/en/e/147.txt

## Source

```svelte
<script lang="ts">
  import { clickOutside } from '@codeatlasdev/ui/actions';

  let count = $state(0);
</script>

<div use:clickOutside={() => count++} class="box">
  <p>Click inside this area, then click outside.</p>
</div>
<p class="hint">Outside clicks: {count}</p>

<style>
  .box {
    padding: 24px;
    border-radius: var(--ca-radius-md);
    box-shadow: inset 0 0 0 1px var(--ca-outline-subtle);
    display: inline-block;
  }
  .box p, .hint { margin: 0; font-size: var(--ca-font-size-body2); }
  .hint { color: var(--ca-text-secondary); align-self: center; }
</style>
```
