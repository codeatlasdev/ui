# #136 Horizontal scroll

A horizontal ScrollArea with an always visible scrollbar holding a row of 24 Tag chips inside a card.

When to use: Overflowing chip, tag or filter rows that should scroll sideways instead of wrapping.

## Facets

- Kind: component / display
- Industry: general
- Style: default
- Motion: subtle
- Interaction: scroll, drag, keyboard
- Layout: stack
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: ScrollArea, Card, Chip
- Also searched as: horizontal overflow, custom scrollbar, tag strip

## Spec

- `<Card p="2" full>` wraps the area
- `<ScrollArea orientation="horizontal" type="always">`
- `{ length: 24 }` builds 24 tags labelled Tag 1 to Tag 24, each rendered as `<Chip label={tag} />`
- Chips sit in a `<div class="row">` styled with `width: max-content` so the content overflows

## Source

```svelte
<script lang="ts">
  import { ScrollArea, Card, Chip } from '@codeatlasdev/ui';

  const tags = Array.from({ length: 24 }, (_, i) => `Tag ${i + 1}`);
</script>

<Card p="2" full>
  <ScrollArea orientation="horizontal" type="always">
    <div class="row">
      {#each tags as tag}<Chip label={tag} />{/each}
    </div>
  </ScrollArea>
</Card>

<style>
  .row { display: flex; gap: var(--ca-space-2); padding: var(--ca-space-2) var(--ca-space-2) var(--ca-space-4); width: max-content; }
</style>
```
