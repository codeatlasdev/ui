# #940 Profile mention

A sentence with an @ada mention link that opens a profile card with a name, a line of detail and a View profile link on hover or keyboard focus.

When to use: Previewing a person, link target or record inline without leaving the page; the link itself stays the primary action.

## Facets

- Kind: component / navigation
- Style: default
- Motion: subtle
- Interaction: hover, keyboard
- Layout: overlay
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Avatar, HoverCard, Stack
- Also searched as: profile preview, mention card, tooltip

## Spec

- `<HoverCard>` with `{#snippet triggerChild(props)}<a class="mention" href="#ada" {...props}>@ada</a>{/snippet}`
- Content is `<Stack gap="2">` with a strong name, a secondary line and `<a class="more" href="#ada-profile">View profile</a>`
- Default delays: the pointer waits 700 ms to open, keyboard focus opens at once; Escape closes

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/navigation/hover-card#profile-mention
Reference: https://ui.codeatlas.com.br/api/v1/en/e/940.txt
