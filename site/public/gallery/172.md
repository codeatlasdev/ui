# #172 404 without actions

The ErrorPage component rendering a 404 status without its action buttons.

When to use: Route-level error screens for not found, forbidden or server errors.

## Facets

- Kind: component / layout
- Style: default
- Motion: none
- Interaction: none
- Layout: full-bleed
- Color mode: both
- Density: airy
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: ErrorPage
- Also searched as: 404, not found, status page

## Spec

- `<ErrorPage status={404} hideActions />`
- Only the `status` prop and `hideActions` are passed, no custom title or actions
