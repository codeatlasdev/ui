# #176 Negative trend

Two KPI cards whose trends fall and are good news (`trendTone="positive-down"`), one with an icon and one without.

When to use: Metrics where a falling number is good news, such as churn rate and response time.

## Facets

- Kind: component / layout
- Style: default, bento
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: KpiCard, KpiGrid
- Also searched as: falling is good, churn metric, inverted trend

## Spec

- `<KpiGrid>` with 2 `KpiCard` items
- `<KpiCard title="Churn Rate" value="5.2" unit="%" trend={-1.8} trendTone="positive-down" icon={Activity} />`
- `<KpiCard title="Response Time" value="1.4" unit="s" trend={-12.3} trendTone="positive-down" />` has no `icon`
