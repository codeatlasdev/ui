# #034 Cards

Radio group in `cards` variant with three plans, one disabled, bound to a selected plan.

When to use: Choosing a subscription plan or any option that needs a title and a short description.

## Facets

- Kind: component / input
- Industry: saas
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: RadioGroup
- Also searched as: plan picker, selectable cards, pricing choice

## Spec

- `<RadioGroup variant="cards"` with `aria-label="Plan"`
- `items={plans}` holds 3 entries with `value`, `label`, `description`: Free, Pro, Team
- Team entry has `disabled: true`
- `bind:value={plan}` with initial `$state('pro')`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/radio#cards
Reference: https://ui.codeatlas.com.br/api/v1/en/e/034.txt

## Source

```svelte
<script lang="ts">
  import { RadioGroup } from '@codeatlasdev/ui';

  let plan = $state('pro');

  const plans = [
    { value: 'free', label: 'Free', description: 'For side projects.' },
    { value: 'pro', label: 'Pro', description: 'For teams that ship weekly.' },
    { value: 'team', label: 'Team', description: 'Shared billing and audit log.', disabled: true },
  ];
</script>

<RadioGroup variant="cards" aria-label="Plan" items={plans} bind:value={plan} />
```
