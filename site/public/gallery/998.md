# #998 Single line, icon only and multiline

A CopyField in three forms: single line, icon-only copy and a multiline command.

When to use: Webhook URLs, request snippets and IDs a user must copy exactly.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: CopyField
- Also searched as: read-only copy box, copy box, show once

## Spec

- `iconOnly hideLabel`
- `multiline size="sm"`
- `label="Webhook URL"`
