# #228 Shadow scale

Five cards, each with one shadow token from xs to xl, labelled with its name and CSS variable.

When to use: Comparing the five shadow sizes before choosing one for a card, popover or floating panel.

## Facets

- Kind: component / foundation
- Industry: general
- Style: default
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: none
- Also searched as: elevation, drop shadow, box shadow

## Spec

- `const sizes = ["xs", "sm", "md", "lg", "xl"]` rendered by `{#each sizes as size (size)}`
- Each card sets `style="--card-shadow: var(--ca-shadow-{size})"`
- Labels `shadow-{size}` and `--ca-shadow-{size}` shown in each card
- Cards use `background: var(--ca-surface-base)` and `box-shadow: var(--card-shadow)`
