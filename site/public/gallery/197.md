# #197 Custom zones

Three gauges (CPU 67, Memory 82, Disk 45) that share colour zones for success, warning and error.

When to use: Resource or SLA dashboards where thresholds change the gauge colour.

## Facets

- Kind: component / chart
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, Grid, GaugeChart
- Also searched as: thresholds, health status, system monitor, traffic light

## Spec

- `const zones: GaugeZone[]` with 3 entries: `{ until: 0.5, color: 'success' }`, `{ until: 0.8, color: 'warning' }`, `{ until: 1, color: 'error' }`
- `const metrics` with 3 items: CPU `67`, Memory `82`, Disk `45`, fields `label` and `value`
- `{#each metrics as m}` renders `<GaugeChart value={m.value} {zones} height="200px" />`
- Each gauge sits in its own `<Card>` inside `<Grid columns={{ base: 1, sm: 3 }} gap="4">`

Needs: @codeatlasdev/ui@4.5.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/gauge#custom-zones
Reference: https://ui.codeatlas.com.br/api/v1/en/e/197.txt

## Source

```svelte
<script lang="ts">
  import { Card, Grid } from '@codeatlasdev/ui';
  import { GaugeChart, type GaugeZone } from '@codeatlasdev/ui/charts';

  // `until` is a fraction of min..max; `color` is a semantic name or any CSS color.
  const zones: GaugeZone[] = [
    { until: 0.5, color: 'success' },
    { until: 0.8, color: 'warning' },
    { until: 1, color: 'error' },
  ];
  const metrics = [
    { label: 'CPU', value: 67 },
    { label: 'Memory', value: 82 },
    { label: 'Disk', value: 45 },
  ];
</script>

<Grid columns={{ base: 1, sm: 3 }} gap="4">
  {#each metrics as m}
    <Card>
      <p class="label">{m.label}</p>
      <GaugeChart value={m.value} {zones} height="200px" />
    </Card>
  {/each}
</Grid>

<style>
  .label {
    text-align: center;
    font-size: var(--ca-font-size-caption);
    color: var(--ca-text-secondary);
    font-weight: 600;
    letter-spacing: 0.05em;
    text-transform: uppercase;
    margin: 0 0 var(--ca-space-1);
  }
</style>
```
