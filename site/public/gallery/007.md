# #007 Disabled

Three disabled checkboxes: unchecked, checked and indeterminate.

When to use: Showing a read-only option whose value the user cannot change, such as a setting locked by plan or permission.

## Facets

- Kind: component / input
- Industry: general
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Checkbox
- Also searched as: tick box

## Spec

- `disabled` with `label="Disabled unchecked"`
- `checked disabled` with `label="Disabled checked"`
- `indeterminate disabled` with `label="Disabled indeterminate"`
- Three `<Checkbox` components, no bound state
