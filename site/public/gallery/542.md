# #542 Strike and rewrite

A rewrite line: one struck-out word with an animated pen line, followed by an animated highlighted replacement.

When to use: Editorial strike-through-and-rewrite effects where the removed text stays announced as deleted and the animation respects reduced motion.

## Facets

- Kind: component / display
- Industry: agency, media
- Style: editorial
- Motion: expressive
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Highlight, StrikeThrough
- Also searched as: strikethrough, line through, text rewrite, crossed out

## Spec

- `<StrikeThrough animated>workarounds</StrikeThrough>` draws the line on mount
- `<Highlight animated>one-shot components</Highlight>` follows as the replacement
- The paragraph uses `--ca-font-size-h4`
