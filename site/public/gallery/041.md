# #041 Empty-value option

Select whose first option has an empty value labelled All projects, with the raw value printed.

When to use: Filters where an empty value means no filter, such as All projects.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Select
- Also searched as: all option, filter dropdown, reset option

## Spec

- `<Select label="Project" placeholder="Choose a project…"` with `options={projects}`
- `projects` has 4 options: All projects with `value: ''`, Web app, API, Docs
- `bind:value={project}` with initial `$state('')`
- Current value is shown as `JSON.stringify(project)`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/select#empty-value-option
Reference: https://ui.codeatlas.com.br/api/v1/en/e/041.txt

## Source

```svelte
<script lang="ts">
  import { Select } from '@codeatlasdev/ui';

  let project = $state('');

  const projects = [
    { value: '', label: 'All projects' },
    { value: 'web', label: 'Web app' },
    { value: 'api', label: 'API' },
    { value: 'docs', label: 'Docs' },
  ];
</script>

<div class="col">
  <Select label="Project" placeholder="Choose a project…" options={projects} bind:value={project} />
  <p class="out">Filter value: <code>{JSON.stringify(project)}</code></p>
</div>
```
