# #047 Step and disabled

A slider that snaps in steps of 10 and a disabled slider fixed at 35.

When to use: Discrete values such as percentages in tens, or a locked setting.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: drag, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Slider
- Also searched as: stepped, snap, disabled

## Spec

- Stepped slider: `<Slider bind:value={stepped} min={0} max={100} step={10} />` with initial `$state(50)`
- Disabled slider: `<Slider value={35} disabled />`
- Rows labelled Step 10 and Disabled with readouts `{stepped}` and 35
- Wrapper `.col` uses `max-width: 480px`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/slider#step-and-disabled
Reference: https://ui.codeatlas.com.br/api/v1/en/e/047.txt
