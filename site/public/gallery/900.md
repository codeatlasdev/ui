# #900 Inline pill

A follow-up list where each row has a title and an inline subtle Badge pill with a status dot: Overdue (danger), Due today (warning), Done (success) and a neutral Draft without a dot.

When to use: Status pills next to a title in lists and queues. The pill sits in text flow; it is not anchored to a corner like a count badge.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Badge
- Also searched as: status pill, task status, overdue label, inline tag

## Spec

- Unstyled list with a grid and `gap: var(--ca-space-2)`; each `li` is a wrapping flex row
- Title `span` in `--ca-text-primary`, followed by `<Badge tone="danger" subtle dot size="md">Overdue</Badge>`
- `tone="warning"` Due today and `tone="success"` Done, both `subtle dot size="md"`
- `tone="neutral" subtle size="md"` Draft with no dot
