# #211 Interactive team builder

A radar chart for My team with six sliders that edit each dimension live.

When to use: Letting users build or tweak a skill or score profile and see the shape update.

## Facets

- Kind: component / chart
- Industry: saas, devtools
- Style: default
- Motion: subtle
- Interaction: drag, keyboard, hover
- Layout: split
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Card, Stack, Flex, Slider, RadarChart
- Also searched as: skill builder, editable radar, slider controls

## Spec

- `let dims = $state([88, 92, 76, 85, 94, 79])` holds the six scores
- `const series = $derived([{ name: 'My team', values: [...dims] }])`
- `<RadarChart {indicators} {series} height="320px" />`
- `{#each DIMS as dim, i}` renders one `<Slider value={dims[i]} min={0} max={100} step={1}`
- `onchange={(v) => { dims[i] = v[0]; }}` writes back the first slider value
- Each row shows the dimension name and `{dims[i]}` in a `<Flex justify="between">`

Needs: @codeatlasdev/ui@4.5.0 + echarts

## Source

```svelte
<script lang="ts">
  import { Card, Stack, Flex, Slider } from '@codeatlasdev/ui';
  import { RadarChart } from '@codeatlasdev/ui/charts';

  const DIMS = ['Speed', 'Quality', 'Reliability', 'Innovation', 'Support', 'Coverage'];
  const indicators = DIMS.map((name) => ({ name, max: 100 }));

  let dims = $state([88, 92, 76, 85, 94, 79]);
  const series = $derived([{ name: 'My team', values: [...dims] }]);
</script>

<Card full>
  <div class="builder">
    <RadarChart {indicators} {series} height="320px" />
    <Stack gap="3">
      {#each DIMS as dim, i}
        <Stack gap="1">
          <Flex justify="between">
            <span class="dim-name">{dim}</span>
            <span class="dim-value">{dims[i]}</span>
          </Flex>
          <Slider value={dims[i]} min={0} max={100} step={1} onchange={(v) => { dims[i] = v[0]; }} />
        </Stack>
      {/each}
    </Stack>
  </div>
</Card>

<style>
  .builder { display: grid; grid-template-columns: minmax(0, 1fr) 280px; gap: var(--ca-space-6); align-items: start; }
  .dim-name { font-size: var(--ca-font-size-body2); }
  .dim-value { color: var(--ca-brand-text); font-weight: 600; font-size: var(--ca-font-size-body2); }
  @media (max-width: 899.98px) { .builder { grid-template-columns: minmax(0, 1fr); } }
</style>
```
