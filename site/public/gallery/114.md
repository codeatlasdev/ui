# #114 On avatars

Three medium avatars each carrying a status dot in success, warning or error color.

When to use: Presence or health indicators on a user avatar.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Badge, Avatar, Flex
- Also searched as: status dot, presence badge, user status

## Spec

- `<Badge dot color="success">` around `<Avatar alt="Ana Lima" size="md" />`
- `<Badge dot color="warning">` around `<Avatar alt="Carlos M" size="md" />`
- `<Badge dot color="error">` around `<Avatar alt="Diana K" size="md" />`
- `<Flex gap="4" align="center" wrap>` lays them out
