# #040 Basic

Select with five framework options and the chosen value printed below.

When to use: Picking one value from a known list in a form, such as a framework or category.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Select
- Also searched as: dropdown, picker, listbox

## Spec

- `<Select label="Framework" options={frameworks}` with `bind:value={framework}`
- `frameworks` has 5 options: Svelte 5, React 19, Vue 3, SolidJS, Astro
- Initial value is `$state('svelte')`
- Selected value is shown in `<strong>{framework}</strong>`
- Wrapper `.col` uses `max-width: 320px`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/select#basic
Reference: https://ui.codeatlas.com.br/api/v1/en/e/040.txt

## Source

```svelte
<script lang="ts">
  import { Select } from '@codeatlasdev/ui';

  let framework = $state('svelte');

  const frameworks = [
    { value: 'svelte', label: 'Svelte 5' },
    { value: 'react', label: 'React 19' },
    { value: 'vue', label: 'Vue 3' },
    { value: 'solid', label: 'SolidJS' },
    { value: 'astro', label: 'Astro' },
  ];
</script>

<div class="col">
  <Select label="Framework" options={frameworks} bind:value={framework} />
  <p class="out">Selected: <strong>{framework}</strong></p>
</div>

<style>
  .col {
    display: flex;
    flex-direction: column;
    gap: var(--ca-space-3);
    width: 100%;
    max-width: 320px;
  }

  .out {
    margin: 0;
    font-size: var(--ca-font-size-body2);
    color: var(--ca-text-secondary);
  }

  .out strong {
    color: var(--ca-brand-text);
    font-family: var(--ca-font-mono);
  }
</style>
```
