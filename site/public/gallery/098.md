# #098 Image placeholder

A flush card skeleton with a 180px rectangular image placeholder above two caption lines.

When to use: Loading placeholder for media cards such as products, posts or galleries.

## Facets

- Kind: component / feedback
- Industry: media
- Style: default
- Motion: expressive
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Skeleton, Card, Stack
- Also searched as: placeholder, image loading, shimmer

## Spec

- `<Card flush full>`
- `<Skeleton variant="rectangular" height="180px" />` fills the top of the card
- Caption in `<Stack gap="2">`: `height="16px" width="50%"` and `height="13px" width="80%"`
- Caption wrapper `<div class="caption">` has `padding: 16px`

Needs: @codeatlasdev/ui@4.5.0
