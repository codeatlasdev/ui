# #213 Basic scatter

A scatter plot of 80 generated points in a single Data points series.

When to use: Exploring the relationship between two numeric variables, such as traffic and conversion.

## Facets

- Kind: component / chart
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, ScatterChart
- Also searched as: correlation, xy plot, dot plot

## Spec

- `<ScatterChart series={[{ name: 'Data points', data }]}`
- `data` is 80 `[number, number]` pairs from `Array.from({ length: 80 }`
- `yName="Conversion %"`
- `yFormatter={(v) => `${v.toFixed(1)}%`}`
- `height="320px"` inside `<Card full>`

Needs: @codeatlasdev/ui@4.5.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/scatter#basic-scatter
Reference: https://ui.codeatlas.com.br/api/v1/en/e/213.txt

## Source

```svelte
<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { ScatterChart } from '@codeatlasdev/ui/charts';

  const data = Array.from({ length: 80 }, (_, i): [number, number] => [
    Math.round(500 + 14500 * (0.5 + 0.5 * Math.sin(i * 0.31 + 1.2)) * (0.7 + 0.3 * Math.cos(i * 0.17))),
    parseFloat((0.5 + 13.5 * (0.5 + 0.5 * Math.cos(i * 0.23 + 0.8)) * (0.6 + 0.4 * Math.sin(i * 0.41))).toFixed(2)),
  ]);
</script>

<Card full>
  <ScatterChart series={[{ name: 'Data points', data }]} yName="Conversion %" yFormatter={(v) => `${v.toFixed(1)}%`} height="320px" />
</Card>
```
