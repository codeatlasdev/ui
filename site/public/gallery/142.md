# #142 Text trigger

A Tooltip wrapping plain inline text, which becomes the hover and focus trigger.

When to use: Adding a short explanation to a term or inline phrase without building a custom trigger.

## Facets

- Kind: component / display
- Industry: general
- Style: default
- Motion: subtle
- Interaction: hover, keyboard
- Layout: overlay
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Tooltip
- Also searched as: hint, inline help, text trigger

## Spec

- `<Tooltip content="Wrapped in the tooltip's own button">` with plain text children
- Children text: hover or focus this text
- No trigger snippet, the tooltip renders its own trigger
- Placed inside a paragraph after the sentence Static text can be a trigger too:
