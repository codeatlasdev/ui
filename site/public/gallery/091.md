# #091 Open from a button

A lightbox opened from a button to show a single generated SVG image.

When to use: Enlarging one thumbnail or photo to full view on click.

## Facets

- Kind: component / feedback
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: overlay
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, Lightbox
- Also searched as: image viewer, zoom image

## Spec

- `<Lightbox bind:open src={photo} alt="Gray circle on a dark background" />`
- `photo` is a `data:image/svg+xml;utf8,` URL built with `encodeURIComponent`, 640 by 400 with a circle `r="90"`
- Trigger is `<Button variant="outlined" onclick={() => (open = true)}>` labelled View photo

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/feedback/lightbox#open-from-a-button
Reference: https://ui.codeatlas.com.br/api/v1/en/e/091.txt

## Source

```svelte
<script lang="ts">
  import { Button, Lightbox } from '@codeatlasdev/ui';

  const photo =
    "data:image/svg+xml;utf8," +
    encodeURIComponent(
      '<svg xmlns="http://www.w3.org/2000/svg" width="640" height="400"><rect width="640" height="400" fill="#334155"/><circle cx="320" cy="200" r="90" fill="#94a3b8"/></svg>'
    );
  let open = $state(false);
</script>

<Button variant="outlined" onclick={() => (open = true)}>View photo</Button>
<Lightbox bind:open src={photo} alt="Gray circle on a dark background" />
```
