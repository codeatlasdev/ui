# #101 Section loader

A card with a centered 40px spinner and a Loading data text.

When to use: Loader for a whole section or panel while its data is fetched.

## Facets

- Kind: component / feedback
- Style: default
- Motion: expressive
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: airy
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Spinner, Card, Stack
- Also searched as: loading, busy

## Spec

- `<Card p="10" full>`
- `<Stack align="center" gap="3">` centers the spinner and text
- `<Spinner size={40} />` above `<span class="text">Loading data…</span>`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/feedback/spinner#section-loader
Reference: https://ui.codeatlas.com.br/api/v1/en/e/101.txt
