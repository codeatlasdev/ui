# #225 Button glass variants

Three native buttons using the glass button classes over a brand to info gradient backdrop.

When to use: Choosing between the default, prominent and clear glass button styles on a colorful or image background.

## Facets

- Kind: component / foundation
- Style: glassmorphism, aurora
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: none
- Also searched as: frosted button, translucent button, blur button

## Spec

- `<button type="button" class="glass-btn">` labelled glass-btn
- `<button type="button" class="glass-btn-prominent">` labelled glass-btn-prominent
- `<button type="button" class="glass-btn-clear">` labelled glass-btn-clear
- Backdrop is `linear-gradient(135deg, var(--ca-brand-main), var(--ca-semantic-info))`
