# #240 IconFallback

Two large avatars whose fallback is a custom icon: one with an image that fails to decode and one with no image.

When to use: Representing groups or bots, where initials do not make sense, with a lucide icon.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Avatar
- Also searched as: icon placeholder, broken image fallback, bot avatar, group avatar

## Spec

- `<Avatar src="data:image/png;base64,AAAA" alt="Family" size="lg" loading="lazy" referrerpolicy="no-referrer">` uses an image that fails to decode
- `{#snippet fallback()}<Users size={22} aria-hidden="true" />{/snippet}` renders the Users icon
- `<Avatar alt="Support bot" size="lg">` has no `src`
- `{#snippet fallback()}<Bot size={22} aria-hidden="true" />{/snippet}` renders the Bot icon

## Source

```svelte
<script lang="ts">
  import { Avatar } from '@codeatlasdev/ui';
  import { Bot, Users } from '@lucide/svelte';
</script>

<!-- An image that fails to decode without a request: shows the fallback, logs no 404. -->
<Avatar src="data:image/png;base64,AAAA" alt="Family" size="lg" loading="lazy" referrerpolicy="no-referrer">
  {#snippet fallback()}<Users size={22} aria-hidden="true" />{/snippet}
</Avatar>
<Avatar alt="Support bot" size="lg">
  {#snippet fallback()}<Bot size={22} aria-hidden="true" />{/snippet}
</Avatar>
```
