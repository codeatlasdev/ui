# #110 Sizes

Avatars at every preset size from extra small to extra large, plus a custom numeric size.

When to use: Choosing avatar size for dense lists, headers and profile pages.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Avatar
- Also searched as: avatar scale, user icon size

## Spec

- `size="xs"` with `alt="Extra small"`
- `size="sm"` with `alt="Small"`
- `size="md"` with `alt="Medium"`
- `size="lg"` with `alt="Large"`
- `size="xl"` with `alt="Extra large"`
- `size={80}` with `alt="Custom"` is a numeric size

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/display/avatar#sizes
Reference: https://ui.codeatlas.com.br/api/v1/en/e/110.txt
