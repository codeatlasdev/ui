# #482 Stacked controls

A Card titled Trending topics that stacks three Checkbox controls in a column with gap="sm", the title aligned with the controls.

When to use: Settings and filter cards whose content is several inline controls (Checkbox, Switch, TextField) that need vertical spacing.

## Facets

- Kind: component / surface
- Style: default
- Motion: none
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Card, Checkbox
- Also searched as: checklist card, titled form card, stacked controls

## Spec

- `<Card title="Trending topics" headingLevel={3} gap="sm" class="stacked">` with `max-width: 320px`
- Three `<Checkbox label="Hacker News" />` children: Hacker News, Product Hunt, Lobsters
- `gap="sm"` stacks the children in a column with 8px between them; the title shares the checkboxes' left edge
