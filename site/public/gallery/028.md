# #028 Default

A default MoneyInput bound to a cents value, with the raw cents and formatted display printed below.

When to use: A price or amount field where the model stores integer cents and the UI shows a formatted amount.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: MoneyInput
- Also searched as: price input, cents, currency

## Spec

- `<MoneyInput label="Price" bind:value={price} />`
- `let price = $state(123456)` holds cents
- Output line prints `{price} cents → {centsToDisplay(price)}`
- Wrapper `.col` has `max-width: 400px`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/money-input#default
Reference: https://ui.codeatlas.com.br/api/v1/en/e/028.txt

## Source

```svelte
<script lang="ts">
  import { MoneyInput, centsToDisplay } from '@codeatlasdev/ui/forms';

  let price = $state(123456);
</script>

<div class="col">
  <MoneyInput label="Price" bind:value={price} />
  <p class="out">value = {price} cents → {centsToDisplay(price)}</p>
</div>

<style>

  }
</style>
```
