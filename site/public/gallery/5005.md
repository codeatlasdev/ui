# #5005 Icon tile

Four KPI cards with the icon in a tinted tile above the label: brand, success, warning and error tones, large numbers and trends.

When to use: Dashboard headline numbers where each metric gets a coloured icon tile instead of a bare corner icon.

## Facets

- Kind: component / layout
- Style: default
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: KpiCard, KpiGrid
- Also searched as: stat card with icon, icon tile metric

## Spec

- `<KpiGrid>` with 4 `KpiCard` items, each with `iconStyle="tile"`
- `<KpiCard title="Revenue" value="$48,200" trend={12.4} icon={DollarSign} iconStyle="tile" />` (brand tone by default)
- Active users uses `tone="success"`; Open incidents `tone="warning"` with `trendTone="positive-down"`; Error rate `tone="error"` with `trendTone="positive-down"`

## Source

```svelte
<script lang="ts">
  import { KpiCard, KpiGrid } from '@codeatlasdev/ui';
  import { Users, DollarSign, AlertTriangle, Activity } from '@lucide/svelte';
</script>

<KpiGrid>
  <KpiCard title="Revenue" value="$48,200" trend={12.4} icon={DollarSign} iconStyle="tile" />
  <KpiCard title="Active users" value="3,847" trend={8.1} icon={Users} iconStyle="tile" tone="success" />
  <KpiCard title="Open incidents" value="7" trend={40} trendTone="positive-down" icon={AlertTriangle} iconStyle="tile" tone="warning" />
  <KpiCard title="Error rate" value="1.2" unit="%" trend={-0.3} trendTone="positive-down" icon={Activity} iconStyle="tile" tone="error" />
</KpiGrid>
```
