# #125 Vertical

Three text items in a row inside a card separated by vertical dividers.

When to use: Separating inline items in a toolbar or meta row.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Divider, Card, Flex
- Also searched as: separator, vertical rule, inline separator

## Spec

- `<Card p="6" full>` wraps the content
- `<Flex gap="6" align="center">` lays out Left, Center and Right
- `<Divider orientation="vertical" />` is placed between them

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/display/divider#vertical
Reference: https://ui.codeatlas.com.br/api/v1/en/e/125.txt

## Source

```svelte
<script lang="ts">
  import { Divider, Card, Flex } from '@codeatlasdev/ui';
</script>

<Card p="6" full>
  <Flex gap="6" align="center">
    <p>Left</p>
    <Divider orientation="vertical" />
    <p>Center</p>
    <Divider orientation="vertical" />
    <p>Right</p>
  </Flex>
</Card>

<style>
  p { margin: 0; font-size: var(--ca-font-size-body1); color: var(--ca-text-secondary); }
</style>
```
