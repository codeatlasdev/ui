# #966 Autoplay

A looping three-quote carousel that advances every 4 seconds, with a Pause button and no arrows.

When to use: Rotating testimonials or announcements; autoplay is opt-in and always stoppable.

## Facets

- Kind: component / display
- Industry: saas, e-commerce
- Style: minimal
- Motion: expressive
- Interaction: drag, keyboard, hover
- Layout: carousel
- Color mode: both
- Density: airy
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Carousel, CarouselItem
- Also searched as: auto rotate, testimonial slider, quote rotator, auto advance

## Spec

- `<Carousel label="Customer quotes" autoplay={4000} loop arrows={false}>`
- Each slide is `<CarouselItem><blockquote class="quote">{quote}</blockquote></CarouselItem>`
- `quotes` holds three short strings

## Source

```svelte
<script lang="ts">
  import { Carousel, CarouselItem } from '@codeatlasdev/ui';

  const quotes = ['"Setup took ten minutes."', '"The keyboard support is real."', '"Our audit passed first time."'];
</script>

<div class="frame">
  <Carousel label="Customer quotes" autoplay={4000} loop arrows={false}>
    {#each quotes as quote (quote)}
      <CarouselItem><blockquote class="quote">{quote}</blockquote></CarouselItem>
    {/each}
  </Carousel>
</div>
```
