# #044 Switch rows

Two setting rows, each with a label, a description and a Switch on the right.

When to use: Preference lists such as notification settings, one toggle per row.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: SettingItem, Switch
- Also searched as: preference row, settings row, toggle row

## Spec

- `<SettingItem label="Email notifications" description="Receive an email for every mention.">`
- `<SettingItem label="Weekly digest" description="One summary every Monday.">`
- Each row wraps `<Switch bind:checked={email} />` or `<Switch bind:checked={digest} />` as children
- Initial state: `$state(true)` for email, `$state(false)` for digest

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/setting-item#switch-rows
Reference: https://ui.codeatlas.com.br/api/v1/en/e/044.txt

## Source

```svelte
<script lang="ts">
  import { SettingItem, Switch } from '@codeatlasdev/ui';

  let email = $state(true);
  let digest = $state(false);
</script>

<SettingItem label="Email notifications" description="Receive an email for every mention.">
  <Switch bind:checked={email} />
</SettingItem>
<SettingItem label="Weekly digest" description="One summary every Monday.">
  <Switch bind:checked={digest} />
</SettingItem>
```
