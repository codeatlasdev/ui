# #002 With icons

Buttons with an icon before the label, after the label, and with a ghost download action.

When to use: Actions that benefit from an icon cue: favourite, continue to next step, download.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button
- Also searched as: icon button, button with icon

## Spec

- Leading icon goes in `{#snippet leading()}` (`Star` from `@lucide/svelte`, `size={15}`)
- Trailing icon goes in `{#snippet trailing()}` (`ArrowRight`, `size={15}`)
- Variants shown: `variant="filled"`, `variant="outlined"`, `variant="ghost"`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/button#with-icons
Reference: https://ui.codeatlas.com.br/api/v1/en/e/002.txt

## Source

```svelte
<script lang="ts">
  import { Button } from '@codeatlasdev/ui';
  import { ArrowRight, Download, Star } from '@lucide/svelte';
</script>

<Button variant="filled">
  {#snippet leading()}<Star size={15} />{/snippet}
  Starred
</Button>
<Button variant="outlined">
  Continue
  {#snippet trailing()}<ArrowRight size={15} />{/snippet}
</Button>
<Button variant="ghost">
  {#snippet leading()}<Download size={15} />{/snippet}
  Download
</Button>
```
