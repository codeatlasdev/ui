# #051 Disabled

Two disabled switches, one off and one on.

When to use: Showing a setting that cannot be changed, for example a locked plan feature.

## Facets

- Kind: component / input
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Switch
- Also searched as: inactive toggle

## Spec

- `<Switch disabled label="Disabled off" />`
- `<Switch checked disabled label="Disabled on" />`
- No bound state
