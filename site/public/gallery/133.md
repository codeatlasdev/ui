# #133 Basic

Pagination for 100 items at 10 per page, with the current page bound to state and printed below.

When to use: Paged lists and tables where the app needs to know the active page to fetch or slice data.

## Facets

- Kind: component / display
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Pagination
- Also searched as: page numbers, pager, next previous

## Spec

- `<Pagination count={100} perPage={10} bind:page />`
- State: `let page = $state(1)` starts on page 1
- A paragraph renders `Current page: {page}` below the control

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/display/pagination#basic
Reference: https://ui.codeatlas.com.br/api/v1/en/e/133.txt

## Source

```svelte
<script lang="ts">
  import { Pagination } from '@codeatlasdev/ui';

  let page = $state(1);
</script>

<div class="wrap">
  <Pagination count={100} perPage={10} bind:page />
  <p>Current page: {page}</p>
```
