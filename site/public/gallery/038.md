# #038 Default

Two segmented controls: a text-only Week/Month/Year period and a List/Grid view switch with icons.

When to use: Switching a view mode or time range inline above a list, chart or dashboard.

## Facets

- Kind: component / input
- Industry: saas
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: SegmentedControl
- Also searched as: tabs switch, view toggle, period selector

## Spec

- Period control `aria-label="Period"` with `bind:value={period}` and 3 items: Week, Month, Year
- Current value is shown as `value: {period}`
- View control `aria-label="View"` with 2 items using `icon: LayoutList` and `icon: LayoutGrid`
- Icons come from `@lucide/svelte`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/segmented-control#default

## Source

```svelte
<script lang="ts">
  import { SegmentedControl } from '@codeatlasdev/ui';
  import { LayoutGrid, LayoutList } from '@lucide/svelte';

  let period = $state('month');
  let view = $state('list');
</script>

<div class="col">
  <div>
    <SegmentedControl
      aria-label="Period"
      bind:value={period}
      items={[
        { value: 'week', label: 'Week' },
        { value: 'month', label: 'Month' },
        { value: 'year', label: 'Year' },
      ]}
    />
    <p class="out">value: {period}</p>
  </div>
  <SegmentedControl
    aria-label="View"
    bind:value={view}
    items={[
      { value: 'list', label: 'List', icon: LayoutList },
      { value: 'grid', label: 'Grid', icon: LayoutGrid },
    ]}
  />
</div>

<style>
  .col {
    display: flex;
    flex-direction: column;
    gap: var(--ca-space-5);
  }

  .out {
    margin: var(--ca-space-3) 0 0;
    font-size: var(--ca-font-size-caption);
    color: var(--ca-text-secondary);
  }
</style>
```
