# #073 Default (closed)

Three independent Collapsible FAQ panels stacked with a small gap, all closed initially.

When to use: Short FAQ or help blocks where each answer expands on its own.

## Facets

- Kind: component / surface
- Industry: saas, education
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Collapsible, Stack
- Also searched as: disclosure, expand collapse, help blocks

## Spec

- `<Stack gap="2" class="collapsible-faq">` with `max-width: 560px`
- 3 `<Collapsible` items with a `title`: What is a surface style?, How do presets work?, Is dark mode automatic?
- Each body is a `<p>` child, two of them include a `<code>` token
- Nothing is bound to the open state, each panel manages its own

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/surfaces/collapsible#default-closed

## Source

```svelte
<script lang="ts">
  import { Collapsible, Stack } from '@codeatlasdev/ui';
</script>

<Stack gap="2" class="collapsible-faq">
  <Collapsible title="What is a surface style?">
    <p>A surface style is one knob of the theme. It decides whether cards are solid paper, outlined, tonal or blurred, and every component follows it.</p>
  </Collapsible>
  <Collapsible title="How do presets work?">
    <p>Presets remap the brand hue token. Switching preset updates every component that reads from <code>--ca-brand-*</code> without any JS.</p>
  </Collapsible>
  <Collapsible title="Is dark mode automatic?">
    <p>Yes. The <code>colorScheme</code> store writes a <code>.dark</code> class to the root element, which flips all dark-mode tokens.</p>
  </Collapsible>
</Stack>

<style>
  :global(.collapsible-faq) { width: 100%; max-width: 560px; }
  p { margin: 0; font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); line-height: 1.6; }
</style>
```
