# #126 In a results table

A table of three domains where each row ends with an ExternalLink to a registrar URL.

When to use: Table cells that link out to a third-party site, with the external-link affordance.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: keyboard, press
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: ExternalLink, SimpleTable, Card
- Also searched as: outbound link, new tab link, domain list, registrar

## Spec

- `<Card flush full>` wraps `<SimpleTable responsive="cards">`
- `const rows` has 3 entries with `domain`, `price` and `url`
- Header cells are Domain, Price and Registrar
- `<ExternalLink href={r.url}>Buy at registrar</ExternalLink>` is rendered in each last cell
- `{#each rows as r (r.domain)}` renders one `<tr>` per row

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/display/external-link#in-a-results-table
Reference: https://ui.codeatlas.com.br/api/v1/en/e/126.txt

## Source

```svelte
<script lang="ts">
  import { ExternalLink, SimpleTable, Card } from '@codeatlasdev/ui';

  const rows = [
    { domain: 'atlas.dev', price: '$12.00', url: 'https://registrar.example/buy?d=atlas.dev' },
    { domain: 'nimbus.io', price: '$38.00', url: 'https://registrar.example/buy?d=nimbus.io' },
    { domain: 'orbit.app', price: '$21.00', url: 'https://registrar.example/buy?d=orbit.app' },
  ];
</script>

<Card flush full>
  <SimpleTable responsive="cards">
    <thead>
      <tr><th>Domain</th><th>Price</th><th>Registrar</th></tr>
    </thead>
    <tbody>
      {#each rows as r (r.domain)}
        <tr>
          <td class="primary">{r.domain}</td>
          <td>{r.price}</td>
          <td><ExternalLink href={r.url}>Buy at registrar</ExternalLink></td>
        </tr>
      {/each}
    </tbody>
  </SimpleTable>
</Card>
```
