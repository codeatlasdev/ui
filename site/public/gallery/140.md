# #140 Simple

A basic Timeline of four project milestones, each with a label and a date.

When to use: Roadmaps, changelogs or release histories that need a short vertical sequence of dated events.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Timeline
- Also searched as: milestones, roadmap, history, release log

## Spec

- `<Timeline {items} />`
- 4 items with `label` and `date` only: Project started Jan 2025, Alpha released Mar 2025, Public beta Jun 2025, v1.0 stable Sep 2025
- Wrapped in `.wrap` with `max-width: 440px`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/display/timeline#simple
Reference: https://ui.codeatlas.com.br/api/v1/en/e/140.txt
