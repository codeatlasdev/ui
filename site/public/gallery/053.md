# #053 Without label

Two switches with no visible label, named only through aria-label.

When to use: Compact toggles in table rows or cards where the context already names the setting.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Switch
- Also searched as: unlabelled, aria label only, toggle

## Spec

- `<Switch bind:checked={analytics} aria-label="Analytics" />` with `$state(false)`
- `<Switch checked aria-label="Always on" />` with no binding
- No `label` prop is passed

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/switch#without-label
Reference: https://ui.codeatlas.com.br/api/v1/en/e/053.txt

```svelte

  import { Switch } from '@codeatlasdev/ui';

</script>
```
