# #154 Custom separator

A breadcrumb with a custom separator character between three items.

When to use: Matching breadcrumb punctuation to a product's visual language, for example a chevron between levels.

## Facets

- Kind: component / navigation
- Industry: devtools
- Style: default
- Motion: none
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Breadcrumb
- Also searched as: trail, path, separator

## Spec

- `<Breadcrumb` with `items` Docs (`href: '/'`), API Reference (`href: '/api'`) and Components (no `href`)
- `separator="›"` sets a single character as the separator

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/navigation/breadcrumb#custom-separator
Reference: https://ui.codeatlas.com.br/api/v1/en/e/154.txt

## Source

```svelte
<script lang="ts">
  import { Breadcrumb } from '@codeatlasdev/ui';
</script>

<Breadcrumb
  items={[{ label: 'Docs', href: '/' }, { label: 'API Reference', href: '/api' }, { label: 'Components' }]}
  separator="›"
/>
```
