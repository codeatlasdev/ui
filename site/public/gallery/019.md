# #019 Default

An ExportMenu exporting three domain rows with custom column headers and a status line reporting the last export.

When to use: Table toolbars that let users download the current data set as a file in a chosen format.

## Facets

- Kind: component / input
- Industry: saas
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: ExportMenu
- Also searched as: download, csv, xlsx, dropdown

## Spec

- `data={rows}` with `const rows` of 3 objects with `domain`, `price` and `available` fields
- `filename="domains"`
- `columns` has 3 entries with `header` `Domain`, `Price (USD)` and `Available`
- `onexport` sets `last` to the exported `e.filename` and `e.rows` count
- Idle status text is `Pick a format to download.`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/export-menu#default

## Source

```svelte
<script lang="ts">
  import { ExportMenu } from '@codeatlasdev/ui';

  const rows = [
    { domain: 'atlas.dev', price: 12, available: true },
    { domain: 'nimbus.io', price: 38, available: false },
    { domain: 'orbit.app', price: 21, available: true },
  ];
  let last = $state('');
</script>

<div class="wrap">
  <ExportMenu
    data={rows}
    filename="domains"
    columns={[{ key: 'domain', header: 'Domain' }, { key: 'price', header: 'Price (USD)' }, { key: 'available', header: 'Available' }]}
    onexport={(e) => (last = `${e.filename}: ${e.rows} rows`)}
  />
  <p class="last" aria-live="off">{last || 'Pick a format to download.'}</p>
</div>

<style>
  .wrap { display: flex; align-items: center; gap: var(--ca-space-3); flex-wrap: wrap; }
  .last { margin: 0; color: var(--ca-text-secondary); font-size: var(--ca-font-size-body2); }
</style>
```
