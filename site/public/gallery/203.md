# #203 Simple line

A basic line chart of a single Revenue series over nine months.

When to use: Showing the trend of one metric over time, the default time-series view.

## Facets

- Kind: component / chart
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, LineChart
- Also searched as: trend line, time series, revenue over time

## Spec

- `<LineChart` with one series `{ name: 'Revenue', data: revenue }`
- `revenue` has 9 values from `42000` to `112000`
- `categories={months}` with `'Jan'` to `'Sep'`
- `valueFormatter={fmt}` renders `$${(v / 1000).toFixed(0)}k`
- `height="300px"` inside `<Card full>`

Needs: @codeatlasdev/ui@4.5.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/line#simple-line
Reference: https://ui.codeatlas.com.br/api/v1/en/e/203.txt

## Source

```svelte
<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { LineChart } from '@codeatlasdev/ui/charts';

  const months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun', 'Jul', 'Aug', 'Sep'];
  const revenue = [42000, 51000, 58000, 63000, 72000, 80000, 88000, 95000, 112000];
  const fmt = (v: number) => `$${(v / 1000).toFixed(0)}k`;
</script>

<Card full>
  <LineChart series={[{ name: 'Revenue', data: revenue }]} categories={months} valueFormatter={fmt} height="300px" />
</Card>
```
