# #117 With icons

Three chips each with a leading lucide icon: star, zap and tag.

When to use: Labelled badges that gain meaning from an icon, such as featured or boosted items.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Chip
- Also searched as: tag with icon, icon label

## Spec

- `<Chip label="Featured" icon={Star} />`
- `<Chip label="Boosted" icon={Zap} />`
- `<Chip label="Tagged" icon={Tag} />`
- `icon` receives the component itself imported from `@lucide/svelte`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/display/chip#with-icons
