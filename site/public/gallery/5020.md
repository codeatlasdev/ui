# #5020 Composer bar, overflow menu

A message action bar that stays on one line: icon buttons move into a More menu when the row is narrow, and Send never leaves.

When to use: A composer, reply box or list header whose controls must not wrap and push the primary action out of view on a phone.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, IconButton, Toolbar
- Also searched as: action bar, composer bar, overflow menu

## Spec

- `<Toolbar aria-label="Message actions" overflow="menu">`
- Five text `IconButton`s (Attach, Templates, Emoji, Bold, Italic), each with an `aria-label`
- `<span class="ca-toolbar-spacer">` then a filled `Send` button carrying `data-priority="primary"`, which never moves into the menu

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/toolbar#composer-bar-overflow-menu
Reference: https://ui.codeatlas.com.br/api/v1/en/e/5020.txt

## Source

```svelte
<script lang="ts">
  import { Bold, Italic, Paperclip, Smile, Sparkles } from '@lucide/svelte';
  import { Button, IconButton, Toolbar } from '@codeatlasdev/ui';

  let sent = $state(0);
</script>

<Toolbar aria-label="Message actions" overflow="menu">
  <IconButton variant="ghost" size="sm" aria-label="Attach"><Paperclip size={16} /></IconButton>
  <IconButton variant="ghost" size="sm" aria-label="Templates"><Sparkles size={16} /></IconButton>
  <IconButton variant="ghost" size="sm" aria-label="Emoji"><Smile size={16} /></IconButton>
  <IconButton variant="ghost" size="sm" aria-label="Bold"><Bold size={16} /></IconButton>
  <IconButton variant="ghost" size="sm" aria-label="Italic"><Italic size={16} /></IconButton>
  <span class="ca-toolbar-spacer"></span>
  <Button data-priority="primary" onclick={() => sent++}>Send{sent ? ` (${sent})` : ''}</Button>
</Toolbar>
```
