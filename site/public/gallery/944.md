# #944 Editor menu bar

An application menu bar with File, Edit, View and a disabled Help menu; File has a submenu, View has a checkbox and a radio group, and a line below reports the last action.

When to use: A desktop-style application or editor menu bar: arrows move between menus, an open menu switches on hover or ArrowRight and ArrowLeft.

## Facets

- Kind: component / navigation
- Industry: devtools
- Style: glassmorphism
- Motion: subtle
- Interaction: keyboard, press, hover
- Layout: stack
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: DropdownMenuCheckboxItem, DropdownMenuItem, DropdownMenuLabel, DropdownMenuRadioGroup, DropdownMenuRadioItem, DropdownMenuSeparator, DropdownMenuSub, DropdownMenuSubTrigger, Menubar, MenubarMenu
- Also searched as: menu bar, application menu, toolbar menu

## Spec

- `<Menubar aria-label="Editor">` holds four `MenubarMenu`s labelled File, Edit, View and a `disabled` Help
- File has `DropdownMenuItem`s, a `DropdownMenuSub` with `DropdownMenuSubTrigger` for Export, a separator and a destructive Close
- View has `<DropdownMenuCheckboxItem bind:checked={wrap}>` and a `<DropdownMenuRadioGroup bind:value={zoom} aria-label="Zoom">` with 100% and 150%
- Action items call `function pick(action: string)`, which sets `last` and calls `announce`

## Source

```svelte
<script lang="ts">
  import {
    announce,
    DropdownMenuCheckboxItem,
    DropdownMenuItem,
    DropdownMenuLabel,
    DropdownMenuRadioGroup,
    DropdownMenuRadioItem,
    DropdownMenuSeparator,
    DropdownMenuSub,
    DropdownMenuSubTrigger,
    Menubar,
    MenubarMenu,
  } from '@codeatlasdev/ui';

  let last = $state('');
  let wrap = $state(true);
  let zoom = $state('100');

  function pick(action: string) {
    last = action;
    announce(`Last action: ${action}`);
  }
</script>

<Menubar aria-label="Editor">
  <MenubarMenu label="File">
    <DropdownMenuItem onclick={() => pick('New file')}>New file</DropdownMenuItem>
    <DropdownMenuItem onclick={() => pick('Open')}>Open</DropdownMenuItem>
    <DropdownMenuSub>
      {#snippet trigger()}<DropdownMenuSubTrigger>Export</DropdownMenuSubTrigger>{/snippet}
      <DropdownMenuItem onclick={() => pick('Export PDF')}>PDF</DropdownMenuItem>
      <DropdownMenuItem onclick={() => pick('Export HTML')}>HTML</DropdownMenuItem>
    </DropdownMenuSub>
    <DropdownMenuSeparator />
    <DropdownMenuItem variant="destructive" onclick={() => pick('Close')}>Close</DropdownMenuItem>
  </MenubarMenu>
  <MenubarMenu label="Edit">
    <DropdownMenuItem onclick={() => pick('Undo')}>Undo</DropdownMenuItem>
    <DropdownMenuItem onclick={() => pick('Redo')}>Redo</DropdownMenuItem>
  </MenubarMenu>
  <MenubarMenu label="View">
    <DropdownMenuCheckboxItem bind:checked={wrap}>Word wrap</DropdownMenuCheckboxItem>
    <DropdownMenuSeparator />
    <DropdownMenuLabel>Zoom</DropdownMenuLabel>
    <DropdownMenuRadioGroup bind:value={zoom} aria-label="Zoom">
      <DropdownMenuRadioItem value="100">100%</DropdownMenuRadioItem>
      <DropdownMenuRadioItem value="150">150%</DropdownMenuRadioItem>
    </DropdownMenuRadioGroup>
  </MenubarMenu>
  <MenubarMenu label="Help" disabled>
    <DropdownMenuItem>About</DropdownMenuItem>
  </MenubarMenu>
</Menubar>

<span class="note">Word wrap: {wrap ? 'on' : 'off'}. Zoom: {zoom}%{last ? `. Last action: ${last}` : ''}</span>

<style>
  .note { display: block; margin-block-start: var(--ca-space-3); font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); }
</style>
```
