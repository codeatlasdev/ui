# #087 Split

A split dialog with a media panel beside a lead form containing name, email and a Save button.

When to use: Detail or onboarding dialogs that pair an image or summary with a short form.

## Facets

- Kind: component / feedback
- Style: default
- Motion: subtle
- Interaction: keyboard, press
- Layout: overlay
- Color mode: both
- Density: airy
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Dialog, Button, TextField, Stack
- Also searched as: two pane modal, media dialog

## Spec

- `<Dialog bind:open title="Lead details" size="split" chromeless>`
- Two direct children: `<div class="media">` labelled Media / summary and `<div class="form">`
- Form uses `<Stack gap="3.5">` with `<TextField label="Full name" bind:value={name}` and `<TextField label="Email" type="email" bind:value={email}`
- Save is `<Button variant="filled" onclick={() => (open = false)}>`

## Source

```svelte
<script lang="ts">
  import { Dialog, Button, TextField, Stack } from '@codeatlasdev/ui';

  let open = $state(false);
  let name = $state('');
  let email = $state('');
</script>

<Button variant="filled" onclick={() => (open = true)}>Open split</Button>

<Dialog bind:open title="Lead details" size="split" chromeless>
  <div class="media">Media / summary</div>
  <div class="form">
    <Stack gap="3.5">
      <TextField label="Full name" bind:value={name} placeholder="Ada Lovelace" />
      <TextField label="Email" type="email" bind:value={email} placeholder="ada@company.com" />
      <Button variant="filled" onclick={() => (open = false)}>Save</Button>
    </Stack>
  </div>
</Dialog>

<style>
  .media {
    display: grid;
    place-items: center;
    min-height: 160px;
    background: color-mix(in oklab, var(--ca-brand-main) 12%, var(--ca-surface-overlay));
    color: var(--ca-text-secondary);
    font-size: var(--ca-font-size-body2);
  }
  .form { padding: 24px; overflow-y: auto; }
</style>
```
