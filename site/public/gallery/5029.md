# #5029 MonthPicker

Two MonthPickers: a field showing month and year with a twelve-month popover grid, one free and one limited to a single year.

When to use: Choosing a billing or reporting month where the day does not matter.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: MonthPicker
- Also searched as: month year picker, billing month, period month

## Spec

- `<MonthPicker label="Billing month" locale="en-US" bind:value={billing} />` initialised with `new CalendarDate(2026, 3, 1)`
- A second `<MonthPicker` with `label="Report month"`, `minValue={new CalendarDate(2026, 1, 1)}`, `maxValue={new CalendarDate(2026, 12, 31)}` and `description="Only 2026 is available."`
- Two `value:` output lines print the ISO date of the 1st of each chosen month
- Wrapper `.col` has `max-width: 400px`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/month-picker#monthpicker

## Source

```svelte
<script lang="ts">
  import { CalendarDate, MonthPicker } from '@codeatlasdev/ui';

  let billing = $state<CalendarDate | undefined>(new CalendarDate(2026, 3, 1));
  let report = $state<CalendarDate | undefined>();
</script>

<div class="col">
  <MonthPicker label="Billing month" locale="en-US" bind:value={billing} />
  <p class="out">value: <code>{billing ? billing.toString() : '–'}</code></p>

  <MonthPicker
    label="Report month"
    description="Only 2026 is available."
    locale="en-US"
    minValue={new CalendarDate(2026, 1, 1)}
    maxValue={new CalendarDate(2026, 12, 31)}
    bind:value={report}
  />
  <p class="out">value: <code>{report ? report.toString() : '–'}</code></p>
</div>

<style>
  .col {
    display: flex;
    flex-direction: column;
    gap: var(--ca-space-4);
    width: 100%;
    max-width: 400px;
  }

  .out {
    margin: 0;
    font-size: var(--ca-font-size-caption);
    color: var(--ca-text-secondary);
  }
</style>
```
