# #170 No results

A no-results state for search with a magnifier icon and a Clear filters button.

When to use: Search and filter screens where the query matched nothing and the user should reset it.

## Facets

- Kind: component / layout
- Industry: saas
- Style: default
- Motion: none
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: EmptyState, Button
- Also searched as: zero results, search empty, clear filters

## Spec

- `<EmptyState icon={Search} title="No results found" description="Try adjusting your search terms or filters.">`
- `{#snippet actions()}` holds `<Button variant="outlined" size="sm">Clear filters</Button>`
