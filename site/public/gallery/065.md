# #065 Controlled

A single-open Accordion with its open item bound to state and the current value printed below.

When to use: FAQ or settings sections where the app needs to read or set which item is open.

## Facets

- Kind: component / surface
- Industry: saas
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Accordion, AccordionItem
- Also searched as: bound state, controlled disclosure

## Spec

- `<Accordion type="single" bind:value>`
- State: `let value = $state<string | string[] | undefined>('c1')` opens the first item initially
- 2 items: `<AccordionItem value="c1" title="First section">` and `<AccordionItem value="c2" title="Second section">`
- `Open item: {Array.isArray(value) ? value.join(', ') : (value ?? 'none')}` prints the bound value
- Wrapped in `.wrap` with `max-width: 560px`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/surfaces/accordion#controlled
Reference: https://ui.codeatlas.com.br/api/v1/en/e/065.txt

## Source

```svelte
<script lang="ts">
  import { Accordion, AccordionItem } from '@codeatlasdev/ui';

  let value = $state<string | string[] | undefined>('c1');
</script>

<div class="wrap">
  <Accordion type="single" bind:value>
    <AccordionItem value="c1" title="First section">Opened from the bound value.</AccordionItem>
    <AccordionItem value="c2" title="Second section">Opening this one closes the first.</AccordionItem>
  </Accordion>
  <p>Open item: {Array.isArray(value) ? value.join(', ') : (value ?? 'none')}</p>
</div>

<style>
  .wrap { width: 100%; max-width: 560px; display: flex; flex-direction: column; gap: var(--ca-space-3); }
  p { margin: 0; font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); }
</style>
```
