# #083 Chromeless

A medium dialog with the chromeless prop, so the content fills the panel edge to edge with no header or padding.

When to use: Previews and media viewers where the content supplies its own layout and close control.

## Facets

- Kind: component / feedback
- Industry: general
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: overlay
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Dialog, Button
- Also searched as: modal, edge to edge

## Spec

- `<Dialog bind:open title="Preview" size="md" chromeless>`
- Body is a `<div class="media">` with a paragraph and a `<Button variant="filled"` labelled Close
- Close button runs `onclick={() => (open = false)}`
- Trigger is `<Button variant="outlined"` labelled Open chromeless

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/feedback/dialog#chromeless

## Source

```svelte
<script lang="ts">
  import { Dialog, Button } from '@codeatlasdev/ui';

  let open = $state(false);
</script>

<Button variant="outlined" onclick={() => (open = true)}>Open chromeless</Button>

<Dialog bind:open title="Preview" size="md" chromeless>
  <div class="media">
    <p>Edge-to-edge content. Close with Esc or by clicking outside.</p>
    <Button variant="filled" onclick={() => (open = false)}>Close</Button>
  </div>
</Dialog>

<style>
  .media {
    display: grid;
    gap: 12px;
    padding: 24px;
    justify-items: start;
    color: var(--ca-text-secondary);
    font-size: var(--ca-font-size-body2);
  }
  .media p { margin: 0; }
</style>
```
