# #221 Outline

Three swatches for the outline tokens, drawn with a border so they stay visible on the page.

When to use: Choosing a divider or border strength from the subtle, default and strong outline tokens.

## Facets

- Kind: component / foundation
- Style: default
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: none
- Also searched as: border colors, stroke, divider

## Spec

- Renders `<Swatches {tokens} bordered={true} />` with 3 tokens
- Tokens in order: `--ca-outline-subtle`, `--ca-outline-default`, `--ca-outline-strong`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/foundation/colors#outline
