# #148 clipboard

A native button that copies an install command to the clipboard and shows a Copied! label for two seconds.

When to use: Copy-to-clipboard affordances for install commands, API keys and share links.

## Facets

- Kind: component / navigation
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: none
- Also searched as: copy to clipboard, copy text

## Spec

- `use:clipboard={'bun add @codeatlasdev/ui'}` imported from `@codeatlasdev/ui/actions` on a native `<button`
- `oncopy={done}` sets `copied = true` and resets it with `setTimeout(() => (copied = false), 2000)`
- Label switches with state: `{copied ? 'Copied!' : 'Copy install command'}`
- `let copied = $state(false)`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/navigation/actions#clipboard

## Source

```svelte
<script lang="ts">
  import { clipboard } from '@codeatlasdev/ui/actions';

  let copied = $state(false);
  function done() {
    copied = true;
    setTimeout(() => (copied = false), 2000);
  }
</script>

<button use:clipboard={'bun add @codeatlasdev/ui'} oncopy={done} class="btn">
  {copied ? 'Copied!' : 'Copy install command'}
</button>

<style>
  .btn {
    min-height: var(--ca-control-height);
    padding: 8px 20px;
    border-radius: var(--ca-radius-md);

    background: var(--ca-action-hover);
    cursor: pointer;
    font: inherit;
    font-size: var(--ca-font-size-body2);
    color: var(--ca-text-primary);
  }
</style>
```
