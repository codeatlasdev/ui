# #492 Description and action

Three buttons that fire a toast with a description, with one inline action, and with both.

When to use: A toast that needs a secondary line of detail or a single shortcut such as Undo, Open or Mark as qualified.

## Facets

- Kind: component / feedback
- Industry: saas
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: overlay
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, Toaster
- Also searched as: snackbar, undo action, notification

## Spec

- `<Toaster />` mounted once, `toast` imported from `@codeatlasdev/ui`
- Description: `toast.success('Task completed', { description: 'Next step scheduled for tomorrow 09:00' })`
- Action: `toast.warning('Sequence paused for Acme', {` with `action: { label: 'Mark as qualified'`, whose `onClick` runs and dismisses the toast; an actionable toast lasts 8 seconds
- Both: `description` and `action` in the same options object
- All triggers are `<Button variant="outlined"`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/feedback/toast#description-and-action
Reference: https://ui.codeatlas.com.br/api/v1/en/e/492.txt

## Source

```svelte
<script lang="ts">
  import { Button, Toaster, toast } from '@codeatlasdev/ui';
</script>

<Toaster />

<Button variant="outlined" onclick={() => toast.success('Task completed', { description: 'Next step scheduled for tomorrow 09:00' })}>
  With description
</Button>
<Button
  variant="outlined"
  onclick={() =>
    toast.warning('Sequence paused for Acme', {
      action: { label: 'Mark as qualified', onClick: () => toast.success('Marked as qualified.') },
    })}
>
  With action
</Button>
<Button
  variant="outlined"
  onclick={() =>
    toast.info('You have 7 tasks today', {
      description: 'Three are due before noon.',
      action: { label: 'Open Today', onClick: () => toast.success('Opening the queue…') },
    })}
>
  Both
</Button>
```
