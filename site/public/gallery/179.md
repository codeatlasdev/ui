# #179 Three cards

A KpiGrid holding three KPI cards to show how the grid lays out an odd number of items.

When to use: Dashboards with three headline metrics, where the grid should still look balanced.

## Facets

- Kind: component / layout
- Style: bento, default
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: KpiCard, KpiGrid
- Also searched as: three metrics, odd count, uneven grid

## Spec

- `<KpiGrid>` with 3 `KpiCard` items
- `<KpiCard title="Revenue" value="$112k" trend={18.4} icon={DollarSign} />`
- `<KpiCard title="Users" value="24.8k" trend={12.1} icon={Users} />`
- `<KpiCard title="Growth" value="34" unit="%" trend={5.6} icon={TrendingUp} />`
