# #541 Animated and static

A sentence with one animated marker-pen highlight and one static highlight.

When to use: Emphasizing a key phrase in a headline or paragraph with a marker sweep that falls back to the final state under reduced motion.

## Facets

- Kind: component / display
- Industry: agency, media
- Style: editorial
- Motion: expressive
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Highlight
- Also searched as: marker, text emphasis, highlighter sweep, mark

## Spec

- `<Highlight animated>editorial pages</Highlight>` sweeps in on mount
- `<Highlight>static marks</Highlight>` is drawn fully with no animation
- The paragraph uses `--ca-font-size-h4`

Needs: @codeatlasdev/ui@4.5.0
