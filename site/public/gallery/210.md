# #210 Comparison

A radar chart comparing Team A and Team B across six dimensions.

When to use: Comparing two entities, such as teams or products, on the same set of scores.

## Facets

- Kind: component / chart
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, RadarChart
- Also searched as: spider chart, two teams, skills comparison

## Spec

- `const indicators` maps 6 names (Speed, Quality, Reliability, Innovation, Support, Coverage) to `{ name, max: 100 }`
- `<RadarChart` with `{indicators}` and 2 series
- `{ name: 'Team A', values: [88, 92, 76, 85, 94, 79] }`
- `{ name: 'Team B', values: [74, 68, 90, 72, 81, 83] }`
- `height="340px"` inside `<Card full>`

Needs: @codeatlasdev/ui@4.5.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/radar#comparison
Reference: https://ui.codeatlas.com.br/api/v1/en/e/210.txt

## Source

```svelte
<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { RadarChart } from '@codeatlasdev/ui/charts';

  const indicators = ['Speed', 'Quality', 'Reliability', 'Innovation', 'Support', 'Coverage'].map((name) => ({ name, max: 100 }));
</script>

<Card full>
  <RadarChart
    {indicators}
    series={[
      { name: 'Team A', values: [88, 92, 76, 85, 94, 79] },
      { name: 'Team B', values: [74, 68, 90, 72, 81, 83] },
    ]}
    height="340px"
  />
</Card>
```
