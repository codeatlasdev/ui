# #182 Flex, Stack and Box

A Stack with a wrapping Flex row of three chips above a single padded Box.

When to use: Composing small layouts with spacing props instead of custom CSS.

## Facets

- Kind: component / layout
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Stack, Flex, Box
- Also searched as: flexbox, vertical rhythm, gap spacing

## Spec

- `<Stack gap="4" p="4">` is the root
- `<Flex gap="3" align="center" justify="between" wrap>` holds 3 `<Box class="chip" px="3" py="1">` items
- Chip labels: Flex, space between; gap 3; wraps
- A last `<Box class="chip" p="4">` reads Stack gap 4, Box padding 4

## Source

```svelte
<script lang="ts">
  import { Stack, Flex, Box } from '@codeatlasdev/ui';
</script>

<Stack gap="4" p="4">
  <Flex gap="3" align="center" justify="between" wrap>
    <Box class="chip" px="3" py="1">Flex, space between</Box>
    <Box class="chip" px="3" py="1">gap 3</Box>
    <Box class="chip" px="3" py="1">wraps</Box>
  </Flex>
  <Box class="chip" p="4">Stack gap 4, Box padding 4</Box>
</Stack>

<style>
  :global(.chip) { background: var(--ca-surface-raised); border-radius: var(--ca-radius-md); box-shadow: inset 0 0 0 1px var(--ca-outline-subtle); font-size: var(--ca-font-size-body2); }
</style>
```
