# #173 Basic form

A complete user creation form with a header, two sections, bound fields and a footer with Cancel and Create user.

When to use: Create or edit pages that group fields into sections and keep their actions in a footer.

## Facets

- Kind: component / layout
- Style: default
- Motion: subtle
- Interaction: keyboard, press
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: AppForm, FormSection, TextField, Select, Switch, Button, Divider
- Also searched as: create user, settings form, sectioned form

## Spec

- `<AppForm title="New User" description="Fill in the details to create a new user.">` with `{#snippet leading()}` holding `<Button variant="ghost" size="sm" aria-label="Back">`
- `<FormSection title="Account details"` holds `<TextField label="Full name" bind:value={name}`, `<TextField label="Work email" bind:value={email}` and `<Select label="Role" bind:value={role} options={roleOptions} />`
- `roleOptions` has 3 entries: Admin, Editor, Viewer, with `let role = $state('viewer')`
- `<FormSection title="Notifications" description="Email preferences." layout="list">` holds `<Switch label="Send welcome email" bind:checked={welcome} />`, `<Divider />` and `<Switch label="Weekly digest" bind:checked={digest} />`
- `{#snippet footer()}` has Cancel with `variant="ghost"` and Create user with `disabled={saving || !name || !email}`
- `function save()` sets `saving = true` and resets it with `setTimeout(() => (saving = false), 1400)`

## Source

```svelte
<script lang="ts">
  import { AppForm, FormSection, TextField, Select, Switch, Button, Divider } from '@codeatlasdev/ui';
  import { ArrowLeft } from '@lucide/svelte';

  let name = $state('');
  let email = $state('');
  let role = $state('viewer');
  let welcome = $state(true);
  let digest = $state(false);
  let saving = $state(false);

  function save() {
    saving = true;
    setTimeout(() => (saving = false), 1400);
  }

  const roleOptions = [
    { value: 'admin', label: 'Admin' },
    { value: 'editor', label: 'Editor' },
    { value: 'viewer', label: 'Viewer' },
  ];
</script>

<div class="frame">
  <AppForm title="New User" description="Fill in the details to create a new user.">
    {#snippet leading()}
      <Button variant="ghost" size="sm" aria-label="Back">
        {#snippet leading()}<ArrowLeft size={15} />{/snippet}
      </Button>
    {/snippet}

    <FormSection title="Account details" description="Basic information for the new user.">
      <TextField label="Full name" bind:value={name} placeholder="Ada Lovelace" />
      <TextField label="Work email" bind:value={email} placeholder="ada@company.com" type="email" />
      <Select label="Role" bind:value={role} options={roleOptions} />
    </FormSection>

    <FormSection title="Notifications" description="Email preferences." layout="list">
      <Switch label="Send welcome email" bind:checked={welcome} />
      <Divider />
      <Switch label="Weekly digest" bind:checked={digest} />
    </FormSection>

    {#snippet footer()}
      <Button variant="ghost">Cancel</Button>
      <Button variant="filled" onclick={save} disabled={saving || !name || !email}>
        {saving ? 'Saving…' : 'Create user'}
      </Button>
    {/snippet}
  </AppForm>
</div>

<style>
  .frame {
    width: 100%;
    height: 480px;
    border-radius: var(--ca-radius-lg);
    box-shadow: inset 0 0 0 1px var(--ca-outline-subtle);
    overflow: hidden;
    display: flex;
    flex-direction: column;
  }
</style>
```
