# #010 Basic

A searchable Combobox over eight frameworks that prints the selected value below the field.

When to use: Picking one item from a long list where typing to filter is faster than scrolling a select.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard, press
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Combobox
- Also searched as: autocomplete, typeahead, searchable select

## Spec

- `<Combobox label="Framework" options={frameworks} bind:value={selected} />`
- `const frameworks` has 8 options with `value` and `label` keys, from `svelte` to `sveltekit`
- `let selected = $state('')` starts empty
- `{#if selected}` renders `Selected:` with the value in `<code>`
- Wrapper `.col` has `max-width: 320px`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/combobox#basic
Reference: https://ui.codeatlas.com.br/api/v1/en/e/010.txt

## Source

```svelte
<script lang="ts">
  import { Combobox } from '@codeatlasdev/ui';

  const frameworks = [
    { value: 'svelte', label: 'Svelte' },
    { value: 'react', label: 'React' },
    { value: 'vue', label: 'Vue' },
    { value: 'angular', label: 'Angular' },
    { value: 'solid', label: 'SolidJS' },
    { value: 'astro', label: 'Astro' },
    { value: 'nuxt', label: 'Nuxt' },
    { value: 'sveltekit', label: 'SvelteKit' },
  ];

  let selected = $state('');
</script>

<div class="col">
  <Combobox label="Framework" options={frameworks} bind:value={selected} />
  {#if selected}
    <p class="out">Selected: <code>{selected}</code></p>
  {/if}
</div>

<style>
  .col {
    width: 100%;
    max-width: 320px;
  }

  .out {
    margin: var(--ca-space-3) 0 0;
    font-size: var(--ca-font-size-body2);
    color: var(--ca-text-secondary);
  }
</style>
```
