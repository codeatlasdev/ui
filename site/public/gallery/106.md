# #106 With title

Two alerts with a bold title above the body text: a success and an error.

When to use: Notices that need a headline plus an explanation, such as save confirmations or failed sign-ins.

## Facets

- Kind: component / display
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Alert
- Also searched as: titled callout, error message, success message

## Spec

- `severity="success"` with `title="Changes saved"`
- `severity="error"` with `title="Authentication failed"`
- Body text is passed as the alert children
- Wrapper `.col` has `max-width: 560px`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/display/alert#with-title
Reference: https://ui.codeatlas.com.br/api/v1/en/e/106.txt

## Source

```svelte
<script lang="ts">
  import { Alert } from '@codeatlasdev/ui';
</script>

<div class="col">
  <Alert severity="success" title="Changes saved">
    All your edits have been persisted to the database.
  </Alert>
  <Alert severity="error" title="Authentication failed">
    The provided credentials are incorrect. Try again or reset your password.
  </Alert>
</div>

<style>
  .col { display: flex; flex-direction: column; gap: var(--ca-space-3); width: 100%; max-width: 560px; }
```
