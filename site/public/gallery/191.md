# #191 Stacked bars

A stacked bar chart splitting six months of revenue into four acquisition channels.

When to use: Showing how a total is composed of channels or segments over time.

## Facets

- Kind: component / chart
- Industry: saas, fintech
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, BarChart
- Also searched as: stacked columns, channel mix, breakdown

## Spec

- `<BarChart` inside `<Card full>`
- 4 series in `series`: Organic, Paid, Referral, Direct, each with 6 values
- `categories={months}` with `'Jan'` to `'Jun'`
- `stacked` prop
- `valueFormatter={fmt}` renders `$${(v / 1000).toFixed(0)}k`
- `height="300px"`

Needs: @codeatlasdev/ui@4.5.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/bar#stacked-bars
Reference: https://ui.codeatlas.com.br/api/v1/en/e/191.txt

## Source

```svelte
<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { BarChart } from '@codeatlasdev/ui/charts';

  const months = ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'];
  const fmt = (v: number) => `$${(v / 1000).toFixed(0)}k`;
</script>

<Card full>
  <BarChart
    series={[
      { name: 'Organic', data: [12400, 14800, 18200, 16600, 21200, 24800] },
      { name: 'Paid', data: [8200, 9600, 11800, 10400, 13600, 15200] },
      { name: 'Referral', data: [4800, 5600, 7200, 6400, 8800, 10400] },
      { name: 'Direct', data: [3200, 4000, 5200, 4600, 6200, 7600] },
    ]}
    categories={months}
    valueFormatter={fmt}
    stacked
    height="300px"
  />
</Card>
```
