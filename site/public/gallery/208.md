# #208 Basic donut

A donut chart of market share split across five categories.

When to use: Showing the proportional split of a total, such as revenue by product line.

## Facets

- Kind: component / chart
- Industry: saas, fintech
- Style: default
- Motion: subtle
- Interaction: hover
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Card, PieChart
- Also searched as: ring chart, share of total, doughnut

## Spec

- `<PieChart data={marketData} donut height="300px" />`
- `marketData` has 5 items with `value` and `name`: Cloud Services `38`, Enterprise SW `24`, SaaS Tools `18`, Infrastructure `12`, Other `8`
- Wrapped in `<Card full>`

Needs: @codeatlasdev/ui@4.5.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/pie#basic-donut
Reference: https://ui.codeatlas.com.br/api/v1/en/e/208.txt

## Source

```svelte
<script lang="ts">
  import { Card } from '@codeatlasdev/ui';
  import { PieChart } from '@codeatlasdev/ui/charts';

  const marketData = [
    { value: 38, name: 'Cloud Services' },
    { value: 24, name: 'Enterprise SW' },
    { value: 18, name: 'SaaS Tools' },
    { value: 12, name: 'Infrastructure' },
    { value: 8, name: 'Other' },
  ];
</script>

<Card full><PieChart data={marketData} donut height="300px" /></Card>
```
