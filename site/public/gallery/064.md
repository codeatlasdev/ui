# #064 With schema

Form using a schema for username length and bio length, with a live character count.

When to use: Forms with several validation rules that run all at once.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard, press
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, TextArea, TextField
- Also searched as: schema validation, character count

## Spec

- `useForm(` with `schema: (data) => {` returns `errs`
- Username rules: `data.username.length < 3` and `data.username.length > 20`
- Bio rule: `data.bio.length > 160` with `Bio must be 160 characters or fewer.`
- Bio TextArea shows `description="{form.fields.bio.value.length}/160"`
- Buttons: `Validate all` calls `form.validate()`, Reset calls `form.reset()`
- Footer prints `valid: {form.valid}`

## Source

```svelte
<script lang="ts">
  import { Button, TextArea, TextField, useForm } from '@codeatlasdev/ui';

  const form = useForm(
    { username: '', bio: '' },
    {
      schema: (data) => {
        const errs: Partial<Record<'username' | 'bio', string>> = {};
        if (data.username.length < 3) errs.username = 'At least 3 characters.';
        if (data.username.length > 20) errs.username = 'Max 20 characters.';
        if (data.bio.length > 160) errs.bio = 'Bio must be 160 characters or fewer.';
        return errs;
      },
    },
  );
</script>

<div class="col">
  <TextField
    label="Username"
    placeholder="john_doe"
    value={form.fields.username.value}
    error={form.fields.username.error}
    description="3–20 characters."
    oninput={(v) => form.set('username', v)}
    onblur={() => form.touch('username')}
  />
  <TextArea
    label="Bio"
    placeholder="Tell us about yourself…"
    value={form.fields.bio.value}
    error={form.fields.bio.error}
    description="{form.fields.bio.value.length}/160"
    oninput={(v) => form.set('bio', v)}
    onblur={() => form.touch('bio')}
  />
  <div class="row">
    <Button onclick={() => form.validate()}>Validate all</Button>
    <Button variant="outlined" onclick={() => form.reset()}>Reset</Button>
  </div>
  <p class="hint">valid: {form.valid}</p>
</div>

<style>

  .hint {
    margin: 0;

    color: var(--ca-text-secondary);
  }
</style>
```
