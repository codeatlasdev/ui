# #5004 Icon tile, count and title extra

A PageShell header with an icon tile before the title, a count badge after it, a titleExtra badge and an action button.

When to use: Product screens that name the list and how many records it holds ("Deals, 128", "Tasks, 12") without replacing the PageShell header.

## Facets

- Kind: component / layout
- Style: default
- Motion: none
- Interaction: none
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: PageShell, Card, Badge, Button
- Also searched as: page header, title with count, icon tile header

## Spec

- Frame is a flush full `Card` holding the `PageShell`
- `<PageShell title="Deals" description="Sales funnel" icon={Handshake} count={128}>`
- `{#snippet titleExtra()}` renders `<Badge tone="warning" subtle>3 overdue</Badge>`; `{#snippet actions()}` renders a small filled `New deal` button
- Body is a `Card full` with a placeholder line
