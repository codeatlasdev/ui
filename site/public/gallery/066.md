# #066 Multiple

An Accordion that lets several of its three items stay open at once.

When to use: Reference or feature lists where users compare multiple sections without the others collapsing.

## Facets

- Kind: component / surface
- Industry: devtools
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Accordion, AccordionItem
- Also searched as: multi open, expand several

## Spec

- `<Accordion type="multiple">`
- 3 items: `<AccordionItem value="b1" title="Svelte 5 runes">`, `value="b2" title="Headless primitives"`, `value="b3" title="CSS custom properties"`
- Item content is plain text passed as children
- The accordion is uncontrolled, nothing is bound
- Wrapped in `.wrap` with `max-width: 560px`

Needs: @codeatlasdev/ui@4.5.0
Live demo: https://ui.codeatlas.com.br/docs/surfaces/accordion#multiple
Reference: https://ui.codeatlas.com.br/api/v1/en/e/066.txt

## Source

```svelte
<script lang="ts">
  import { Accordion, AccordionItem } from '@codeatlasdev/ui';
</script>

<div class="wrap">
  <Accordion type="multiple">
    <AccordionItem value="b1" title="Svelte 5 runes">
      Runes replace reactive declarations with explicit $state(), $derived() and $effect().
    </AccordionItem>
    <AccordionItem value="b2" title="Headless primitives">
      Unstyled, accessible primitives with the WAI-ARIA patterns built in.
    </AccordionItem>
    <AccordionItem value="b3" title="CSS custom properties">
      All --ca-* tokens are set in global.css and cascade into every component without runtime
      overhead.
    </AccordionItem>
  </Accordion>
</div>

<style>
  .wrap { width: 100%; max-width: 560px; }
</style>
```
