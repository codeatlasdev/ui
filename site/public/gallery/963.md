# #963 Nested and saved

A persisted horizontal group (Folders, Main) whose Main panel holds a vertical group (Messages over Reader).

When to use: Three-pane layouts (mail, issue trackers) where the layout survives a reload.

## Facets

- Kind: component / layout
- Industry: saas, devtools
- Style: default, minimal
- Motion: subtle
- Interaction: drag, keyboard, hover
- Layout: split
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: ResizableHandle, ResizablePanel, ResizablePanels
- Also searched as: three pane, mail layout, vertical split, persisted layout

## Spec

- `<ResizablePanels label="Mail" persist="ca-demo-mail-layout">`
- `<ResizablePanel id="folders" defaultSize={20} minSize={12}>` and `<ResizablePanel id="main" defaultSize={80}>`
- `<ResizablePanels direction="vertical" label="Message list and reader">` inside `main` with `list` (40) and `reader` (60)
- `<ResizableHandle label="Resize folders" />` and `<ResizableHandle label="Resize message list" />`

Needs: @codeatlasdev/ui@4.5.0
