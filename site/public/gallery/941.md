# #941 Delays, side and bind:open

An outlined Plan details button with a top-start hover card, plus a button that shows or hides the card from code and a line reporting the last user-driven change.

When to use: Short delays, a custom side and alignment, and driving the card with bind:open while onOpenChange reports only what the user did.

## Facets

- Kind: component / navigation
- Style: default
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: overlay
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, HoverCard
- Also searched as: preview card, controlled tooltip

## Spec

- `let open = $state(false)` is bound with `<HoverCard bind:open openDelay={150} closeDelay={150} side="top" align="start" {onOpenChange}>`
- `{#snippet triggerChild(props)}<Button variant="outlined" {...props}>Plan details</Button>{/snippet}`
- `function onOpenChange(o: boolean)` sets `log` to `opened by the user` or `closed by the user`; the code button toggles `open` and does not touch `log`
- A second button flips `open` with `onclick={() => (open = !open)}`

## Source

```svelte
<script lang="ts">
  import { Button, HoverCard } from '@codeatlasdev/ui';

  let open = $state(false);
  let log = $state('closed');

  function onOpenChange(o: boolean) {
    log = o ? 'opened by the user' : 'closed by the user';
  }
</script>

<div class="row">
  <HoverCard bind:open openDelay={150} closeDelay={150} side="top" align="start" {onOpenChange}>
    {#snippet triggerChild(props)}<Button variant="outlined" {...props}>Plan details</Button>{/snippet}
    <p class="text">Team plan: 10 seats, 100 GB storage, priority support.</p>
  </HoverCard>
  <Button variant="ghost" onclick={() => (open = !open)}>{open ? 'Hide' : 'Show'} from code</Button>
</div>
<span class="note">State: {log}</span>

<style>
  .row { display: flex; gap: var(--ca-space-3); align-items: center; flex-wrap: wrap; }
  .text { margin: 0; color: var(--ca-text-secondary); }
  .note { font-size: var(--ca-font-size-body2); color: var(--ca-text-secondary); }
</style>
```
