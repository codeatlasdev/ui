# #195 Progress ring

A ring gauge controlled by a slider, starting at 65.

When to use: Letting users tune a percentage or score and see the gauge respond live.

## Facets

- Kind: component / chart
- Style: default
- Motion: subtle
- Interaction: drag, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Card, Stack, Slider, GaugeChart
- Also searched as: progress ring, radial progress, slider driven

## Spec

- `let value = $state(65)` shared by gauge and slider
- `<GaugeChart {value} variant="ring" height="260px" />`
- `<Slider bind:value min={0} max={100} step={1} />`
- `<Stack gap="5">` stacks gauge and slider inside `<Card full>`

Needs: @codeatlasdev/ui@4.6.0 + echarts
Live demo: https://ui.codeatlas.com.br/docs/charts/gauge#progress-ring
Reference: https://ui.codeatlas.com.br/api/v1/en/e/195.txt

## Source

```svelte
<script lang="ts">
  import { Card, Stack, Slider } from '@codeatlasdev/ui';
  import { GaugeChart } from '@codeatlasdev/ui/charts';

  let value = $state(65);
</script>

<Card full>
  <Stack gap="5">
    <GaugeChart {value} variant="ring" height="260px" />
    <div class="slider"><Slider bind:value min={0} max={100} step={1} /></div>
  </Stack>
</Card>

<style>
  .slider { padding: 0 var(--ca-space-3); }
</style>
```
