# #962 Two panels

A two-panel horizontal group (Files 25%, Editor 75%) in a bordered frame with a caption showing the live percentages.

When to use: Split views where the user sizes a side panel: file trees, inspectors, mail readers.

## Facets

- Kind: component / layout
- Industry: devtools
- Style: default, minimal
- Motion: subtle
- Interaction: drag, keyboard, hover
- Layout: split
- Color mode: both
- Density: compact
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: ResizableHandle, ResizablePanel, ResizablePanels
- Also searched as: split pane, resizable split, editor layout, divider

## Spec

- `<ResizablePanels label="Workspace" onlayout={(s) => (sizes = s)}>`
- `<ResizablePanel id="files" defaultSize={25} minSize={15} maxSize={50}>` and `<ResizablePanel id="editor" defaultSize={75}>`
- `<ResizableHandle label="Resize files" />` between them
- Caption `Files {Math.round(sizes[0])}% · Editor {Math.round(sizes[1])}%`

```svelte
<script lang="ts">
  import { ResizableHandle, ResizablePanel, ResizablePanels } from '@codeatlasdev/ui';

  let sizes = $state<number[]>([25, 75]);
</script>

<div class="frame">
  <ResizablePanels label="Workspace" onlayout={(s) => (sizes = s)}>
    <ResizablePanel id="files" defaultSize={25} minSize={15} maxSize={50}>
      <p class="pane">Files</p>
    </ResizablePanel>
    <ResizableHandle label="Resize files" />
    <ResizablePanel id="editor" defaultSize={75}>
      <p class="pane">Editor</p>
    </ResizablePanel>
  </ResizablePanels>
</div>
<p class="note">Files {Math.round(sizes[0])}% · Editor {Math.round(sizes[1])}%. Focus the handle and use the arrow keys.</p>
```
