# #222 Semantic

Four swatches for the semantic status color tokens: success, warning, error and info.

When to use: Choosing a status color for alerts, badges and validation states.

## Facets

- Kind: component / foundation
- Style: default
- Motion: none
- Interaction: none
- Layout: grid
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: none
- Also searched as: status colors, success warning error, feedback colors

## Spec

- Renders `<Swatches {tokens} bordered={false} />` with 4 tokens
- Tokens in order: `--ca-semantic-success`, `--ca-semantic-warning`, `--ca-semantic-error`, `--ca-semantic-info`
