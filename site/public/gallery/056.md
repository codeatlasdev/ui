# #056 Default

Two basic text fields: a full name and an email with type email.

When to use: Standard single-line inputs in a signup or profile form.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: TextField
- Also searched as: input, form field

## Spec

- `<TextField label="Full name" placeholder="Jane Smith" bind:value={name} />`
- `<TextField label="Email" placeholder="you@example.com" type="email" bind:value={email} />`
- Both values start as `$state('')`

Needs: @codeatlasdev/ui@4.6.0
