# #5031 Soft limit and threshold

Two text areas with a character counter: a post with a soft 280-character limit and a report whose count appears only from 400 characters.

When to use: Composers and long-form fields where a length limit matters only near the end.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: TextArea
- Also searched as: character counter, char count, soft limit, composer

## Spec

- Post has `counter={{ max: 280 }}` and no `maxlength`: typing may go past 280 and the count turns to the error tone
- Report details has `maxlength={500}` and `counter={{ from: 400 }}`: no count below 400 characters
- Both have `rows={3}` and a description beside the count
- Column wrapper has `max-width: 480px`

## Source

```svelte
<script lang="ts">
  import { TextArea } from '@codeatlasdev/ui';

  let post = $state('Shipping the new release notes today.');
  let report = $state('');
</script>

<div class="col">
  <TextArea
    label="Post"
    description="Posts over 280 characters cannot be sent."
    bind:value={post}
    counter={{ max: 280 }}
    rows={3}
  />
  <TextArea
    label="Report details"
    description="The count appears from 400 characters."
    bind:value={report}
    maxlength={500}
    counter={{ from: 400 }}
    rows={3}
  />
</div>

<style>
  .col {
    display: flex;
    flex-direction: column;
    gap: var(--ca-space-4);
    width: 100%;
    max-width: 480px;
  }
</style>
```
