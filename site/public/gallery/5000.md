# #5000 Show once

Show-a-secret-once recipe: AlertDialog + masked CopyField, Confirm disabled until copied.

When to use: After creating an API key or a recovery code the user must save.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: AlertDialog, Button, CopyField
- Also searched as: read-only copy box, copy box, show once

## Spec

- `confirmDisabled={!copied}`
- `mask copyLabel="Copy key"`
- `oncopy={() => (copied = true)}`

## Source

```svelte
<script lang="ts">
  import { AlertDialog, Button, CopyField } from '@codeatlasdev/ui';

  let open = $state(false);
  let copied = $state(false);
  const secret = 'acme_demo_A1b2C3d4E5F6g7H8i9J0k1L2m3N4o5P6';
</script>

<Button variant="outlined" onclick={() => { copied = false; open = true; }}>Create API key</Button>

<!-- AlertDialog has no X and ignores scrim clicks; Confirm stays off until the key is copied.
     Escape still closes it, so say so in the description. -->
<AlertDialog
  bind:open
  title="Your new API key"
  description="This is the only time the key is shown. Copy it now; Escape closes this dialog and the key is gone."
  confirmLabel="I saved it"
  confirmDisabled={!copied}
  cancelLabel="Close"
  onconfirm={() => {}}
>
  <CopyField label="API key" value={secret} mask copyLabel="Copy key" oncopy={() => (copied = true)} />
</AlertDialog>
```
