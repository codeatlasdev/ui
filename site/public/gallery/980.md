# #980 Text, icon and filled groups

Three ButtonGroups: text buttons (Day, Week, Month), icon buttons (Bold, Italic, Underline) and a filled plus destructive pair.

When to use: Related actions that read as one control: a range switcher, a formatting toolbar, an approve and reject pair.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Button, ButtonGroup, IconButton
- Also searched as: segmented buttons, toolbar group, joined buttons

## Spec

- `<ButtonGroup aria-label="View range">` with three `variant="outlined" tone="neutral"` Buttons
- `<ButtonGroup aria-label="Text style">` with three outlined neutral `IconButton`s, each with an `aria-label`
- `<ButtonGroup aria-label="Review">` with a `filled` Approve and a `destructive` Reject
- The groups are stacked in a column with `gap: var(--ca-space-3)`

## Source

```svelte
<script lang="ts">
  import { Button, ButtonGroup, IconButton } from '@codeatlasdev/ui';
  import { Bold, Italic, Underline } from '@lucide/svelte';
</script>

<div class="col">
  <ButtonGroup aria-label="View range">
    <Button variant="outlined" tone="neutral">Day</Button>
    <Button variant="outlined" tone="neutral">Week</Button>
    <Button variant="outlined" tone="neutral">Month</Button>
  </ButtonGroup>

  <ButtonGroup aria-label="Text style">
    <IconButton variant="outlined" tone="neutral" aria-label="Bold"><Bold size={16} /></IconButton>
    <IconButton variant="outlined" tone="neutral" aria-label="Italic"><Italic size={16} /></IconButton>
    <IconButton variant="outlined" tone="neutral" aria-label="Underline"><Underline size={16} /></IconButton>
  </ButtonGroup>

  <ButtonGroup aria-label="Review">
    <Button variant="filled">Approve</Button>
    <Button variant="destructive">Reject</Button>
  </ButtonGroup>
</div>

<style>
  .col { display: grid; gap: var(--ca-space-3); justify-items: start; }
</style>
```
