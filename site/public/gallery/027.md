# #027 Currency and locale

MoneyInput in three currencies and locales: USD en-US, JPY without decimals and EUR de-DE.

When to use: Price fields in multi-currency products that must format and parse per locale.

## Facets

- Kind: component / input
- Style: default
- Motion: subtle
- Interaction: keyboard
- Layout: stack
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: MoneyInput
- Also searched as: locale, price input, multi currency

## Spec

- `currency="USD" locale="en-US"` with `bind:value={usd}` starting at `$state(123456)`
- `currency="JPY" locale="en-US"` with `bind:value={jpy}` starting at `$state(1234)`
- `currency="EUR" locale="de-DE"` with `bind:value={eur}` starting at `$state(123456)`
- Labels: `Price (USD, en-US)`, `Price (JPY, no decimals)` and `Preis (EUR, de-DE)`

Needs: @codeatlasdev/ui@4.6.0
Live demo: https://ui.codeatlas.com.br/docs/inputs/money-input#currency-and-locale
