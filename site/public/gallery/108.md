# #108 Initials fallback

Large avatars with no image source: three given only `alt` names and two given explicit `fallback` text.

When to use: Users who have no uploaded photo, shown with initials or a placeholder character.

## Facets

- Kind: component / display
- Industry: general
- Style: default
- Motion: none
- Interaction: none
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: not interactive
- Components: Avatar
- Also searched as: monogram, name initials, placeholder user

## Spec

- `alt="Alice Martin"`, `alt="Bob Chen"` and `alt="Clara Silva"` with no image
- `fallback="DK"` sets explicit text
- `fallback="?"` sets a placeholder character
- All five use `size="lg"`
