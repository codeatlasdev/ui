# #071 Link card

A solid Card that is a link as a whole, with a Surface heading and a one line description.

When to use: Clickable cards that navigate to a detail page, such as index tiles or related-article links.

## Facets

- Kind: component / surface
- Industry: saas
- Style: default
- Motion: subtle
- Interaction: hover, press, keyboard
- Layout: single-column
- Color mode: both
- Density: regular
- Tech: css (cost: css)
- Reduced motion: handled; keyboard: operable
- Components: Card
- Also searched as: clickable card, link tile, navigation card

## Spec

- `<Card href="/docs/surfaces/surface/" title="Surface" headingLevel={3} material="solid" elevation={2}>`
- `href` makes the whole card the link
- `headingLevel={3}` sets the title heading level
- Body is plain text: The one painted container every card is built on
