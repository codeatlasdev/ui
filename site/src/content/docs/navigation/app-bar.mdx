```svelte
<script>
  import { GlassAppBar, IconButton } from "@codeatlasdev/ui";
</script>

<GlassAppBar>
  My Application
  {#snippet trailing()}<IconButton aria-label="Search">...</IconButton>{/snippet}
</GlassAppBar>
```

Renders a `<header>`. Icon-only buttons inside it need an `aria-label`. Inside [AppShell](/docs/layout/app-shell/) use the shell's own header; this bar is for standalone pages.
