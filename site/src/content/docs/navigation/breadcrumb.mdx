
Rendered as a `nav` landmark with an ordered list. The last item is the current page: it has `aria-current="page"` and is never a link. Items without `href` render as plain text.

## Icon separator and router links

`separator` also takes a snippet, drawn inside the same `aria-hidden` span. `link` renders the anchor of every non-current item that has an `href`, so a client router link replaces the plain `<a>`; the last item stays the `aria-current="page"` text.

```svelte
<script>
  import { Breadcrumb } from "@codeatlasdev/ui";
  import { ChevronRight } from "lucide-svelte";
  import { Link } from "my-router";
</script>

{#snippet chevron()}<ChevronRight size={14} />{/snippet}
{#snippet routerLink(item)}<Link to={item.href}>{item.label}</Link>{/snippet}

<Breadcrumb items={[{ label: "Projects", href: "/projects" }, { label: "Atlas" }]} separator={chevron} link={routerLink} />
```

The type and the link focus radius are tokens on the `nav` or any ancestor, so no selector against `.ca-breadcrumb__*` is needed:

```css
.detail-header {
  --ca-breadcrumb-size: 12px;
  --ca-breadcrumb-line-height: 16.8px;
  --ca-breadcrumb-tracking: 0.02em;
  --ca-breadcrumb-link-radius: 4px;
}
```
