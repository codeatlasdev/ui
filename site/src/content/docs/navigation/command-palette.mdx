```svelte
<script>
  import { CommandPalette } from "@codeatlasdev/ui";
  import { goto } from "$app/navigation";
  let open = $state(false);
</script>

<CommandPalette modules={NAV} onNavigate={(path) => goto(path)} bind:open />
```

The palette searches the same `NavModule[]` you pass to [AppShellLayout](/docs/layout/app-shell/), matching on item label and module label. It registers `Cmd+K` and `Ctrl+K` itself on `window`, so mount it once near the root. It opens as a modal dialog layer. Arrow keys move the selection, Enter navigates and Escape closes.
