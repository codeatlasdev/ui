```svelte
<script>
  import { Tabs, TabsList, TabsTrigger, TabsContent } from "@codeatlasdev/ui";
</script>

<Tabs value="overview">
  <TabsList>
    <TabsTrigger value="overview">Overview</TabsTrigger>
    <TabsTrigger value="props">Props</TabsTrigger>
  </TabsList>
  <TabsContent value="overview">...</TabsContent>
  <TabsContent value="props">...</TabsContent>
</Tabs>
```

Arrow keys move between tabs, Home and End jump to the first and last, and the panels use the `tabpanel` role. Each `TabsTrigger` and `TabsContent` pair must share a `value`.
