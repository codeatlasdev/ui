```svelte
<script>
  import { Stepper } from "@codeatlasdev/ui";
  let step = $state(0);
  const steps = [{ label: "Account" }, { label: "Profile" }, { label: "Review" }];
</script>

<Stepper {steps} bind:current={step} />
```

The Stepper shows progress and each step bubble is a button that sets `current` when clicked. It does not render the step content or the Back and Next buttons. Drive `current` from your own form state, as in the demo.
