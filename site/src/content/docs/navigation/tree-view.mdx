title: TreeView

import Props from "~/components/docs/Props.astro";

`TreeView` follows the tree pattern: one Tab stop, arrow keys to move, Right to expand or enter, Left to collapse or go to the parent, Home and End for the ends, Enter or Space to select. A node with `hasChildren` and no `children` loads them through `loadChildren` the first time it opens, with a spinner and `aria-busy` while it waits.

```svelte
<TreeView aria-label="Files" {nodes} bind:selected bind:expanded loadChildren={(node) => api.list(node.id)} />
```

Tokens: `--ca-tree-row-h`, `--ca-tree-indent`. Under a coarse pointer a row is `--ca-touch-target` tall.
