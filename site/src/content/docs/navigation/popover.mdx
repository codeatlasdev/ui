```svelte
<script>
  import { Popover, Button } from "@codeatlasdev/ui";
</script>

<Popover side="bottom" align="start">
  {#snippet triggerChild(props)}<Button {...props}>Open</Button>{/snippet}
  Popover content
</Popover>
```

Escape closes the popover and returns focus to the trigger, and a press outside dismisses it. It is a popover layer in the browser top layer, positioned with CSS anchor positioning where supported, so it stays above a dialog it opens from. Pass an interactive trigger through `triggerChild` and spread the received `props` on it; use `trigger` only for non-interactive content. For a hint that appears on hover, use [Tooltip](/docs/display/tooltip/) instead.

To control it, `bind:open` reads and sets the open state, and `onOpenChange` fires when the user opens or closes it (not when your code sets the value). The `children` snippet receives `close`, which closes the popover and returns focus to the trigger: call it after a choice is made inside, the way [DropdownMenu](/docs/navigation/menu/) closes on selection.

```svelte
<Popover bind:open>
  {#snippet triggerChild(props)}<Button {...props}>Pick a date</Button>{/snippet}
  {#snippet children({ close })}
    <Calendar onchange={() => close()} />
  {/snippet}
</Popover>
```
