```svelte
<script>
  import { Menubar, MenubarMenu, DropdownMenuItem } from "@codeatlasdev/ui";
</script>

<Menubar aria-label="Application">
  <MenubarMenu label="File">
    <DropdownMenuItem onclick={newFile}>New file</DropdownMenuItem>
  </MenubarMenu>
  <MenubarMenu label="Edit">
    <DropdownMenuItem onclick={undo}>Undo</DropdownMenuItem>
  </MenubarMenu>
</Menubar>
```

`Menubar` is the WAI-ARIA menubar pattern for an application or editor: a row of top-level menus, each a [DropdownMenu](/docs/navigation/menu/) whose content is the same items (`DropdownMenuItem`, checkbox and radio items, `DropdownMenuSub`, labels, separators). The bar is one tab stop. Left and Right move between the bar items (Home and End jump, disabled menus are skipped, the ends wrap); Enter, Space or Down open a menu on its first item and Up on its last. Inside an open menu, Right and Left move to the adjacent menu and open it on its first item, except on a submenu trigger, where Right opens the submenu and Left closes it. Escape closes the menu and returns focus to its bar item; Tab closes it and leaves the bar.

With the pointer, a click opens a menu and a second click closes it. Once one menu is open, resting on another bar item switches to it; hover alone never opens a menu. Give the bar an `aria-label`.

A menubar is for actions in a desktop-style application. For a menu on one button use `DropdownMenu`; for site navigation with links use `NavigationMenu`, which is not `role="menu"`.
