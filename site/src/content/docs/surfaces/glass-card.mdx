```svelte
<script>
  import { GlassCard } from "@codeatlasdev/ui";
</script>

<GlassCard title="Overview" headerActions={actions}>…</GlassCard>
```

GlassCard is the primary surface of the library. Padding comes from `--ca-card-padding`; use `flush` for content that touches the edges, such as tables, images and code. Backdrop blur needs something behind the card, which is why the demos sit on a gradient.
