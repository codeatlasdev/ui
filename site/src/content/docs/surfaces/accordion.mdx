```svelte
<script>
  import { Accordion, AccordionItem } from "@codeatlasdev/ui";
</script>

<Accordion type="single">
  <AccordionItem value="a" title="Question">Answer</AccordionItem>
</Accordion>
```

Triggers are buttons with `aria-expanded`, and Arrow, Home and End keys move between them. With `type="single"` the bound `value` is a string, with `type="multiple"` it is a string array.
