```svelte
<Accordion type="single">
  <AccordionItem value="a" title="Question">Answer</AccordionItem>
</Accordion>
```

Triggers are buttons with `aria-expanded`. Arrow Up, Arrow Down, Home and End move focus between the enabled triggers, and every trigger stays in the tab order. With `type="single"` the bound `value` is a string, with `type="multiple"` it is a string array.

## Variants

- `boxed` (default): every item is a bordered, rounded box. Use it on a page body or a plain background.
- `flush`: no border, radius or background and no inline padding, so titles, chevrons and bodies sit on the gutter of the container. Use it inside a panel, drawer or side sheet that is already a surface. Triggers keep a `--ca-touch-target` minimum height. Add `divided` to draw a subtle top border between items.

The trigger only reads `--ca-glass-bg` under the `glass` and `frosted` surface styles.
