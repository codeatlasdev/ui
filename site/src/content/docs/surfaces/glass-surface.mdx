<Callout type="caution" title="Deprecated">
`GlassSurface` is replaced by [Surface](/docs/surfaces/surface/) and removed in the next major version. It still works and looks the same: it renders a Surface, keeps its `glass*` classes, and logs a `[ca-ui]` warning in development.
</Callout>

```sh
bunx @codeatlasdev/ui migrate --write src
```

| GlassSurface | Surface |
|---|---|
| `thickness="ultra-thin"` `"thin"` `"regular"` `"thick"` `"chrome"` | `elevation={1}` `{2}` `{3}` (default) `{4}` `{5}` |
| `tinted` | `tone="brand"` |
| `glowing` | `glow` |
| `refraction` (default `true`) | `material="liquid"`; `refraction={false}` is `material="glass"` |
| `class`, `style`, other attributes | unchanged (use `p` / `as` instead of a padding style) |

Dynamic props (`thickness={t}`) are not rewritten by the codemod: map them by hand with the table above.
