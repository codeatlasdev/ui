Every color is a CSS custom property. Components never hardcode a color, so changing the preset, the scheme or a single token restyles the whole app.

```css
.badge {
  color: var(--ca-brand-text);
  background: color-mix(in oklab, var(--ca-brand-main) 14%, var(--ca-surface-base));
  border: 1px solid var(--ca-outline-default);
}
```

The swatches below read the live tokens, so they follow the theme switcher in the header. Use `--ca-brand-text` for brand-colored text and `--ca-brand-fill` for filled brand surfaces: both are tuned to keep contrast in light and dark.
