```css
}
```

The default shadows are neutral black with no hue: soft in light mode, deeper in dark mode, so one token works in both. The `flat`, `outlined` and similar styles replace them with none or a hairline ring, and the `liquid` recipe uses hue-tinted ones. [Surface](/docs/surfaces/surface/) takes its drop shadow from `elevation` (`--ca-elevation-0` to `--ca-elevation-5`), not from these tokens, see [Materials](/docs/foundation/materials/).
