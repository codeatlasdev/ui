Materials are CSS classes (`glass-ultra-thin`, `glass-thin`, `glass-regular`, `glass-thick`, `glass-chrome`) backed by `backdrop-filter`. [Surface](/docs/surfaces/surface/) applies a material for you from its `material` and `elevation` props, and adds the refraction layer for `material="liquid"`.

```svelte
<script>
  import { Surface } from "@codeatlasdev/ui";
</script>

<Surface material="glass" elevation={4} tone="brand">Content</Surface>
```

The surface style on `<html data-style>` changes every material at once: `solid` (default: no blur, no glow, hairline edges), `flat` (no blur, no shadows), `frosted` (less blur) and `glass` (the opt-in `liquid` look: blur, mesh, glow). Switch it with `colorScheme.setStyle()`, see [Theming](/docs/getting-started/theming/#surface-styles). Browsers with `prefers-reduced-transparency: reduce` automatically get opaque surfaces.
