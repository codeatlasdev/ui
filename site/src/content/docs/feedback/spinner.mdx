```svelte
  import { Spinner } from "@codeatlasdev/ui";
</script>

<Spinner size={24} />
```

The spinner has `role="status"` and a localized `aria-label`. Under `prefers-reduced-motion` it slows down instead of stopping. For buttons, prefer `Button`'s `loading` prop, which swaps the leading icon for a spinner and sets `aria-busy`.
