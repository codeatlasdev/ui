```svelte
  import { InstallPrompt } from "@codeatlasdev/ui";
</script>

<InstallPrompt onchoice={(outcome) => console.log(outcome)} />
```

Render it once, in the root layout. It shows nothing until there is something to offer:

- **Chromium (Android, desktop)**: it keeps the `beforeinstallprompt` event, so the browser's own mini-infobar does not appear, and shows an **Install** button that opens the native dialog. The browser only fires the event when the app is installable: a manifest with `display: "standalone"` and 192 and 512 icons, and a service worker (see [PWA](/docs/getting-started/pwa/)).
- **iOS Safari** (iPhone, and iPad, which reports a Mac user agent): Safari has no install API, so it shows the two steps, Share then Add to Home Screen.
- **Already installed** (`display-mode: standalone`, or `navigator.standalone`): nothing.
- **Dismissed**: nothing for `dismissDays`, remembered in `localStorage`.
