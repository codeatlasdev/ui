```svelte
<script>
  import { Progress } from "@codeatlasdev/ui";
</script>

<Progress value={60} label="Upload progress" />
<Progress indeterminate label="Loading" />
```

Renders `role="progressbar"` with `aria-valuenow`, `aria-valuemin` (always 0) and `aria-valuemax` (from `max`). Always pass `label` so screen readers know what is progressing. The indeterminate state omits `aria-valuenow`.
