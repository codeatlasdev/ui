```svelte
<script>
  import { Drawer, Button } from "@codeatlasdev/ui";
  let open = $state(false);
</script>

<Drawer bind:open title="Filters" side="right" width="360px">
  ...
  {#snippet actions()}<Button onclick={apply}>Apply</Button>{/snippet}
</Drawer>
```

Same architecture as [Dialog](/docs/feedback/dialog/): the overlay blurs the page and the panel is a solid surface that slides in from an edge. For a mobile bottom panel with swipe to dismiss, use [Sheet](/docs/feedback/sheet/).

The panel needs a name. Pass `title` (add `hideTitle` to keep it for screen readers only), or `aria-label`, or `aria-labelledby` with the id of your own heading. Any other attribute (`id`, `data-*`, `style`) reaches the `<dialog>` element.
