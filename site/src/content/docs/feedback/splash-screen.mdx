```svelte
<script>
  import { SplashScreen } from "@codeatlasdev/ui";
</script>

<SplashScreen ready={session.loaded} minDuration={600}>
  {#snippet logo()}<Wordmark />{/snippet}
</SplashScreen>
```

A `role="status"` region named "Loading…". It leaves once `ready` is true **and** it has shown for `minDuration`, so a fast boot never flashes it (`LoadingBoundary` does the same for content). Under `prefers-reduced-motion: reduce` it is skipped: nothing renders and `ondone` fires at once.
