```svelte
<!-- +layout.svelte: mount once -->
<script>
  import { Toaster } from "@codeatlasdev/ui";
</script>
<Toaster />

<!-- anywhere -->
<script>
  import { toast } from "@codeatlasdev/ui";
</script>
<button onclick={() => toast.success("Changes saved.")}>Save</button>
```

`toast` is a global store, so the calls need no component context. The Toaster is a polite live region (`role="region"`, `aria-live="polite"`) and each toast is a `role="status"`. Toasts stack in the bottom right corner. The demo below mounts its own `Toaster` because every demo is an independent island.
