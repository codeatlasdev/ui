Mount `Toaster` once in the root layout:

```svelte
<!-- +layout.svelte -->
<script>
  import { Toaster } from "@codeatlasdev/ui";
  let { children } = $props();
</script>

{@render children()}
<Toaster />
```

Then call `toast` from anywhere:

```svelte
<script>
  import { toast } from "@codeatlasdev/ui";
</script>

<button onclick={() => toast.success("Changes saved.")}>Save</button>
```

`toast` is a global store, so the calls need no component context. The Toaster is a polite live region (`role="region"`, `aria-live="polite"`) and each toast is a `role="status"` (success, info, default) or `role="alert"` (error, warning) with a dismiss button. Toasts stack in the bottom right corner, up to 380px wide, in a fixed container layered with `--ca-z-snackbar` (they are not in the browser top layer, unlike dialogs and popovers). `toast.show` accepts `variant`, `duration`, `id`, `description` and `action` in its options; the shortcut methods take the duration or the same options object (without `variant`) as a second argument.

Calling `toast` with the same variant and message again does not stack a copy: the existing toast restarts its timer and shows a `×N` count, so `toast.error("x")` ten times in a row leaves one toast. At most three toasts show at once and the oldest is dropped past that. Pass `id` to replace one specific toast in place (new text, variant and timer, count back to 1), for example an "Uploading…" toast that becomes "Uploaded". The demo below mounts its own `Toaster` because every demo is an independent island.

Add a secondary line with `description` and one inline button with `action: { label, onClick }`. Clicking the action runs `onClick` and dismisses the toast, and an actionable toast stays 8 seconds unless you pass `duration`. The description is part of the same live-region announcement as the message. The auto-dismiss timer pauses while the toast is hovered or holds focus (WCAG 2.2.1) and restarts with the time that was left; Escape dismisses the toast that has focus. Toasts with an action never merge as repeats, since each carries its own handler.
