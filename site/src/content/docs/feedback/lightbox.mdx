```svelte
<script>
  import { Lightbox } from "@codeatlasdev/ui";

  let open = $state(false);
</script>

<button onclick={() => (open = true)}>View photo</button>
<Lightbox bind:open src={url} alt="Photo sent by Maria" />
```

Pass `items` for a gallery of images and videos; `src` and `alt` are sugar for a single image.

```svelte
<Lightbox bind:open bind:index items={[
  { src: photo, alt: "Beach", caption: "Praia", meta: "Maria, 10:42" },
  { type: "video", src: clip, poster, alt: "Short clip" },
]} ondownload={(item, i) => save(item)} />
```

With more than one item the viewer shows previous and next buttons, a counter, and answers to the ArrowLeft and ArrowRight keys and to a horizontal swipe. It does not wrap: the buttons at either end are `aria-disabled` and keep focus. Arrow keys are left alone while a video has focus so they keep seeking, and a video is paused as soon as you move to another item. The caption and `meta` (sender, time) overlay the bottom edge without changing the media box. A Download button appears for galleries: `ondownload(item, index)` replaces the default `<a download>` to `item.download ?? item.src`, which only works for same-origin or CORS-enabled files.

The media is contained in the viewport and respects the device safe areas. Escape, the close button and a click on the backdrop close it. Because it is a native modal `<dialog>`, the page behind is inert, focus returns to the trigger and scrolling is locked while it is open. `alt` is required.
