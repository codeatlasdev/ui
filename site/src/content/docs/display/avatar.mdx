```svelte
<script>
  import { Avatar } from "@codeatlasdev/ui";
</script>

<Avatar src="/ana.jpg" alt="Ana Lima" size="lg" status="online" />
```

Without `src`, or when the image fails to load, the avatar shows initials derived from `alt` (or `fallback`). `fallback` also takes a snippet, for an icon on groups, channels and bots that have no meaningful initials. The photo is a real `<img>`: pass `loading="lazy"` in long lists and `referrerpolicy="no-referrer"` for CDNs that reject a cross-origin `Referer`; `onerror` fires when it fails so you can refetch a signed URL. The background color is generated from the name, so the same person always gets the same color.
