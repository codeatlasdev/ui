```svelte
</script>

<Heading level={1} size="display">Ship the interface</Heading>
```

`Heading` renders a real `<h1>` to `<h6>` (`level`) and draws it at `size`, so the document outline and the look are decoupled. Without `size` it uses the size of its level.

`size="display"` is the display text role. It reads `--ca-font-display` (the body font until the theme sets `fonts.display`), `--ca-display-tracking`, `--ca-display-leading` and the fluid `--ca-font-size-display-1`. `display-2` and `display-3` are the smaller steps of the same role. Set the knobs once in the theme: `defineTheme({ fonts: { display: "Fraunces, serif" }, typography: { displayTracking: "-0.055em", displayLeading: 0.84 } })`.

Title-bearing components take the same role with a `display` prop: `AuthCard`, `PageShell`, `EmptyState` (title at `--ca-font-size-display-3`) and `SiteHeader` (the current crumb). Without it their titles keep the compact heading look.
