```svelte
<script>
  import { Avatar, ConversationItem } from "@codeatlasdev/ui";
</script>

<ConversationItem title="Maria Souza" time="14:32" preview="Sent it by email." unread={3} active>
  {#snippet avatar()}<Avatar alt="Maria Souza" size="lg" />{/snippet}
</ConversationItem>
```

The whole row is the hit area (at least 44px tall). With `href` it renders a link, otherwise a button. `active` sets `aria-current`; unread rows make the title and time bold; the count is capped at 99+ and announced as "3 unread messages". `typing` replaces the preview.
