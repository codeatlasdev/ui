```svelte
<script>
  import { Image } from "@codeatlasdev/ui";
</script>

<Image src="/hero.avif" alt="Dashboard overview" width={1200} height={630} priority />
```

`width` and `height` are the intrinsic pixel size of the file. The browser derives the aspect ratio from them before the image arrives, so nothing jumps when it loads, and `max-width: 100%` with `height: auto` keeps that ratio on small screens. Images are `loading="lazy"` and `decoding="async"` by default.

Use `priority` on the one image that is the largest thing visible on first paint (the LCP element). It loads eagerly, sets `fetchpriority="high"` and adds a `<link rel="preload" as="image">` to `<head>`. Never put it on more than one image per page.

## Ratio

`ratio` crops the image to a box of that width to height (`16 / 9`, `1`) and fills the width of its container, so a grid of covers or thumbnails shares one shape whatever the files measure. `fit="cover"` (default) crops, `fit="contain"` letterboxes. Without `ratio` the `width` and `height` attributes keep the picture's own shape. For a video, a map or an embed use [`AspectRatio`](/docs/display/aspect-ratio/).

For AVIF and WebP generation at build time see [Performance](/docs/getting-started/performance/#images).

## Alt text

`alt` is required. An image that carries no meaning passes `decorative` instead of `alt=""`; it renders `alt=""` with `aria-hidden="true"`. In development the component warns when `alt=""` is passed without `decorative`, when `width` or `height` is missing, and when `decorative` is combined with a non-empty `alt`.

Other `<img>` attributes are forwarded as they are. `srcset` and `sizes` are the ones you will use most: `srcset` lists the candidate renditions and `sizes` tells the browser the rendered width. With `priority`, both are copied onto the preload link in `<head>`. `fetchpriority` is controlled by `priority`.
