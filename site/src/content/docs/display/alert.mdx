```svelte
<script>
  import { Alert } from "@codeatlasdev/ui";
</script>

<Alert severity="success" title="Saved">Your changes were saved.</Alert>
```

The parent owns visibility: render the alert conditionally and hide it from `onclose`. The root has `role="alert"` with `aria-live="polite"`, so assistive technology announces it.
