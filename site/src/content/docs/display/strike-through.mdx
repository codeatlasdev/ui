`StrikeThrough` renders a native `<del>`, so assistive technology announces the text as deleted. The line is a slightly tilted pen stroke; with `animated` it draws left to right once on mount with `--ca-ease-out-quart`. Under `prefers-reduced-motion: reduce`, or `--ca-motion-scale: 0`, it is drawn complete with no animation. The color is `--ca-strike-color` (the error color by default). Under forced colors it falls back to the native `line-through`. Pair it with [Highlight](/docs/display/highlight/) for a rewrite effect.
