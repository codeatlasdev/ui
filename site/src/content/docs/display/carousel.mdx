The replacement for shadcn `Carousel` (Embla). The strip is native `scroll-snap`, so touch, trackpad and the browser's own scrolling work with no pointer code; the buttons and dots only move it, and a scroll by touch updates the dots. No JavaScript carousel engine, nothing to install.

## Accessibility

It follows the WAI-ARIA carousel pattern. The carousel is a labelled `role="region"` with `aria-roledescription="carousel"`; each slide is a `role="group"` named "2 of 4". Slides outside the view are `inert`, so their links and buttons leave the tab order and the reading order. The dots are labelled buttons with `aria-current` on the current one (the slides are not tab panels, so they are not a tablist). The slide strip is the one tab stop (it scrolls, so it must be reachable without a pointer, even when no slide holds a control). With it focused, Left and Right (mirrored in RTL), Home and End move the slides.

## Autoplay behavior

Off unless you set `autoplay` (milliseconds). When on, a Pause / Start button appears, rotation stops while focus or the pointer is inside, and the strip is `aria-live="off"` while it rotates (a rotating live region would read every slide) and `polite` once it stops. A manual move stops it for good. Under `prefers-reduced-motion: reduce` it never runs, the button is not shown and scrolling is instant. Without `loop` it stops on the last slide.
