```svelte
<script>
  import { SimpleTable } from "@codeatlasdev/ui";
</script>

<SimpleTable responsive="cards">
  <thead>…</thead>
  <tbody>…</tbody>
</SimpleTable>
```

SimpleTable styles plain `thead` and `tbody` markup. For search, sorting and pagination use [DataTable](/docs/display/data-table/). In `cards` mode the header row stays available to screen readers.
