```svelte
<script>
  import { SimpleTable } from "@codeatlasdev/ui";

<SimpleTable responsive="cards">
  <thead>…</thead>
  <tbody>…</tbody>
</SimpleTable>
```

SimpleTable styles plain `thead` and `tbody` markup inside a focusable, horizontally scrolling region. For search, sorting and pagination use [DataTable](/docs/display/data-table/). It is exported from `@codeatlasdev/ui`. `@codeatlasdev/ui/table` also exports a `Table`, a bordered wrapper around a plain `<table>` that forwards native table attributes.

## Dense records screens

For a CRM-style list (thousands of rows, ~10 columns) set `density="compact"` (rows up to 40px), `frame={false}` when the table sits in a framed panel, and `scroll="none"` when the page or panel is the scroller so the sticky header keeps working. `stickyColumns={n}` pins the first `n` columns (checkbox, primary column); their background follows hover, selected and focus states and is never transparent. `headerCase="sentence"` drops the uppercase micro labels.

- `TableRow`: `selected` sets `aria-selected`; `onactivate` makes the row reachable by Tab and activates it on click, Enter and Space with an inset focus ring. Events from a checkbox, button, link, menu or input inside the row never activate it (add `data-row-ignore` to any other element that must not).
- `TableGroupRow`: a section row that spans `colspan` columns. With `collapsible` its label is a button with `aria-expanded` bound to `open`; render the group's rows under `{#if open}`. The label stays pinned to the left while the table scrolls.
- `TableSortHeader`: a sentence-case sortable `th` with a direction icon. Pass the column's `sort` (`'none' | 'asc' | 'desc'`, which sets `aria-sort`) and an `onsort` handler; you own the sort state.
