```svelte
</script>

<MediaGrid items={[{ src: "/a.jpg", alt: "Beach" }, { type: "video", src: "/b.mp4", thumb: "/b.jpg", duration: "0:12" }]} />
```

Tiles keep their box while the thumbnail loads (a skeleton shows meanwhile) and show an error state if it fails. Past `maxVisible` the last tile reads "+N more" and opens the gallery at that index. Images and videos open a [Lightbox](/docs/feedback/lightbox/) with previous and next; documents are plain download links and stay out of the gallery.
