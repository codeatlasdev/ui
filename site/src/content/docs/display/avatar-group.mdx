
Overlapping avatars from `items`, or your own [`Avatar`](/docs/display/avatar/) children (give them the same `size`; `max` counts `items` only). `max` draws that many and turns the rest into one `+N` chip. The group is `role="group"` named by `label` (default "Avatars" / "Avatares"); each avatar is an image named after the person, and the chip is an image named "2 more" / "mais 2", so a screen reader hears who is shown and how many are not. `moreLabel={(n) => ...}` replaces that name.

## Tokens

`--ca-avatar-group-overlap` sets how far each avatar slides under the previous one (default 20% of the size). `--ca-avatar-group-ring` is the colour of the 2px ring that separates them (default `--ca-bg-body`): set it to the surface the group sits on, for instance `--ca-surface-raised` inside a card.
