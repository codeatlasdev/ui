`Kanban` is the board around [`useDnd`](/docs/foundation/drag-and-drop/): you pass columns of cards and apply `onmove` to your data; the component owns the layout, the drag, the keyboard map and the touch alternative. Give it a parent with a height (a flex child or `height`), because every column list scrolls on its own.

## Drops

By default a column is the drop target as a whole (`drop="container"`): it is highlighted, no insertion line is drawn and `to.index` is always `0`. That is right for columns the server orders (newest first), where dropping "between cards" would mean nothing. Set `drop="position"` to let the card land between cards; the line appears and `to.index` is the position.

## Moving cards

| Input | How it works |
|---|---|
| Mouse and pen | Press a card and move 4px. The empty board background pans sideways; a vertical wheel over the gaps scrolls the board sideways; trackpad `deltaX` stays native. |
| Touch | Press and hold, then drag. Near the left or right edge the board scrolls, faster the closer you are. |
| Keyboard | Focus a card, Space lifts it, Left and Right move it to the same index of the neighbouring column (an empty column receives it), Up, Down, Home and End move inside a column (with `drop="position"`), Enter drops, Escape cancels. Every step is announced. |
| Menu | Every card has a "Move to…" button that opens a menu of the other columns. It is the touch and screen reader alternative to dragging and announces the result. |

## Loading more

A column with `hasMore` fires `onloadmore(columnId)` when its list scrolls within `nearEnd` pixels of the end (once per page: it waits until the item count changes) and shows a "Load more (N)" button, where N is `total - items.length`. Set `loadingMore` on the column while the page loads to show skeleton cards, and `loading` for the first page.

## Mobile

Below 600px of its own width (or with `compact`) the board shows one column at a time. A `role="tablist"` strip with a colour dot, the label and the count selects the column (arrow keys move between tabs; every tab is 44px tall), and the board never scrolls sideways. The "Move to…" menu replaces dragging between columns.
