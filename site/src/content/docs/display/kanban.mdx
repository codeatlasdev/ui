`Kanban` is the board around [`useDnd`](/docs/foundation/drag-and-drop/): you pass columns of cards and apply `onmove` to your data; the component owns the layout, the drag, the keyboard map and the touch alternative. Give it a parent with a height (a flex child or `height`), because every column list scrolls on its own. A plain wrapper with a scoped class is enough, no `:global` needed:

## Column summary

Pass a `summary` snippet to show an aggregate (a money total, a weight, hours) after each column's count. The colour rail, title and count stay; `header` is for replacing the whole row and drops all three. The snippet receives the column, so compute from `column.items`; for a server-paged column (`total` larger than the loaded items) send the aggregate with the column data instead. On the mobile tab layout the summary shows as a row above the active column's cards.

## Drops

By default a column is the drop target as a whole (`drop="container"`): it is highlighted, no insertion line is drawn and `to.index` is always `0`. That is right for columns the server orders (newest first), where dropping "between cards" would mean nothing. Set `drop="position"` to let the card land between cards; the line appears and `to.index` is the position.

## Moving cards

| Input | How it works |
|---|---|
| Mouse and pen | Press a card and move 4px. The empty board background pans sideways; a vertical wheel over the gaps scrolls the board sideways; a trackpad swipe, Shift+wheel or horizontal wheel pans the board from anywhere, over a card list included (only vertical scrolling is contained in a list). |
| Touch | Press and hold, then drag, or drag the grip (`dragHandle`) at once. Near the left or right edge the board scrolls, faster the closer you are. |
| Keyboard | Focus a card: Up and Down move focus between the cards of a column, Left and Right to the same position (clamped) in the neighbouring column. Space lifts it, Left and Right move it to the same index of the neighbouring column (an empty column receives it), Up, Down, Home and End move inside a column (with `drop="position"`), Enter drops, Escape cancels. Every step is announced. |
| Menu | Every card has a "Move to…" button that opens a menu of the other columns. It is the touch and screen reader alternative to dragging and announces the result. |

## Frameless and dense boards

`variant="flat"` removes the column panel (its border and tint) and `cardChrome="none"` removes the card's own box, so the `card` snippet draws all of the chrome. Two tokens size the board, set them on the board or any ancestor: `--ca-kanban-col-width` (default `clamp(15rem, 22vw, 20rem)`) and `--ca-kanban-gap` (default `var(--ca-space-3)`).

```svelte
<div style="--ca-kanban-col-width: 13rem; --ca-kanban-gap: 0">
  <Kanban {columns} getId={(c) => c.id} variant="flat" cardChrome="none" {card} />
</div>
```

## Cards that are links

``cardHref={(card) => `/leads/${card.id}`}`` renders the card body as an `<a href>` instead of `div[role=button]`, so a card that navigates has no nested interactive control (axe `nested-interactive`). Enter follows the link and Space lifts the card; the "Move to…" menu stays.

## Hooks for tests and automation

Every column is `[data-kanban-column="<column id>"]` and every card `[data-card-id="<card id>"]`; both are stable and documented, so an end-to-end test needs no selector on `.ca-kanban*` classes.

## Loading more

A column with `hasMore` fires `onloadmore(columnId)` when its list scrolls within `nearEnd` pixels of the end (once per page: it waits until the item count changes) and shows a "Load more (N)" button, where N is `total - items.length`. Set `loadingMore` on the column while the page loads to show skeleton cards, and `loading` for the first page.

## Heading level

Each column title is a heading, `<h2>` by default (inside a `PageShell` it follows the page's section level), so a board under the page `<h1>` keeps the heading order for axe and screen readers. Pass `headingLevel={3}` when the board sits under an `<h2>` of its own. Only the tag changes, never the look. A custom `header` snippet replaces the title row, so you choose its tag; the mobile tab layout renders no column headings.

## Mobile

Below 600px of its own width (or with `compact`) the board shows one stage per screen. The stages are one horizontal swipe track (`scroll-snap`, one column per screen): swiping changes the stage and the `role="tablist"` strip (colour dot, label, count, 44px tall, arrow keys) follows it; a tab press scrolls the track. Holding a card near the left or right edge scrolls to the neighbouring stage, so a drag can end in another stage without the menu. `swipeStages={false}` goes back to one visible column at a time with the tabs as the only way to change stage. The "Move to…" menu is always there as the non-drag path.

Touch drags start with a press and hold (350 ms) so the page still scrolls. `dragHandle` adds a grip to each card that starts a drag at once: `auto` (default) shows it under `pointer: coarse`, `always` shows it everywhere, `none` leaves the press and hold alone. On a desktop board `snap="columns"` makes a swipe on a touch laptop or tablet land on a column edge.

## Recipe: a deals board page

The pipeline screen of a CRM: a `PageShell` with the title, a deal count and the primary action, around a `Kanban` with one money total per column. Copy it whole and change the data, the copy and the stage names. The board needs a parent with a height (`.board` below), and on a phone it becomes one stage per screen with the tab strip, so nothing else is needed for 390px.

```ts
// src/lib/messages.ts (the keys the deals page reads)
export const m = {
  deals: {
    title: "Deals",
    description: "Drag a deal to the next stage.",
    add: "New deal",
    board: "Deals pipeline",
    stages: { new: "New", talking: "Talking", won: "Won" },
  },
} as const;
```

```svelte
<!-- src/routes/(app)/deals/+page.svelte -->
<script lang="ts">
  import { Button, Kanban, PageShell, type KanbanColumn, type KanbanMove } from "@codeatlasdev/ui";
  import { m } from "#lib/messages.ts";
  import { Plus } from "@lucide/svelte";

  type Deal = { id: string; name: string; company: string; value: number };

  let columns = $state<KanbanColumn<Deal>[]>([
    { id: "new", label: m.deals.stages.new, color: "var(--ca-info-main)", items: [] },
    { id: "talking", label: m.deals.stages.talking, color: "var(--ca-warning-main)", items: [] },
    { id: "won", label: m.deals.stages.won, color: "var(--ca-success-main)", items: [] },
  ]);

  const money = new Intl.NumberFormat("en-US", { style: "currency", currency: "USD", maximumFractionDigits: 0 });
  const sum = (c: KanbanColumn<Deal>) => money.format(c.items.reduce((acc, d) => acc + d.value, 0));
  const count = $derived(columns.reduce((n, c) => n + c.items.length, 0));

  // The server orders each column newest first: a drop never picks a position.
  function onmove({ card, from, to }: KanbanMove<Deal>) {
    const src = columns.find((c) => c.id === from.column);
    const dst = columns.find((c) => c.id === to.column);
    if (!src || !dst) return;
    src.items = src.items.filter((d) => d.id !== card.id);
    dst.items = [card, ...dst.items];
    // persist the move here; put the old columns back when it fails
  }
</script>

<svelte:head><title>{m.deals.title}</title></svelte:head>

<PageShell title={m.deals.title} description={m.deals.description} {count}>
  {#snippet actions()}
    <Button variant="filled" size="sm" href="/deals/new">
      {#snippet leading()}<Plus size={14} />{/snippet}
      {m.deals.add}
    </Button>
  {/snippet}

  <div class="board">
    <Kanban {columns} getId={(d) => d.id} label={m.deals.board} {onmove}>
      {#snippet card(deal)}
        <strong class="name">{deal.name}</strong>
        <span class="meta">{deal.company}</span>
        <span class="meta">{money.format(deal.value)}</span>
      {/snippet}
      {#snippet summary(column)}{sum(column)}{/snippet}
    </Kanban>
  </div>
</PageShell>

<style>
  .board { display: flex; height: calc(var(--ca-vh) - 14rem); min-height: 20rem; }
  .name { display: block; font-size: var(--ca-font-size-body2); color: var(--ca-text-primary); }
  .meta { display: block; font-size: var(--ca-font-size-caption); color: var(--ca-text-secondary); font-variant-numeric: tabular-nums; }
</style>
```
