```svelte
<script>
  import { Chip, StatusChip } from "@codeatlasdev/ui";
</script>

<Chip label="Design" variant="brand" deletable ondelete={remove} />
<StatusChip status="success" label="Active" />
```

A chip becomes a keyboard-focusable toggle button when `onclick` is set: Enter and Space activate it and `aria-pressed` follows `selected`. `StatusChip` is a separate, non-interactive component for dot + label statuses.
