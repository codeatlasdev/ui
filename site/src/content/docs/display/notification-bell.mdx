```svelte
<script>
  import { NotificationBell } from "@codeatlasdev/ui";
</script>

<NotificationBell notifications={items} onRead={markRead} onReadAll={markAll} onClear={clear} />
```

The unread count defaults to the number of `notifications` where `read` is falsy. Pass `count` to show an independent unread total, including zero, while loading only part of the list. Update your list in `onRead`, `onReadAll` and `onClear`. Every visible string can be replaced through `labels`. The panel is a popover layer, by default below the bell and aligned to its end edge (`side`, `align`, `sideOffset`), and closes on Escape or an outside press. Escape returns focus to the trigger.

Use `bind:open` to enable your list query only while the panel is open, and refresh `count` independently in the background. `onOpenChange` runs when the user opens or closes the panel; assigning `open` from code does not call it. Count changes update the trigger's accessible name and are announced politely.

```svelte
<script>
  import { NotificationBell } from "@codeatlasdev/ui";

  let open = $state(false);
</script>

<NotificationBell
  bind:open
  count={unread}
  notifications={items}
  loading={list.isFetching}
  onOpenChange={(isOpen) => isOpen && refresh()}
/>
```

While `loading` is true, the panel shows loading text instead of the empty state. Any loaded notifications remain visible during a refresh.

## Placement and width

`side`, `align` and `sideOffset` place the panel; it flips and shifts to stay in the viewport. A bell at the bottom of a left rail uses `side="right" align="end"`; one in a bottom sheet uses `side="top"`. `width` takes any CSS length (or set `--ca-notif-width`); the panel is never wider than the viewport.

```svelte
<NotificationBell side="right" align="end" width="380px" notifications={items} />
```

## Rows

A notification can carry `href` and `icon`. With `href` the row is a link and a separate "mark as read" button (shown for unread items when `onRead` is set) marks it; without `href` the whole row is the action, as before. `icon` (a lucide component) replaces the unread dot and is tinted by `variant`. Long bodies wrap up to four lines (`--ca-notif-body-lines`). To own the row, pass an `item` snippet: `{#snippet item(n, { close, markRead })}`; it replaces the default row entirely.

## States and header

`loading` shows the loading text; `error={{ onRetry, message? }}` shows an alert with a retry button above any loaded rows (`loading` wins while true); `emptyContent` replaces the empty string. "Clear" shows only when `onClear` is passed. Header actions are small `Button`s. `max` (default 99) caps the badge text as `max+`; the accessible name keeps the real count.
