```svelte
<script>
  import { NotificationBell } from "@codeatlasdev/ui";
</script>

<NotificationBell notifications={items} onRead={markRead} onReadAll={markAll} onClear={clear} />
```

The unread count defaults to the number of `notifications` where `read` is falsy. Pass `count` to show an independent unread total, including zero, while loading only part of the list. Update your list in `onRead`, `onReadAll` and `onClear`. Every visible string can be replaced through `labels`. The panel is a popover layer anchored below the bell, aligned to its end edge, and closes on Escape or an outside press. Escape returns focus to the trigger.

Use `bind:open` to enable your list query only while the panel is open, and refresh `count` independently in the background. `onOpenChange` runs when the user opens or closes the panel; assigning `open` from code does not call it. Count changes update the trigger's accessible name and are announced politely.

```svelte
<script>
  import { NotificationBell } from "@codeatlasdev/ui";

  let open = $state(false);
</script>

<NotificationBell
  bind:open
  count={unread}
  notifications={items}
  loading={list.isFetching}
  onOpenChange={(isOpen) => isOpen && refresh()}
/>
```

While `loading` is true, the panel shows loading text instead of the empty state. Any loaded notifications remain visible during a refresh.
