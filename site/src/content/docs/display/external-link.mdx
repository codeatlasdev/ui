```svelte
<script>
  import { ExternalLink } from "@codeatlasdev/ui";
</script>

<ExternalLink href="https://registrar.example/buy?d=atlas.dev">Buy at registrar</ExternalLink>
```

`ExternalLink` always sets `target="_blank"` with `rel="noopener noreferrer"`, draws a trailing arrow icon (hidden from assistive technology) and appends a visually hidden "(opens in a new tab)" to the accessible name. The hint comes from the i18n catalog (`externalLink.newTab`), so it follows `setLocale`. Without it a screen reader user gets no warning that the link leaves the page.

A results table with a per-row external link needs nothing more than putting it in a cell. For links that look like buttons, use `Button` with `href` and `target="_blank"`; it already sets `rel`.
