```svelte
</script>

<ScrollArea maxHeight="240px">…</ScrollArea>
```

The area scrolls once its content exceeds `maxHeight` or `maxWidth`, so set one of them (or a height through `class`). Native scrolling, touch momentum and keyboard scrolling are preserved.
