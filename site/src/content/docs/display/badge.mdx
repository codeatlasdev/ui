```svelte
<script>
  import { Badge, IconButton } from "@codeatlasdev/ui";
</script>

<Badge count={3}><IconButton aria-label="Messages">…</IconButton></Badge>
```

Badge wraps its child and positions the indicator on the corner. Pass `count` for a number (hidden at 0, capped at `99+`) or `dot` for a plain status dot. The indicator is a `role="status"` element labelled "New" (dot) or "N notifications" (count) from the i18n catalog; still give the wrapped control its own accessible name.

**Status pill in a text row: `tone`.** `<Badge tone="danger" subtle dot size="md">Overdue</Badge>` renders an inline pill in text flow (its children are the label) instead of a corner indicator: 24px high at `md` (20px at `sm`), a 6px dot with `dot`, and with `subtle` a translucent tinted background whose label clears 4.5:1 in light and dark. Tones: `brand`, `success`, `danger`, `warning`, `info`, `neutral`. The dot is decorative: the label carries the meaning, so never rely on colour alone. Do not write a `.overdue` class with `color-mix` and a `.dot` span. For a status with a fixed vocabulary and no dot, `StatusChip` is still fine.
