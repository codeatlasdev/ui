```svelte
<script>
  import { Badge, IconButton } from "@codeatlasdev/ui";
</script>

<Badge count={3}><IconButton aria-label="Messages">…</IconButton></Badge>
```

Badge wraps its child and positions the indicator on the corner. Pass `count` for a number (hidden at 0, capped at `99+`) or `dot` for a plain status dot. The indicator is a `role="status"` element labelled "New" (dot) or "N notifications" (count) from the i18n catalog; still give the wrapped control its own accessible name.
