```svelte
<script>
  import { VirtualList } from "@codeatlasdev/ui";
</script>

<VirtualList {items} getKey={(m) => m.id} label="Conversation" {hasMore} loadingMore={loading} onloadmore={loadOlder}>
  {#snippet item(m)}<Message {m} />{/snippet}
</VirtualList>
```

Only the rows in view (plus `overscan`) are in the DOM; row heights are measured, so they can vary. Prepending older rows keeps the row you were reading in the same place: the list finds the previous first row by `getKey` and corrects `scrollTop`. `LiveList` follows the bottom but cannot prepend history without a jump; this one can, and also follows new rows while you are at the bottom. A visible "Load older messages" button gives keyboard and screen reader users the same trigger as scrolling.
