```svelte
</script>

<AudioPlayer src="/voice/42.ogg" peaks={peaks} duration={31} />
```

The native `<audio controls>` is unstyled and differs in dark mode and on iOS. This player keeps the `<audio>` element but draws its own controls. The `src` is attached on the first play (`preload="none"`), so a thread with fifty voice notes makes no request until you press play; pass `duration` so the UI is complete before that. The waveform is a `role="slider"`: drag or click to seek, Arrow keys move 5 seconds, Page Up and Page Down 10, Home and End jump. Starting one player pauses any other.
