```svelte
<script>
  import { MessageBubble } from "@codeatlasdev/ui";
</script>

<MessageBubble direction="out" time="14:32" status="delivered">Sent it by email.</MessageBubble>
```

`direction` picks the side and colors (`out` uses the brand fill). Consecutive messages from one person use `grouped`: `first`, `middle` and `last` flatten the joined corners, and only `single` and `last` keep the tail and show the `avatar` slot (the other positions reserve its width so the column stays aligned). The delivery ticks are decorative; the state is also written as visually hidden text after the time, so a screen reader hears "14:32, Delivered" once. The bubble has no live region: the list that appends messages decides what is announced.

`status="failed"` shows a warning chip in the error colour and the visually hidden text "Not sent" (localized in en and pt-BR). Pass `onretry` to add a "Retry" button after it (a real `<button>`, keyboard reachable); the `retry` snippet replaces its label. Pass `onquoteclick` to turn the quote into a real button for jumping to the quoted message: its accessible name is "Go to the quoted message." followed by the quote text, or `quoteLabel` when you set it. Without `onquoteclick` the quote stays a plain block.
