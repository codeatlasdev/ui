```svelte
<script>
  import { PasswordStrength, TextField } from "@codeatlasdev/ui";
  let password = $state("");
</script>

<TextField label="Password" type="password" bind:value={password} />
<PasswordStrength value={password} />
```

The label ("Weak", "Fair", "Strong", from the i18n catalog) is a polite live region; the bar is decoration, so colour is never the only signal. A hint, not a policy: enforce rules on the server. `passwordScore(value)` is the pure function behind it (0 empty to 3 strong); pass `score` for your own rule.
