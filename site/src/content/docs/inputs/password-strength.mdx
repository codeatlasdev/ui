```svelte
  import { PasswordStrength, TextField } from "@codeatlasdev/ui";
  let password = $state("");
</script>

<TextField label="Password" type="password" bind:value={password} />
<PasswordStrength value={password} />
```

The label ("Weak", "Fair", "Strong", from the i18n catalog) is a polite live region; the bar is decoration, so colour is never the only signal. A hint, not a policy: enforce rules on the server. `passwordScore(value)` is the pure function behind it (0 empty to 3 strong); pass `score` for your own rule.

### Inline and hidden while empty

`layout="inline"` puts the bar (it flexes) and the label on one row, 12px apart; `hideWhenEmpty` draws nothing until the first character. The label stays mounted as a polite live region (collapsed, not `display: none`), so the first strength after typing starts is still announced. Tune it with tokens, never with a selector on `.ca-pwstrength*`: `--ca-pwstrength-gap`, `--ca-pwstrength-empty-bg`, `--ca-pwstrength-label-leading`, `--ca-pwstrength-label-tracking`, or `components.passwordStrength` in the theme.

```svelte
<PasswordStrength value={password} layout="inline" hideWhenEmpty />
```
