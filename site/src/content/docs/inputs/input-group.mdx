`InputGroup` joins one field (`TextField`, `Select` or `NumberField`) with `Button` or `IconButton` members: a single row, aligned to the field box, inner corners squared and one border between neighbours. It is a `role="group"` and needs a name.

```svelte
<InputGroup aria-label="Invite a teammate">
  <TextField label="Email" type="email" bind:value={email} />
  <Button variant="filled" onclick={invite}>Send invite</Button>
</InputGroup>
```

Put a field's hint or error message outside the group: text below the field box would shift the alignment. For a button inside the field box itself (a "copy" or "show" action), use `TextField`'s `prefix` / `suffix` addons.
