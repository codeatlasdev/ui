Each star is a native radio in a labelled group, so arrow keys move by one step, Home and End jump to the ends, and the value is part of the form under `name`. `step={0.5}` adds half steps. `readonly` draws the value as one image whose name says it ("Average: 4.5 of 5 stars"), with no inputs.

<Demo title="Rating" description="Editable whole and half steps, and a read-only average." src={DefaultSrc}><Default client:visible /></Demo>

Tokens: `--ca-rating-size`, `--ca-rating-color` (default `--ca-semantic-warning`), `--ca-rating-empty`. Under a coarse pointer a whole star is `--ca-touch-target` wide.
