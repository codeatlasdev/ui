```svelte
<script>
  import { RadioGroup } from "@codeatlasdev/ui";
  let plan = $state("pro");
</script>

<RadioGroup items={[{ value: "free", label: "Free" }, { value: "pro", label: "Pro" }]} bind:value={plan} />
```

Arrow keys move focus and selection inside the group, Tab leaves it. The group has no visible title of its own, so wrap it in a `fieldset` with a `legend` when the choice needs a heading.
