```svelte
<script>
  import { RadioGroup } from "@codeatlasdev/ui";
  let plan = $state("pro");
</script>

<RadioGroup items={[{ value: "free", label: "Free" }, { value: "pro", label: "Pro" }]} bind:value={plan} />
```

The options are native radio inputs that share one `name`, so arrow keys move focus and selection inside the group and Tab leaves it. The group has no visible title of its own: pass `aria-label`, or wrap it in a `fieldset` with a `legend` when the choice needs a visible heading.
