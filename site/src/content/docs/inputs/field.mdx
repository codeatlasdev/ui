The library's fields (`TextField`, `Select`, `Combobox`…) wire their own label, hint and error. Use these for a control the library does not ship: a third-party picker, a native element with custom styling, your own widget.

`Field` passes the wiring to its child: spread it onto the element that takes the value, and the control gets its accessible name from `label`, its description from `description` and `error`, and `aria-invalid` / `aria-required`.

```svelte
<Field label="Plan code" description="Six letters." error={errors.code} required>
  {#snippet children(control)}<CodeInput {...control} bind:value={code} />{/snippet}
</Field>
```

`Fieldset` names a group of controls with a `<legend>`; `disabled` disables every control inside it. `Label` is the field label alone, for a layout `Field` does not fit.
