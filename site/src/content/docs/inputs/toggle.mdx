```svelte
<script>
  import { Bold } from "@lucide/svelte";
  import { Toggle } from "@codeatlasdev/ui";
  let bold = $state(false);
</script>

<Toggle icon={Bold} aria-label="Bold" bind:pressed={bold} />
```

A `Toggle` is a `<button type="button">` with `aria-pressed`, so a screen reader announces "Bold, toggle button, pressed". Space and Enter flip it. It uses the item styles of [ToggleGroup](/docs/inputs/toggle-group/) (`toggle-group.css`), so a `Toggle` and a group item look the same in both variants and both sizes. Use a `Toggle` for one independent on/off control (bold, pin, mute); use a `ToggleGroup` when several belong together, and [Switch](/docs/inputs/switch/) or [Checkbox](/docs/inputs/checkbox/) for a setting that is submitted with a form.

An icon-only toggle has no text to name it: pass `aria-label`. Without a `label`, `children` or an accessible name, development builds print a warning. The hit area grows to the touch target under a coarse pointer in both axes. Extra attributes (`id`, `title`, `data-*`, `aria-describedby`) go to the button.
