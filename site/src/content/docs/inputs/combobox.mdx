```svelte
<script>
  import { Combobox } from "@codeatlasdev/ui";
  let value = $state("");
</script>

<Combobox label="Framework" options={[{ value: "svelte", label: "Svelte" }]} bind:value />
```

Typing in the popup filters options by label, and opening the list moves focus to the search input. Pass a `label` (or `ariaLabel`) so the trigger and listbox have an accessible name. It has no `name` prop and does not submit with a native form (unlike `Select`): read `value` instead.

## Multiple selection

Set `multiple` and bind `value` to a `string[]`. The popup becomes a `listbox` with `aria-multiselectable`, each pick toggles its option (`aria-selected`) and the list stays open so you can keep picking. Selected values show as removable chips above the trigger, and the trigger shows the count. With the search input focused, `Enter` toggles the highlighted option and `Backspace` on an empty query removes the last chip.

Add `creatable` to offer a `Create "text"` row when the query matches no option exactly. Choosing it appends the text to `value` and calls `oncreate(text)`: add it to `options` there if you want it to stay selectable. In single mode `creatable` sets `value` to the new text and closes the list.
