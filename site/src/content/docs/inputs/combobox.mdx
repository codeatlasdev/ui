```svelte
<script>
  import { Combobox } from "@codeatlasdev/ui";
  let value = $state("");
</script>

<Combobox label="Framework" options={[{ value: "svelte", label: "Svelte" }]} bind:value />
```

Typing in the popup filters options by label, ignoring case and accents (`sao` finds "São Paulo"), ranks matches at the start of a word first and highlights the matched text. Printable keys always go to the search field. Opening the list moves focus to the search input. Pass a `label` (or `ariaLabel`) so the trigger and listbox have an accessible name. It has no `name` prop and does not submit with a native form (unlike `Select`): read `value` instead.

Spacing, label and hint typography and the typed text come from the shared field tokens (`--ca-field-gap`, `--ca-field-label-leading`, `--ca-field-label-tracking`, `--ca-field-hint-leading`, `--ca-field-hint-tracking`, `--ca-input-letter-spacing`, `--ca-input-line-height`); `--ca-cb-*` (and `components.combobox`) set this component only and win. See [Field tokens](/docs/getting-started/theming/#field-tokens).

## Multiple selection

Set `multiple` and bind `value` to a `string[]`. The popup becomes a `listbox` with `aria-multiselectable`, each pick toggles its option (`aria-selected`) and the list stays open so you can keep picking. Selected values show as removable chips above the trigger, and the trigger keeps the placeholder so it still reads as the place to add more; set `showCount` to show "N selected" there instead. With the search input focused, `Enter` toggles the highlighted option and `Backspace` on an empty query removes the last chip.

Add `creatable` to offer a `Create "text"` row when the query matches no option exactly. Choosing it appends the text to `value` and calls `oncreate(text)`: add it to `options` there if you want it to stay selectable. In single mode `creatable` sets `value` to the new text and closes the list.

## Grouped options

Give options a `group` to render section headers. Options sharing a `group` are gathered under one `role="group"` labelled by its header (placed where the group first appears), the header is never highlighted or reached by the arrow keys, and filtering hides a group that has no match, header included. Options without a `group` render as before.

```svelte
<Combobox label="Field" bind:value options={[
  { value: "name", label: "Name", group: "Contact" },
  { value: "company", label: "Company", group: "Account" },
]} />
```
