```svelte
<script>
  import { ColorField } from "@codeatlasdev/ui";
  let brand = $state("#2b5fd9");
</script>

<ColorField label="Brand color" bind:value={brand} against="#ffffff" role="fill" minRatio={3} />
```

The swatch shows the color, the chip at the end opens the native picker, and the text field accepts `#rgb`, `#rrggbb`, a bare `rrggbb`, `rgb()`, `oklch()` and `color-mix()`. `value` keeps the notation the person typed, so an `oklch()` stays `oklch()`; `format` only decides what the picker writes. An invalid entry shows an error and never reaches `value`.

With `against` the field shows the WCAG contrast ratio and says in words whether it passes (`Passes AA`, `Below 4.5:1`), so the verdict never rests on color alone. Use `role="text"` (default) to measure the color as text on `against`, or `role="fill"` to measure `against` as the label on the color. Translucent colors are composited over the background before measuring, and the verdict follows the real ratio, not the rounded one shown.

The color helpers behind it are public: `parseColorInput`, `contrast`, `wcagLevel`, `toHex`, `toOklch`, `formatOklch`, and `extractPalette` with `pickBrand` for deriving a brand from the pixels of a logo.
