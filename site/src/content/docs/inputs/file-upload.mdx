```svelte
<script>
  import { FileUpload } from "@codeatlasdev/ui";
  let files = $state([]);
</script>

<FileUpload bind:files multiple accept="image/*" maxSize={10 * 1024 * 1024} />
```

The drop zone is a keyboard-operable control: Enter or Space opens the file picker. Files larger than `maxSize` are rejected with a per-file error message. In `multiple` mode new picks are appended to `files`, otherwise they replace it. The component never uploads: send `files` to your API yourself.

Native input attributes (`name`, `capture`, `data-*`...) are spread on the `<input type="file">`, and `bind:ref` gives you that input. To open the picker from a button elsewhere, keep the component instance with `bind:this` and call `open()` (a no-op while `disabled`). For apps that upload on pick and draw their own progress, set `list={false}`: `onchange` receives only the files just picked, nothing is kept in `files`, and the built-in list is not rendered.
