`ExportMenu` is a `DropdownMenu` with CSV and JSON items. Choosing one builds the file from `data`, downloads it and announces "Exported 3 rows as CSV" politely. It is disabled while `data` is empty. Pass all rows, not only the visible page.

CSV is RFC 4180 (CRLF, quoted fields) with a UTF-8 BOM in the downloaded file so Excel reads accents correctly. Text cells that start with `=`, `+`, `-` or `@` get a leading `'` so a spreadsheet never runs them as a formula (CSV injection). Numbers are left as they are.

## Helpers

The same logic is exported for custom UI:

```ts
import { toCsv, toJson, downloadFile } from "@codeatlasdev/ui";

downloadFile("domains.csv", toCsv(rows, columns), "text/csv;charset=utf-8");
```
