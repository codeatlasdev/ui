```svelte
<script>
  import { TextField, useForm } from "@codeatlasdev/ui";

  const form = useForm(
    { email: "" },
    { schema: (data) => (data.email.includes("@") ? {} : { email: "Enter a valid email." }) },
  );
</script>

<TextField
  label="Email"
  value={form.fields.email.value}
  error={form.fields.email.error}
  oninput={(v) => form.set("email", v)}
  onblur={() => form.touch("email")}
/>
```

`useForm` has no dependencies. The `schema` option accepts a plain function that returns an object of field errors, a Zod schema (`safeParse`) or a Valibot schema. Every field value is a string. Errors only appear after a field is touched (on blur) or after `validate()`, and then update on each keystroke.

Pass `arrays` for repeatable row groups, for example `useForm({ name: "" }, { arrays: { phones: [{ number: "" }] } })`, and use `form.arrays.phones.add`, `remove` and `move`.
