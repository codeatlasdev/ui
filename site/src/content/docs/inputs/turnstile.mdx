```svelte
<script>
  import { Turnstile } from "@codeatlasdev/ui/forms";
  let handle = $state();
</script>

<Turnstile siteKey={PUBLIC_TURNSTILE_KEY} action="sign-in" bind:handle />
<!-- submit: handle.getToken(); failed submit: handle.reset() -->
```

It lives in `@codeatlasdev/ui/forms`, adds no dependency and loads Cloudflare's script on demand, once per page (never on the server). It follows the colour scheme and UI language, re-renders when either changes and removes the widget on unmount. Without a `siteKey` it renders and loads nothing and `getToken()` is `undefined`. A token is single-use and only counts once your server verifies it: call `reset()` after a failed submit. Strict CSP: pass `nonce`, allow `challenges.cloudflare.com`.
