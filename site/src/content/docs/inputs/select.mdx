For long lists that need filtering, use [Combobox](/docs/inputs/combobox/). Without a `label`, pass `aria-label` (or `aria-labelledby`) to name the trigger: the accessible name is that text followed by the current value, so it still contains the visible text. With neither, the `placeholder` names it. Arrow keys, Enter and Space open the list from the trigger, and Escape closes it. Pass `name` to submit the selected value with a native form (a hidden input; nothing is sent while no option is selected or the field is disabled). `required` blocks native form submission while nothing is selected. Text inside inputs stays at 16px or more on touch screens, so iOS Safari never zooms on focus.

Spacing, label and hint typography and the typed text come from the shared field tokens (`--ca-field-gap`, `--ca-field-label-leading`, `--ca-field-label-tracking`, `--ca-field-hint-leading`, `--ca-field-hint-tracking`, `--ca-input-letter-spacing`, `--ca-input-line-height`); `--ca-sel-*` (and `components.select`) set this component only and win. See [Field tokens](/docs/getting-started/theming/#field-tokens).

## A different text in the closed trigger

An option's `triggerLabel` is what the closed trigger shows once it is selected; the open list keeps `label`. A "view as" selector lists plain names and reads as a sentence once one is picked:

```svelte
<Select label="View as" bind:value options={[
  { value: "me", label: "My queue" },
  { value: "ana", label: "Ana", triggerLabel: "Queue of Ana" },
]} />
```

## Grouped options

Give options a `group` to render section headers. Consecutive options with the same `group` share one `role="group"` whose `aria-labelledby` is the header; the header is not an option, so arrow keys, Home/End and typeahead never land on it. Options without a `group` render exactly as before.

```svelte
<Select label="Field" bind:value options={[
  { value: "name", label: "Name", group: "Contact" },
  { value: "email", label: "Email", group: "Contact" },
  { value: "company", label: "Company", group: "Account" },
]} />
```
