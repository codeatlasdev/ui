```svelte
<script>
  import { Select } from "@codeatlasdev/ui";
  let value = $state("br");
</script>

<Select label="Country" options={[{ value: "br", label: "Brazil" }]} bind:value />
```

For long lists that need filtering, use [Combobox](/docs/inputs/combobox/). Without a `label` the trigger is named by its `placeholder`. Arrow keys, Enter and Space open the list from the trigger, and Escape closes it. Pass `name` to submit the selected value with a native form (a hidden input; nothing is sent while no option is selected or the field is disabled). `required` blocks native form submission while nothing is selected. Text inside inputs stays at 16px or more on touch screens, so iOS Safari never zooms on focus.
