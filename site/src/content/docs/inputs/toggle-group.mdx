```svelte
<script>
  import { ToggleGroup } from "@codeatlasdev/ui";
  let format = $state(["bold"]);
  const items = [
    { value: "bold", label: "Bold" },
    { value: "italic", label: "Italic" },
  ];
</script>

<ToggleGroup type="multiple" aria-label="Text formatting" bind:value={format} {items} />
```

In `single` mode the user can press the active item again to clear the selection, so `value` can be an empty string. Use [SegmentedControl](/docs/inputs/segmented-control/) when a choice is required. In `single` mode the group is one tab stop and arrow keys move focus (Home and End jump to the ends); in `multiple` mode each item stays in the tab order. Icon-only items need an `aria-label`.
