```svelte
<script>
  import { Slider } from "@codeatlasdev/ui";
  let volume = $state(60);
  let range = $state([20, 75]);
</script>

<Slider bind:value={volume} />
<Slider bind:values={range} />
```

`value` and `values` are independent: bind one or the other. The bare slider has no visible label or value readout: pass `label` so assistive tech hears "Radius" instead of "Value 40", and use [SliderField](/docs/inputs/slider/#sliderfield) when you want the label and an editable number built in. Arrow keys move by `step`, Home and End jump to the bounds.

## SliderField

A labelled slider with an editable number and an optional unit, for settings where people scrub and also type an exact value.

```svelte
<script>
  import { SliderField } from "@codeatlasdev/ui";
  let radius = $state(0.8);
</script>

<SliderField label="Radius" bind:value={radius} min={0} max={2} step={0.05} unit="x" />
```

The slider scrubs, the number field types. Both write the same `value`. A typed value is clamped to the range and snapped to `step` when the field commits (Enter or blur), so `1.234` with `step={0.05}` becomes `1.25`. The label names both controls, and Arrow, Page and Home/End keys work on the slider.
