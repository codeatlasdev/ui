The value sits in a read-only box (`role="textbox"`, `aria-readonly`) named by `label`. One click selects all of it (`user-select: all`), a long token wraps instead of scrolling the page sideways, and the copy button is a [CopyButton](/docs/inputs/copy-button/): it announces `Copied` and reports a failed write as an error, never as a success.

## Show a secret once

There is no separate component: compose an [AlertDialog](/docs/feedback/alert-dialog/) with a masked `CopyField`. AlertDialog has no close button and ignores scrim clicks, and `confirmDisabled` keeps the confirm button off until the user has copied. Escape still closes the dialog, so say in the description that the secret is gone once it closes.
