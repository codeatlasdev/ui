```svelte
<script>
  import { Switch } from "@codeatlasdev/ui";
  let enabled = $state(false);
</script>

<Switch label="Notifications" bind:checked={enabled} />
```

Without a visible `label`, always pass `aria-label` (or `aria-labelledby`) so the switch has an accessible name. The track is 44px wide, so it is comfortable to hit on touch screens.
