```svelte
  let enabled = $state(false);
</script>

<Switch label="Notifications" bind:checked={enabled} />
```

Without a visible `label`, always pass `aria-label` (or `aria-labelledby`) so the switch has an accessible name. The track is 44px wide, so it is comfortable to hit on touch screens. `size="sm"` is the compact 32 x 20 track (14px thumb) for a dense row.

## Geometry and colours from the theme

Set the look once in the theme, no selector against `.ca-switch*` needed. The thumb travels `track-width - thumb - 2 * (padding + border)`, so it stays flush at both ends in both states for any size:

```ts
defineTheme({
  components: {
    switch: {
      trackWidth: "40px", trackHeight: "24px", padding: "2px", borderWidth: "1px", thumbSize: "18px",
      thumbBackground: "var(--ca-brand-contrast)", thumbShadow: "none", onBackground: "var(--ca-brand-fill)",
      sm: { trackWidth: "32px", trackHeight: "20px", thumbSize: "14px" },
    },
  },
});
```

| Token (theme key) | Default |
|---|---|
| `--ca-switch-track-width` (`trackWidth`) | `44px` |
| `--ca-switch-track-height` (`trackHeight`) | `24px` |
| `--ca-switch-padding` (`padding`) | `--ca-space-0-5` |
| `--ca-switch-border-width` (`borderWidth`) | `0px` (`1px` for `size="sm"`) |
| `--ca-switch-border-color` | transparent |
| `--ca-switch-thumb-size` (`thumbSize`) | track height minus twice padding and border |
| `--ca-switch-thumb-bg` (`thumbBackground`) | white |
| `--ca-switch-thumb-shadow` (`thumbShadow`) | `--ca-shadow-sm` |
| `--ca-switch-on-bg` (`onBackground`) | `--ca-state-indicator` |
| `--ca-switch-sm-{track-width,track-height,padding,thumb-size}` (`sm`) | `32px`, `20px`, `--ca-space-0-5`, `14px` |

Keep the contrast of the thumb against both track colours at 3:1 or more when you change them.
