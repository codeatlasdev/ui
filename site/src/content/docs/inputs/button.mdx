```svelte
<script>
  import { Button } from "@codeatlasdev/ui";
</script>

<Button variant="filled" onclick={save}>Save</Button>
```

**Secondary actions use `tone="neutral"`.** One brand `filled` button per card; the actions beside it (Edit, Snooze, Previous, Skip) are `variant="outlined"` or `"ghost"` with `tone="neutral"`: `--ca-text-primary` label (`--ca-text-secondary` for ghost), `--ca-outline-control` border, `--ca-action-hover` / `--ca-action-selected` hover and pressed fills, and the same sizes, loading, disabled and focus ring. Never override `.ca-btn` colours from the app. `IconButton` takes the same `tone` on its `outlined` variant (its `text` variant is already neutral); extra attributes such as `aria-expanded` are forwarded, so both work as `Popover` triggers. Label and border contrast on the raised and overlay surfaces is measured for every preset in `tests/contrast.test.ts`.

On touch devices every size grows to a 44px target and presses scale down slightly, like a native control.

## Tokens

Weight, tracking, line-height, gap, padding and size are component tokens: declare them on `:root`, on a wrapper, or through [`ThemeOptions.components`](/docs/getting-started/theming/#component-tokens). Unset, a button draws exactly what it always did. Never write `.app .ca-btn--lg { font-weight: 400 }`: a size token wins over the all-sizes token, so `--ca-btn-lg-font-weight` changes `lg` only.

| Token | Default | Drives |
|---|---|---|
| `--ca-btn-font-weight` | `--ca-font-weight-medium` (500) | Weight, every size |
| `--ca-btn-letter-spacing` | `--ca-label-tracking` | Tracking, every size |
| `--ca-btn-line-height` | inherited | Line-height (unitless or length) |
| `--ca-btn-gap` | `--ca-space-1-5` | Space between icon and label |
| `--ca-btn-{sm,md,lg}-height` | `--ca-control-height-{sm,*,lg}` | Height |
| `--ca-btn-{sm,md,lg}-padding-x` | `--ca-space-2-5` / `--ca-control-px` / `--ca-space-5` | Horizontal padding |
| `--ca-btn-{sm,md,lg}-font-size` | `--ca-font-size-body2` / `-button` / `-dialog` | Font size |
| `--ca-btn-{sm,md,lg}-font-weight` | `--ca-btn-font-weight` | Weight of one size |
| `--ca-btn-{sm,md,lg}-letter-spacing` | `--ca-btn-letter-spacing` | Tracking of one size |
| `--ca-btn-ghost-border-width` | `--ca-border-width` | `0px` makes a ghost button as wide as a text button |
| `--ca-btn-disabled-bg` | `--ca-action-disabled-bg` | Background of a disabled button (e.g. `var(--ca-brand-fill)`) |
| `--ca-btn-touch-height` | `--ca-touch-target` (44px) | Minimum height under `pointer: coarse` |
| `--ca-icon-btn-size-{sm,md,lg}` | `--ca-space-8` / `-10` / `-12` | `IconButton` width and height |
| `--ca-icon-btn-font-weight` | inherited | `IconButton` weight |
| `--ca-icon-btn-touch-size` | `--ca-touch-target` (44px) | `IconButton` minimum side under `pointer: coarse` |

The 44px touch target stays unless you set `--ca-btn-touch-height` or `--ca-icon-btn-touch-size` yourself.
