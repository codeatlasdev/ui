The result is announced through a polite live region (`Copied`), and a failed copy raises an error toast. For a success toast, pass `toast` and mount a `<Toaster />` once in your layout. An icon-only button (`label=""`) is named from the localized `Copy` label by default. In a list or table every row would then announce the same name, so pass a distinct `aria-label` per row (`aria-label="Copy client_id of Acme"`). Other attributes (`id`, `data-*`, `aria-describedby`) go to the underlying button. Default labels come from the active i18n catalog.
