```svelte
<script>
  import { MaskedField, maskCPF, isValidCPF } from "@codeatlasdev/ui/forms";
  let cpf = $state("");
</script>

<MaskedField
  label="CPF"
  mask={maskCPF}
  validate={(v) => (isValidCPF(v) ? undefined : "Invalid CPF")}
  bind:value={cpf}
/>
```

These components live in the `@codeatlasdev/ui/forms` subpath. A `mask` is a pure function from raw text to formatted text, so you can write your own. `MaskedField` renders a [TextField](/docs/inputs/text-field/) and forwards its props. Digit-only masks set `inputmode="numeric"` automatically.

The package never makes network requests. `CepField` only calls the `onlookup` function you inject (for example a ViaCEP client) once 8 digits are typed.

Documents try these values: CPF `123.456.789-09` is valid and `111.111.111-11` is invalid. Validation runs on blur.
