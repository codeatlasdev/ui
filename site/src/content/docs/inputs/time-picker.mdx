```svelte

  let start = $state(new Time(9, 0));
</script>

<TimePicker label="Opens at" bind:value={start} step={30} />
```

`TimePicker` is a [`TimeField`](/docs/inputs/date-picker/) (type digits or step the segments with the arrows) plus a button that opens a list of times on the same popover shell as `DatePicker`. The value is a `Time` from `@internationalized/date`, re-exported by the package.

The list runs from 00:00 to 23:59 in `step` minutes (default 15). Times before `minValue` or after `maxValue` are disabled. The current value is selected (`aria-selected`) and scrolled into view when the list opens; a typed value that falls between two steps (09:07 with a 15-minute step) is kept in the field and selects nothing in the list.

**Keyboard.** Enter, Space or the arrows on the button open the list with the focus on the chosen time. Up and Down move, Home and End jump to the first and last enabled time, typing a few characters jumps to a match, Enter or Space picks and closes, Escape closes and returns the focus to the button. Disabled times are skipped.

The list is a `role="listbox"` named after the `label`; the button is named by `triggerLabel` (localized). Under a coarse pointer every row is at least `--ca-touch-target` tall. `--ca-tp-max-height` sets the height of the list (default 280px).
