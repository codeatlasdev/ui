```svelte
<script>
  import { Checkbox } from "@codeatlasdev/ui";
  let accepted = $state(false);
</script>

<Checkbox label="I accept the terms" bind:checked={accepted} />
```

A checkbox rendered without `label` (for example in a table row) needs an `aria-label`. Space toggles it. Any other native attribute or handler (`data-*`, `id`, `onclick`, `onkeydown`, `aria-describedby`, `value`...) is forwarded to the native `<input>`, and `ref` gives you that input.
