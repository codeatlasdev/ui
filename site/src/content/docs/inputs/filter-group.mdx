```svelte
<script>
  import { FilterGroup } from "@codeatlasdev/ui";

  let role = $state("all");
</script>

<FilterGroup
  label="Role"
  options={[{ value: "admin", label: "Admin" }, { value: "editor", label: "Editor" }]}
  bind:value={role}
/>
```

An "All" option is added in front of `options` and the value is `'all'` when nothing is filtered. Clicking the active option clears the filter and goes back to `'all'`. Inside [AppList](/docs/layout/list-page/), render it in the `filters` snippet and connect it to `list.setFilter`.
