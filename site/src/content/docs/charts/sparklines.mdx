```svelte
<script>
  import { Sparkline } from "@codeatlasdev/ui/charts";
</script>

<Sparkline data={[42, 51, 58, 63, 72]} trend="up" height="32px" />
```

A sparkline has no axes, legend or tooltip. `trend` picks the color: success for `up`, error for `down` and a neutral tone otherwise.
