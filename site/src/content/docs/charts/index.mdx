```svelte

  import { LineChart } from "@codeatlasdev/ui/charts";
</script>

<LineChart series={[{ name: "Revenue", data: [42, 58, 51, 74] }]} categories={["Jan", "Feb", "Mar", "Apr"]} />
```

Charts live in the `@codeatlasdev/ui/charts` subpath and need the optional peer dependency `echarts` (`bun add echarts`, version 6). Every chart takes data and a few semantic props. There is no style or font prop on purpose: the palette follows the active preset, axes, legend and tooltips read the `--ca-*` tokens, and charts re-theme when the color scheme, preset or surface style changes. Series can take an explicit `color`; use hex or rgb, because ECharts paints on a canvas and cannot parse `oklch()`. Charts render on the client, so hydrate them with `client:visible` in Astro.

|Component|Use for|
|---|---|
|[LineChart](/docs/charts/line/)|Trends over time, areas, live streams|
|[BarChart](/docs/charts/bar/)|Vertical, horizontal, stacked and grouped bars|
|[PieChart](/docs/charts/pie/)|Pie, donut and rose proportions|
|[ScatterChart](/docs/charts/scatter/)|Correlations and bubble sizing|
|[RadarChart](/docs/charts/radar/)|Multi-dimension profiles|
|[GaugeChart](/docs/charts/gauge/)|KPI gauges and progress rings|
|[HeatmapChart](/docs/charts/heatmap/)|Calendar and matrix density|
|[Sparkline](/docs/charts/sparklines/)|Inline micro charts|

All chart components also accept `height` (CSS length, each chart has its own default) and `class`.
