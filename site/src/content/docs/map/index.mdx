```svelte
<script>
  import { MapStage, MapControls, mapColors } from "@codeatlasdev/ui/map";
  import { ScatterplotLayer } from "@deck.gl/layers";

  const layers = $derived.by(() => {
    const c = mapColors(); // reactive: re-runs on scheme or preset change
    return [new ScatterplotLayer({ id: "pins", data, getPosition: (d) => d.xy, getFillColor: c.brand })];
  });
</script>

<MapStage styles={{ light: "…/light.json", dark: "…/dark.json" }} {layers} fit={bounds}>
  <MapControls />
</MapStage>
```

The map lives in the `@codeatlasdev/ui/map` subpath and every engine is an optional peer, so install only what you use: `maplibre-gl` (default, no token) or `mapbox-gl` (`engine="mapbox"` and an `accessToken`), and for data layers `@deck.gl/core` plus `@deck.gl/mapbox`. Pin all `@deck.gl/*` packages to the same minor (`~9.4`): mixing `@luma.gl/core` 9.3 and 9.4 breaks the overlay at install time. Nothing is imported on the server: the engines load inside `onMount`, so `MapStage` and `MapControls` render in SSR (an empty stage with disabled controls) and hydrate on the client. In Astro, use `client:visible`.

`MapStage` keeps the basemap in step with the theme: it passes `styles.light` or `styles.dark` for `colorScheme.resolved` and, when the scheme changes, calls `map.setStyle` on the same map. The camera, the deck.gl overlay and your event handlers survive. The overlay is a `MapboxOverlay` with `interleaved: true`, so layers sit between the basemap's labels like native ones, and replacing the `layers` array updates it. `fit` runs `fitBounds` with `padding`, the pixels your UI covers on each side. Behind a `PageFrame` you pass nothing: each side defaults to `stageInsets.current` and the map fits again when the frame moves. Under `prefers-reduced-motion`, `flyTo` becomes `jumpTo` and `fit` does not animate.

## Colors for deck.gl

deck.gl takes `[r, g, b, a]` and MapLibre paint wants `rgba()`, but the tokens are `oklch()` and `color-mix()`. `tokenColor(token, alpha?)` resolves any token or CSS color through a 1×1 canvas and caches by the resolved value, so a theme change needs no manual cache reset. `mapColors()` returns the semantic set, and reading it inside `$derived` or `$effect` subscribes to the scheme, preset and surface style. `rgbaCss(color)` turns a result into a string for paint properties.
