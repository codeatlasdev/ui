```svelte
</script>

<MobilePane bind:open title="Maria Souza" onback={() => (chatId = null)}>
  <Messages />
</MobilePane>
```

The pane is a modal `<dialog>` in the top layer that covers the viewport, with a header that has a back button. Escape and the back button close it, focus moves into the pane on open and returns to the opener on close, and the body respects safe-area insets and the virtual keyboard. It replaces hand-rolled fixed panels. With the overlay-history bridge mounted, the browser's Back (the Android back button, the iOS edge swipe) closes it too: see [Back button on mobile](/docs/getting-started/mobile/#back-button-on-mobile).
