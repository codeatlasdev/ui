```svelte
<script>
  import { AuthCard, Button, CenteredPage } from "@codeatlasdev/ui";
</script>

<CenteredPage maxWidth="sm">
  {#snippet brand()}<img src="/logo.svg" alt="" width="32" height="32" />{/snippet}
  <AuthCard title="Join Acme" subtitle="Ana invited you to the Design workspace.">
    <Button fullWidth>Accept invite</Button>
  </AuthCard>
</CenteredPage>
```

It renders the skip link and `<main id="main" tabindex="-1">`, so the page has exactly one landmark. The column is `min(100%, maxWidth)` wide and centred both ways inside a `--ca-vh` tall page (the mobile browser chrome does not clip it), with at least `--ca-space-5` of padding on every side and the device's safe area where it is larger (the notch and the home indicator). Content taller than the viewport scrolls the page, not the column. The background is `--ca-surface-base`; `surface="mesh"` lets the style's page paint through.

The library draws no logo: pass the `brand` snippet (linked to `brandHref`, default `/`; give it `brandLabel` when the logo has no text). `mainId={null}` renders neither the `id` nor the skip link, for a page inside another landmark.
