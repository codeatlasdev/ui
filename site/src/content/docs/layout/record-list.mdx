The usual dashboard list is neither a table nor a card per record. `Table` with `responsive="cards"` makes each row three or four times taller on a phone, and a `Card` per record repeats the chrome. `RecordList` owns what every app hand-rolls around that shape: the flush container, the separators, one column template shared by the header and every row, the re-flow below a width, and a 44px actions cell.

`columns` is one `grid-template-columns` value: the identity first, then one track per `RecordCell`. Set `actions` when the rows have an actions slot: the list appends the actions track (`var(--ca-touch-target)`) for the header and every row. Without `actions` on the list, write that track yourself as the last one: `var(--ca-touch-target)`, never `2.75rem`, which is 41px at this library's 15px root and leaves the 44px cell overflowing its track. A list that does it anyway logs one dev warning. `labels` are the column headers of the identity and the cells.

## Wide and stacked

Wide, the header is an `aria-hidden` row and every `RecordCell` keeps its `label` as a visually hidden `dt`, so assistive technology still gets "Scopes: read:invoices" per cell. Below 36rem of the **list's own width** (a container query, not the viewport) the header disappears and the row becomes two lines: identity and actions on the first, the cells below as small label/value pairs that wrap. The same list behaves the same in a narrow card or beside a sidebar, and it needs no JavaScript, so server-rendered pages are correct from the first paint.

With no rows, render your own [empty state](/docs/layout/empty-state/) instead of the list.

## Accessibility

The list is a real `<ul>` with one `<li>` per record: give it an `aria-label`. Per-cell labels are `dt`/`dd` pairs inside a `dl`, so they are announced with their value in both layouts. Put an `aria-label` that names the record on every action button ("Actions for Billing"), because the visible column header is hidden from assistive technology.

## Recipe: a record page

The detail screen of one CRM record (a company, an account, a project): a `PageShell` with a back link, an edit action and a summary in the `aside`, and the related records as a `RecordList` inside a flush `Card`. The aside drops below the content on a narrow shell and the list stacks to two-line rows, so the page fits 390px without a breakpoint of your own. Copy it whole and change the data and the copy.

```ts
// src/lib/messages.ts (the keys the record page reads)
export const m = {
  company: {
    back: "Back to companies",
    description: (since: string) => `Customer since ${since}.`,
    edit: "Edit",
    aside: "Company summary",
    summary: { title: "Summary", owner: "Owner", plan: "Plan" },
    contacts: {
      title: "Contacts",
      list: "Contacts",
      labels: ["Contact", "Role", "Last seen"],
      role: "Role",
      seen: "Last seen",
      open: "Open",
      remove: "Remove",
      actions: (name: string) => `Actions for ${name}`,
    },
  },
} as const;
```

```svelte
<!-- src/routes/(app)/companies/[id]/+page.svelte -->
<script lang="ts">
  import {
    Avatar, Button, Card, DropdownMenu, DropdownMenuItem, IconButton, PageShell, RecordCell, RecordList, RecordRow,
  } from "@codeatlasdev/ui";
  import { m } from "#lib/messages.ts";
  import { MoreHorizontal, Pencil } from "@lucide/svelte";

  type Contact = { id: number; name: string; role: string; seen: string };
  let { data }: { data: { company: { name: string; owner: string; plan: string; since: string }; contacts: Contact[] } } = $props();
</script>

<PageShell title={data.company.name} description={m.company.description(data.company.since)} backHref="/companies" backLabel={m.company.back} asideLabel={m.company.aside}>
  {#snippet actions()}
    <Button variant="outlined" size="sm" href="./edit">
      {#snippet leading()}<Pencil size={14} />{/snippet}
      {m.company.edit}
    </Button>
  {/snippet}

  {#snippet aside()}
    <Card full title={m.company.summary.title} headingLevel={2}>
      <dl class="facts">
        <dt>{m.company.summary.owner}</dt><dd>{data.company.owner}</dd>
        <dt>{m.company.summary.plan}</dt><dd>{data.company.plan}</dd>
      </dl>
    </Card>
  {/snippet}

  <Card full flush title={m.company.contacts.title} headingLevel={2}>
    <RecordList columns="minmax(0,1.4fr) minmax(0,1fr) 6rem" actions labels={[...m.company.contacts.labels]} aria-label={m.company.contacts.list}>
      {#each data.contacts as c (c.id)}
        <RecordRow>
          {#snippet identity()}
            <span class="who"><Avatar alt={c.name} size="sm" decorative /> <strong>{c.name}</strong></span>
          {/snippet}
          <RecordCell label={m.company.contacts.role}>{c.role}</RecordCell>
          <RecordCell label={m.company.contacts.seen}>{c.seen}</RecordCell>
          {#snippet actions()}
            <DropdownMenu align="end">
              {#snippet triggerChild(props)}
                <IconButton aria-label={m.company.contacts.actions(c.name)} {...props}><MoreHorizontal size={18} /></IconButton>
              {/snippet}
              <DropdownMenuItem>{m.company.contacts.open}</DropdownMenuItem>
              <DropdownMenuItem>{m.company.contacts.remove}</DropdownMenuItem>
            </DropdownMenu>
          {/snippet}
        </RecordRow>
      {/each}
    </RecordList>
  </Card>
</PageShell>

<style>
  .who { display: flex; align-items: center; gap: var(--ca-space-2); min-width: 0; }
  .facts { display: grid; grid-template-columns: auto 1fr; gap: var(--ca-space-2) var(--ca-space-4); margin: 0; font-size: var(--ca-font-size-body2); }
  .facts dt { color: var(--ca-text-secondary); }
  .facts dd { margin: 0; color: var(--ca-text-primary); }
</style>
```
