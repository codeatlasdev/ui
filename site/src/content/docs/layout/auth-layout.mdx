```svelte
<script>
  import { AuthLayout, AuthCard, TextField, Button, Stack } from "@codeatlasdev/ui";
</script>

<AuthLayout logoName="Acme">
  {#snippet panel()}
    <blockquote>Ship the boring parts in a day.</blockquote>
  {/snippet}

  <AuthCard title="Welcome back" subtitle="Sign in to continue">
    <form>
      <Stack gap="3">
        <TextField label="Email" type="email" />
        <Button type="submit" fullWidth>Sign in</Button>
      </Stack>
    </form>
    {#snippet footer()}
      <a href="/sign-up">Create an account</a>
    {/snippet}
  </AuthCard>
</AuthLayout>
```

`AuthLayout` renders the page `<main id="main">`, so a route that uses it must not add another one. The `panel` snippet fills the side column; below 900px (`panelHidden="lg"`: 1024px) it is hidden and `mobileBrand` shows a compact brand strip above the form. The full pages live in the [sign in, sign up and forgot password templates](/templates/).

## Form first, with a full-bleed map or image

Put the panel on the right, fill it edge to edge, add a bar above the form and left-align the form. The panel is hidden below 1024px, and its snippet is not mounted there, so a map, video or image inside it is never fetched on mobile. The `header` snippet sticks to the top of the form column with the safe-area inset and replaces the mobile brand strip. See the [waitlist with map template](/templates/auth/sign-in-map/).

```svelte
<AuthLayout panelSide="right" panelBleed panelHidden="lg" align="start">
  {#snippet header()}
    <a href="/"><img src="/wordmark.svg" alt="Acme" height="24" /></a>
    <Button variant="outlined" size="sm" href="/sign-up">Create account</Button>
  {/snippet}
  {#snippet panel()}<LiveMap />{/snippet}

  <AuthCard variant="plain" title="Sign in">…</AuthCard>
</AuthLayout>
```

With `panelBleed` the panel has no padding, no logo and no blobs, sticks to the viewport height, and the divider between the columns is the low-contrast `--ca-outline-subtle` hairline.
