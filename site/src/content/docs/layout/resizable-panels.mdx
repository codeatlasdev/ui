The replacement for `react-resizable-panels` / shadcn `Resizable`. Sizes are percentages of the group and always add up to 100; the group fills its container, so give the parent a height. Each `ResizableHandle` moves the boundary between its two neighbours only, and never past either panel's `minSize` / `maxSize`.

## Keyboard

A handle is a WAI-ARIA window splitter: `role="separator"`, focusable, with `aria-valuenow` the size of the panel before it, and `aria-valuemin` / `aria-valuemax` the reachable range. Arrows move 1% (Left and Right in a horizontal group, Up and Down in a vertical one, mirrored in RTL), Shift plus an arrow 10%, Home and End go to the limits. Name each handle after what it resizes.

## Saving the layout

`persist="key"` saves `{ panelId: percent }` in `localStorage` when a drag or key press settles and restores it on mount. A stored layout that does not name exactly the panels on screen is ignored, so adding a panel never breaks a returning user. Panel ids are therefore part of the key: keep them stable. `onlayout` receives the same sizes without storage, for your own persistence.
