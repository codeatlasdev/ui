## In a list or a grid of cards

`size="row"` draws the empty state as one line: a 16 px icon, the text and an optional action, about one control high. Use it for an empty slot inside a list, a card or a grid, where the stacked block would push the content that does exist out of view. A row's title is text, not a heading (five empty rows would add five headings to the page outline), and it stays a `role="status"` named by its title. `variant`, `display`, `actionsFill` and `headingLevel` only apply to the stacked layout.

```svelte
<Card title="Support queue">
  <EmptyState size="row" bare icon={Inbox} title="No one in this queue" description="New tickets land here.">
    {#snippet actions()}<Button size="sm" variant="ghost">Add ticket</Button>{/snippet}
  </EmptyState>
</Card>
```

**Repeated empties are grouped; an empty never takes a whole card in a grid of siblings.** When several collections sit side by side (queues, lists, segments) and most are empty, render a card only for the ones with items and gather the empty ones into a single row that names them. Five cards saying "nobody here" fill the screen and push the one queue with people below the fold.

```svelte
<script>
  import { Card, EmptyState } from "@codeatlasdev/ui";
  import { CircleCheck } from "@lucide/svelte";
  let { queues } = $props();
  const full = $derived(queues.filter((q) => q.items.length > 0));
  const empty = $derived(queues.filter((q) => q.items.length === 0));
  const names = $derived(new Intl.ListFormat("en", { type: "conjunction" }).format(empty.map((q) => q.name)));
</script>

{#each full as q (q.id)}
  <Card title={q.name}><QueueList items={q.items} /></Card>
{/each}
{#if empty.length > 0}
  <EmptyState size="row" icon={CircleCheck} title="Nothing pending in {names}" />
{/if}
```

## Tokens

`--ca-empty-padding` (default `--ca-space-12 --ca-space-6`; `bare` wins), `--ca-empty-title-size` and `--ca-empty-title-weight`. A row reads only `--ca-empty-row-padding` (default `--ca-space-2 --ca-space-3`; `bare` wins): the stacked tokens size a heading and a tile it does not have.
