```svelte
<script>
  import { MasterDetail, EmptyState } from "@codeatlasdev/ui";
  let id = $state(null);
</script>

<MasterDetail bind:selected={id} detailTitle={name}>
  {#snippet master()}<ConversationList />{/snippet}
  {#snippet detail()}<Thread />{/snippet}
  {#snippet empty()}<EmptyState title="Select a conversation" />{/snippet}
</MasterDetail>
```

Wide: the master next to the detail, with `empty` until a row is selected. Narrow: the master fills the container and the detail becomes a full-screen modal layer while `selected` is set. Escape and the back button close it, focus returns to the row, and with the [overlay-history bridge](/docs/getting-started/mobile/#back-button-on-mobile) the browser's Back closes it too.

The detail is one DOM node and the split is a container query, so the first paint is right (no squeezed desktop layout flashing before hydration) and a draft in the composer survives crossing the breakpoint. The breakpoint is measured on the component's own width, so it works inside a shell with a panel.
