```svelte
<script>
  import { AppForm, FormSection, TextField, Button } from "@codeatlasdev/ui";
</script>

<AppForm title="New user" backHref="/users">
  <FormSection title="Account">
    <TextField label="Name" bind:value={name} />
  </FormSection>
  {#snippet footer()}
    <Button variant="ghost" href="/users">Cancel</Button>
    <Button variant="filled" onclick={save}>Save</Button>
  {/snippet}
</AppForm>
```

`FormSection` titles inside an AppForm are `<h2>` under the page `<h1>` (pass `headingLevel` on the section to override).

AppForm fills its parent, so give the parent a height. It replaces the removed FormPage. For a floating action bar inside your own scroll container, use [StickyActions](/docs/layout/sticky-actions/).

## Using the width: the aside slot

A form capped at a reading measure leaves the right half of a desktop empty. Never stretch the fields to fill it: pass an `aside` snippet with context (a preview of what is being edited, help, status, a checklist). From a 1280px page the aside sits beside the form, 20rem wide (`asideWidth`) and sticky at the top; below that it follows the form, so a 390px phone has one column and no sideways scroll. It renders as `<aside>` named "Page sidebar" (`asideLabel` renames it). The same `aside`, `asideLabel` and `asideWidth` props exist on `AppSettings` (inside the tab content) and on `PageFrame mode="page"`.

There are no ready-made aside cards: compose them from `Card`, `Stat` and `Stepper`, as in the demo. The docs column is narrower than 1280px, so the demo shows the aside below the form; open it at full width to see two columns.
