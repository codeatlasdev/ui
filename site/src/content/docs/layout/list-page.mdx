## Inside a PageShell

`AppList`, `AppForm` and `AppSettings` are full pages: each draws its own header and applies `--ca-page-px`. Put one inside a `PageShell` and the gutter and the header would double, so pass `embedded`: the header is not rendered (the shell's title stays the page `<h1>`) and the page padding is zero, which aligns the content to the shell's left edge. Standalone use is unchanged.

```svelte
<PageShell title="Settings">
  <AppSettings embedded {tabs}>…</AppSettings>
</PageShell>
```
