```svelte
<script>
  import { KpiCard } from "@codeatlasdev/ui";
  import { DollarSign } from "@lucide/svelte";
</script>

<KpiCard title="Monthly Revenue" value="$48,200" trend={12.4} icon={DollarSign} />
```

A `KpiCard` is a [Stat](/docs/layout/stat/) inside a Card. For a plain number inside a card you already have, with a `hint` line and no second box, use `Stat`.

Put several cards in a [KpiGrid](/docs/layout/kpi-grid/) so a row never ends on an empty cell.

`trend` is a relative percent change (`12.4` renders `+12.4%`), computed by you: a metric that went from 80 to 90 passes `12.5`, not `10`. By default a rise is green and a fall red. `trendTone="positive-down"` flips the colour for metrics where down is good (churn, cost, latency); the arrow still follows the sign and the accessible label says "better" or "worse". `trendTone="neutral"` judges neither way. Do not omit `trend` to avoid a wrong colour.

`chart` is a snippet, usually `<Sparkline data={...} />` from `@codeatlasdev/ui/charts` (it needs the `echarts` peer). It is not a data prop because the charts subpath stays out of the core entry. The sparkline colour comes from its own `trend` (`"up"` is green), independent of `trendTone`: for a falling churn give the `Sparkline` `trend="up"`. Do not compose `Card` + `Stat` + `Sparkline` for this tile.
